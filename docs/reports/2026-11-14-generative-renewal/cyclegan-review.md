- All 24 permutations exactly match the target marginal. Each has an inverse and therefore both zero cycles. Because the supports are disjoint in one scalar space, target-domain identity extensions also have zero loss for all 24 choices. These explicit lookup functions do not claim arbitrary neural feasibility under smoothness/architecture constraints.
- The increasing assignment has mean absolute reference error 13; the specified reference has error zero. The two new diagrams show these exact values and the remaining correspondence counts after anchors: 24, 6, 2, 1, 1.
- All 16 assignments into a two-code alphabet and all 16 source-valued reconstruction pairs are enumerated. The optimum is 5/4; one code gives 11/4. A scalar absolute-error median can be chosen at an observed group value, so the finite enumeration attains the optimum over arbitrary real reconstructions too. The restricted alphabet cannot simultaneously match the original four-point target marginal; the note states this explicitly.
- The equal-probability inputs ±1/100 mapped to one code have cycle error 1/100 despite noninjectivity. Exact zero loss implies an almost-sure identity, while small nonzero loss does not imply invertibility.
- Scores −1/4 and 7/4 separate squaring their mean error (1/16) from averaging their squared errors (17/16). The difference is their population variance, 1.
- Kernel sizes 4, strides 2/2/2/1/1 and padding 1 give sizes 128/64/32/31/30 and a convolution-only footprint of 70 from input size 256. Spatial instance normalization makes the full normalized network depend on more than this nominal footprint.
