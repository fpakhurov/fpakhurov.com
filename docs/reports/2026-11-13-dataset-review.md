## Direct pixel reproduction and verification

- `src/components/figures/self-supervised-learning/SimClrPipeline.astro`: arrays `zero` and `three` reproduce samples 0 and 3. One view shifts a sample right by one pixel and scales intensity by 0.75; the other shifts it down by one pixel. The numerical embedding vectors are separately supplied illustrative values.
- `src/components/figures/vision-transformers/PatchTokens.astro`: `img` reproduces sample 3 and splits it into four 4 x 4 patches, flattening them for the illustrated projection.
- All three arrays were compared element-for-element against `sklearn/datasets/data/digits.csv.gz` in the official scikit-learn repository. Inspected data blob: `e191a13019b607d4477d1031503ab46218e21040`, 1,797 rows. All 64 pixel entries in each array matched the named row exactly.
- Credits are placed directly after `<SimClrPipeline />` and `<PatchTokens />` in both English and Russian notes. The source arrays also carry creator/DOI/license comments.
- `autoencoders/DenoisingPipeline.astro` constructs a 16 x 16 toy seven from three stroke coordinates, distances and synthetic noise; it is not a reproduced MNIST sample. `singular-value-decomposition/svd.ts` constructs its test image from a formula; its embedded PNG is not a downloaded third-party image.

## BIASED notebooks and validation limits

All 51 current `content/notebooks/*.ipynb` files were parsed as JSON. Searches of code cells found no calls to the named sklearn dataset loaders, torchvision/keras benchmark dataset constructors, Hugging Face `load_dataset`, dataset-file network downloads, or external CSV/parquet readers. Saved outputs contain no `image/*` payloads. The examples use small supplied/synthetic values, and the new retrieval lab embeds its independently authored fictional corpus. A markdown sentence saying that a toy network is not ImageNet is not a dataset dependency.

No dependency installation, training run, build, commit, or production mutation was performed. The edits only add source/permission credits and this report. Fenced experiment code, figure arrays and model calculations are checked against Git before/after; the dataset credit additions do not establish that every previously reported metric was independently reproduced. MNIST/CIFAR/diabetes licensing uncertainties remain explicitly unresolved rather than silently assigned a package license.
