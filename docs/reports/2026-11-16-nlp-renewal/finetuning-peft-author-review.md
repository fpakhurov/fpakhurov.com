## Teaching and technical review

All four final bodies were read in full, including the paired formulas, examples, caveats, tables, references and code. Fine-tuning derives the binary gradient and distinguishes simultaneous full updates, frozen-feature probing, and a head-first two-update trajectory. The unequal update budgets are explicit. The checkpoint curve uses two declared expected-loss distributions, not a sampled heldout experiment. Answer-only loss, unequal-length averaging, padding counts and packed-example boundaries are separate concepts.

PEFT derives the two factor gradients with shapes, explains zero/nonzero initialization and both-zero stalling, checks a new 2-by-3 step, and bounds deterministic merging. The nonlinear counterexample prevents conflating residual bottlenecks with linear updates. The determinant example bounds rank-one expressiveness and rank growth under addition. Memory counts assume four FP32 arrays for trainable entries and one for the frozen base, excluding activations/buffers/runtime. Prompt and prefix counts declare the implementation layout. QLoRA distinguishes storage from computation without a downloaded asset or an implementation-performance claim.

Five new figure components use the exact saved JSON cases: update coordinates, train/validation trajectory, low-rank matrices, rank addition, and explicit state arrays. Theme classes, local labels, SVG titles/descriptions, flexible matrix panels and numeric formatting were reviewed in source. This is source/actual-fragment rendering evidence, not a browser visual pass at specific viewport sizes.
