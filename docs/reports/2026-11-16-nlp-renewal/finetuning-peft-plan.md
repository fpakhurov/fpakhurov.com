Derive gradients for A and B; confirm finite differences, B-only first gradient, and a simultaneous learning-rate0.1 update. Compare branch evaluation and exact merged W0+(alpha/r)BA. Show that initializing both factors to zero blocks both factor gradients. No adapter implementation from a library is copied.
