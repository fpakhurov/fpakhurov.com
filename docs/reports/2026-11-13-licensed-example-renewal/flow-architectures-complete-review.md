# Flow architectures: complete scoped renewal

Reviewed 2026-11-13 by Codex `course_licenses`. Scope is the complete English/Russian note, its six teaching figures, `MathText.astro`, transitive figure/geometry/language helpers, the replacement practice and new verifier. This is a decision for these exact files and identified uses, not the remaining Generative Models course. Current changes, new checks and explanations were authored for Fedor Pakhurov's project with Codex assistance; historical local code is not represented as newly written in this run.

## Substantive corrections

- The optional practice no longer requires the unverified `nflib` implementation or a CelebA VAPNEV homework chain. It uses the original two-coordinate coupling/permutation/scaling check published in the preceding bounded batch. No model, image, dataset or source notebook is downloaded.
- The X-shaped conditional-density example is distinguished from MAF Figure 1's different banana target; the cited five-layer paper result is not claimed as a local training run.
- A radial layer has an analytic quadratic inverse, including the centre case. The selection table no longer incorrectly groups it with planar scalar-root inversion. The radial Jacobian is scalar identity plus rank one, not identity plus rank one.
- Applying an LU inverse to a vector costs quadratic work; forming the full inverse generally costs cubic work. A fixed pivot permutation represents a factorization chart. Learned Glow mixing is not a learned discrete permutation, and an orthogonal initializer need not be a rotation.
- Spline endpoint numerator terms are nonnegative rather than all strictly positive. Default eight-bin experimental settings are qualified. ActNorm formulas require positive channel variance or a numerical floor.
- The universality claim now states dimension at least two, sufficient scale/shift-network assumptions and weak convergence in distribution. It does not promise exact finite-network representation, density convergence or training success.
- The out-of-distribution likelihood example is restricted to the model/dataset scope established by Nalisnick et al.

## Executed checks

`node scripts/notes/check-flow-architectures-renewal.cjs` replays saved `flow-architectures-checks.json`; `--write` regenerates it. It executes all six figure frontmatters in each locale and checks the two masks/path counts, coupling sparsity, exact LU product/determinant, local Gaussian-conditional numbers, spline finite-difference derivatives and inverse, area quadrature, radial inverse/centre determinant, planar fold root, multiscale dimension accounting and squeeze permutation. New fixtures and verifier use no network or external data.

The existing optional practice was independently replayed in the previous batch; it checks a fixed flow's density/inverse, not neural optimization. Both final localized MDX bodies compile with strict KaTeX. Numerical comparison does not establish provenance by itself; it is paired with the scoped source/dependency comparison above. Browser layout, integrated build, independent coordinator review and publication are separate checks. No additional source-specific unresolved reused artifact was identified within this exact scope; this is not a universal historical-ownership guarantee.
