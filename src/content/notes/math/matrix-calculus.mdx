Fit a Gaussian to data by maximum likelihood, and the covariance matrix $\Sigma$ is found where the derivative of the log-likelihood

$$
\ell(\Sigma) = -\frac n2 \log\det\Sigma - \frac12 \operatorname{tr}\big(\Sigma^{-1}S\big)
$$

vanishes. Here $n$ is the number of points and $S$ the matrix of their scatter around the mean, defined below. What is the derivative of a log-determinant with respect to a matrix? And of an inverse?

The [previous note](/notes/math/gradients-jacobians-hessians) differentiated one coordinate at a time, and for small expressions that works. In the quadratic form $x^\top Ax = \sum_i \sum_j x_i A_{ij} x_j$, the derivative in $x_k$ collects the terms with $i = k$, which give $\sum_j A_{kj}x_j$, and those with $j = k$, which give $\sum_i x_i A_{ik}$. The term $A_{kk}x_k^2$ belongs to both groups, and its derivative $2A_{kk}x_k$ is shared between them:

$$
\frac{\partial}{\partial x_k}\, x^\top Ax = (Ax)_k + (A^\top x)_k .
$$

For $\log\det\Sigma$ the same route needs the cofactor expansion of the determinant, and $\Sigma^{-1}$ is defined only implicitly, by $\Sigma\Sigma^{-1} = I$. Even when the entries come out right, they must be put back into a matrix of some shape. The losses of machine learning are written this way throughout: $\lVert Xw - y\rVert^2$, the cross-entropy of $\operatorname{softmax}(Wx)$, the Gaussian above. We want to differentiate them as whole expressions, the way we differentiate $\log x$ or $1/x$ for a number.

## Layout: what shape a derivative has

Texts disagree on whether the derivative of a scalar with respect to a column vector is a column or a row. Every course on this site uses one convention:

- for a scalar $f$ of a vector $x$, the gradient $\partial f/\partial x = \nabla f(x)$ is a column with the shape of $x$;
- for a scalar $f$ of a matrix $X$, $\partial f/\partial X$ has the shape of $X$, with entries $\partial f/\partial X_{ij}$;
- for a vector function $f$ of $x$, the Jacobian $\partial f/\partial x$ is $m \times n$, outputs × inputs.

For gradients this is the **denominator layout**: the derivative is laid out like the variable in the denominator. For Jacobians it is the **numerator layout**, so the gradient of a scalar is the transpose of its $1 \times n$ Jacobian. The [least-squares note](/notes/ml/least-squares#the-normal-equations) writes its gradient $2X^\top(Xw - y)$ as a column, and the [adjoints of backpropagation](/notes/ml/backpropagation#the-chain-rule-in-matrix-form) have the shapes of their variables. *The Matrix Cookbook* uses the same convention for scalars ([Petersen and Pedersen, 2012](#references)).

The reason to prefer it: the update $W \leftarrow W - \eta\, \partial L/\partial W$ only makes sense when $\partial L/\partial W$ has the shape of $W$. A source in the pure numerator layout writes $\partial(a^\top x)/\partial x = a^\top$, a row. That one formula tells you which layout a source uses.

## The differential method

The **differential** $df$ of a scalar function is the linear part of its change: $f(X + dX) = f(X) + df + o(\lVert dX\rVert)$, where $dX$ is a small change of $X$, a matrix of the same shape. The linear part has one coefficient per entry of $dX$. The layout convention puts the coefficient of $dX_{ij}$ at position $(i, j)$, and the identity $\operatorname{tr}(A^\top B) = \sum_{ij} A_{ij} B_{ij}$ turns the sum of products into a trace. The identity holds because the $j$-th diagonal entry of $A^\top B$ is $\sum_i A_{ij} B_{ij}$:

$$
\begin{aligned}
df &= \sum_{i,j} \frac{\partial f}{\partial X_{ij}}\, dX_{ij} \\
&= \operatorname{tr}\Big(\Big(\frac{\partial f}{\partial X}\Big)^{\!\top} dX\Big) .
\end{aligned}
$$

Conversely, if $df = \operatorname{tr}(G^\top dX)$ for every $dX$, then the choice $dX = E_{ij}$, the matrix with a single 1 at $(i, j)$, gives $G_{ij} = \partial f/\partial X_{ij}$. So the gradient can be read off any expression of the right form:

$$
\boxed{\; df = \operatorname{tr}\big(G^\top dX\big) \ \text{for all } dX \iff \frac{\partial f}{\partial X} = G \;}
$$

For a vector variable the same statement reads $df = g^\top dx \iff \nabla f = g$. [Merkulov (2024)](#references) writes it with the inner product, $df = \langle \nabla f, dx\rangle$, and the trace is that inner product for matrices.

Differentials obey a few rules. Each comes from expanding $f(X + dX)$ and dropping products of two small changes.

| Rule | Why |
| --- | --- |
| $dA = 0$ for a constant $A$ | it does not change |
| $d(\alpha X + \beta Y) = \alpha\, dX + \beta\, dY$ | linearity |
| $d(XY) = (dX)\,Y + X\,(dY)$ | the term $(dX)(dY)$ is second order |
| $d(X^\top) = (dX)^\top$, $\ d\operatorname{tr}X = \operatorname{tr}dX$ | both maps are linear |
| $d\,\varphi(x) = \varphi'(x) \odot dx$ for an elementwise $\varphi$ | one variable per entry |

Here $\odot$ is the elementwise product. The rearranging is done by three facts about the trace: a scalar is its own trace, $\operatorname{tr}(A^\top) = \operatorname{tr}A$, and $\operatorname{tr}(AB) = \operatorname{tr}(BA)$, since both equal $\sum_{i,j} A_{ij}B_{ji}$. Applied to the pair $AB$ and $C$, the last fact gives $\operatorname{tr}(ABC) = \operatorname{tr}(CAB)$, the **cyclic property**. A derivation then has three steps:

1. compute $df$ with the rules;
2. move $dX$ to the right end of a trace with the cyclic property, $df = \operatorname{tr}(M\, dX)$;
3. read off $\partial f/\partial X = M^\top$.

## Linear and quadratic forms

A linear form changes by the form applied to the change, $d(a^\top x) = a^\top dx$, so its gradient is $a$. The quadratic form has $x$ in two places, and the product rule gives one term for each:

$$
\begin{aligned}
d(x^\top Ax) &= (dx)^\top Ax + x^\top A\, dx && \text{product rule} \\
&= x^\top A^\top dx + x^\top A\, dx && \text{transpose a scalar} \\
&= \big((A + A^\top)x\big)^\top dx .
\end{aligned}
$$

The gradient is $(A + A^\top)x$, the result of the index computation above. For a symmetric $A$ it is $2Ax$, and only then.

Take $A$ with rows $(1, 2)$ and $(0, 3)$ and $x = (1, 2)$. Then $x^\top Ax = x_1^2 + 2x_1x_2 + 3x_2^2 = 17$, and $A + A^\top$ has rows $(2, 2)$ and $(2, 6)$, so the gradient is $(6, 14)$. The partial derivatives $2x_1 + 2x_2 = 6$ and $2x_1 + 6x_2 = 14$ agree. The shortcut $2Ax = (10, 12)$ is wrong, because this $A$ is not symmetric.

## Least squares

Why is the gradient of $\lVert Ax - b\rVert^2$ equal to $2A^\top(Ax - b)$? Go through the residual $r = Ax - b$, which changes by $dr = A\, dx$:

$$
\begin{aligned}
d(r^\top r) &= 2\,r^\top dr && \text{product rule, transpose} \\
&= 2\,r^\top A\, dx \\
&= \big(2A^\top r\big)^\top dx , \\
d\big(2A^\top r\big) &= 2A^\top A\, dx .
\end{aligned}
$$

The third line gives the gradient $2A^\top(Ax - b)$. The Hessian is the Jacobian of the gradient, so the last line gives $\nabla^2 = 2A^\top A$.

With the same $A$, $b = (1, 1)$ and $x = (1, 2)$: $Ax = (5, 6)$, $r = (4, 5)$, $\lVert r\rVert^2 = 41$, and the gradient is $2A^\top r = (8, 46)$. With $A = X$, the design matrix, and $b = y$, these are the gradient $2X^\top(Xw - y)$ and the Hessian $2X^\top X$ of the [least-squares note](/notes/ml/least-squares#the-normal-equations), and setting the gradient to zero gives its normal equations. In that note's four-point example, $X$ has columns $(1, 1, 1, 1)$ and $(0, 1, 2, 3)$ and $y = (1, 3, 2, 5)$. The gradient is $(-22, -44)$ at $w = 0$ and zero at $\hat w = (1.1, 1.1)$.

## Traces of matrix products

When the variable is a matrix, the trace is already there. For $\operatorname{tr}(AX)$ the differential is $\operatorname{tr}(A\, dX)$, so $M = A$ and the gradient is $A^\top$. For $\operatorname{tr}(X^\top AX)$ the product rule gives two terms. Transposing the first inside its trace puts $dX$ at the right end of both:

$$
\begin{aligned}
d\operatorname{tr}(X^\top A X) &= \operatorname{tr}\big((dX)^\top A X\big) + \operatorname{tr}\big(X^\top A\, dX\big) \\
&= \operatorname{tr}\big(X^\top A^\top dX\big) + \operatorname{tr}\big(X^\top A\, dX\big) \\
&= \operatorname{tr}\big(X^\top (A + A^\top)\, dX\big) .
\end{aligned}
$$

So $M = X^\top(A + A^\top)$ and the gradient is $(A + A^\top)X$. The squared Frobenius norm $\lVert X\rVert_F^2 = \operatorname{tr}(X^\top X)$ is the case $A = I$, with gradient $2X$: the derivative of the weight-decay penalty $\lambda\lVert W\rVert_F^2$ of [regularization](/notes/ml/regularization).

The transpose in $\partial\operatorname{tr}(AX)/\partial X = A^\top$ is easy to lose. For $A$ with rows $(1, 2)$ and $(3, 4)$, $\operatorname{tr}(AX) = \sum_{ij} A_{ji} X_{ij}$, so the coefficient of $X_{12}$ is $A_{21} = 3$, the entry $(1, 2)$ of $A^\top$. A guess of $A$ would give 2.

## The log-determinant

The columns of $X$ span a parallelogram, or in $n$ dimensions a parallelepiped, of volume $\lvert\det X\rvert$. How much does the volume change when the columns move a little? We need one fact first. For a small matrix $E$,

$$
\det(I + E) = 1 + \operatorname{tr}E + O\big(\lVert E\rVert^2\big) .
$$

By the Leibniz formula $\det M = \sum_\sigma \operatorname{sgn}\sigma \prod_i M_{i\sigma(i)}$, the identity permutation contributes $\prod_i (1 + E_{ii}) = 1 + \sum_i E_{ii}$ plus products of two or more entries of $E$. Every other permutation moves at least two indices, so its product contains at least two off-diagonal entries of $E$ and is second order. For invertible $X$ we factor $X + dX = X(I + X^{-1}dX)$, use the [product rule](/notes/math/determinants-and-eigenvalues#properties-used-everywhere) $\det(AB) = \det A \det B$, and apply the fact with $E = X^{-1}dX$. Since $\lVert X^{-1}dX\rVert \le \lVert X^{-1}\rVert\, \lVert dX\rVert$, a term of second order in $E$ is of second order in $dX$:

$$
\begin{aligned}
\det(X + dX) &= \det X \,\det\big(I + X^{-1}dX\big) \\
&= \det X \,\big(1 + \operatorname{tr}(X^{-1}dX)\big) + O\big(\lVert dX\rVert^2\big) .
\end{aligned}
$$

The linear part is the differential, and dividing by $\det X$ gives the logarithm, since $d\log\lvert t\rvert = dt/t$:

$$
\begin{aligned}
d\det X &= \det X \cdot \operatorname{tr}\big(X^{-1}dX\big) , \\
d\log\lvert\det X\rvert &= \operatorname{tr}\big(X^{-1}dX\big) .
\end{aligned}
$$

Reading off, $\partial \log\lvert\det X\rvert/\partial X = X^{-\top}$, where $X^{-\top} = (X^{-1})^\top$, and $\partial\det X/\partial X = \det X \cdot X^{-\top}$. For a symmetric $X$ the first is $X^{-1}$. The second is the matrix of cofactors. Every Leibniz product contains the entry $X_{ij}$ at most once, so $\det X$ is affine in $X_{ij}$, and its coefficient there, $\partial\det X/\partial X_{ij}$, is by definition the cofactor $C_{ij}$. So $C = \det X \cdot X^{-\top}$, which is the cofactor formula $X^{-1} = C^\top/\det X$. [Strang (2018)](#references) reaches the gradient from that side, through the cofactor expansion along a row.

A worked example with $X$ of rows $(2, 1)$ and $(0.5, 1.5)$, and a change $dX$ of rows $(0.1, 0.05)$ and $(-0.05, 0.1)$:

| Quantity | Value |
| --- | --- |
| $\det X$ | $2.5$ |
| $X^{-1}$, by rows | $(0.6, -0.4)$, $(-0.2, 0.8)$ |
| $\partial\det X/\partial X = 2.5\,X^{-\top}$, by rows | $(1.5, -0.5)$, $(-1, 2)$ |
| $\operatorname{tr}(X^{-1}dX)$ | $0.15$ |
| first-order prediction $2.5 \cdot 1.15$ | $2.875$ |
| exact $\det(X + dX)$ | $2.8875$ |

The area grows by 15% to first order. The remaining $0.0125$ is $\det(dX)$: for $2 \times 2$ matrices, $\det(X + E) = \det X\,\big(1 + \operatorname{tr}(X^{-1}E)\big) + \det E$ exactly. Raising only $X_{11}$ by $0.1$ raises the determinant by exactly $1.5 \cdot 0.1 = 0.15$, because the determinant is affine in each single entry, with the cofactor $C_{11} = X_{22} = 1.5$ as slope.

Write $X$ with rows $(a, b)$ and $(c, d)$, and expand the $2 \times 2$ formula for $X + E$:

\begin{aligned}
\det(X + E) &= (a + e_{11})(d + e_{22}) - (b + e_{12})(c + e_{21}) \\
&= \det X + \big(d\,e_{11} - c\,e_{12} - b\,e_{21} + a\,e_{22}\big) + \det E .
\end{aligned}
$$

The middle bracket is $\operatorname{tr}(C^\top E)$ with the cofactors $C_{11} = d$, $C_{12} = -c$, $C_{21} = -b$, $C_{22} = a$. By the cofactor formula $C^\top = \det X \cdot X^{-1}$, so the bracket is $\det X \operatorname{tr}(X^{-1}E)$. In the example, $\det dX = 0.01 + 0.0025 = 0.0125$.

The log-determinant appears wherever a density is normalized or transformed: $-\tfrac12\log\det\Sigma$ in the log-likelihood of the [multivariate Gaussian](/notes/probability/multivariate-gaussian#the-density), $\log\lvert\det J\rvert$ in [normalizing flows](/notes/generative-models/normalizing-flows#change-of-variables), and the evidence of [Bayesian linear regression](/notes/bayesian-methods/bayesian-linear-regression#tools-matrix-derivatives-and-gaussian-identities) and of [Gaussian processes](/notes/bayesian-methods/gaussian-processes#the-gradient), whose gradients use this identity and the next one.

## The inverse

The inverse is defined by $XX^{-1} = I$. Differentiate both sides; the right side does not change:

$$
\begin{aligned}
0 &= d\big(XX^{-1}\big) \\
&= (dX)\,X^{-1} + X\, d\big(X^{-1}\big) .
\end{aligned}
$$

Multiplying by $X^{-1}$ on the left gives

$$
d\big(X^{-1}\big) = -X^{-1}(dX)\,X^{-1} .
$$

For $1 \times 1$ matrices this is the familiar $d(1/x) = -dx/x^2$. Differentiating $XX^{-1}$ assumed that $X^{-1}$ has a differential at all; the fold checks the result directly.

<details>
<summary>Derivation: the inverse has this differential</summary>

Let $E$ be a small change and $Y = X^{-1} - X^{-1}EX^{-1}$ the candidate. Multiply out:

$$
\begin{aligned}
(X + E)\,Y &= I + EX^{-1} - EX^{-1} - EX^{-1}EX^{-1} \\
&= I - \big(EX^{-1}\big)^2 .
\end{aligned}
$$

Multiplying on the left by $(X + E)^{-1}$, which exists for small $E$ because $\det(X + E)$ is close to $\det X \ne 0$:

$$
(X + E)^{-1} - Y = (X + E)^{-1}\big(EX^{-1}\big)^2 .
$$

By the cofactor formula the entries of $(X + E)^{-1}$ are polynomials in the entries divided by $\det(X + E)$, so they stay bounded near $X$. The right side is therefore $O(\lVert E\rVert^2)$, and $-X^{-1}EX^{-1}$ is the linear part of the change.

</details>

A scalar built from the inverse, such as $a^\top X^{-1}b$ for fixed vectors $a$ and $b$, then follows in two steps:

$$
\begin{aligned}
d\big(a^\top X^{-1}b\big) &= -a^\top X^{-1}(dX)\,X^{-1}b \\
&= -\operatorname{tr}\big(X^{-1}b\,a^\top X^{-1}\, dX\big) && \text{cyclic property}
\end{aligned}
$$

So $M = -X^{-1}ba^\top X^{-1}$, and the gradient is $M^\top = -X^{-\top}ab^\top X^{-\top}$.

With $X$ as above, $a = (1, 2)$ and $b = (1, 1)$: $X^{-1}b = (0.2, 0.6)$ and $a^\top X^{-1}b = 1.4$. The gradient is minus the outer product of $X^{-\top}a = (0.2, 1.2)$ and $X^{-1}b$:

$$
\frac{\partial\, a^\top X^{-1}b}{\partial X} = -\begin{pmatrix} 0.2 \\ 1.2\end{pmatrix}\begin{pmatrix} 0.2 & 0.6\end{pmatrix} = \begin{pmatrix} -0.04 & -0.12 \\ -0.24 & -0.72\end{pmatrix} .
$$

Raising $X_{22}$ by $0.01$ should lower the value by about $0.0072$.

## Back to the Gaussian covariance

Now the opening problem takes a few lines. For points $x_1, \dots, x_n$ with a known mean $\mu$, let $S = \sum_i (x_i - \mu)(x_i - \mu)^\top$. Each quadratic term of the Gaussian log-density is a scalar, hence its own trace, and the cyclic property turns it into $\operatorname{tr}\big(\Sigma^{-1}(x_i - \mu)(x_i - \mu)^\top\big)$. Linearity of the trace collects the sum into one trace. Up to the term with $\log 2\pi$ of the [density](/notes/probability/multivariate-gaussian#the-density), which does not depend on $\Sigma$,

$$
\begin{aligned}
\ell(\Sigma) &= -\frac n2 \log\det\Sigma - \frac12 \sum_{i=1}^n (x_i - \mu)^\top \Sigma^{-1}(x_i - \mu) \\
&= -\frac n2 \log\det\Sigma - \frac12 \operatorname{tr}\big(\Sigma^{-1}S\big) .
\end{aligned}
$$

A covariance matrix is positive definite, so $\det\Sigma \gt 0$ and $\log\det\Sigma = \log\lvert\det\Sigma\rvert$. The log-determinant rule handles the first term. For the second, $d\operatorname{tr}(\Sigma^{-1}S) = \operatorname{tr}\big(d(\Sigma^{-1})\,S\big)$, the inverse rule gives the second line, and the cyclic property moves $d\Sigma$ to the right end:

$$
\begin{aligned}
d\ell &= -\frac n2 \operatorname{tr}\big(\Sigma^{-1}d\Sigma\big) \\
&\quad + \frac12 \operatorname{tr}\big(\Sigma^{-1}(d\Sigma)\,\Sigma^{-1}S\big) \\
&= \frac12 \operatorname{tr}\Big(\big(\Sigma^{-1}S\Sigma^{-1} - n\Sigma^{-1}\big)\, d\Sigma\Big) .
\end{aligned}
$$

Only symmetric changes $d\Sigma$ keep $\Sigma$ a covariance matrix. The matrix $M = \Sigma^{-1}S\Sigma^{-1} - n\Sigma^{-1}$ in the bracket is symmetric too, and the choice $d\Sigma = M$ gives $\operatorname{tr}(M^2) = \lVert M\rVert_F^2$. So the differential vanishes for every symmetric $d\Sigma$ exactly when $M = 0$. Multiplying $\Sigma^{-1}S\Sigma^{-1} = n\Sigma^{-1}$ by $\Sigma$ on both sides gives $S = n\Sigma$, that is,

$$
\hat\Sigma = \frac1n S = \frac1n \sum_{i=1}^n (x_i - \mu)(x_i - \mu)^\top .
$$

The estimate is a valid covariance when $S$ is positive definite, that is, when the centred points $x_i - \mu$ span the whole space: $u^\top S u = \sum_i \big((x_i - \mu)^\top u\big)^2$ vanishes only for a $u$ orthogonal to all of them. Written in the precision $\Lambda = \Sigma^{-1}$, the log-likelihood is $\tfrac n2 \log\det\Lambda - \tfrac12\operatorname{tr}(\Lambda S)$, and the log-determinant rule alone gives $\Lambda^{-1} = S/n$, the form in which [Merkulov (2024)](#references) poses the exercise.

For the three points $(1, 0)$, $(-1, 1)$ and $(0, -1)$, whose mean is $0$, $S$ has rows $(2, -1)$ and $(-1, 2)$, and $\hat\Sigma = S/3$. The factor $1/n$ instead of $1/(n - 1)$ is the bias of maximum likelihood discussed in the [estimators note](/notes/probability/estimators#the-sample-variance-and-n-1). The same estimate, weighted by responsibilities, is the M-step of the [EM algorithm](/notes/ml/em-algorithm) for each component.

## The softmax cross-entropy

For scores $z \in \mathbb R^K$ the probabilities are $p = \operatorname{softmax}(z)$, with $p_k = e^{z_k}/\sum_j e^{z_j}$, and the loss for a one-hot label $y$ is $L = -\sum_k y_k \log p_k$. Two facts make the differential short. First, $\log p_k = z_k - \operatorname{lse}(z)$, where $\operatorname{lse}(z) = \log\sum_j e^{z_j}$ is the log-sum-exp, and $\sum_k y_k = 1$, so $L = -y^\top z + \operatorname{lse}(z)$. Second, $\partial\operatorname{lse}/\partial z_k = e^{z_k}/\sum_j e^{z_j} = p_k$, by the chain rule through the logarithm. For a linear layer $z = Wx + b$, so that $dz = (dW)\,x + db$:

$$
\begin{aligned}
dL &= -y^\top dz + p^\top dz \\
&= (p - y)^\top dz \\
&= (p - y)^\top (dW)\,x + (p - y)^\top db \\
&= \operatorname{tr}\big(x\,(p - y)^\top dW\big) + (p - y)^\top db .
\end{aligned}
$$

So $\nabla_z L = p - y$, $\partial L/\partial W = (p - y)\,x^\top$ and $\partial L/\partial b = p - y$.

Take $z = (2, 1, 0.1)$ with the true class first, $y = (1, 0, 0)$, and the input $x = (1, -2)$:

| Quantity | Value |
| --- | --- |
| $p = \operatorname{softmax}(z)$ | $(0.659, 0.242, 0.099)$ |
| $L = -\log p_1$ | $0.417$ |
| $\nabla_z L = p - y$ | $(-0.341, 0.242, 0.099)$ |
| $\partial L/\partial W = (p - y)x^\top$, by rows | $(-0.341, 0.682)$, $(0.242, -0.485)$, $(0.099, -0.197)$ |

The entries of $p - y$ sum to 0, because $\mathbf 1^\top p = \mathbf 1^\top y = 1$, where $\mathbf 1$ is the vector of ones: adding the same constant to every score changes nothing. With the sign reversed, the same result is the score of a softmax policy, $\nabla_z \log p_a = y - p$ for the action $a$ taken, the factor that [policy gradients](/notes/agents/policy-gradients#the-policy-gradient-theorem) multiply by the return.

The route through the softmax Jacobian gives the same result with more work. From $\log p_k = z_k - \operatorname{lse}(z)$, $dp_k = p_k\, d\log p_k = p_k\big(dz_k - p^\top dz\big)$, so $dp = \big(\operatorname{diag}(p) - pp^\top\big)\, dz$. The gradient of the loss in $p$ is $-y/p$, entry by entry, and the chain rule multiplies it by the symmetric Jacobian: $-\operatorname{diag}(p)\,y/p + p\,(\mathbf 1^\top y) = -y + p$. Frameworks therefore fuse softmax and cross-entropy into one operation. It is also more stable numerically: it computes $-\log p_k = \operatorname{lse}(z) - z_k$ with the [maximum subtracted](/notes/math/conditioning-and-stability#log-sum-exp-and-the-stable-softmax), and never takes the logarithm of a probability that has underflowed to 0. For a batch with the examples as the rows of $X$, $Z = XW^\top + \mathbf 1b^\top$, the loss is the sum over examples, and summing the per-example gradients $(p_i - y_i)\,x_i^\top$ over the rows gives $\partial L/\partial W = (P - Y)^\top X$. It is the $X^\top(P - Y)$ of the [logistic regression note](/notes/ml/logistic-regression#several-classes-the-softmax), with the weights stored as columns instead of rows.

## The check against logistic regression

Binary logistic regression has $p_i = \sigma(z_i)$, $z = Xw$ and the loss $L(w) = -\sum_i \big[y_i \log p_i + (1 - y_i)\log(1 - p_i)\big]$. With $\sigma(z) = 1/(1 + e^{-z})$, the chain rule gives $\sigma'(z) = e^{-z}/(1 + e^{-z})^2$, and since $1 - \sigma(z) = e^{-z}/(1 + e^{-z})$, this is $\sigma' = \sigma(1 - \sigma)$. Dividing by $\sigma$ and by $1 - \sigma$, the two kinds of terms change by

$$
\begin{aligned}
d\big[-\log\sigma(z)\big] &= -\big(1 - \sigma(z)\big)\, dz , \\
d\big[-\log\big(1 - \sigma(z)\big)\big] &= \sigma(z)\, dz .
\end{aligned}
$$

For either label the term changes by $(p_i - y_i)\, dz_i$, the binary case of $p - y$. With $dz = X\,dw$ and $dp_i = p_i(1 - p_i)\, dz_i$:

$$
\begin{aligned}
dL &= (p - y)^\top X\, dw , \\
d\big(X^\top(p - y)\big) &= X^\top S X\, dw ,
\end{aligned}
$$

where $S = \operatorname{diag}\big(p_i(1 - p_i)\big)$. So $\nabla L = X^\top(p - y)$ and $\nabla^2 L = X^\top S X$, the gradient and the Hessian of the [logistic regression note](/notes/ml/logistic-regression#the-gradient-residuals-times-inputs). In its worked example, with one feature $x = (2, -1, 0.5)$, labels $y = (1, 0, 0)$ and $w = 1$, the residuals are $p - y = (-0.119, 0.269, 0.622)$, the gradient is $-0.196$, and the Hessian is $\sum_i p_i(1 - p_i)\, x_i^2 = 0.675$.

## Where it breaks

Every formula above treats the entries of $X$ as independent variables. A covariance matrix is symmetric, and if its parameters are only the distinct entries, the formulas give the wrong number. Take $\Sigma$ with rows $(2, s)$ and $(s, 2)$ at $s = 1$, so that $\log\det\Sigma = \log(4 - s^2)$. The derivative in the single parameter $s$ is

$$
\frac{d}{ds}\log(4 - s^2) = -\frac{2s}{4 - s^2} = -\frac23 .
$$

The formula $\partial\log\det\Sigma/\partial\Sigma = \Sigma^{-1}$ gives $-\tfrac13$ at position $(1, 2)$. Both entries $(1, 2)$ and $(2, 1)$ move with $s$, so the true derivative is the sum of the two, $2(\Sigma^{-1})_{12}$. In general, let $G$ be the gradient computed as if all $n^2$ entries were independent, and let the parameters be the entries $s_{ij}$ with $i \le j$, so that $X_{ij} = X_{ji} = s_{ij}$. The chain rule adds the two entries that move with $s_{ij}$: $\partial f/\partial s_{ij} = G_{ij} + G_{ji}$ for $i \ne j$, and $G_{ii}$ on the diagonal. In matrix form the gradient is $G + G^\top - \operatorname{diag}(G)$ ([Petersen and Pedersen, 2012](#references), Section 2.8.2, equation 138). An optimizer that updates all $n^2$ entries needs the formulas as derived here, and for a symmetric $\Sigma$ the gradients $\Sigma^{-1}$ and $\Sigma^{-1}S\Sigma^{-1}$ are symmetric anyway, so the iterates stay symmetric.

Layouts cause the second common error. An identity copied from a text in the numerator layout arrives transposed; check it with $\partial(a^\top x)/\partial x$ and by the shapes. Matrix-valued functions of matrices have four-index derivatives, which the method avoids by keeping a scalar loss at the end of every chain. And a formula is not an algorithm: numerical code computes $X^{-1}b$ by a [linear solve](/notes/math/matrices-and-linear-systems#the-inverse-and-why-it-is-rarely-formed) and $\log\det\Sigma$ as twice the sum of the logarithms of the diagonal entries of a [Cholesky factor](/notes/math/determinants-and-eigenvalues#the-log-determinant), which never forms a determinant that could overflow or underflow. For training code, [automatic differentiation](/notes/ml/backpropagation) computes the gradients; the identities give closed forms, Hessians for Newton's method, and a check on what autograd returns.

## What you should remember

- Gradients have the shape of the variable; Jacobians are outputs × inputs.
- $df = \operatorname{tr}(M\, dX)$ means $\partial f/\partial X = M^\top$. Get there with the product rule and the cyclic trace.
- $\nabla(x^\top Ax) = (A + A^\top)x$; $\ \nabla\lVert Ax - b\rVert^2 = 2A^\top(Ax - b)$; $\ \partial\operatorname{tr}(AX)/\partial X = A^\top$.
- $d\log\lvert\det X\rvert = \operatorname{tr}(X^{-1}dX)$ and $d(X^{-1}) = -X^{-1}(dX)X^{-1}$.
- Softmax cross-entropy: $\nabla_z L = p - y$, $\ \partial L/\partial W = (p - y)x^\top$.
- For symmetric parameters, count each off-diagonal entry twice.

## Code

Every identity of the note is checked against central differences, with a helper that perturbs one entry of a vector or a matrix at a time; the random matrices are fixed by a seed. Digits in the last places may vary across platforms.

```python
import numpy as np

rng = np.random.default_rng(0)

def num_grad(f, X, h=1e-6):
    """Central differences in every entry of X; the result has the shape of X."""
    G = np.zeros_like(X, dtype=float)
    for idx in np.ndindex(X.shape):
        E = np.zeros_like(X, dtype=float); E[idx] = h
        G[idx] = (f(X + E) - f(X - E)) / (2 * h)
    return G

def check(name, f, X, G):
    print(f'{name:14s} max error {np.abs(num_grad(f, X) - G).max():.1e}')

# the worked examples
A = np.array([[1., 2], [0, 3]]); x = np.array([1., 2]); b = np.array([1., 1])
print(x @ A @ x, (A + A.T) @ x, 2 * A @ x, 2 * A.T @ (A @ x - b))   # 17.0 [ 6. 14.] [10. 12.] [ 8. 46.]
X = np.array([[2., 1], [0.5, 1.5]]); Xi = np.linalg.inv(X); dX = np.array([[0.1, 0.05], [-0.05, 0.1]])
print(np.linalg.det(X).round(6), (np.linalg.det(X) * Xi.T).round(6), np.trace(Xi @ dX).round(6),
      (np.linalg.det(X) * (1 + np.trace(Xi @ dX))).round(6), np.linalg.det(X + dX).round(6), np.linalg.det(dX).round(6))
# 2.5 [[ 1.5 -0.5] [-1.   2. ]] 0.15 2.875 2.8875 0.0125
a = np.array([1., 2]); print(round(a @ Xi @ b, 6), (-Xi.T @ np.outer(a, b) @ Xi.T).round(6))   # 1.4 [[-0.04 -0.12] [-0.24 -0.72]]

# every identity on random matrices
n = 4
a, b, x = rng.normal(size=n), rng.normal(size=n), rng.normal(size=n)
A, B = rng.normal(size=(n, n)), rng.normal(size=(n, n))
X = rng.normal(size=(n, n)) + n * np.eye(n)                         # comfortably invertible
check('a^T x', lambda v: a @ v, x, a)
check('x^T A x', lambda v: v @ A @ v, x, (A + A.T) @ x)
check('|Ax - b|^2', lambda v: np.sum((A @ v - b) ** 2), x, 2 * A.T @ (A @ x - b))
check('tr(AX)', lambda M: np.trace(A @ M), X, A.T)
check('tr(X^T A X)', lambda M: np.trace(M.T @ A @ M), X, (A + A.T) @ X)
check('log|det X|', lambda M: np.linalg.slogdet(M)[1], X, np.linalg.inv(X).T)
Xi = np.linalg.inv(X)
check('a^T X^-1 b', lambda M: a @ np.linalg.solve(M, b), X, -Xi.T @ np.outer(a, b) @ Xi.T)
# each line prints a max error between 3e-11 and 7e-09: agreement to the accuracy of central differences
# d(X^-1) itself: the first-order change of the inverse matches -X^-1 dX X^-1
E = 1e-6 * rng.normal(size=(n, n))
print(f'{np.abs(np.linalg.inv(X + E) - Xi - (-Xi @ E @ Xi)).max():.1e}')   # 7.0e-14: second order in E

# softmax cross-entropy: the worked example, then a random layer
softmax = lambda z: np.exp(z - z.max()) / np.exp(z - z.max()).sum()
z = np.array([2., 1, 0.1]); y = np.array([1., 0, 0]); p = softmax(z)
print(p.round(3), round(-np.log(p[0]), 3), (p - y).round(3), np.outer(p - y, [1, -2]).round(3))
# [0.659 0.242 0.099] 0.417 [-0.341  0.242  0.099] [[-0.341  0.682] [ 0.242 -0.485] [ 0.099 -0.197]]
K, d = 3, 5
W, bb, xx = rng.normal(size=(K, d)), rng.normal(size=K), rng.normal(size=d)
ce = lambda W_, b_: -np.log(softmax(W_ @ xx + b_)[1])                 # true class 1
p = softmax(W @ xx + bb); y = np.eye(K)[1]
check('CE, W', lambda M: ce(M, bb), W, np.outer(p - y, xx))
check('CE, b', lambda v: ce(W, v), bb, p - y)
# CE, W max error 2.4e-10 | CE, b max error 1.5e-10

# least squares on the four points of the least-squares note
Xd = np.column_stack([np.ones(4), [0., 1, 2, 3]]); yd = np.array([1., 3, 2, 5])
print(2 * Xd.T @ (Xd @ np.zeros(2) - yd), (2 * Xd.T @ (Xd @ np.array([1.1, 1.1]) - yd)).round(12) + 0)   # [-22. -44.] [0. 0.]

# logistic regression: the worked example of its note, then a random design
sig = lambda t: 1 / (1 + np.exp(-t))
xl, yl = np.array([2., -1, 0.5]), np.array([1., 0, 0]); pl = sig(xl)
print((pl - yl).round(3), round(xl @ (pl - yl), 3), round(np.sum(pl * (1 - pl) * xl ** 2), 3))   # [-0.119  0.269  0.622] -0.196 0.675
Xr, yr, w = rng.normal(size=(20, 3)), rng.integers(0, 2, 20).astype(float), rng.normal(size=3)
nll = lambda v: -np.sum(yr * np.log(sig(Xr @ v)) + (1 - yr) * np.log(1 - sig(Xr @ v)))
pr = sig(Xr @ w)
check('logistic grad', nll, w, Xr.T @ (pr - yr))
grad_l = lambda v: Xr.T @ (sig(Xr @ v) - yr)
H_num = np.column_stack([(grad_l(w + 1e-6 * e) - grad_l(w - 1e-6 * e)) / 2e-6 for e in np.eye(3)])   # Jacobian of the gradient
print(f'{"logistic Hess":14s} max error {np.abs(H_num - Xr.T @ np.diag(pr * (1 - pr)) @ Xr).max():.1e}')
# logistic grad max error 2.0e-09 | logistic Hess max error 7.2e-10

# the Gaussian covariance by maximum likelihood: the gradient vanishes at S / n
P3 = np.array([[1., 0], [-1, 1], [0, -1]]); S = P3.T @ P3
ell = lambda Sig: -1.5 * np.linalg.slogdet(Sig)[1] - 0.5 * np.trace(np.linalg.solve(Sig, S))
G_at = lambda Sig: -1.5 * np.linalg.inv(Sig) + 0.5 * np.linalg.inv(Sig) @ S @ np.linalg.inv(Sig)
check('Gaussian ell', ell, np.eye(2), G_at(np.eye(2)))   # max error 2.6e-10
print((S / 3).round(3), np.abs(num_grad(ell, S / 3)).max() < 1e-8)   # [[ 0.667 -0.333] [-0.333  0.667]] True

# where it breaks: a symmetric matrix with one shared off-diagonal parameter s
logdet_s = lambda s: np.linalg.slogdet(np.array([[2., s], [s, 2.]]))[1]
h = 1e-6
print(round((logdet_s(1 + h) - logdet_s(1 - h)) / (2 * h), 4), np.linalg.inv([[2., 1], [1, 2]])[0, 1].round(4))
# -0.6667 -0.3333: the derivative in s is twice the (1, 2) entry of the inverse
```
