The convolutional classifier of the [previous note](/notes/nlp/cnn-text-classification) sees a window of $k$ tokens and forgets position at pooling. The n-gram language model of the [earlier note](/notes/nlp/n-gram-language-models) sees $n - 1$ tokens and cannot generalize across them. Both have a context of fixed, small size. This note introduces a model whose context is, in principle, the entire prefix: it reads tokens in order and keeps a summary in a vector that it updates at every step.

**Notation.** Input token vectors $x_1, \dots, x_T \in \mathbb R^{d}$; hidden states $h_t \in \mathbb R^{H}$; outputs $y_t$. Weight matrices $W_x \in \mathbb R^{H \times d}$, $W_h \in \mathbb R^{H \times H}$, $W_y \in \mathbb R^{K \times H}$ and biases $b, b_y$. $\odot$ is the element-wise product.

## The recurrence

<aside class="callout"><strong>Key idea.</strong> Apply the same small function at every position, feeding it the current token and the result of the previous application. The state after the last token depends on every token before it.</aside>

$$
h_t = \tanh\big(W_x x_t + W_h h_{t-1} + b\big), \qquad h_0 = 0,
$$

$$
y_t = W_y h_t + b_y .
$$

$W_x$ reads the current token, $W_h$ carries the previous state forward, and $\tanh$ keeps every coordinate of $h_t$ in $(-1, 1)$. The same $W_x, W_h, b$ are used at every step, so the parameter count is $H d + H^2 + H$ whatever $T$ is: a sequence of 5 tokens and one of 500 run the same cell 5 or 500 times. Unrolled over time, the computation is a chain of identical cells with the hidden state as the only connection between them.

Shapes for a batch: input $[B, T, d]$, hidden states $[B, T, H]$, final state $[B, H]$. The PyTorch module `nn.RNN(d, H, batch_first=True)` returns both the full sequence of states and the last one.

### Worked example

Scalar case, $d = H = 1$, $W_x = 1$, $W_h = 0.5$, $b = 0$, inputs $x = (1, 0, 0)$:

| $t$ | $x_t$ | $W_x x_t + W_h h_{t-1}$ | $h_t = \tanh(\cdot)$ |
| --- | --- | --- | --- |
| 1 | 1 | $1 + 0 = 1$ | $0.762$ |
| 2 | 0 | $0 + 0.381 = 0.381$ | $0.363$ |
| 3 | 0 | $0 + 0.182 = 0.182$ | $0.180$ |

The input at step 1 is still visible in $h_3$, attenuated by $0.5$ per step and by the $\tanh$. With $W_h = 2$ instead, the same input would grow: $h_2 = \tanh(1.52) = 0.909$, $h_3 = \tanh(1.82) = 0.949$, saturating at the edge of $\tanh$'s range. The recurrent weight decides whether the past fades or floods, and it is the same weight at every step, so whatever it does, it does $T$ times.

## Two ways to use the states

### RNN as a classifier

Read the whole document and use the last state as its representation: $\hat y = \mathrm{softmax}(W_y h_T + b_y)$. Unlike max-pooling, $h_T$ is computed in order, so it can in principle distinguish `not good` from `good not`. In the AG News setting of the previous note, a one-layer GRU (a gated cell from the [next note](/notes/nlp/lstm-and-gru)) with $H = 128$ reads the same 100-dimensional Word2Vec vectors and feeds its last state to a linear layer. It has $3(100 \cdot 128 + 128 \cdot 128 + 2 \cdot 128) + 128 \cdot 4 + 4 = 88{,}836$ parameters, comparable to the convolutional models. Its accuracy was not saved in the notebook outputs; the lesson drawn there was that it scores slightly higher than the convolutional classifiers at a similar size, which is consistent with the model capturing more of the sentence, and still below the TF-IDF baseline.

One practical point. The last state of a *padded* sequence is the state after the padding tokens, not after the last real one. Either pack the sequences so the recurrence stops at the true length, or feed the padding at the start, or read the state at index `length - 1` per example. The notebook's GRU classifier takes the final state after padding, which is a known simplification.

### RNN as a language model

Produce an output at every step and make it a distribution over the vocabulary:

$$
P(w_{t+1} \mid w_{\le t}) = \mathrm{softmax}(W_y h_t + b_y), \qquad W_y \in \mathbb R^{|V| \times H}.
$$

This is the chain-rule factorization of the [n-gram note](/notes/nlp/n-gram-language-models#from-a-joint-probability-to-a-product-of-conditionals) with the Markov assumption removed: the conditional depends on $h_t$, which depends on the whole prefix. Training uses **teacher forcing**: the input sequence is the text shifted by one, $x = (w_1, \dots, w_{T-1})$, the targets are $y = (w_2, \dots, w_T)$, and the loss is the cross-entropy summed over positions, which is exactly the per-token negative log-likelihood whose exponential is the perplexity. Padding positions are excluded from the loss with `ignore_index`. At generation time the model's own sample is fed back as the next input, as in every autoregressive model.

Shapes: ids $[B, T]$ → embeddings $[B, T, E]$ → states $[B, T, H]$ → logits $[B, T, |V|]$. The cross-entropy is computed on the flattened $[B \cdot T, |V|]$ logits against $[B \cdot T]$ targets.

The notebook's model on the BPE-tokenized joke corpus has $E = 256$, $H = 512$ and $|V| = 37{,}580$: 9.6 M parameters in the input embedding, 0.39 M in the recurrent cell, and 19.3 M in the output layer, 29.3 M in total. Two thirds of the model is the output softmax, the same cost structure that drove [negative sampling](/notes/nlp/word2vec#why-the-softmax-is-the-problem) in Word2Vec; for a language model the full softmax is kept because the distribution itself is the output. The training run was not completed in the saved notebook, so no perplexity is reported for it; the [GPT note](/notes/nlp/gpt) returns to neural language-model perplexities with a Transformer.

## Gradients through time

Training unrolls the recurrence and backpropagates through every step. The gradient of the loss at step $T$ with respect to the state at step $t$ passes through $T - t$ applications of the cell:

$$
\frac{\partial h_T}{\partial h_t} = \prod_{s=t+1}^{T} \frac{\partial h_s}{\partial h_{s-1}}
= \prod_{s=t+1}^{T} \mathrm{diag}\big(1 - h_s^2\big)\, W_h .
$$

Each factor is the same $W_h$ scaled by the derivative of $\tanh$ (at most 1). If the largest singular value of $W_h$ is below 1 the product shrinks geometrically and the gradient **vanishes**: the loss at the end of a sentence cannot adjust what the cell did at its start. If it is above 1 the product grows and the gradient **explodes**. With a scalar recurrent weight $w = 2$, fifty steps multiply the gradient by $2^{50} \approx 10^{15}$. The figure below, shared with the [Generative Models note](/notes/generative-models/training-background#vanishing-and-exploding-gradients) where the computation is written out, shows the mechanism.

Two consequences for practice. **Gradient clipping** rescales the gradient vector when its norm exceeds a threshold (the notebook clips at 1.0), which stops explosions from destroying the weights but does nothing for vanishing. And vanishing is the binding constraint: a plain RNN learns dependencies over a handful of tokens and loses the rest, which is why "context is the whole prefix" is true of the forward pass and not of what the model learns ([Bengio, Simard and Frasconi, 1994](#references)). The [next note](/notes/nlp/lstm-and-gru) changes the cell so that the state has an additive path with a gradient factor near 1.

## What changed

| | CNN classifier | N-gram LM | RNN |
| --- | --- | --- | --- |
| Context | $k$ tokens per filter | $n - 1$ tokens | Whole prefix (in principle) |
| Parameters vs length | Independent | Table grows with data | Independent |
| Position | Lost at pooling | Last $n-1$ only | Encoded in state order |
| Generalizes across tokens | Yes (embeddings) | No | Yes |
| Generation | No | Yes | Yes, with $|V|$-way output |
| Parallel over $T$ | Yes | — | No: $h_t$ needs $h_{t-1}$ |

## Limitations

- **Short effective memory.** Gradients vanish over tens of steps; the state cannot be trained to keep information for long.
- **Sequential computation.** Step $t$ waits for step $t - 1$, so an RNN cannot use a GPU's parallelism along the sequence. Training time grows linearly with $T$ per example, and the [Transformer note](/notes/nlp/transformers) will make this the central argument against recurrence.
- **One state for everything.** A single vector $h_T$ must summarize the whole input. For classification that is adequate; for translating a 30-word sentence it is the bottleneck that the [seq2seq note](/notes/nlp/seq2seq) runs into.
- **Padding interacts with the last state.** Variable lengths need packing or masking that the convolutional model did not.

## What you should remember

- $h_t = \tanh(W_x x_t + W_h h_{t-1} + b)$: the same cell at every step, parameters independent of length, state carries the prefix.
- Classifier: last state → linear. Language model: every state → softmax over $|V|$, trained by teacher forcing on the shifted sequence with padding ignored.
- The gradient through $T - t$ steps is a product of $T - t$ copies of $\mathrm{diag}(1 - h^2)W_h$; it vanishes or explodes geometrically. Clipping handles explosion only.
- Recurrence is sequential: no parallelism along the sequence.
