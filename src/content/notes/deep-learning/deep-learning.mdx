The Machine Learning course ended its part on neural networks with three results. A network is a stack of linear maps and nonlinearities whose hidden layers [learn their own features](/notes/ml/neural-networks#a-network-learns-its-own-features); [backpropagation](/notes/ml/backpropagation) gives the gradient of the loss with respect to every weight for about the cost of one forward pass; and a handful of remedies, collected in [Training deep networks](/notes/ml/training-deep-networks), keep a deep stack trainable. Those notes worked with small networks on small tables. This course is about the regime where networks became the default: raw images with millions of pixels and labels, networks with millions of weights, and a training procedure that has to work reliably at that scale. This note says what is different about learning deep, why it started to win around 2012, and sets up the one loop that every later note modifies.

**Notation.** An example is an input $x$ with a target $y$. A network $f_\theta$ with parameters $\theta$ maps $x$ to a prediction; for classification its outputs are logits. A **representation** (or feature map) $h(x)$ is a vector computed from $x$ that a simple model, such as a linear classifier, then uses. $\ell(f_\theta(x), y)$ is the loss on one example, $B$ is a mini-batch of examples and $\eta > 0$ the learning rate.

## Baseline: features designed by hand

Until about 2012 a typical system for images, sound or text had two stages. A **fixed feature extractor** $h$, designed by people, turned the raw input into a vector: histograms of local gradient orientations for images (SIFT, HOG), spectral coefficients for speech, n-gram counts for text. A **trained classifier** on top of it, usually linear:

$$
f(x) = W h(x) + b, \qquad h \text{ fixed}, \quad W, b \text{ learned}.
$$

Only $W$ and $b$ see the labels. With the logistic loss this is a convex problem, solved reliably, and all the knowledge about what matters in an image sits in $h$. The winners of the first two ImageNet challenges were systems of this kind. In 2010 the NEC team combined SIFT and LBP descriptors with two nonlinear coding steps and an SVM trained by stochastic gradient descent; in 2011 the XRCE team used Fisher-vector image signatures with one-against-all linear SVMs ([Russakovsky et al., 2015](#references), section 5.1). Their top-5 errors were 28.2% and 25.8%: in about a quarter of the test images, the correct class was not among the five the system ranked highest.

The weakness is the fixed stage. Whatever $h$ discards, the classifier cannot recover, and improving $h$ takes a new idea from a person rather than more data.

## Representation learning

<aside class="callout"><strong>Key idea.</strong> Learn the feature map together with the classifier, from the labels, by gradient descent on one loss. Deep learning builds the feature map as a composition of many simple learned stages, each working on the output of the previous one.</aside>

A deep network replaces the fixed $h$ by a learned composition:

$$
\begin{aligned}
f_\theta(x) &= W h_L(x) + b, \\
h_l &= \varphi\big(W_l h_{l-1} + b_l\big), \quad h_0 = x .
\end{aligned}
$$

Here $h_l$ is the representation after layer $l$, $\varphi$ is a nonlinearity such as the ReLU, and $\theta$ collects every $W_l$, $b_l$, $W$ and $b$. The last layer is still a linear classifier on features, exactly as in the baseline; the difference is that the gradient of the loss now reaches the features and changes them. "Deep" refers to the number of learned stages $L$. Composition lets later stages reuse what earlier stages computed, which can be exponentially more economical than one wide stage, as the [depth-versus-width example](/notes/ml/neural-networks#depth-versus-width) of the Machine Learning course shows. **Worked example: what a learned representation looks like.** Take the 8 × 8 images of digits bundled with scikit-learn, 1078 for training and 719 for testing, and measure each representation with the simplest classifier there is: assign a test image to the class whose mean training representation is closest. On raw pixels this gets 0.898 of the test images right. On the 128 outputs of the second hidden layer of a network $64 \to 128 \to 128 \to 10$ with random weights it gets 0.853: random layers do not organize the data by class. After the same network is trained for 30 epochs, the nearest class mean on that layer gets 0.947. Training has moved the images of each digit closer to their own class mean and away from the others, so that a cruder classifier works better on the learned features than on the pixels. The numbers come from the Code section.

The same run is also a fair warning. Logistic regression on the raw pixels reaches a test accuracy of 0.972, the trained network 0.958. On 64-pixel images that are already centred and scaled, the pixels are good features, and a deep network has nothing to add. Representation learning pays off where hand-made features are weak and data are plentiful: photographs of millions of pixels, raw audio, text.

## Why deep networks took off around 2012

Multilayer networks trained by backpropagation date from the 1980s, and convolutional networks were reading the digits on bank cheques in the 1990s ([LeCun et al., 1998](#references)). What changed around 2012 was not one idea but four conditions at once, all visible in the network that won the ImageNet challenge that year ([Krizhevsky, Sutskever and Hinton, 2012](#references)):

- **Data.** The ImageNet challenge provided about 1.2 million labelled training images in 1000 classes (1,281,167 in the 2012–2014 editions; [Russakovsky et al., 2015](#references), Table 2), where earlier labelled image datasets had tens of thousands. The winning network had 60 million parameters, and even with 1.2 million examples overfitting was a significant problem for it (section 1).
- **Compute.** The network was trained on two NVIDIA GTX 580 graphics cards with 3 GB of memory each, for about 90 passes over the training set, in five to six days (sections 1 and 5). Graphics processors execute the many independent multiply–adds of a convolution or a matrix product in parallel, and a fast GPU implementation of convolution is what made a network of this size trainable at all (section 1).
- **ReLU.** Saturating units such as tanh pass small gradients once their inputs are large. On CIFAR-10, a four-layer convolutional network with ReLUs reached 25% training error six times faster than the same network with tanh units (section 3.1, Figure 1).
- **Better training.** Dropout in the two large fully connected layers, without which the network "exhibits substantial overfitting" (section 4.2); data augmentation by random crops and reflections (section 4.1); and stochastic gradient descent with momentum 0.9 and weight decay 0.0005 (section 5).

The result: a top-5 test error of 15.3% for an ensemble that also used extra training data, and 16.4% with the challenge data alone, against 26.2% for the second-best entry, a system built on Fisher vectors ([Russakovsky et al., 2015](#references), section 5.1). From 2013 on, the vast majority of entries were convolutional networks (section 5.1), and the error kept falling as networks became deeper and easier to train:

Most of what made the later networks trainable is the content of this course: normalization layers and careful initialization ([Normalization and initialization](/notes/deep-learning/normalization-and-initialization)), adaptive optimizers and learning-rate schedules ([Optimizing deep networks](/notes/deep-learning/optimizing-deep-networks)), and residual connections ([Convolutional architectures](/notes/deep-learning/cnn-architectures)). Those numbers are for one benchmark, measured on its own test set; how far they carry to other data is a separate question, taken up in [Adversarial examples](/notes/deep-learning/adversarial-examples).

## The training loop

Every network in this course, whatever its architecture or task, is trained by the same procedure: **mini-batch stochastic gradient descent**. One turn of the loop takes a batch $B$ of examples and updates the parameters,

$$
\theta \leftarrow \theta - \eta\, \nabla_\theta \frac{1}{|B|} \sum_{i \in B} \ell\big(f_\theta(x_i), y_i\big),
$$

where $\nabla_\theta$ is the gradient with respect to all parameters, computed by backpropagation, and $\eta$ the learning rate. The average over the batch is an unbiased estimate of the gradient of the average loss over the whole training set, as the [optimizers note](/notes/ml/stochastic-and-adaptive-optimizers#a-gradient-from-a-sample) of the Machine Learning course shows. One pass over the training set is an **epoch**.

**Worked example: one turn by hand.** A model with two parameters, $f(x) = wx + b$, starts at $w = 0.5$, $b = 0$. The batch has two examples, $(x, y) = (1, 2)$ and $(2, 3)$, the loss is the squared error averaged over the batch and $\eta = 0.1$.

<TrainingLoop />

1. **Batch.** $x = (1, 2)$, $y = (2, 3)$.
2. **Forward.** $\hat y = wx + b = (0.5, 1.0)$.
3. **Loss.** The residuals are $\hat y - y = (-1.5, -2)$, and $L = \tfrac12\big(1.5^2 + 2^2\big) = 3.125$.
4. **Backward.** $\partial L / \partial w = \tfrac12 \sum_i 2(\hat y_i - y_i)\, x_i = (-1.5) \cdot 1 + (-2) \cdot 2 = -5.5$ and $\partial L / \partial b = \tfrac12 \sum_i 2(\hat y_i - y_i) = -3.5$.
5. **Step.** $w \leftarrow 0.5 - 0.1 \cdot (-5.5) = 1.05$ and $b \leftarrow 0 - 0.1 \cdot (-3.5) = 0.35$.

On the same batch, the loss at the new parameters is $\tfrac12\big(0.6^2 + 0.55^2\big) = 0.331$, a tenth of what it was.

A real network differs only in scale: $\theta$ has millions of entries, the forward pass is a stack of layers, and the backward pass is backpropagation through all of them, computed automatically. Each later note changes one part of this loop and leaves the rest as it is:

## The plan of the course

1. **Training Neural Networks.** The loop above, made concrete: tensors and automatic differentiation in PyTorch, the losses that measure a prediction and the regularizers that keep a large network from memorizing its training set, normalization layers and initialization that keep signals at a usable scale through many layers, and the optimizers and schedules that take the steps.
2. **Convolutional Networks.** A layer that shares its weights across the positions of an image, its shapes and receptive fields; the architectures from AlexNet to residual networks that made depth work; and two tasks beyond labelling a whole image: object detection, which finds and boxes every object, and semantic segmentation, which labels every pixel.
3. **Representations and Vision Transformers.** Learning features from images without labels, by contrastive and related objectives, and the Vision Transformer, which cuts an image into patches and processes them with the attention of the NLP course.
4. **Robustness and Deployment.** Where trained networks fail: adversarial examples, tiny input changes that flip a prediction. How to make a network small and fast by pruning and distillation. And the practice of training: debugging, choosing hyperparameters and reading learning curves, closing with the course in one paragraph.

## What changed

| | Hand-designed features | Deep learning |
| --- | --- | --- |
| Feature map | fixed, designed by people | learned from the labels, in many stages |
| What is trained | the last linear layer | every layer, through one loss |
| Optimization | often convex | nonconvex, by stochastic gradient descent |
| Where progress comes from | better features | more data, more compute, better architectures and training |
| ImageNet top-5 error | 28.2% (2010), 25.8% (2011) | 16.4% (2012), 3.57% (2015) |

## Limitations

- **Data hunger.** Learning the features costs examples. On small or clean inputs a linear model on good features can match a network, as logistic regression on the digit pixels did here; on typical tables of moderate size, [tree ensembles still compete](/notes/ml/neural-networks#limitations).
- **Compute and energy.** The gains of the last decade came with networks and datasets that grew by orders of magnitude, and the cost of training grew with them.
- **Benchmarks are not the world.** The error rates above are measured on one test set drawn like the training set. A network can rely on cues that hold in the benchmark and fail elsewhere, and small deliberate changes to an input can flip its prediction.
- **No guarantee from the loop.** Gradient descent on a nonconvex loss can stall or diverge, and whether a run works depends on many choices; much of this course is about making it work reliably.
- **Opaque features.** A learned feature is a direction in a layer, not a named quantity, which makes a network harder to inspect than a model on hand-made features.

## What you should remember

- Deep learning learns the feature map, as a composition of many simple stages, jointly with the classifier, by gradient descent on one loss.
- The last layer is still a linear model on features; training moves the features so that a simple rule separates the classes.
- It started to win around 2012 because large labelled datasets, GPUs, ReLUs and better regularization arrived together: 16.4% against 26.2% top-5 error on ImageNet.
- Every network is trained by the same loop: batch, forward, loss, backward, step; the rest of the course changes one part of it at a time.
- Learned features pay off on raw, high-dimensional inputs with plenty of data, not necessarily on small clean ones.

## Code

One turn of the loop by hand, the same loop training a network on the bundled digits, and the nearest-class-mean test of each representation. Seeds are fixed; exact numbers can differ slightly across platforms and library versions. The script runs in a few seconds on a laptop CPU.

```python
import numpy as np, torch
from torch import nn
from sklearn.datasets import load_digits
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

# 1. one turn of the loop by hand: f(x) = w x + b, squared error, a batch of two points, step 0.1
w = torch.tensor(0.5, requires_grad=True); b = torch.tensor(0.0, requires_grad=True)
xb, yb = torch.tensor([1.0, 2.0]), torch.tensor([2.0, 3.0])
loss = ((w * xb + b - yb) ** 2).mean()          # forward and loss
loss.backward()                                 # backward
print(loss.item(), w.grad.item(), b.grad.item())   # 3.125 -5.5 -3.5
with torch.no_grad():                           # step
    w -= 0.1 * w.grad; b -= 0.1 * b.grad
print(round(w.item(), 4), round(b.item(), 4), round(((w * xb + b - yb) ** 2).mean().item(), 5))   # 1.05 0.35 0.33125

# 2. the same loop on 8x8 digits: 1078 training and 719 test images, a 64 -> 128 -> 128 -> 10 network
X, y = load_digits(return_X_y=True)
Xtr, Xte, ytr, yte = train_test_split(X / 16.0, y, test_size=0.4, random_state=0, stratify=y)
Xtr_t, ytr_t, Xte_t = torch.tensor(Xtr, dtype=torch.float32), torch.tensor(ytr), torch.tensor(Xte, dtype=torch.float32)
loader = torch.utils.data.DataLoader(torch.utils.data.TensorDataset(Xtr_t, ytr_t), batch_size=32, shuffle=True)

torch.manual_seed(0)
def mlp():
    return nn.Sequential(nn.Linear(64, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, 10))
untrained, model = mlp(), mlp()
opt = torch.optim.SGD(model.parameters(), lr=0.1)
for epoch in range(1, 31):
    total = 0.0
    for xb, yb in loader:
        loss = nn.functional.cross_entropy(model(xb), yb)   # forward, loss
        opt.zero_grad()
        loss.backward()                                     # backward
        opt.step()                                          # step
        total += loss.item() * len(xb)
    if epoch in (1, 10, 30):
        with torch.no_grad():
            acc = (model(Xte_t).argmax(1).numpy() == yte).mean()
        print(epoch, round(total / len(Xtr), 3), round(float(acc), 3))
# 1 2.272 0.43 | 10 0.226 0.912 | 30 0.062 0.958   (epoch, mean training loss, test accuracy)

# 3. representations: the nearest class mean on the pixels, on the second hidden layer of the untrained
#    network, and on the same layer after training
def nearest_mean(F, G):
    means = np.stack([F[ytr == k].mean(0) for k in range(10)])
    return (((G[:, None, :] - means[None]) ** 2).sum(-1).argmin(1) == yte).mean()
def layer(net, A):   # output of the second hidden layer, after its ReLU
    with torch.no_grad():
        return net[:4](torch.tensor(A, dtype=torch.float32)).numpy()
print(round(nearest_mean(Xtr, Xte), 3), round(nearest_mean(layer(untrained, Xtr), layer(untrained, Xte)), 3),
      round(nearest_mean(layer(model, Xtr), layer(model, Xte)), 3))   # 0.898 0.853 0.947
print(round(LogisticRegression(max_iter=5000).fit(Xtr, ytr).score(Xte, yte), 3))   # 0.972: pixels are good features here
```
