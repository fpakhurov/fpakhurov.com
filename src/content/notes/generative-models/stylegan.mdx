Move a face generator's input $z$ a little along one coordinate: the head turns, but the person, the hair and the light change too. You would like one direction to change only the pose. The scaled-up GANs of the [previous note](/notes/generative-models/gan-scaling) draw convincing faces at $1024 \times 1024$, yet nothing ties a direction of $z$ to one attribute.

Two ways give such control without labels. **InfoGAN** ([Chen et al., 2016](#references)) changes the objective: part of the input must be readable back from the image. **StyleGAN** ([Karras, Laine and Aila, 2019](#references)) changes the generator: the code sets the "style" of every layer, and a separate noise input supplies random detail. Its two successors repair what it broke.

## Why z is entangled

We call a representation **disentangled** when one direction changes one factor of variation (pose) and leaves the others (identity) alone, as in the [β-VAE note](/notes/generative-models/vae-variants#what-β-buys-and-what-it-does-not). The GAN objective does not ask for it: $D$ judges whole images, however the generator uses $z$.

There is also a structural reason ([Karras, Laine and Aila, 2019](#references)). The generator maps the fixed $\mathcal N(0, I)$ to the data, so every region of $z$-space must give a realistic image, at the frequencies of the training set. With masculinity and hair length on two axes and no long-haired men in the data, straight axes would sample the missing corner; the map must curve, and along it one axis of $z$ changes both factors.

## InfoGAN: a code the image must reveal

InfoGAN splits the input into noise $z$ and a code $c = (c_1, \dots, c_M)$ with a factorized prior $p(c) = \prod_i p(c_i)$ and generates $x = G(z, c)$. A plain GAN could ignore $c$, since an image distribution independent of $c$ fools the discriminator as well, so InfoGAN asks for a large **mutual information** between the code and the image,

$$
\begin{aligned}
I(c; x) &= H(c) - H(c \mid x), \\
H(c \mid x) &= -\mathbb E_{(c, x)} \log p(c \mid x),
\end{aligned}
$$

where $H$ is [entropy](/notes/generative-models/entropy-and-divergences#entropy-expected-surprise) in nats: $I$ is the drop in uncertainty about $c$ once the image is seen, zero when $x$ is independent of $c$. With the GAN value function $V$ and a weight $\lambda$, the game is

$$
\min_G \max_D \; V(D, G) - \lambda\, I\big(c; G(z, c)\big) .
$$

### A lower bound on mutual information

The generator's posterior $p(c \mid x)$ is unknown, so InfoGAN adds an auxiliary network $q_\phi(c \mid x)$ that guesses the code from the image. Write $\log p = \log q_\phi + \log(p/q_\phi)$ inside the conditional entropy; averaged over $c \sim p(c \mid x)$, the second term is the KL divergence from $p(\cdot \mid x)$ to $q_\phi(\cdot \mid x)$, by definition:

$$
\begin{aligned}
-H(c \mid x) &= \mathbb E_{x}\, \mathbb E_{c \sim p(c \mid x)} \log p(c \mid x) \\
&= \mathbb E_{x}\, \mathbb E_{c \sim p(c \mid x)} \log q_\phi(c \mid x) \\
&\quad + \mathbb E_x\, D_{\mathrm{KL}}\big(p(\cdot \mid x) \,\|\, q_\phi(\cdot \mid x)\big) \\
&\ge \mathbb E_{x}\, \mathbb E_{c \sim p(c \mid x)} \log q_\phi(c \mid x) .
\end{aligned}
$$

The last step drops the KL term, which is never negative (the [entropy note](/notes/generative-models/entropy-and-divergences#kullbackleibler-divergence) proves $D_{\mathrm{KL}} \ge 0$ by Jensen's inequality) and zero only when the distributions coincide. The remaining expectation is over $p(x)\,p(c \mid x) = p(c)\,p(x \mid c)$ by the product rule, so pairs are sampled forwards, $c \sim p(c)$, $z \sim p(z)$, $x = G(z, c)$, and the posterior is never needed. Adding $H(c)$ gives the bound

$$
\begin{aligned}
\mathcal L_I(G, q_\phi) &= \mathbb E_{c,\, z} \log q_\phi\big(c \mid G(z, c)\big) + H(c) \\
&\le I\big(c; G(z, c)\big),
\end{aligned}
$$

tight when $q_\phi$ equals the posterior. $H(c)$ is a constant, so the game becomes

$$
\min_{G,\, q_\phi} \max_D \; V(D, G) - \lambda\, \mathcal L_I(G, q_\phi) .
$$

Over $q_\phi$ this fits the guesser to the generator; over $G$ it makes the code easy to guess. Dropping a non-negative KL to an approximate posterior also gives the [ELBO](/notes/generative-models/vae#where-the-elbo-comes-from).

The guesser shares all convolutional layers with the discriminator and adds one head: a softmax for a categorical code, so $-\log q_\phi$ is a cross-entropy, and for a continuous code a mean $\mu(x)$ and a standard deviation $\sigma(x)$, with

$$
\log q_\phi(c \mid x) = -\frac{(c - \mu(x))^2}{2\sigma(x)^2} - \ln \sigma(x) - \tfrac12 \ln 2\pi ,
$$

a squared error weighted by the network's confidence.

Toy numbers: a uniform 10-way code has $H(c) = \ln 10 = 2.303$ nats, and $\mathcal L_I \le \ln 10$ because $\log q_\phi \le 0$ for a discrete code. A continuous code $c = 0.6$ guessed as $\mu = 0.5$, $\sigma = 0.2$ gives the term $-0.1250 + 1.6094 - 0.9189 = 0.5655$, positive because a density can exceed 1.

### What InfoGAN found

On MNIST, with one 10-way and two continuous codes and no labels, the categorical code sorts the digits by class (a 5% error when matched to digit types), and the continuous codes control rotation and width. On faces, codes find pose, lighting and glasses.

### Where InfoGAN stops

The codes are designed by hand, and which factor each one controls can change between runs. Mutual information also asks for less than disentanglement: $c$ must be readable from the image, but nothing says that each $c_i$ controls a single factor absent from $z$. Most of the input is still the entangled $z$, and the experiments stop at $64 \times 64$.

StyleGAN takes the other route: it changes where and how the code enters the network.

## StyleGAN: a style-based generator

A traditional generator, such as [Progressive GAN](/notes/generative-models/gan-scaling#progan-growing-the-networks), feeds the code through its first layer only. StyleGAN instead sends $z \in \mathbb R^{512}$ through a **mapping network** $f$, an 8-layer MLP, to $w = f(z) \in \mathcal W = \mathbb R^{512}$. The **synthesis network** $g$ starts from a learned $4 \times 4 \times 512$ constant, and $w$ reaches each of its 18 layers, two per resolution from $4^2$ to $1024^2$, as a style; $G = g \circ f$. The discriminator is that of Progressive GAN.

### The mapping network and the space W

The [entanglement argument](#why-z-is-entangled) applies to $z$ because its distribution is fixed. The density of $\mathcal W$ is whatever $f$ makes of $\mathcal N(0, I)$, so $f$ can absorb the curving the data force: the missing combination of factors can be a region of $\mathcal W$ that $f$ never reaches, while the axes of $\mathcal W$ stay straight.

Nothing forces training to use this freedom; the authors argue that a disentangled $\mathcal W$ is easier to render, and the two metrics [below](#measuring-disentanglement-without-an-encoder) test the claim.

### Styles through AdaIN

A learned affine map $A_\ell$ turns $w$ into the style $y_\ell = (y_s, y_b)$ of layer $\ell$: one scale and one bias per channel. The style acts through **adaptive instance normalization** ([Huang and Belongie, 2017](#references)), defined for channel $i$ of a feature map $x$ as

$$
\mathrm{AdaIN}(x_i, y) = y_{s,i}\,\frac{x_i - \mu(x_i)}{\sigma(x_i)} + y_{b,i},
$$

where $\mu(x_i)$ and $\sigma(x_i)$ are the mean and standard deviation of channel $i$ over its spatial positions, as in [instance normalization](/notes/generative-models/training-background#instance-normalization).

For example, a channel $(1, 3, 5, 7)$ normalizes to $(-1.342, -0.447, 0.447, 1.342)$ whatever its scale, since multiplying it by 10 scales $x_i - \mu(x_i)$ and $\sigma(x_i)$ alike; the style $y_s = 2$, $y_b = 0.5$ then gives $(-2.18, -0.39, 1.39, 3.18)$.

So AdaIN erases the mean and scale that earlier layers chose, and each style controls one convolution, up to the next AdaIN. A style is also spatially uniform, which suits global aspects such as pose, lighting and the overall look.

With styles in place, the code at the first layer no longer helped: a learned constant instead moved FID from 5.34 to 5.07 on CelebA-HQ and from 4.85 to 4.88 on FFHQ ([Karras, Laine and Aila, 2019](#references), Table 1). All image content then comes from the styles and the noise.

### Noise for stochastic detail

Much of a portrait is harmlessly random: hairs, freckles and pores. Instead of spending capacity to produce it from the input, StyleGAN adds to each layer a fresh single-channel image of Gaussian noise, scaled per channel by learned factors $B$.

Redrawing the noise for a fixed $w$ moves individual hairs and keeps identity and pose; without noise the images look painterly. A style scales whole maps, the natural channel for global decisions; pose driven by independent per-pixel noise would vary inconsistently across the image, which the discriminator would penalize.

### Style mixing: coarse, middle and fine styles

Nothing forces all layers to use the same $w$. **Style mixing** maps $z_1, z_2$ to $w_1, w_2$ and switches from $w_1$ to $w_2$ at a random crossover layer, on 90% of the training images, so the network cannot assume adjacent styles are correlated. Single-code FID stays at 4.40 against 4.42 on FFHQ; two-code images improve from 8.22 to 5.11 ([Karras, Laine and Aila, 2019](#references), Table 2).

Mixing two faces shows what each group of layers controls:

- coarse styles, $4^2$ to $8^2$: pose, general hair style, face shape and eyeglasses;
- middle styles, $16^2$ to $32^2$: smaller facial features, hair style, eyes open or closed;
- fine styles, $64^2$ to $1024^2$: mainly the colour scheme and microstructure.

The coarse layers decide the layout, the fine ones the texture; on bedrooms, the viewpoint and the materials. A separate $w$ per layer defines the extended space $\mathcal W^+$, which the [drag-editing note](/notes/generative-models/drag-editing#the-stylegan2-generator-in-brief) uses.

### Truncation in W

Low-density regions are poorly learned, so sampling near the centre trades variety for quality. StyleGAN shrinks each $w$ toward the centre of mass, with $\psi < 1$:

$$
\begin{aligned}
\bar w &= \mathbb E_{z \sim p(z)} f(z), \\
w' &= \bar w + \psi\,(w - \bar w) .
\end{aligned}
$$

At $\psi = 0.7$ each $w$ keeps 70% of its distance from the centre; at $\psi = 0$ every sample is the "mean face", and a negative $\psi$ flips viewpoint, glasses, age and hair length. Unlike the [truncation trick of BigGAN](/notes/generative-models/gan-scaling#the-truncation-trick) in $z$, it needs no change to the loss and can be applied to the coarse layers only.

## Measuring disentanglement without an encoder

Most disentanglement metrics need an encoder, which a GAN lacks; StyleGAN proposes two that need neither an encoder nor known factors.

**Perceptual path length** (PPL) asks how fast the image changes along an interpolation; in an entangled space a path can pass through features absent at both ends. With the [LPIPS](/notes/generative-models/lpips) distance $d$ ([Zhang et al., 2018](#references)), $w_1 = f(z_1)$, $w_2 = f(z_2)$, $t \sim U(0, 1)$ and $\varepsilon = 10^{-4}$,

$$
\begin{aligned}
l_{\mathcal W} = \mathbb E\Big[\tfrac{1}{\varepsilon^2}\, d\big(&g(\mathrm{lerp}(w_1, w_2; t)),\\
&g(\mathrm{lerp}(w_1, w_2; t + \varepsilon))\big)\Big] .
\end{aligned}
$$

In $z$-space [slerp](/notes/generative-models/alpha-gan#latent-interpolation-lerp-or-slerp) replaces lerp, since a straight line between two Gaussian samples dips inside their shell. Why divide by $\varepsilon^2$? LPIPS is a weighted sum of squared differences of normalized features ([LPIPS note](/notes/generative-models/lpips#the-formula)), and to first order (Taylor) a small step changes the features by $\varepsilon$ times their derivative along the path. So $d \approx \varepsilon^2 \times$ (squared speed).

**Linear separability** asks whether a binary attribute such as gender is cut off by a hyperplane in the latent space. Attribute classifiers label generated images, a linear SVM predicts each label from the code, and the score is the exponential of the summed conditional entropies of the labels given the side: 1 when every attribute is linear.

Both metrics favour $\mathcal W$: a traditional generator with a mapping network in front has separability 6.52 in $\mathcal W$ and 170.29 in its input space. PPL also crept up late in training while FID kept falling: some quality was paid for with entanglement.

## StyleGAN2: removing the artifacts

StyleGAN images often contain a blob like a water droplet, and details such as teeth can stay fixed while the face turns. StyleGAN2 ([Karras et al., 2020](#references)) traces the first to AdaIN and the second to progressive growing, and adds a smoothness regularizer.

### Droplets and the normalization in AdaIN

The droplet appears around $64 \times 64$ in the feature maps. Instance normalization sets the mean and variance of each feature map separately, destroying the information in the relative sizes of the features; the hypothesis is that the generator smuggles it past the normalization with a strong local spike that dominates the statistics. Without the normalization step, the droplets disappear.

A toy map shows it: 16 positions, a pattern $\pm a$ on 15 of them (8 positive, 7 negative) and a spike $S$ on the 16th. Without a spike the normalized pattern has half-gap 1.035 for every $a$: the scale $a$ is lost. With $a = 1$ and $S = 4$, 10, 40 the half-gap is 0.737, 0.386, 0.103, so it depends on $S/a$, and the spike itself becomes 3.85 at $S = 40$: a volume knob the normalization cannot remove.

StyleGAN2 first splits AdaIN into modulation and normalization, moves the bias and the noise outside the styled part and normalizes the standard deviation only, so that the normalization can be replaced.

### Weight modulation and demodulation

Write $w_{ijk}$ for the weight from input channel $i$ to output channel $j$ at kernel position $k$ (not the latent), and $s_i$ for the style's scale of input channel $i$.

Modulation is a weight change: convolution is linear in each input channel, so scaling channel $i$ by $s_i$ and convolving equals convolving with $w'_{ijk} = s_i\, w_{ijk}$.

Assume independent unit-variance inputs. Output $j$ at one position is $\sum_{i,k} w'_{ijk}\, x_{i,k}$, and the variances of independent terms add, so

$$
\sigma_j = \sqrt{\textstyle\sum_{i,k} w'^2_{ijk}} .
$$

Dividing output $j$ by $\sigma_j$ removes the effect of $s$ on the output scale, and the division folds into the weights:

$$
w''_{ijk} = \frac{w'_{ijk}}{\sqrt{\sum_{i,k} w'^2_{ijk} + \epsilon}} .
$$

The style block is now one convolution with style-dependent weights, scaled from the weights and the style, never from the feature maps, so a spike no longer changes the scaling and the droplet loses its purpose. The per-sample weights run as one grouped convolution.

Toy numbers: one output channel of a $1 \times 1$ convolution has weights $w = (0.6, 0.8)$, so unit-variance inputs give output variance 1.

| Quantity | Value |
| --- | --- |
| style $s$ | $(3, 0.5)$ |
| modulated $w'$ | $(1.8, 0.4)$ |
| output variance $\sum w'^2$ | $3.24 + 0.16 = 3.4$ |
| $\sigma = \sqrt{3.4}$ | 1.844 |
| demodulated $w''$ | $(0.976, 0.217)$ |
| output variance | $0.953 + 0.047 = 1$ |

The style still decides the mix (the first input carries 95% of the variance instead of 36%) but no longer the overall scale.

The price is an assumption: demodulation equalizes the variance only for independent inputs. With correlation 0.5 between the two inputs, $\operatorname{Var}(aX + bY) = a^2 + b^2 + 2ab\rho$ gives $1 + 2 \cdot 0.5 \cdot 0.976 \cdot 0.217 = 1.21$ for the same $w''$. Real feature maps are correlated, so demodulation normalizes more weakly, a price accepted to remove the droplets. The figure repeats the test on a $3 \times 3$ convolution.

### Path-length regularization

Models with equal FID can differ visibly in quality, and PPL tracks the difference: the generator, the authors suggest, stretches the regions of $\mathcal W$ that give good images and squeezes bad ones into small regions of rapid change. They ask that a fixed step in $\mathcal W$ give a fixed-size change in the image, in every direction:

$$
\mathcal L_{\mathrm{pl}} = \mathbb E_{w,\, y} \big(\lVert J_w^\top y \rVert_2 - a\big)^2 ,
$$

where $J_w = \partial g(w) / \partial w$ is the Jacobian of the synthesis network, $y \sim \mathcal N(0, I)$ is a random image, and $a$ is a running average of the length, so the network picks the global scale. With $a$ at the mean, the penalty is the variance of the length $\ell = \lVert J_w^\top y \rVert$, $\operatorname{Var} \ell \approx \sum_i \sigma_i^4 / (2 \sum_i \sigma_i^2)$ in the singular values $\sigma_i$ of $J_w$, smallest when $J_w$ is orthogonal up to scale (derivation below).

<details>
<summary>Derivation</summary>

The Jacobian is never formed: $y$ is a constant, so by linearity of differentiation component $k$ of the gradient of the scalar $g(w) \cdot y = \sum_i y_i\, g_i(w)$ is $\sum_i y_i\, \partial g_i / \partial w_k = (J_w^\top y)_k$, and one backward pass gives $J_w^\top y$. Take the [singular value decomposition](/notes/math/singular-value-decomposition#rotate-stretch-rotate) $J_w^\top = U \Sigma V^\top$ with singular values $\sigma_1, \dots, \sigma_L$, $L = 512$. $U$ preserves lengths, and $\tilde y = V^\top y$ is again $\mathcal N(0, I)$, because an [affine map](/notes/probability/multivariate-gaussian#affine-maps) sends $\mathcal N(0, I)$ to $\mathcal N(0, V^\top V) = \mathcal N(0, I)$. So $\ell^2 = Q = \sum_i \sigma_i^2 \tilde y_i^2$. Then:

$$
\begin{aligned}
\mathbb E\, Q &= \textstyle\sum_i \sigma_i^2 , \\
\operatorname{Var} Q &= 2 \textstyle\sum_i \sigma_i^4 , \\
\operatorname{Var} \ell &\approx \frac{\operatorname{Var} Q}{4\, \mathbb E\, Q} = \frac{\sum_i \sigma_i^4}{2 \sum_i \sigma_i^2} .
\end{aligned}
$$

1. The mean uses $\mathbb E\, \tilde y_i^2 = 1$ and linearity of expectation.
2. The variance adds over the independent terms, and $\operatorname{Var} \tilde y_i^2 = \mathbb E\, \tilde y_i^4 - 1 = 2$: integration by parts with $\varphi'(y) = -y\varphi(y)$ for the standard normal density gives $\int y^3 \cdot y\varphi(y)\,dy = \int 3y^2\varphi(y)\,dy = 3$, the boundary terms vanishing.
3. The last line expands $\ell = \sqrt Q$ to first order around $\mathbb E\, Q$, $\sqrt Q \approx \sqrt{\mathbb E Q} + (Q - \mathbb E Q)/(2\sqrt{\mathbb E Q})$, accurate when $Q$ concentrates. From the first two lines, $\operatorname{Var} Q/(\mathbb E Q)^2 = 2\sum_i \sigma_i^4/(\sum_i \sigma_i^2)^2 \le 2\max_i \sigma_i^2/\sum_i \sigma_i^2$: for equal singular values $2/L$, a relative spread $\sqrt{2/512} \approx 6\%$, small unless a few $\sigma_i$ dominate.

For a fixed $\sum_i \sigma_i^2$, the Cauchy–Schwarz inequality $\big(\sum_i \sigma_i^2 \cdot 1\big)^2 \le L \sum_i \sigma_i^4$ bounds $\sum_i \sigma_i^4$ from below, with equality only when all $\sigma_i$ are equal: the penalty is smallest for a Jacobian that stretches no direction more than another.

</details>

The Code section checks the formula: 0.50 for equal singular values, 0.82 when half of them are three times the others. The discriminators of StyleGAN and StyleGAN2 carry the **R1 penalty** $\tfrac\gamma2\,\mathbb E_{x\sim P}\lVert\nabla_x D(x)\rVert^2$ on real images, with $\gamma = 10$ in StyleGAN ([Mescheder, Geiger and Nowozin, 2018](#references), Eq. 9); the [StarGAN note](/notes/generative-models/stargan#r1-a-penalty-on-real-images-only) shows why it helps training converge. Both penalties run only every 16 (R1) and 8 (path length) minibatches, **lazy regularization**, with FID 4.38 against 4.40 ([Karras et al., 2020](#references), Table 1).

### Without progressive growing

[Progressive growing](/notes/generative-models/gan-scaling#progan-growing-the-networks) gives StyleGAN a strong location preference for details: when a face turns, the teeth stay aligned with the camera, then jump, since each resolution, once an output, keeps producing too high frequencies. StyleGAN2 trains coarse-first with a fixed network: the generator sums upsampled RGB outputs of every resolution (**skip** connections), the discriminator is residual, and low resolutions dominate early, high ones later. With demodulation, path-length regularization and larger networks, FID on FFHQ falls from 4.40 to 2.84.

## StyleGAN3: details glued to the pixel grid

In a latent interpolation of StyleGAN2, fine detail such as hair stays fixed in pixel coordinates instead of moving with the face: **texture sticking** ([Karras et al., 2021](#references)). The network uses unintended positional references: image borders, the per-pixel noise, and **aliasing**, faint after-images of the pixel grid left by imperfect upsampling filters and by pointwise nonlinearities such as ReLU.

The fix treats every feature map as samples of a continuous, bandlimited signal. Sampling cannot tell some frequencies apart: on a grid of 8 samples per unit, $t = n/8$, and

$$
\begin{aligned}
\cos\big(2\pi \cdot 5 \tfrac n8\big) &= \cos\big(2\pi n - 2\pi \cdot 3 \tfrac n8\big) \\
&= \cos\big(2\pi \cdot 3 \tfrac n8\big),
\end{aligned}
$$

because cosine has period $2\pi$ and is even; likewise, on $s$ samples per unit, frequencies $f$ and $s - f$ give identical samples. The **Nyquist–Shannon sampling theorem** makes this a guarantee: a signal with no frequencies at or above $s/2$ is determined by its samples at rate $s$ and rebuilt from them by sinc interpolation ([Oppenheim, Willsky and Nawab, 1997](#references), Sections 7.1–7.2); by the folding above, no two frequencies below $s/2$ share their samples. A layer is **equivariant** to a shift if shifting the continuous input shifts the continuous output, so it must not create frequencies its grid cannot hold.

A ReLU breaks this rule. Take a wave of frequency 3 on 8 samples per unit, below the limit of 4. With $\theta = 2\pi \cdot 3t$, the coefficient of $\cos 2\theta$, frequency 6, in the Fourier series of $\max(0, \cos\theta)$ is

$$
\begin{aligned}
a_2 &= \frac1\pi \int_{-\pi/2}^{\pi/2} \cos\theta \cos 2\theta \, d\theta \\
&= \frac{1}{2\pi} \int_{-\pi/2}^{\pi/2} (\cos 3\theta + \cos\theta)\, d\theta \\
&= \frac{1}{2\pi}\Big(-\frac23 + 2\Big) = \frac{2}{3\pi} \approx 0.21 ,
\end{aligned}
$$

where the integral shrinks to $[-\pi/2, \pi/2]$ because the ReLU output is zero elsewhere, and the second line is the product-to-sum identity. Frequency 6 folds to $8 - 6 = 2$. The table gives the **amplitude** $\lvert \hat x_k\rvert/N$ of the discrete Fourier transform of $N$ samples: the mean at frequency 0, half the cosine coefficient elsewhere. The continuous output has amplitudes $1/\pi \approx 0.318$, $0.25$ at frequency 3 and $\tfrac12 \cdot \tfrac{2}{3\pi} \approx 0.106$ at 6; on the grid, harmonics 12, 18, 24 and higher fold too, giving the alias 0.125 and the mean 0.302. A half-pixel shift, $\tfrac1{16}$ of a unit, only changes phases in the continuous domain, where the pointwise ReLU commutes with it; on the grid the amplitudes change:

| Amplitude after ReLU | 8 per unit | 8, shifted $\tfrac1{16}$ | 16 per unit | 16, shifted $\tfrac1{32}$ |
| --- | --- | --- | --- | --- |
| frequency 0 (the mean) | 0.302 | 0.327 | 0.314 | 0.320 |
| frequency 2 (the alias) | 0.125 | 0.096 | 0.015 | 0.006 |
| frequency 3 | 0.250 | 0.250 | 0.250 | 0.250 |

The output depends on where the wave sits relative to the pixels, a positional signal the network exploits. The last two columns compute the ReLU on a grid twice as fine and keep only frequencies below 4, an ideal low-pass filter, shifting by half the finer pixel (a shift of $\tfrac1{16}$ would move a whole sample and prove nothing). The dependence shrinks about fourfold, 0.015 against 0.006, but harmonics 18 and above still fold. StyleGAN3 found twice the resolution sufficient; four times raised translation equivariance from 66.7 to 74.2 dB for 2.3 times the training time ([Karras et al., 2021](#references), Figure 3).

StyleGAN3 builds the generator from such operations: windowed-sinc upsampling, close to the ideal low-pass filter; each nonlinearity at twice the resolution between an upsampling and a filtered downsampling; exactly shiftable Fourier features instead of the learned constant; no noise inputs; a margin instead of padding. FID stays level with StyleGAN2, and detail moves with the surface. The rotation-equivariant variant costs about twice the compute, 2,248 against 1,106 GPU-hours on FFHQ at $1024^2$ (Section 4).

## Where control breaks

StyleGAN controls images it produced from a known $w$. Editing a photograph first needs a $w$ that reproduces it, **GAN inversion**, explained with its fidelity–editability trade-off in the [drag-editing note](/notes/generative-models/drag-editing#editing-a-real-photo-gan-inversion). What lies outside the generator's range cannot be reached; the path-length regularized StyleGAN2 is markedly easier to invert.

Nothing guarantees disentanglement: the separability of $\mathcal W$ stays well above its floor of 1, PPL rises again late in training, and factors such as hair style spread over several layer groups. All three papers train one model per kind of object, mostly on aligned crops.

## What changed

| | Traditional generator | InfoGAN | StyleGAN | StyleGAN2 | StyleGAN3 |
| --- | --- | --- | --- | --- | --- |
| Where the code enters | first layer | first layer, as $(z, c)$ | every layer, as AdaIN styles of $w = f(z)$ | every layer, as weight modulation | the same |
| Source of control | none | an information term | the architecture | the same | the same |
| Random detail | from $z$ | from $z$ | per-pixel noise | per-pixel noise | no noise |
| Artifact addressed | – | the code is ignored | entangled $z$ | droplets, details tied to positions | texture sticking |

## What you should remember

- A fixed prior that must cover correlated data forces an entangled map from $z$ to images.
- InfoGAN: maximize $\mathbb E \log q_\phi(c \mid G(z, c)) + H(c) \le I(c; x)$; the codes are chosen by hand.
- StyleGAN: $w = f(z)$, a learned constant, per-layer AdaIN styles, per-pixel noise; coarse layers set layout, fine ones texture.
- StyleGAN2: $w''_{ijk} = s_i w_{ijk} / \sigma_j$, exact only for independent inputs.
- StyleGAN3: run nonlinearities at twice the resolution and filter, against aliases.

## Code

A modulated convolution with one style vector per sample, the variance of $\lVert J^\top y \rVert$ behind the path-length penalty, and the aliasing of a ReLU on a pixel grid; NumPy only, about two seconds.

```python
import numpy as np
from numpy.lib.stride_tricks import sliding_window_view

rng = np.random.default_rng(0)

# 1. A modulated 3x3 convolution with one style vector per sample.
N, C, k, H = 4, 64, 3, 32                        # 4 samples, 64 channels in and out
x = rng.standard_normal((N, C, H, H))            # i.i.d. unit-variance inputs
w = rng.standard_normal((C, C, k, k)) / np.sqrt(C * k * k)   # (out, in, k, k)
s = np.exp(1.5 * rng.standard_normal((N, C)))    # styles s_i, one vector per sample
wm = w[None] * s[:, None, :, None, None]         # modulate: (N, out, in, k, k)
wd = wm / np.sqrt((wm ** 2).sum(axis=(2, 3, 4), keepdims=True) + 1e-8)   # demodulate

patches = sliding_window_view(x, (k, k), axis=(2, 3))     # (N, in, 30, 30, k, k)
for name, wt in [("modulated", wm), ("demodulated", wd)]:
    y = np.einsum("nichab,noiab->noch", patches, wt)      # per-sample weights
    sd = y.std(axis=(2, 3))
    print(f"{name:12s} channel std: min {sd.min():.2f}, max {sd.max():.2f}")
# modulated    channel std: min 1.97, max 7.12
# demodulated  channel std: min 0.92, max 1.07

# 2. The path-length penalty is the variance of |J^T y|; it is smallest for equal singular values.
L = 512
y = rng.standard_normal((20000, L))
for name, sig in [("equal", np.ones(L)), ("half 3x larger", np.r_[np.ones(256), 3 * np.ones(256)])]:
    sig = sig * np.sqrt(L / (sig ** 2).sum())            # same sum of sigma_i^2 = 512
    length = np.sqrt((sig ** 2 * y ** 2).sum(axis=1))
    print(f"{name:15s} Var|J^T y| = {length.var():.2f}, formula {(sig**4).sum() / (2 * (sig**2).sum()):.2f}")
# equal           Var|J^T y| = 0.51, formula 0.50
# half 3x larger  Var|J^T y| = 0.84, formula 0.82

# 3. Aliasing: ReLU of a frequency-3 wave on a grid, shifted by half a pixel.
def relu_spectrum(pixels_per_unit, shift):
    t = np.arange(pixels_per_unit) / pixels_per_unit
    out = np.maximum(0, np.cos(2 * np.pi * 3 * (t - shift)))
    return np.abs(np.fft.rfft(out))[:4] / pixels_per_unit   # amplitudes at frequencies 0..3

for m in [8, 16]:                                 # 8: the layer's grid; 16: twice the resolution, then low-pass
    print(m, relu_spectrum(m, 0).round(3), relu_spectrum(m, 1 / (2 * m)).round(3))   # shift by half of its pixel
# 8 [0.302 0.    0.125 0.25 ] [0.327 0.    0.096 0.25 ]
# 16 [0.314 0.    0.015 0.25 ] [0.32  0.    0.006 0.25 ]
```
