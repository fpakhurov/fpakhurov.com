Раздел анализа закончился полным набором инструментов дифференцирования: градиенты и гессианы функций от векторов, цепное правило для матриц и, в [предыдущей заметке](/ru/notes/math/multiple-integrals), замена переменных в интегралах. Обучение модели использует эти инструменты, чтобы найти минимум функции потерь. Градиент находит точки, где наклон обращается в ноль, а гессиан говорит, является ли такая точка локальным минимумом. Ни тот, ни другой не говорит, самая ли это низкая точка вообще: оба описывают функцию только вблизи точки. Эта заметка вводит свойство, которое превращает локальную информацию в глобальную, — **выпуклость** (convexity). Она открывает раздел оптимизации, и следующие три заметки строят на ней алгоритмы и задачи с ограничениями.

**Обозначения.** Векторы обозначаются строчными буквами, $x, y \in \mathbb R^n$, матрицы — прописными. $f: \mathbb R^n \to \mathbb R$ — функция с градиентом $\nabla f(x)$ и гессианом $\nabla^2 f(x)$, как в [заметке о градиентах](/ru/notes/math/gradients-jacobians-hessians). Число $\theta \in [0, 1]$ задаёт веса двух точек; $\theta x + (1 - \theta)y$ пробегает отрезок от $y$ до $x$. Для симметричной матрицы $A \succeq 0$ означает положительную полуопределённость ($v^\top A v \ge 0$ при всех $v$), а $A \succeq B$ означает $A - B \succeq 0$; $\lambda_{\min}$ и $\lambda_{\max}$ — её крайние собственные значения, как в [заметке о симметричных матрицах](/ru/notes/math/symmetric-matrices). $\lVert \cdot \rVert$ — евклидова норма.

## Отправная точка: нулевой градиент — лишь кандидат \{#baseline-a-zero-gradient-is-only-a-candidate\}

Рассмотрим функцию одной переменной

$$
f(x) = x^4 - 2x^2 + \tfrac12 x , \qquad f'(x) = 4x^3 - 4x + \tfrac12 .
$$

Её производная обращается в ноль в трёх точках, $x = -1.057$, $0.127$ и $0.930$, где $f$ принимает значения $-1.515$, $0.032$ и $-0.517$, а вторая производная $f''(x) = 12x^2 - 4$ равна $9.42$, $-3.81$ и $6.39$. Две из них — локальные минимумы. Градиентный спуск с шагом $0.05$, начатый в $x = 1.5$, останавливается в $0.930$; начатый в $-1.5$ — в $-1.057$. В обеих точках производная равна нулю, а вторая производная положительна, так что признак, который смотрит только на точку, не может отличить глобальный минимум от другого. Не может и алгоритм: он сообщает о сходимости в обоих запусках.

Для функции потерь нейронной сети с миллионами переменных нет списка критических точек, который можно было бы сравнить. Выход — сузить класс функций так, чтобы локальный признак стал глобальным. Этот класс — выпуклые функции, и сужение обходится дешевле, чем кажется: у метода наименьших квадратов, логистической регрессии, метода опорных векторов (SVM) и лассо функции потерь выпуклы.

## Выпуклые множества \{#convex-sets\}

Множество $C \subseteq \mathbb R^n$ **выпукло** (convex set), если оно содержит отрезок между любыми двумя своими точками:

$$
x, y \in C,\ \theta \in [0, 1] \quad\Longrightarrow\quad \theta x + (1 - \theta)y \in C .
$$

<ConvexSets />

Примеры, которые встречаются в машинном обучении повсюду:

- **Гиперплоскости и полупространства**, $\{x : a^\top x = b\}$ и $\{x : a^\top x \le b\}$. Если $a^\top x \le b$ и $a^\top y \le b$, то $a^\top(\theta x + (1 - \theta)y) = \theta\,a^\top x + (1 - \theta)\,a^\top y \le \theta b + (1 - \theta) b = b$. Линейный классификатор делит пространство на два полупространства.
- **Шары по норме**, $\{x : \lVert x - c\rVert \le r\}$. По неравенству треугольника $\lVert \theta(x - c) + (1 - \theta)(y - c)\rVert \le \theta r + (1 - \theta) r = r$. Тот же довод работает для любой нормы, так что шар в норме L1 из лассо тоже выпуклый.
- **Вероятностный симплекс** (probability simplex), $\Delta = \{p : p_i \ge 0,\ \sum_i p_i = 1\}$, — множество распределений на $n$ исходах и множество значений softmax.
- **Положительно полуопределённые матрицы**: если $v^\top A v \ge 0$ и $v^\top B v \ge 0$ при любом $v$, то это верно и для $\theta\,v^\top A v + (1 - \theta)\,v^\top B v$. Ковариационные матрицы и матрицы ядра лежат в этом множестве.

Невыпуклы, например, кольцо $\{1 \le \lVert x\rVert \le 2\}$, хорды которого могут проходить через дыру, и объединение двух непересекающихся кругов.

**Пересечение сохраняет выпуклость.** Если $x$ и $y$ лежат в каждом $C_i$ и каждое $C_i$ выпукло, то отрезок между ними лежит в каждом $C_i$, а значит, и в пересечении. Конечное пересечение полупространств, $\{x : A x \le b\}$, называется **многогранником** (polyhedron); допустимые множества задач линейного программирования и SVM — многогранники. Объединение выпуклость не сохраняет, как показывают два круга.

**Выпуклая оболочка.** **Выпуклая комбинация** (convex combination) точек $x_1, \dots, x_k$ — это $\sum_i \theta_i x_i$ с $\theta_i \ge 0$ и $\sum_i \theta_i = 1$, взвешенное среднее. **Выпуклая оболочка** (convex hull) $\operatorname{conv}\{x_1, \dots, x_k\}$ — множество всех выпуклых комбинаций. Она выпукла, содержит эти точки и является наименьшим таким множеством: выпуклое множество, содержащее точки, содержит и любую их выпуклую комбинацию, что доказывается индукцией по $k$ из определения. Для конечного числа точек на плоскости это многоугольник, который образовала бы натянутая вокруг них резинка.

**Разобранный пример.** Лежит ли $(1, 1)$ в выпуклой оболочке точек $(0, 0)$, $(3, 0)$ и $(0, 3)$? Решим $\theta_1 (0, 0) + \theta_2 (3, 0) + \theta_3 (0, 3) = (1, 1)$ при $\theta_1 + \theta_2 + \theta_3 = 1$: $\theta_2 = \theta_3 = \tfrac13$ и $\theta_1 = \tfrac13$, все неотрицательны, так что лежит. Для $(2, 2)$ те же уравнения дают $\theta_2 = \theta_3 = \tfrac23$ и $\theta_1 = -\tfrac13$. Веса здесь единственны, потому что три точки, не лежащие на одной прямой, образуют треугольник, и один из весов отрицателен, так что $(2, 2)$ лежит снаружи. Вероятностный симплекс — выпуклая оболочка стандартных базисных векторов, а [заметка о двойственности](/ru/notes/math/duality) показывает, что SVM с жёстким зазором ищет две ближайшие точки выпуклых оболочек двух своих классов.

## Выпуклые функции \{#convex-functions\}

Функция $f$, заданная на выпуклом множестве, **выпукла** (convex function), если любая хорда лежит на её графике или выше него:

$$
f\big(\theta x + (1 - \theta)y\big) \le \theta f(x) + (1 - \theta) f(y) \qquad \text{для всех } x, y,\ \theta \in [0, 1] .
$$

Она **строго выпукла** (strictly convex), если неравенство строгое при $x \ne y$ и $0 \lt \theta \lt 1$, и **вогнута** (concave), если выпукла $-f$. Равносильно: область над графиком, **надграфик** (epigraph) $\{(x, t) : t \ge f(x)\}$, — выпуклое множество; два определения переводятся одно в другое через точки $(x, f(x))$ и $(y, f(y))$. По индукции неравенство переносится с двух точек на любую выпуклую комбинацию, $f(\sum_i \theta_i x_i) \le \sum_i \theta_i f(x_i)$, — это **неравенство Йенсена** (Jensen's inequality); если читать веса как вероятности, оно утверждает $f(E[X]) \le E[f(X)]$ — в этой форме оно даёт оценку логарифма правдоподобия в [заметке о VAE](/ru/notes/generative-models/vae#where-the-elbo-comes-from), где логарифм вогнут и неравенство меняет знак.

**Разобранный пример.** Для $f(x) = x^2$, $x = 0$, $y = 2$ и $\theta = \tfrac12$ значение функции в середине равно $f(1) = 1$, а хорды в середине — $\tfrac12 \cdot 0 + \tfrac12 \cdot 4 = 2$. В общем случае зазор равен $\theta f(x) + (1 - \theta) f(y) - f(\theta x + (1 - \theta) y) = \theta(1 - \theta)(x - y)^2$, здесь $\tfrac14 \cdot 4 = 1$: он неотрицателен для любой пары, так что $x^2$ выпукла, и положителен при $x \ne y$, так что она строго выпукла. Любая норма выпукла по неравенству треугольника, как и шары выше.

Проверять хорды пара за парой в многомерном случае непрактично. Для дифференцируемых функций два признака используют вместо этого производные.

## Условие первого порядка: касательная лежит ниже \{#the-first-order-condition-the-tangent-lies-below\}

Идея: у выпуклой функции хорда из $x$ в сторону $y$ лежит над графиком, а когда хорда стягивается в точку, она превращается в касательную. Поэтому касательная в любой точке лежит ниже всего графика. Для дифференцируемой $f$ на открытом выпуклом множестве

$$
\boxed{\; f \text{ выпукла} \iff f(y) \ge f(x) + \nabla f(x)^\top (y - x) \quad \text{для всех } x, y . \;}
$$

<TangentBelow />

Почему выпуклость даёт оценку касательной. Зафиксируем $x$ и $y$ и возьмём $0 \lt \theta \le 1$; точка $x + \theta(y - x) = \theta y + (1 - \theta)x$ лежит на отрезке:

$$
\begin{aligned}
f\big(x + \theta(y - x)\big) &\le \theta f(y) + (1 - \theta) f(x) && \text{выпуклость с весами } \theta,\ 1 - \theta \\
f(y) &\ge f(x) + \frac{f\big(x + \theta(y - x)\big) - f(x)}{\theta} && \text{вычесть } f(x) \text{, разделить на } \theta \gt 0 \\
&\to f(x) + \nabla f(x)^\top (y - x) \quad (\theta \to 0) && \text{отношение — производная по направлению.}
\end{aligned}
$$

Последняя строка — цепное правило для $t \mapsto f(x + t(y - x))$ в точке $t = 0$, производная которой равна $\nabla f(x)^\top(y - x)$. Неравенство выполнено при каждом $\theta$, поэтому сохраняется в пределе. Обратное утверждение доказывается так же коротко: положим $z = \theta x + (1 - \theta)y$, запишем оценку касательной в $z$ один раз в сторону $x$ и один раз в сторону $y$, умножим два неравенства на $\theta$ и $1 - \theta$ и сложим. Члены с градиентом сокращаются, потому что $\theta(x - z) + (1 - \theta)(y - z) = 0$, и остаётся $\theta f(x) + (1 - \theta) f(y) \ge f(z)$.

**Разобранный пример.** У $f(x) = e^x$ в точке $x = 0$ касательная $1 + y$, поэтому оценка утверждает $e^y \ge 1 + y$ при любом $y$: при $y = 1$ имеем $2.718 \ge 2$, при $y = -2$ — $0.135 \ge -1$. Функция из начала заметки признак не проходит. В её локальном минимуме $x = 0.930$ касательная — горизонтальная прямая на высоте $-0.517$, а в точке $x = -1.057$ график лежит на $0.998$ ниже неё.

Эта оценка и есть причина, по которой выпуклость важна. Подставим в неё $\nabla f(x^*) = 0$: $f(y) \ge f(x^*)$ при любом $y$. **У дифференцируемой выпуклой функции точка с нулевым градиентом — глобальный минимум.** Локальный признак стал глобальным.

## Условие второго порядка: положительно полуопределённый гессиан \{#the-second-order-condition-a-positive-semidefinite-hessian\}

Идея: функция выпукла ровно тогда, когда она выпукла вдоль каждой прямой, а вдоль прямой её вторая производная — квадратичная форма гессиана. Для дважды дифференцируемой $f$ на открытом выпуклом множестве

$$
\boxed{\; f \text{ выпукла} \iff \nabla^2 f(x) \succeq 0 \quad \text{для всех } x . \;}
$$

Почему. Ограничим $f$ на прямую через $x$ в направлении $v$, $g(t) = f(x + t v)$. Хорды $g$ — это хорды $f$, поэтому $f$ выпукла тогда и только тогда, когда выпукла каждая такая $g$. Для $g$:

$$
\begin{aligned}
g'(t) &= \nabla f(x + t v)^\top v && \text{цепное правило} \\
g''(t) &= v^\top \nabla^2 f(x + t v)\, v && \text{снова цепное правило, для каждой компоненты } \nabla f \\
g \text{ выпукла} &\iff g'' \ge 0 \text{ всюду} && \text{одна переменная: } g' \text{ не убывает, признак касательной выше.}
\end{aligned}
$$

Последняя строка — факт для одной переменной: $g'' \ge 0$ означает, что $g'$ нигде не убывает, и тогда $g(s) - g(t) - g'(t)(s - t) = \int_t^s \big(g'(r) - g'(t)\big)\,dr \ge 0$ по обе стороны от $t$, а это оценка касательной; обратно, у выпуклой $g$ производная $g'$ не убывает — это следует из оценки касательной, записанной в $s$ и в $t$ и сложенной. Требование $g'' \ge 0$ в каждой точке и в каждом направлении $v$ и есть $\nabla^2 f \succeq 0$ всюду. Если всюду $\nabla^2 f(x) \succ 0$ (положительная определённость), то $f$ строго выпукла; обратное неверно, поскольку $x^4$ строго выпукла, а $f''(0) = 0$.

**Разобранный пример.** У квадратичной функции $f(x) = \tfrac12 x^\top A x + b^\top x$ с симметричной $A$ постоянный гессиан $A$, поэтому она выпукла ровно тогда, когда $A \succeq 0$. Для $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$ собственные значения равны 1 и 3, оба положительны: функция выпукла. Для $A = \begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}$ они равны 3 и $-1$, и это обнаруживает направление $v = (1, -1)$ с $v^\top A v = -2$: при $b = 0$ имеем $f(\pm v) = -1$, а в середине $f(0) = 0$, выше хорды.

**Разобранный пример: log-sum-exp.** Функция $\operatorname{lse}(z) = \log\sum_i e^{z_i}$, которая превращает логиты в нормирующий множитель softmax, имеет градиент $p = \operatorname{softmax}(z)$ и гессиан $\operatorname{diag}(p) - p p^\top$. Для любого $v$

$$
v^\top \big(\operatorname{diag}(p) - p p^\top\big)v = \sum_i p_i v_i^2 - \Big(\sum_i p_i v_i\Big)^2 \ge 0 ,
$$

потому что правая часть — дисперсия случайной величины, принимающей значение $v_i$ с вероятностью $p_i$. Для $z = (1, 2, 3)$ имеем $p = (0.090, 0.245, 0.665)$, собственные значения гессиана равны $0$, $0.119$ и $0.371$, а при $v = (1, 0, -1)$ обе части равны $0.424$. Нулевое собственное значение отвечает $v = (1, 1, 1)$: прибавление одной и той же константы ко всем логитам ничего не меняет, так что lse выпукла, но не строго.

## Операции, сохраняющие выпуклость \{#operations-that-preserve-convexity\}

Большинство функций потерь не проверяют с нуля. Их собирают из выпуклых частей операциями, которые сохраняют выпуклость, и каждая из них проверяется одной строкой алгебры из определения через хорды:

- **Неотрицательные взвешенные суммы.** Если $f_1, \dots, f_k$ выпуклы и $w_i \ge 0$, то $\sum_i w_i f_i$ выпукла: сложим неравенства для хорд с весами $w_i$. Средняя функция потерь по обучающим примерам плюс выпуклый штраф выпукла.
- **Композиция с аффинным отображением.** Если $f$ выпукла, то выпукла и $x \mapsto f(A x + b)$, потому что $A(\theta x + (1 - \theta)y) + b = \theta(A x + b) + (1 - \theta)(A y + b)$. Выпуклая функция потерь от предсказания линейной модели выпукла по весам.
- **Поточечный максимум.** Если $f_1, \dots, f_k$ выпуклы, то выпукла и $\max_i f_i$: каждая $f_i$ в смешанной точке не больше хорды $f_i$, а та не больше хорды максимума. Надграфик максимума — пересечение надграфиков. Кусочно-линейная функция $\max(0, 1 - m)$ (hinge) — максимум двух аффинных функций.
- **Композиция с выпуклой неубывающей функцией.** Если $g$ выпукла, а $h: \mathbb R \to \mathbb R$ выпукла и не убывает, то $h(g(x))$ выпукла: $h(g(\theta x + (1 - \theta)y)) \le h(\theta g(x) + (1 - \theta) g(y)) \le \theta h(g(x)) + (1 - \theta) h(g(y))$, первый шаг — потому что $h$ не убывает, второй — потому что $h$ выпукла. Поэтому выпукла $e^{g(x)}$, а также $\lVert A x - b\rVert^2$: доводу нужно, чтобы $h$ не убывала лишь на значениях $g$, а $h(t) = t^2$ не убывает при $t \ge 0$, то есть на значениях нормы.

Произведение выпуклых функций, их разность или композиция в неправильном порядке не обязаны быть выпуклыми: $x$ и $-x$ выпуклы, но их произведение $-x^2$ — нет, а $(ab - 1)^2$, квадрат ошибки произведения двух весов, — контрпример из последнего раздела.

## Почему каждый локальный минимум глобален \{#why-every-local-minimum-is-global\}

<aside class="callout"><strong>Ключевая идея.</strong> У выпуклой функции хорда из точки в сторону любой более низкой точки прошла бы под графиком вблизи первой точки. Поэтому ни одна точка не может быть локальным минимумом, не будучи глобальным, а у дифференцируемых выпуклых функций нулевой градиент удостоверяет глобальный минимум.</aside>

Точка $x^*$ — **локальный минимум** (local minimum), если $f(x^*) \le f(x)$ для всех $x$ из некоторого шара $\lVert x - x^*\rVert \le r$ с $r > 0$. Утверждение для выпуклой $f$ на выпуклом множестве $C$:

$$
\boxed{\; x^* \text{ — локальный минимум выпуклой } f \text{ на } C \ \Longrightarrow\ f(x^*) \le f(y) \text{ для любого } y \in C . \;}
$$

Почему. Предположим, что у некоторого $y \in C$ значение $f(y) \lt f(x^*)$. Пройдём от $x^*$ малую долю $\theta$ пути к $y$, в точку $z = (1 - \theta)x^* + \theta y$, где $\theta$ настолько мало, что $\lVert z - x^*\rVert = \theta\lVert y - x^*\rVert \le r$:

$$
\begin{aligned}
f(z) &\le (1 - \theta) f(x^*) + \theta f(y) && \text{выпуклость; } z \in C \text{, потому что } C \text{ выпукло} \\
&\lt (1 - \theta) f(x^*) + \theta f(x^*) && f(y) \lt f(x^*) \text{ и } \theta \gt 0 \\
&= f(x^*) && \text{приводим подобные.}
\end{aligned}
$$

Значит, $z$ лежит внутри шара и строго ниже $x^*$, что противоречит локальной минимальности $x^*$. Следовательно, такого $y$ нет. Из той же хорды вытекают два следствия. Множество точек минимума выпукло: если $x$ и $y$ обе достигают минимального значения $p$, хорда даёт $f \le p$ на отрезке, так что его достигает весь отрезок. И у строго выпуклой функции не больше одной точки минимума: при двух различных середина была бы строго ниже обеих.

**Разобранный пример.** У метода наименьших квадратов с двумя одинаковыми столбцами признаков выпуклая функция потерь $(w_1 + w_2 - 1)^2$ для целевого значения 1 и признака, равного 1: её точки минимума — вся прямая $w_1 + w_2 = 1$, выпуклое множество, и градиентный спуск останавливается где-то на ней, всегда на минимальном значении 0. Штраф $\lambda(w_1^2 + w_2^2)$ делает функцию потерь строго выпуклой и оставляет одну точку минимума, $w_1 = w_2 = 1/(2 + \lambda)$, то есть $(0.476, 0.476)$ при $\lambda = 0.1$. Выпуклость не обещает, что минимум существует: $e^x$ выпукла и точки минимума не имеет. Для существования нужно больше, например сильная выпуклость из следующего раздела или замкнутое ограниченное допустимое множество.

## Сильная выпуклость и гладкость \{#strong-convexity-and-smoothness\}

Выпуклость говорит, что функция лежит над своими касательными. Две количественные версии говорят, насколько — не меньше чем на сколько и не больше чем на сколько, — и они задают скорость каждого алгоритма из [следующей заметки](/ru/notes/math/unconstrained-optimization).

Дифференцируемая $f$ называется **$\mu$-сильно выпуклой** (μ-strongly convex), $\mu \gt 0$, если она лежит над своими касательными не меньше чем на параболу:

$$
f(y) \ge f(x) + \nabla f(x)^\top(y - x) + \frac\mu2 \lVert y - x\rVert^2 .
$$

Равносильно: функция $f(x) - \frac\mu2\lVert x\rVert^2$ выпукла, а для дважды дифференцируемой $f$ — $\nabla^2 f(x) \succeq \mu I$: каждое собственное значение гессиана всюду не меньше $\mu$. Первая равносильность — признак касательной для $f - \frac\mu2\lVert\cdot\rVert^2$, градиент которой равен $\nabla f(x) - \mu x$; вторая — признак по гессиану для неё же.

Дифференцируемая $f$ называется **$L$-гладкой** (L-smooth), если её градиент $L$-липшицев (Lipschitz gradient), $\lVert\nabla f(x) - \nabla f(y)\rVert \le L\lVert x - y\rVert$; для дважды дифференцируемой $f$ это $-LI \preceq \nabla^2 f(x) \preceq LI$. Идея главного следствия: градиент не может меняться быстрее чем на $L$ на единицу расстояния, поэтому функция не может подниматься над своей касательной быстрее параболы кривизны $L$:

$$
\boxed{\; f(y) \le f(x) + \nabla f(x)^\top(y - x) + \frac L2 \lVert y - x\rVert^2 . \;}
$$

Почему. Запишем отклонение от касательной как интеграл вдоль отрезка $x_t = x + t(y - x)$:

$$
\begin{aligned}
f(y) - f(x) - \nabla f(x)^\top(y - x) &= \int_0^1 \big(\nabla f(x_t) - \nabla f(x)\big)^\top (y - x)\, dt && \text{формула Ньютона–Лейбница для } t \mapsto f(x_t) \\
&\le \int_0^1 \lVert\nabla f(x_t) - \nabla f(x)\rVert\, \lVert y - x\rVert\, dt && \text{Коши–Буняковский} \\
&\le \int_0^1 L\, t\, \lVert y - x\rVert^2\, dt && \text{липшицевость, } \lVert x_t - x\rVert = t\lVert y - x\rVert \\
&= \frac L2 \lVert y - x\rVert^2 && \textstyle\int_0^1 t\, dt = \frac12 .
\end{aligned}
$$

Первая строка использует $\frac{d}{dt} f(x_t) = \nabla f(x_t)^\top(y - x)$, а постоянная $\nabla f(x)^\top(y - x)$ интегрируется сама в себя. Функция, которая одновременно сильно выпукла и гладка, зажата вокруг каждой касательной между двумя параболами кривизн $\mu$ и $L$. Их отношение

$$
\kappa = \frac{L}{\mu} \ge 1
$$

называется **числом обусловленности** (condition number) $f$. Для квадратичной функции это $\lambda_{\max}(A)/\lambda_{\min}(A)$ — число обусловленности матрицы, которое [заметка об обусловленности](/ru/notes/math/conditioning-and-stability) изучает с вычислительной стороны.

**Разобранный пример.** Для $f(x) = \tfrac12x^\top A x$ с $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$ имеем $\mu = 1$, $L = 3$ и $\kappa = 3$. От $x = 0$ к $y = (1, 0)$: касательная равна 0, $f(y) = 1$, а две параболы дают $0.5 \le 1 \le 1.5$.

**Насколько далеко до минимума?** Сильная выпуклость превращает малый градиент в гарантию. Идея: нижняя парабола в $x$ не может опуститься ниже $f(x) - \lVert\nabla f(x)\rVert^2/(2\mu)$, а минимальное значение $f^* = f(x^*)$ лежит на ней или выше:

$$
\boxed{\; f(x) - f^* \le \frac{1}{2\mu}\lVert\nabla f(x)\rVert^2 . \;}
$$

$$
\begin{aligned}
f^* = f(x^*) &\ge f(x) + \nabla f(x)^\top(x^* - x) + \frac\mu2\lVert x^* - x\rVert^2 && \text{сильная выпуклость в } x \text{ в сторону } x^* \\
&\ge \min_{y} \Big( f(x) + \nabla f(x)^\top(y - x) + \frac\mu2\lVert y - x\rVert^2 \Big) && \text{значение не меньше минимума} \\
&= f(x) - \frac{1}{2\mu}\lVert\nabla f(x)\rVert^2 && \text{точка минимума } y - x = -\nabla f(x)/\mu .
\end{aligned}
$$

Последняя строка приравнивает нулю градиент параболы, $\nabla f(x) + \mu(y - x)$, и подставляет решение. Это **неравенство Поляка–Лоясевича** (Polyak–Łojasiewicz inequality), и следующая заметка превращает его в линейную скорость сходимости градиентного спуска. Для квадратичной функции выше в точке $x = (1, 1)$ имеем $f = 3$, $\nabla f = (3, 3)$, и оценка равна $18/2 = 9 \ge 3$.

**Откуда берутся $\mu$ и $L$ в машинном обучении.** Гребневый штраф $\lambda\lVert w\rVert^2$ прибавляет $2\lambda I$ к любому гессиану, поэтому выпуклая функция потерь плюс гребневый штраф $2\lambda$-сильно выпукла: [заметка о регуляризации](/ru/notes/ml/regularization) использует штраф ради статистики, а он заодно исправляет геометрию. У логистической функции потерь гессиан $\frac1n X^\top S X$ с $S = \operatorname{diag}(p_i(1 - p_i))$, и $p(1 - p) \le \tfrac14$, поэтому она $L$-гладкая с $L = \lambda_{\max}(X^\top X)/(4n)$. Её наименьшее собственное значение гессиана стремится к 0 вдали от начала координат, где предсказания насыщаются, так что без штрафа она строго выпукла, но не сильно выпукла.

## Какие функции потерь машинного обучения выпуклы \{#which-machine-learning-losses-are-convex\}

Признаки выше решают вопрос для стандартных функций потерь линейных моделей, все — по весам $w$ при фиксированных данных:

| Функция потерь | Почему выпукла | Сильно выпукла? |
| --- | --- | --- |
| наименьшие квадраты $\frac1n\lVert X w - y\rVert^2$ | гессиан $\frac2n X^\top X \succeq 0$ ([метод наименьших квадратов](/ru/notes/ml/least-squares)) | если у $X$ полный ранг по столбцам |
| логистическая $\frac1n\sum_i \log(1 + e^{-y_i w^\top x_i})$ | выпуклая функция от аффинного отображения; гессиан $\frac1n X^\top S X$ ([логистическая регрессия](/ru/notes/ml/logistic-regression#the-gradient-residuals-times-inputs)) | нет, только со штрафом |
| кросс-энтропия softmax | lse от аффинного отображения минус линейный член | нет: сдвиг всех логитов не меняет её |
| кусочно-линейная (hinge) $\frac1n\sum_i \max(0, 1 - y_i w^\top x_i)$ | максимум аффинных функций ([SVM](/ru/notes/ml/support-vector-machines)) | нет; к тому же недифференцируема |
| гребневый штраф $\lambda\lVert w\rVert^2$, лассо $\lambda\lVert w\rVert_1$ | квадрат нормы, норма | гребневый да ($2\lambda$), лассо нет |

**Что не выпукло.** Нейронная сеть — композиция линейных отображений с нелинейными активациями, и функция потерь как функция всех весов не выпукла. Простейший пример — «сеть» с одним скрытым нейроном без активации, $\hat y = a\,b\,x$, обученная на одном примере $x = y = 1$:

$$
f(a, b) = (ab - 1)^2 , \qquad \nabla^2 f(a, b) = \begin{pmatrix} 2b^2 & 4ab - 2 \\ 4ab - 2 & 2a^2 \end{pmatrix} .
$$

И $(1, 1)$, и $(-1, -1)$ подходят точно, с потерями 0, но их середина $(0, 0)$ имеет потери 1, выше хорды. Гессиан там имеет собственные значения $2$ и $-2$: начало координат — седловая точка с нулевым градиентом. Та же симметрия знаков, а также симметрия перестановок скрытых нейронов есть в любой сети, как разбирает [курс глубокого обучения](/ru/notes/deep-learning/optimizing-deep-networks#many-equivalent-minima-so-not-convex). Матричная факторизация, $k$-средних и смеси распределений невыпуклы по той же причине: у модели со взаимозаменяемыми частями несколько равноценных точек минимума и худшие точки между ними. Для них гарантии следующей заметки сжимаются до «градиент становится малым», и начальная точка имеет значение.

## Что изменилось \{#what-changed\}

| | Дифференцируемая функция общего вида | Выпуклая функция |
| --- | --- | --- |
| Нулевой градиент | кандидат: минимум, максимум или седло | глобальный минимум |
| Локальные минимумы | возможно, много, с разными значениями | все глобальны; точки минимума образуют выпуклое множество |
| Касательная в точке | описывает $f$ только вблизи | лежит ниже $f$ всюду |
| Гессиан | любая симметричная матрица | положительно полуопределён всюду |
| С $\mu$ и $L$ | гарантий нет | $f(x) - f^* \le \lVert\nabla f\rVert^2/(2\mu)$; число обусловленности $\kappa = L/\mu$ |
| Типичные функции потерь ML | нейронные сети, факторизации, смеси | наименьшие квадраты, логистическая, softmax, hinge, гребневый штраф, лассо |

## Ограничения \{#limitations\}

- **Выпуклость ничего не говорит о скорости.** Выпуклая функция может быть очень пологой или очень плохо обусловленной; это измеряют $\mu$ и $L$, а следующая заметка показывает, что число шагов градиентного спуска растёт с $\kappa$.
- **Минимум может не существовать.** У выпуклых функций, таких как $e^x$ или логистическая функция потерь на линейно разделимых данных, есть инфимум, которого не достигает ни одна точка.
- **Недифференцируемым выпуклым функциям**, таким как hinge и норма L1, вместо градиентов нужны субградиенты; оценка касательной превращается в семейство опорных прямых.
- **Глубокое обучение невыпукло.** Теория здесь описывает линейные модели и выпуклые подзадачи внутри других методов (M-шаг EM, один слой при фиксированных остальных), а не обучение сети.

## Что нужно запомнить \{#what-you-should-remember\}

- Множество выпукло, если содержит каждую свою хорду; пересечение выпуклых множеств выпукло; выпуклая оболочка — множество выпуклых комбинаций.
- Функция выпукла, если каждая хорда лежит над её графиком; равносильно, каждая касательная лежит под ним, или, для дважды дифференцируемой функции, её гессиан всюду положительно полуопределён.
- Неотрицательные суммы, аффинные подстановки, поточечные максимумы и выпуклые неубывающие внешние функции сохраняют выпуклость.
- У выпуклых функций каждый локальный минимум глобален, а нулевой градиент удостоверяет глобальную оптимальность.
- $\mu$-сильная выпуклость и $L$-гладкость зажимают $f$ вокруг каждой касательной между параболами кривизн $\mu$ и $L$; $\kappa = L/\mu$; $f(x) - f^* \le \lVert\nabla f(x)\rVert^2/(2\mu)$.
- Наименьшие квадраты, логистическая функция потерь и кросс-энтропия softmax, hinge и обычные штрафы выпуклы; нейронные сети, факторизации и смеси — нет.

## Код \{#code\}

Отправная точка, проверка хорд на трёх выпуклых функциях потерь и одной невыпуклой, признаки касательной и гессиана, зажатие между параболами и неравенство Поляка–Лоясевича, на NumPy. Последние цифры могут немного отличаться на разных платформах и версиях библиотек.

```python
import numpy as np
rng = np.random.default_rng(0)

# отправная точка: у f(x) = x^4 - 2x^2 + x/2 два локальных минимума; градиентный спуск находит ближайший к старту
f = lambda x: x**4 - 2 * x**2 + 0.5 * x
df = lambda x: 4 * x**3 - 4 * x + 0.5
crit = np.sort(np.roots([4, 0, -4, 0.5]).real)
print(crit.round(3), f(crit).round(3), (12 * crit**2 - 4).round(2))   # стационарные точки, значения, f''
for x in (1.5, -1.5):
    x0 = x
    for _ in range(2000):
        x -= 0.05 * df(x)
    print(x0, round(x, 3), round(f(x), 3))
# [-1.057  0.127  0.93 ] [-1.515  0.032 -0.517] [ 9.42 -3.81  6.39]
# 1.5 0.93 -0.517 | -1.5 -1.057 -1.515

# проверка хорд f(t u + (1 - t) v) <= t f(u) + (1 - t) f(v) на 10 000 случайных пар
X = rng.normal(size=(50, 3)); y = np.sign(rng.normal(size=50))
losses = {
    'least squares': lambda w: np.mean((X @ w - y) ** 2),
    'logistic': lambda w: np.mean(np.logaddexp(0, -y * (X @ w))),
    'hinge': lambda w: np.mean(np.maximum(0, 1 - y * (X @ w))),
    '(ab - 1)^2': lambda w: (w[0] * w[1] - 1) ** 2,
}
for name, L in losses.items():
    bad = 0
    for _ in range(10_000):
        u, v, t = rng.normal(size=3) * 2, rng.normal(size=3) * 2, rng.uniform()
        bad += L(t * u + (1 - t) * v) > t * L(u) + (1 - t) * L(v) + 1e-12
    print(name, bad)
# least squares 0 | logistic 0 | hinge 0 | (ab - 1)^2 1779

# (ab - 1)^2: две точки минимума, худшая середина и знаконеопределённый гессиан в ней
g = losses['(ab - 1)^2']
print(g(np.array([1., 1, 0])), g(np.array([-1., -1, 0])), g(np.zeros(3)), np.linalg.eigvalsh([[0, -2], [-2, 0]]))
# 0.0 0.0 1.0 [-2.  2.]

# касательная лежит ниже: e^y >= 1 + y; в локальном минимуме функции из начала заметки горизонтальная касательная — нет
print(np.exp(1.0) - 2, f(crit[0]) - f(crit[2]))
# 0.7182818284590451 -0.9980051329904565

# гессиан log-sum-exp равен diag(p) - p p^T, это ковариационная матрица
z = np.array([1., 2, 3]); p = np.exp(z) / np.exp(z).sum()
H = np.diag(p) - np.outer(p, p); v = np.array([1., 0, -1])
print(p.round(4), np.linalg.eigvalsh(H).round(4), round(v @ H @ v, 4), round(p @ v**2 - (p @ v) ** 2, 4))
# [0.09   0.2447 0.6652] [-0.      0.1186  0.3709] 0.4244 0.4244

# mu и L квадратичной функции и зажатие mu/2 |d|^2 <= f(x + d) - f(x) - grad^T d <= L/2 |d|^2
A = np.array([[2., 1], [1, 2]]); mu, L = np.linalg.eigvalsh(A)
q = lambda x: 0.5 * x @ A @ x
ok = 0
for _ in range(10_000):
    x, d = rng.normal(size=2), rng.normal(size=2)
    gap = q(x + d) - q(x) - (A @ x) @ d
    ok += mu / 2 * d @ d - 1e-12 <= gap <= L / 2 * d @ d + 1e-12
print(mu, L, L / mu, ok)
# 1.0 3.0 3.0 10000

# неравенство Поляка-Лоясевича f(w) - f* <= |grad f(w)|^2 / (2 mu) для логистической функции потерь + (lam/2)|w|^2, mu = lam
lam = 0.1
F = lambda w: np.mean(np.logaddexp(0, -y * (X @ w))) + lam / 2 * w @ w
G = lambda w: -X.T @ (y / (1 + np.exp(y * (X @ w)))) / len(y) + lam * w
w = np.zeros(3)
for _ in range(20):                                   # метод Ньютона находит точку минимума с машинной точностью
    p_ = 1 / (1 + np.exp(-(X @ w)))
    w -= np.linalg.solve((X.T * (p_ * (1 - p_))) @ X / len(y) + lam * np.eye(3), G(w))
Fs = F(w)
ratios = [(F(u) - Fs) / (G(u) @ G(u) / (2 * lam)) for u in rng.normal(size=(1000, 3)) * 3]
print(round(max(ratios), 3))                           # не больше 1: оценка выполнена в каждой выбранной точке
# 0.9

# выпуклая оболочка (0,0), (3,0), (0,3): веса точки (1,1) и точки (2,2)
P = np.array([[0., 3, 0], [0, 0, 3], [1, 1, 1]])      # столбцы — точки, со строкой единиц для суммы = 1
print(np.linalg.solve(P, [1, 1, 1]).round(3), np.linalg.solve(P, [2, 2, 1]).round(3))
# [0.333 0.333 0.333] [-0.333  0.667  0.667]
```
