[Предыдущая заметка](/ru/notes/math/unconstrained-optimization) минимизировала функции на всём $\mathbb R^n$, где у минимума нулевой градиент. Многие задачи машинного обучения ограничивают переменные. Вектор вероятностей должен лежать на симплексе, первая главная компонента — лучшее направление среди единичных векторов, а SVM требует, чтобы каждая обучающая точка лежала по правильную сторону своего зазора. В условном минимуме градиент не обязан обращаться в ноль: функция может продолжать убывать, но только в направлениях, которые запрещают ограничения. Эта заметка превращает это наблюдение в уравнения: условия Лагранжа для ограничений-равенств и условия Каруша–Куна–Таккера (ККТ, Karush–Kuhn–Tucker conditions) для неравенств.

**Обозначения.** Задача имеет вид

$$
\min_{x \in \mathbb R^n} f(x) \quad \text{при условиях} \quad g_i(x) \le 0,\ i = 1, \dots, m, \qquad h_j(x) = 0,\ j = 1, \dots, p ,
$$

с дифференцируемыми $f$, $g_i$ и $h_j$. Точка, удовлетворяющая всем ограничениям, называется **допустимой** (feasible). Каждому неравенству соответствует множитель $\lambda_i$, каждому равенству — множитель $\nu_j$; они собраны в $\lambda \in \mathbb R^m$ и $\nu \in \mathbb R^p$. Неравенство **активно** (active) в $x$, если $g_i(x) = 0$, и **неактивно** (inactive), если $g_i(x) \lt 0$.

## Отправная точка: исключить ограничение \{#baseline-eliminate-the-constraint\}

Минимизируем $f(x) = x_1^2 + 2x_2^2$ при условии $x_1 + x_2 = 1$. Ограничение можно разрешить относительно одной переменной, $x_1 = 1 - x_2$, и останется задача без ограничений с одной переменной:

$$
\varphi(x_2) = (1 - x_2)^2 + 2x_2^2 , \qquad \varphi'(x_2) = -2(1 - x_2) + 4x_2 = 0 \ \Longrightarrow\ x_2 = \tfrac13,\ x_1 = \tfrac23,\ f = \tfrac23 .
$$

Исключение работает, когда ограничение разрешается явно и глобально. На единичной окружности $x_1^2 + x_2^2 = 1$ оно даёт две ветви $x_1 = \pm\sqrt{1 - x_2^2}$ с бесконечным наклоном на концах. С неравенствами $x_i \ge 0$ симплекса оно превращается в перебор случаев — какие координаты равны нулю, — $2^n$ случаев в размерности $n$. У SVM по одному неравенству на каждую обучающую точку. Нужен метод, который сохраняет все переменные и обращается со всеми ограничениями одинаково.

## Ограничения-равенства: градиент параллелен нормали \{#equality-constraints-the-gradient-is-parallel-to-the-normal\}

<LagrangeGeometry />

Идея: в условном минимуме ни одно направление, остающееся на поверхности ограничения, не может уменьшить $f$ в первом порядке, поэтому градиент $f$ перпендикулярен поверхности — как и градиент ограничения. Два вектора, перпендикулярные одной и той же поверхности размерности $n - 1$, параллельны. Для одного ограничения $h(x) = 0$ с $\nabla h(x^*) \ne 0$ локальный минимум $x^*$ удовлетворяет условию

$$
\boxed{\; \nabla f(x^*) + \nu\,\nabla h(x^*) = 0 , \qquad h(x^*) = 0 \quad \text{при некотором } \nu \in \mathbb R . \;}
$$

Почему. Возьмём любую гладкую кривую $x(t)$ на поверхности с $x(0) = x^*$ и скоростью $x'(0) = v$:

$$
\begin{aligned}
h(x(t)) = 0 \text{ при всех } t \ &\Longrightarrow\ \nabla h(x^*)^\top v = 0 && \text{цепное правило при } t = 0 \\
f(x(t)) \ge f(x^*) \text{ вблизи } t = 0 \ &\Longrightarrow\ \nabla f(x^*)^\top v = 0 && \text{у минимума по одной переменной } t \text{ нулевая производная} \\
\{v : \nabla h^\top v = 0\} &\subseteq \{v : \nabla f^\top v = 0\} && \text{каждый такой } v \text{ — скорость некоторой кривой на поверхности} \\
\nabla f(x^*) &= -\nu\,\nabla h(x^*) && \text{только кратные } \nabla h \text{ ортогональны всему } \nabla h^\perp .
\end{aligned}
$$

Третья строка — то место, где нужно $\nabla h(x^*) \ne 0$: тогда по теореме о неявной функции поверхность вблизи $x^*$ гладкая, и каждое направление, ортогональное $\nabla h$, касается её. С несколькими ограничениями $h_1, \dots, h_p$ тот же довод с касательными направлениями $\{v : \nabla h_j^\top v = 0 \text{ при всех } j\}$ даёт $\nabla f(x^*) + \sum_j \nu_j\nabla h_j(x^*) = 0$ при условии, что градиенты $\nabla h_j(x^*)$ линейно независимы. Эта оговорка — **условие регулярности** (constraint qualification); без него множителей может не существовать.

**Разобранный пример.** Для задачи из начала заметки $\nabla f = (2x_1, 4x_2)$ и $\nabla h = (1, 1)$. В $x^* = (\tfrac23, \tfrac13)$ имеем $\nabla f = (\tfrac43, \tfrac43)$, параллельный $(1, 1)$, с $\nu = -\tfrac43$. А в допустимой точке $(0, 1)$ градиент $\nabla f = (0, 4)$ не параллелен $(1, 1)$. Его составляющая вдоль прямой, в единичном направлении $v = (1, -1)/\sqrt2$, равна $\nabla f^\top v = -4/\sqrt2 = -2.83$, так что движение вдоль прямой в сторону больших $x_1$ уменьшает $f$: эта точка — не минимум. На рисунке линия уровня $f$ через $x^*$ касается прямой, а через $(0, 1)$ — пересекает её.

## Функция Лагранжа \{#the-lagrangian\}

Эти условия — условия стационарности одной функции. **Функция Лагранжа** (лагранжиан, Lagrangian) прибавляет к целевой функции каждое ограничение с его множителем:

$$
\mathcal L(x, \nu) = f(x) + \sum_{j=1}^p \nu_j h_j(x) .
$$

Её градиент по $x$ равен $\nabla f + \sum_j \nu_j\nabla h_j$, а градиент по $\nu$ — вектор значений ограничений $h_j(x)$. Приравнивание обоих нулю даёт условия в рамке: задача с ограничениями от $n$ переменных становится системой из $n + p$ уравнений с $n + p$ неизвестными, и ограничений не остаётся. Для задачи из начала заметки это $2x_1 + \nu = 0$, $4x_2 + \nu = 0$ и $x_1 + x_2 = 1$ — линейная система с решением $(\tfrac23, \tfrac13, -\tfrac43)$. Точка $(x^*, \nu^*)$ — стационарная точка $\mathcal L$, а не минимум: $\mathcal L$ линейна по $\nu$ и не ограничена по нему. Как и нулевой градиент, условия дают кандидатов; [заметка о двойственности](/ru/notes/math/duality) объясняет, когда они дают ответ.

### Ближайшая точка плоскости \{#the-nearest-point-on-a-plane\}

Идея: кратчайший путь от точки до плоскости идёт по нормали к плоскости, поэтому ближайшая точка — это $p$, сдвинутая вдоль $a$ до выполнения ограничения. Для плоскости $a^\top x = b$ и точки $p$

$$
\boxed{\; x^* = p - \frac{a^\top p - b}{\lVert a\rVert^2}\,a , \qquad \lVert x^* - p\rVert = \frac{\lvert a^\top p - b\rvert}{\lVert a\rVert} . \;}
$$

Минимизируем $\lVert x - p\rVert^2$ с функцией Лагранжа $\lVert x - p\rVert^2 + \nu(a^\top x - b)$:

$$
\begin{aligned}
2(x - p) + \nu\,a &= 0 \ \Longrightarrow\ x = p - \tfrac\nu2\,a && \text{стационарность по } x \\
a^\top p - \tfrac\nu2\lVert a\rVert^2 &= b \ \Longrightarrow\ \nu = \frac{2(a^\top p - b)}{\lVert a\rVert^2} && \text{подставить в ограничение} \\
x^* &= p - \frac{a^\top p - b}{\lVert a\rVert^2}\,a && \text{подставить } \nu \text{ обратно.}
\end{aligned}
$$

Целевая функция выпукла, а ограничение аффинно, поэтому по результату о достаточности ниже эта стационарная точка — глобальный минимум. Формула расстояния — та, которой [заметка об SVM](/ru/notes/ml/support-vector-machines#which-separating-line) измеряет зазор гиперплоскости. **Числовой пример.** $a = (1, 2, 2)$, $b = 3$, $p = (1, 1, 1)$. Тогда $a^\top p = 5$, $\lVert a\rVert^2 = 9$, $\nu = \tfrac49$, $x^* = (1, 1, 1) - \tfrac29(1, 2, 2) = (\tfrac79, \tfrac59, \tfrac59)$, и действительно $\tfrac79 + \tfrac{10}9 + \tfrac{10}9 = 3$. Расстояние равно $\tfrac23$.

### Максимум энтропии \{#maximum-entropy\}

Идея: среди всех распределений с заданным средним распределение с наибольшей энтропией распределяет вероятность так равномерно, как позволяет ограничение, а условия Лагранжа показывают, что результат всегда — экспонента от ограничиваемой величины. Максимизируем энтропию $H(p) = -\sum_i p_i\log p_i$ распределения на значениях $x_1, \dots, x_k$ при условиях $\sum_i p_i = 1$ и $\sum_i p_i x_i = m$:

$$
\boxed{\; p_i = \frac{e^{-\beta x_i}}{\sum_j e^{-\beta x_j}} , \qquad \beta \text{ подобрано так, что } \textstyle\sum_i p_i x_i = m . \;}
$$

Минимизируем $-H$ с множителями $\alpha$ для нормировки и $\beta$ для среднего:

$$
\begin{aligned}
\frac{\partial}{\partial p_i}\Big(\sum_r p_r\log p_r + \alpha\big(\textstyle\sum_r p_r - 1\big) + \beta\big(\textstyle\sum_r p_r x_r - m\big)\Big) &= \log p_i + 1 + \alpha + \beta x_i = 0 && \text{стационарность по } p_i \\
p_i &= e^{-1 - \alpha}\, e^{-\beta x_i} && \text{выразить } p_i \\
p_i &= \frac{e^{-\beta x_i}}{\sum_j e^{-\beta x_j}} && \textstyle\sum_i p_i = 1 \text{ определяет } e^{-1-\alpha} .
\end{aligned}
$$

Каждое $p_i$ положительно, поэтому опущенные ограничения $p_i \ge 0$ выполняются автоматически, а $\sum_i p_i\log p_i$ выпукла, поэтому стационарная точка — максимум энтропии. Без ограничения на среднее ($\beta = 0$) ответом будет равномерное распределение. **Числовой пример.** Игральная кость с гранями $1, \dots, 6$ и средним $4.5$ даёт $\beta = -0.371$ и $p = (0.054, 0.079, 0.114, 0.165, 0.240, 0.347)$ с энтропией $1.614$ ната (nats) против $\log 6 = 1.792$ у честной кости. Формула в рамке — softmax от оценок $-\beta x_i$: softmax — распределение максимальной энтропии с заданными средними оценками, и [экспоненциальные семейства](/ru/notes/bayesian-methods/conjugate-priors#the-exponential-family) в статистике возникают так же. Если заменить энтропию на KL-дивергенцию до эталонного распределения со знаком минус, а награду перенести из ограничения в целевую функцию, те же шаги дают оптимум [обучения с подкреплением с KL-регуляризацией](/ru/notes/agents/rl-for-language-models#the-kl-regularized-objective-and-its-optimum): эталонное распределение, перевзвешенное экспонентой награды. Самой энтропии посвящена [заметка об энтропии](/ru/notes/generative-models/entropy-and-divergences#entropy-expected-surprise).

### Что измеряет множитель \{#what-the-multiplier-measures\}

Множитель — цена ограничения. Если ограничение сдвинуть до $h(x) = u$, оптимальное значение $f^*(u)$ меняется со скоростью

$$
\boxed{\; \frac{d f^*}{du} = -\nu^* . \;}
$$

Предположим, что решение $x^*(u)$ гладко зависит от $u$:

$$
\begin{aligned}
\frac{d f^*}{du} = \nabla f(x^*)^\top\frac{d x^*}{du} &= -\nu^*\,\nabla h(x^*)^\top\frac{d x^*}{du} && \text{цепное правило, затем стационарность } \nabla f = -\nu\nabla h \\
&= -\nu^*\,\frac{d}{du}h\big(x^*(u)\big) = -\nu^* && \text{цепное правило в обратную сторону; у } h(x^*(u)) = u \text{ производная } 1 .
\end{aligned}
$$

**Числовой пример.** Для плоскости $f^*(b) = (a^\top p - b)^2/\lVert a\rVert^2$, и её производная при $b = 3$ равна $-2 \cdot 2/9 = -\tfrac49 = -\nu$; здесь $h(x) = a^\top x - b$, так что сдвиг $b$ — это сдвиг $u$. Для задачи из начала заметки $f^*(s) = \tfrac23 s^2$ на прямой $x_1 + x_2 = s$, с производной $\tfrac43 = -\nu$ при $s = 1$. В экономике множитель называют теневой ценой (shadow price); в SVM он измеряет, насколько уменьшилось бы оптимальное значение целевой функции, если бы зазор, требуемый от одной обучающей точки, немного ослабили.

## Ограничения-неравенства: активные или неактивные \{#inequality-constraints-active-or-inactive\}

<aside class="callout"><strong>Ключевая идея.</strong> В условном минимуме градиент целевой функции уравновешен градиентами тех ограничений, которые на него давят, с множителями, назначающими цену каждому ограничению. Неравенство либо давит — и тогда действует как равенство, множитель которого обязан быть неотрицательным, — либо нет, и тогда его множитель равен нулю. Дополняющая нежёсткость, $\lambda_i g_i(x^*) = 0$, записывает оба случая одним уравнением.</aside>

<KktActiveInactive />

Для ограничения $g(x) \le 0$ в локальном минимуме $x^*$ возможны два случая:

- **Неактивное**, $g(x^*) \lt 0$. Любой малый сдвиг сохраняет допустимость, поэтому $x^*$ — локальный минимум без ограничений и $\nabla f(x^*) = 0$. Ограничение не играет роли; дадим ему множитель $\lambda = 0$.
- **Активное**, $g(x^*) = 0$. Локально ограничение действует как равенство $g = 0$, поэтому $\nabla f + \lambda\nabla g = 0$ при некотором $\lambda$, и теперь важен знак: $\lambda \ge 0$. Если бы $\lambda$ было отрицательным, $-\nabla f = \lambda\nabla g$ указывал бы внутрь допустимой области, где $g$ убывает, и малый шаг вдоль него уменьшил бы $f$, не выходя из допустимого множества. При $\lambda \ge 0$ направление спуска $-\nabla f$ смотрит наружу, в стенку.

**Разобранный пример с одной переменной.** Минимизируем $(x - 2)^2$ при $x \le 1$, то есть $g(x) = x - 1 \le 0$. Минимум без ограничений $x = 2$ недопустим, поэтому ограничение активно, $x^* = 1$, и $f'(1) + \lambda g'(1) = -2 + \lambda = 0$ даёт $\lambda = 2 \ge 0$. При более слабом ограничении $x \le 3$ минимум без ограничений $x = 2$ допустим, ограничение неактивно и $\lambda = 0$. Множитель снова оказывается ценой: сдвиг стенки из 1 в $1 + u$ уменьшает оптимальное значение $(1 + u - 2)^2$ со скоростью $2 = \lambda$.

**На рисунке.** Обе панели минимизируют $\lVert x - c\rVert^2$ по треугольнику $x_1 + x_2 \le 2$, $x_1 \ge 0$, $x_2 \ge 0$, записанному как $g_1 = x_1 + x_2 - 2$, $g_2 = -x_1$ и $g_3 = -x_2$, все $\le 0$. Для $c = (0.8, 0.6)$ внутри треугольника ответ — сама $c$, ни одно ограничение не активно и $\lambda = 0$. Для $c = (2, 1)$ вне его ответ — $x^* = (1.5, 0.5)$ на наклонной стороне, с $\nabla f(x^*) = 2(x^* - c) = (-1, -1)$ и $\nabla g_1 = (1, 1)$, так что $\lambda_1 = 1$; $g_2$ и $g_3$ неактивны и $\lambda_2 = \lambda_3 = 0$.

## Условия ККТ \{#the-kkt-conditions\}

Идея: объединить условие Лагранжа для равенств с двумя случаями для каждого неравенства. Точка $x^*$ с множителями $\lambda, \nu$ удовлетворяет **условиям Каруша–Куна–Таккера**, если

$$
\boxed{\;
\begin{aligned}
&\nabla f(x^*) + \textstyle\sum_i \lambda_i\nabla g_i(x^*) + \sum_j \nu_j\nabla h_j(x^*) = 0 && \text{стационарность} \\
&g_i(x^*) \le 0,\quad h_j(x^*) = 0 && \text{допустимость в прямой задаче} \\
&\lambda_i \ge 0 && \text{допустимость в двойственной задаче} \\
&\lambda_i\, g_i(x^*) = 0 && \text{дополняющая нежёсткость.}
\end{aligned}
\;}
$$

**Условие дополняющей нежёсткости** (complementary slackness) кодирует разбор случаев. Произведение $\lambda_i g_i$ неотрицательного и неположительного чисел равно нулю, только если один из множителей нулевой: либо ограничение активно ($g_i = 0$) и его множитель может быть положительным, либо оно неактивно и его множитель равен нулю. Положительный множитель удостоверяет, что ограничение натянуто; у ненатянутого ограничения цены нет. В SVM обучающие точки с положительными множителями — это в точности опорные векторы, которые лежат на зазоре или внутри него ([опорные векторы](/ru/notes/ml/support-vector-machines#support-vectors-what-the-dual-variables-tell-you)). Оба сомножителя могут обращаться в ноль одновременно — у ограничения, которое касается решения, не давя на него.

**Когда они необходимы?** В локальном минимуме условия ККТ выполнены, если там выполнено условие регулярности, например если градиенты активных ограничений линейно независимы (LICQ), или, для выпуклых задач, если некоторая точка удовлетворяет всем неравенствам строго (**условие Слейтера**, Slater's condition, — тема [заметки о двойственности](/ru/notes/math/duality)). Без условия регулярности они могут не выполняться: у задачи минимизации $x$ при $x^2 \le 0$ решение $x = 0$, где $\nabla g = 0$, и у уравнения $1 + \lambda \cdot 0 = 0$ решения нет.

**Когда они достаточны?** Для **выпуклой задачи** (convex problem), где $f$ и все $g_i$ выпуклы, а все $h_j$ аффинны, любая точка, удовлетворяющая условиям ККТ, — глобальный минимум. Для любой допустимой $x$:

$$
\begin{aligned}
f(x) &\ge f(x) + \textstyle\sum_i \lambda_i g_i(x) + \sum_j \nu_j h_j(x) && \lambda_i \ge 0,\ g_i(x) \le 0,\ h_j(x) = 0 \\
&= \mathcal L(x, \lambda, \nu) && \text{определение функции Лагранжа} \\
&\ge \mathcal L(x^*, \lambda, \nu) && \mathcal L(\cdot, \lambda, \nu) \text{ выпукла и стационарна в } x^* \\
&= f(x^*) && \text{дополняющая нежёсткость и } h_j(x^*) = 0 .
\end{aligned}
$$

Третья строка использует оценку касательной из [заметки о выпуклости](/ru/notes/math/convex-sets-and-functions#the-first-order-condition-the-tangent-lies-below): неотрицательная комбинация выпуклых функций плюс аффинные члены выпукла, а выпуклая функция достигает минимума везде, где её градиент обращается в ноль. На рисунке множители $\lambda = (1, 0, 0)$ и точка $(1.5, 0.5)$ удовлетворяют всем четырём условиям, так что эта точка — глобальный минимум.

## Проекция на брус и на симплекс \{#projection-onto-a-box-and-onto-the-simplex\}

Многим алгоритмам нужна ближайшая к данному $v$ точка выпуклого множества $C$ — **проекция** (projection) $\Pi_C(v) = \arg\min_{x \in C}\tfrac12\lVert x - v\rVert^2$. Метод проекции градиента (projected gradient descent) чередует шаг градиентного спуска с проекцией, $x \leftarrow \Pi_C(x - \eta\nabla f(x))$, и так решает задачи с ограничениями средствами предыдущей заметки. Для двух множеств, которые постоянно встречаются в машинном обучении, условия ККТ дают проекцию в замкнутом виде.

**Брус** (box) $\{x : l_i \le x_i \le u_i\}$. Задача распадается по координатам. Для одной координаты, с множителями $\lambda_i^u$ для $x_i - u_i \le 0$ и $\lambda_i^l$ для $l_i - x_i \le 0$, стационарность имеет вид $x_i - v_i + \lambda_i^u - \lambda_i^l = 0$. Если $v_i \gt u_i$, верхняя граница обязана быть активной (иначе $x_i = v_i + \lambda_i^l \ge v_i$ было бы недопустимым), $x_i = u_i$ и $\lambda_i^u = v_i - u_i \gt 0$; снизу симметрично. Итак,

$$
\Pi_{\text{box}}(v)_i = \min\big(\max(v_i, l_i), u_i\big) ,
$$

обрезка (clipping), и множители равны отрезанным величинам. Для $v = (1.7, -0.4, 0.3)$ и единичного бруса: $x^* = (1, 0, 0.3)$, $\lambda_1^u = 0.7$, $\lambda_2^l = 0.4$, все остальные множители равны нулю. Двойственная задача SVM с мягким зазором — задача на брусе, $0 \le \alpha_i \le C$, и [заметка о двойственности](/ru/notes/math/duality#the-duality-gap-as-a-stopping-criterion) решает её проективным градиентным подъёмом именно с такой обрезкой.

**Вероятностный симплекс** $\Delta = \{x : x_i \ge 0, \sum_i x_i = 1\}$. Идея: вычесть из каждой координаты один и тот же порог $\tau$ и обрезать снизу нулём, подобрав $\tau$ так, чтобы оставшееся давало в сумме 1.

$$
\boxed{\; \Pi_\Delta(v)_i = \max(v_i - \tau, 0) , \qquad \tau \text{ такое, что } \textstyle\sum_i \max(v_i - \tau, 0) = 1 . \;}
$$

С множителем $\tau$ для $\sum_i x_i = 1$ и $\lambda_i$ для $-x_i \le 0$:

$$
\begin{aligned}
x_i - v_i + \tau - \lambda_i &= 0 && \text{стационарность } \tfrac12\lVert x - v\rVert^2 + \tau\big(\textstyle\sum_i x_i - 1\big) - \sum_i\lambda_i x_i \\
x_i \gt 0 \ &\Longrightarrow\ \lambda_i = 0,\ x_i = v_i - \tau && \text{дополняющая нежёсткость} \\
x_i = 0 \ &\Longrightarrow\ \lambda_i = \tau - v_i \ge 0,\ \text{так что } v_i \le \tau && \text{допустимость в двойственной задаче} \\
x_i &= \max(v_i - \tau, 0) && \text{оба случая вместе.}
\end{aligned}
$$

Левая часть условия на $\tau$ непрерывно убывает от больших значений до 0 при росте $\tau$, поэтому подходит ровно одно $\tau$. Его находят, сортируя $v$ по убыванию, $u_1 \ge u_2 \ge \dots$, беря наибольшее $r$ с $u_r - \frac1r\big(\sum_{s \le r} u_s - 1\big) \gt 0$ и полагая $\tau = \frac1r\big(\sum_{s \le r}u_s - 1\big)$, за $O(n\log n)$ операций ([Duchi et al., 2008](#references)). **Числовой пример.** Для $v = (0.5, 1.2, -0.3)$ отсортированные значения — $1.2, 0.5, -0.3$; при $r = 1$ имеем $\tau = 0.2$ и $1.2 - 0.2 \gt 0$; при $r = 2$ — $\tau = (1.7 - 1)/2 = 0.35$ и $0.5 - 0.35 \gt 0$; при $r = 3$ — $\tau = (1.4 - 1)/3 = 0.133$ и $-0.3 - 0.133 \lt 0$. Значит, $\tau = 0.35$, $\Pi_\Delta(v) = (0.15, 0.85, 0)$ и $\lambda_3 = 0.35 + 0.3 = 0.65$. В применении к логитам классификатора эта проекция называется **sparsemax** ([Martins and Astudillo, 2016](#references)) — альтернатива softmax, которая назначает классам с низкими оценками ровно нулевую вероятность; softmax был ответом с максимальной энтропией выше, sparsemax — ответ через ближайшую точку.

## Направление наибольшей дисперсии — собственный вектор \{#the-direction-of-maximum-variance-is-an-eigenvector\}

[Заметка о симметричных матрицах](/ru/notes/math/symmetric-matrices#the-rayleigh-quotient-the-extreme-directions) оценивает отношение Рэлея с помощью спектральной теоремы. Условия Лагранжа приходят к тому же ответу без неё и объясняют, почему кандидатами могут быть только собственные векторы. Для ковариационной матрицы $\Sigma$ дисперсия данных, спроецированных на единичный вектор $u$, равна $u^\top\Sigma u$; PCA максимизирует её при условии $u^\top u = 1$. С функцией Лагранжа $u^\top\Sigma u - \nu(u^\top u - 1)$

$$
\boxed{\; \Sigma\,u = \nu\,u , \qquad u^\top\Sigma u = \nu . \;}
$$

$$
\begin{aligned}
\nabla_{u}\big(u^\top\Sigma u - \nu(u^\top u - 1)\big) &= 2\Sigma u - 2\nu u = 0 && \nabla(u^\top\Sigma u) = 2\Sigma u \text{ для симметричной } \Sigma \\
\Sigma u &= \nu u && \text{каждая стационарная точка — единичный собственный вектор} \\
u^\top\Sigma u &= \nu\,u^\top u = \nu && \text{умножить на } u^\top \text{, использовать ограничение.}
\end{aligned}
$$

Кандидаты — единичные собственные векторы, значение целевой функции на каждом равно его собственному значению, и сравнение кандидатов выбирает наибольшее собственное значение как максимум, а наименьшее — как минимум. Множитель равен захваченной дисперсии. **Числовой пример.** Для $\Sigma = \begin{pmatrix} 2 & 1.2 \\ 1.2 & 1 \end{pmatrix}$, ковариационной матрицы из [заметки о многомерном нормальном распределении](/ru/notes/probability/multivariate-gaussian#covariance-as-geometry), собственные значения равны 2.8 и 0.2; направление $u = (0.832, 0.555)$ захватывает дисперсию 2.8 из общих 3, и перебор 100 001 единичного вектора находит тот же максимум. [Заметка о снижении размерности](/ru/notes/ml/dimensionality-reduction#pca-as-variance-maximization) строит на этом PCA.

Чему равно $\lambda_3$? (3) Спроецируйте $(2, 0, 0)$ и $(0.4, 0.4, 0.4)$ на вероятностный симплекс. (4) В решении у ограничения $g_1(x) \le 0$ множитель $\lambda_1 = 2$. Минимум при $\nu = 1/\sqrt2$: $x^* = -(1, 1)/\sqrt2$, значение $-\sqrt2$. (2) Нулю по дополняющей нежёсткости: ограничение неактивно. (3) $(1, 0, 0)$ с $\tau = 1$; $(\tfrac13, \tfrac13, \tfrac13)$ с $\tau = 0.0667$. (4) Оно уменьшится примерно на $2 \cdot 0.01 = 0.02$.</details></aside>

## Что изменилось \{#what-changed\}

| | Без ограничений | Ограничения-равенства | Ограничения-неравенства |
| --- | --- | --- | --- |
| В минимуме | $\nabla f = 0$ | $\nabla f + \sum_j \nu_j\nabla h_j = 0$ | ККТ: стационарность, допустимость, $\lambda_i \ge 0$, $\lambda_i g_i = 0$ |
| Множители | нет | любого знака | неотрицательные, нулевые у неактивных |
| Неизвестные | $n$ | $n + p$ | $n + m + p$ и то, какие ограничения активны |
| Достаточны, когда | $f$ выпукла | $f$ выпукла, $h_j$ аффинны | $f$, $g_i$ выпуклы, $h_j$ аффинны |
| Смысл множителя | | $-df^*/du$ для $h_j = u$ | то же, и ноль у ненатянутого ограничения |

## Ограничения \{#limitations\}

- **Кандидаты, а не ответы.** Без выпуклости условия перечисляют стационарные точки, включая максимумы и сёдла, и кандидатов приходится сравнивать.
- **Нужно условие регулярности**, чтобы условия были необходимыми; в вырожденных точках (точки возврата, касающиеся ограничения) множителей может не существовать.
- **Решить систему ККТ в общем случае трудно.** Множество активных ограничений неизвестно, и его угадывание — комбинаторное ядро условной оптимизации; стандартные алгоритмы — методы внутренней точки и методы активного множества ([Nocedal and Wright, 2006](#references), главы 16 и 19).
- **Проекции дёшевы только для простых множеств.** У брусов, шаров и симплексов есть замкнутые формулы; для общего многогранника на каждую проекцию нужна задача квадратичного программирования.

## Что нужно запомнить \{#what-you-should-remember\}

- В условном минимуме с ограничениями-равенствами градиент $f$ — комбинация градиентов ограничений: $\nabla f + \sum_j\nu_j\nabla h_j = 0$, стационарность функции Лагранжа $\mathcal L = f + \sum_j\nu_j h_j$.
- Множитель — чувствительность оптимального значения: $df^*/du = -\nu$ для ограничения $h = u$.
- ККТ: стационарность, допустимость в прямой задаче, $\lambda_i \ge 0$ и дополняющая нежёсткость $\lambda_i g_i = 0$; необходимы при условии регулярности, достаточны для выпуклых задач.
- Активное неравенство действует как равенство с неотрицательным множителем; у неактивного множитель равен нулю.
- Проекция на брус — обрезка; на симплекс — $\max(v_i - \tau, 0)$ с порогом, найденным сортировкой.
- Максимум энтропии при ограничении на среднее даёт форму softmax $p_i \propto e^{-\beta x_i}$; максимум дисперсии на единичной сфере даёт главный собственный вектор, а множитель равен дисперсии.

## Код \{#code\}

Задача из начала заметки как линейная система, плоскость, максимум энтропии, два случая ККТ с рисунка, проекции на брус и на симплекс, сверенные с решателем SLSQP из SciPy, и направление наибольшей дисперсии. Последние цифры могут немного отличаться на разных платформах и версиях библиотек.

```python
import numpy as np
from scipy.optimize import brentq, minimize

# min x1^2 + 2 x2^2 при x1 + x2 = 1: уравнения стационарности функции Лагранжа линейны
K = np.array([[2., 0, 1], [0, 4, 1], [1, 1, 0]])          # 2 x1 + nu = 0, 4 x2 + nu = 0, x1 + x2 = 1
x1, x2, nu = np.linalg.solve(K, [0, 0, 1])
print(round(x1, 4), round(x2, 4), round(nu, 4), round(x1**2 + 2 * x2**2, 4))
# 0.6667 0.3333 -1.3333 0.6667
fstar = lambda s: np.linalg.solve(K, [0, 0, s])[:2] @ np.diag([1., 2]) @ np.linalg.solve(K, [0, 0, s])[:2]
print(round((fstar(1 + 1e-6) - fstar(1 - 1e-6)) / 2e-6, 4))   # d f*/ds = -nu
# 1.3333

# ближайшая к p точка плоскости a.x = b
a, b, p = np.array([1., 2, 2]), 3.0, np.array([1., 1, 1])
nu = 2 * (a @ p - b) / (a @ a); x = p - nu / 2 * a
print(x.round(4), round(a @ x, 10), round(np.linalg.norm(x - p), 4), round(nu, 4))
pst = lambda b: (a @ p - b) ** 2 / (a @ a)                 # оптимальное значение как функция b
print(round((pst(b + 1e-6) - pst(b - 1e-6)) / 2e-6, 4))
# [0.7778 0.5556 0.5556] 3.0 0.6667 0.4444
# -0.4444

# максимум энтропии на {1, ..., 6} со средним 4.5: p_i пропорционально exp(-beta i)
k = np.arange(1, 7)
mean = lambda beta: k @ np.exp(-beta * k) / np.exp(-beta * k).sum()
beta = brentq(lambda t: mean(t) - 4.5, -5, 5)
pm = np.exp(-beta * k); pm /= pm.sum()
res = minimize(lambda q: q @ np.log(q), np.ones(6) / 6, method='SLSQP', bounds=[(1e-9, 1)] * 6,
               constraints=[{'type': 'eq', 'fun': lambda q: q.sum() - 1}, {'type': 'eq', 'fun': lambda q: q @ k - 4.5}],
               options={'ftol': 1e-14, 'maxiter': 500})
print(round(beta, 4), pm.round(4), round(-pm @ np.log(pm), 4), round(np.log(6), 4), np.abs(res.x - pm).max() < 1e-5)
# -0.371 [0.0544 0.0788 0.1142 0.1654 0.2398 0.3475] 1.6136 1.7918 True

# ККТ с активными и неактивными ограничениями: min |x - c|^2 при x1 + x2 <= 2, x1 >= 0, x2 >= 0
for c in (np.array([2., 1]), np.array([0.8, 0.6])):
    r = minimize(lambda x: (x - c) @ (x - c), np.zeros(2), method='SLSQP', bounds=[(0, None)] * 2,
                 constraints=[{'type': 'ineq', 'fun': lambda x: 2 - x.sum()}], options={'ftol': 1e-14})
    xs = r.x; lam1 = -2 * (xs - c)[0] if abs(xs.sum() - 2) < 1e-9 else 0.0   # стационарность: 2(x - c) + lam1 (1, 1) = 0
    print(c, xs.round(4), round(lam1, 4), abs(round(lam1 * (xs.sum() - 2), 12)))
# [2. 1.] [1.5 0.5] 1.0 0.0
# [0.8 0.6] [0.8 0.6] 0.0 0.0

# проекция на брус — обрезка; множитель границы равен отрезанной величине
v = np.array([1.7, -0.4, 0.3]); xb = np.clip(v, 0, 1)
print(xb, np.maximum(v - 1, 0), np.maximum(-v, 0))         # x, множители x <= 1, множители x >= 0
# [1.  0.  0.3] [0.7 0.  0. ] [0.  0.4 0. ]

# проекция на вероятностный симплекс: x = max(v - tau, 0), tau по отсортированным значениям
def proj_simplex(v):
    u = np.sort(v)[::-1]; css = np.cumsum(u) - 1
    rho = np.nonzero(u - css / np.arange(1, len(v) + 1) > 0)[0][-1]
    tau = css[rho] / (rho + 1)
    return np.maximum(v - tau, 0), tau
v = np.array([0.5, 1.2, -0.3]); xs, tau = proj_simplex(v)
lam = xs - v + tau                                          # стационарность 1/2|x - v|^2 + tau (sum x - 1) - lam.x
r = minimize(lambda x: 0.5 * (x - v) @ (x - v), np.ones(3) / 3, method='SLSQP', bounds=[(0, None)] * 3,
             constraints=[{'type': 'eq', 'fun': lambda x: x.sum() - 1}], options={'ftol': 1e-14})
print(xs, tau, lam.round(4), lam @ xs, np.abs(r.x - xs).max() < 1e-6)
rng = np.random.default_rng(0)                              # 1000 случайных векторов против SLSQP
print(max(np.abs(proj_simplex(w)[0] - minimize(lambda x: 0.5 * (x - w) @ (x - w), np.ones(5) / 5, method='SLSQP', bounds=[(0, None)] * 5,
      constraints=[{'type': 'eq', 'fun': lambda x: x.sum() - 1}], options={'ftol': 1e-14}).x).max() for w in rng.normal(size=(1000, 5))) < 1e-6)
# [0.15 0.85 0.  ] 0.35 [0.   0.   0.65] 0.0 True
# True

# направление наибольшей дисперсии: стационарные точки u' S u на единичной окружности — собственные векторы
S = np.array([[2., 1.2], [1.2, 1]])
ang = np.linspace(0, np.pi, 100_001); U = np.stack([np.cos(ang), np.sin(ang)])
var = np.einsum('in,ij,jn->n', U, S, U)
w, V = np.linalg.eigh(S)
print(w, np.abs(V[:, 1]).round(3), round(var.max(), 6), round(var.min(), 6), U[:, var.argmax()].round(3))
# [0.2 2.8] [0.832 0.555] 2.8 0.2 [0.832 0.555]
```

## Дальше \{#next\}

Условия ККТ пришли с доказательством достаточности, которое сравнивало $f(x)$ с функцией Лагранжа — нижней оценкой целевой функции на допустимом множестве. [Следующая заметка](/ru/notes/math/duality) делает эту оценку главным объектом. Минимизация функции Лагранжа по $x$ при фиксированных множителях даёт функцию одних только множителей — двойственную функцию, максимум которой — наилучшая такая нижняя оценка. Для выпуклых задач он равен оптимуму, что превращает SVM в задачу по её множителям и даёт любому решателю удостоверение того, насколько он далёк от оптимума.
