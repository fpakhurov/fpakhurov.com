[Предыдущая заметка](/ru/notes/math/gradients-jacobians-hessians) дифференцировала функции покоординатно и собирала результаты в градиенты, якобианы и гессианы. Машинное обучение записывает свои функции потерь целыми векторами и матрицами: $\lVert Xw - y\rVert^2$, логарифм правдоподобия гауссианы с ковариацией $\Sigma$, кросс-энтропия $\operatorname{softmax}(Wx)$. Записать такое выражение через индексы, продифференцировать поэлементно и снова собрать матрицу — долго, и легко ошибиться. Эта заметка сначала фиксирует, какую форму имеет производная, а затем вводит **дифференциал** (differential) — исчисление, работающее с целыми матрицами: вычисляем изменение выражения в первом порядке, преобразуем его с помощью следа и считываем градиент. Так выводится каждое стандартное тождество, и каждое проверяется конечными разностями, а градиенты метода наименьших квадратов и логистической регрессии получаются ровно в том виде, в каком их используют заметки о машинном обучении.

**Обозначения.** Векторы обозначаются строчными буквами и записываются столбцами, матрицы — прописными: $x \in \mathbb R^n$ и $X \in \mathbb R^{m \times n}$ — переменные; $a$, $b$, $A$, $B$ — константы. $f$ — скалярная функция. $\operatorname{tr}$ — след, а $\langle A, B\rangle = \operatorname{tr}(A^\top B) = \sum_{ij} A_{ij} B_{ij}$ — скалярное произведение двух матриц одинаковой формы, $\lVert A\rVert_F^2 = \langle A, A\rangle$. $X^{-\top} = (X^{-1})^\top = (X^\top)^{-1}$. $E_{ij}$ — матрица с единицей в позиции $(i, j)$ и нулями в остальных, $\mathbf 1$ — вектор из единиц, $\odot$ — поэлементное произведение. $dX$ — малое изменение $X$, матрица той же формы, а $df$ — вызванное им изменение $f$ в первом порядке.

## Отправная точка: индекс за индексом \{#baseline-index-by-index\}

Квадратичную форму $x^\top Ax = \sum_i \sum_j x_i A_{ij} x_j$ можно продифференцировать поэлементно. Производная по $x_k$ собирает слагаемые с $i = k$, которые дают $\sum_j A_{kj} x_j$, и слагаемые с $j = k$, которые дают $\sum_i x_i A_{ik}$:

$$
\frac{\partial}{\partial x_k}\, x^\top Ax = (Ax)_k + (A^\top x)_k, \qquad \text{поэтому} \qquad \nabla_{x}\, x^\top Ax = (A + A^\top)x .
$$

Здесь это работает, но быстро перестаёт работать. Определителю нужно разложение по алгебраическим дополнениям, обратная матрица задана лишь неявно, а произведение четырёх матриц — сумма по четырём индексам. И даже когда элементы найдены верно, их нужно снова собрать в матрицу, а это ставит вопрос, какой формы должен быть результат.

## Раскладка: какую форму имеет производная \{#layout-what-shape-a-derivative-has\}

Учебники расходятся в том, является ли производная скаляра по вектору-столбцу столбцом или строкой. В этом курсе, как и во всех курсах сайта, принято одно соглашение (layout convention):

- для скалярной $f$ от вектора $x$ градиент $\partial f/\partial x = \nabla f(x)$ — **столбец** той же формы, что $x$;
- для скалярной $f$ от матрицы $X$ производная $\partial f/\partial X$ — матрица **той же формы, что $X$**, $\big(\partial f/\partial X\big)_{ij} = \partial f/\partial X_{ij}$;
- для векторной функции $f$ от $x$ **якобиан** $\partial f/\partial x$ имеет размер $m \times n$, выходы × входы.

Для градиентов это **раскладка знаменателя** (denominator layout): производная располагается так же, как переменная в знаменателе. Для якобианов это **раскладка числителя** (numerator layout), так что градиент скаляра — транспонированный якобиан размера $1 \times n$. Это соглашение [заметки о методе наименьших квадратов](/ru/notes/ml/least-squares#the-normal-equations), где $\nabla_{w} = 2X^\top(Xw - y)$ — столбец, [заметки о логистической регрессии](/ru/notes/ml/logistic-regression#the-gradient-residuals-times-inputs), где $\nabla = X^\top(p - y)$, и [сопряжённых величин обратного распространения ошибки](/ru/notes/ml/backpropagation#the-chain-rule-in-matrix-form), имеющих форму своих переменных; The Matrix Cookbook использует его и для скаляров ([Petersen and Pedersen, 2012](#references)). Причина предпочесть его: обновление $W \leftarrow W - \eta\, \partial L/\partial W$ имеет смысл, только когда $\partial L/\partial W$ имеет форму $W$. Источник, написанный в чистой раскладке числителя, даёт градиенты-строки и несёт лишние транспонирования, например $\partial(a^\top x)/\partial x = a^\top$. Эта одна формула — быстрый способ узнать, какой раскладкой пользуется источник.

## Метод дифференциалов \{#the-differential-method\}

<aside class="callout"><strong>Ключевая идея.</strong> Изменение скалярной функции в первом порядке при малом изменении $dX$ линейно по $dX$, а любая линейная функция матрицы — скалярное произведение с фиксированной матрицей той же формы. Запишем изменение в виде $df = \operatorname{tr}(G^\top dX)$, пользуясь лишь несколькими правилами для дифференциалов и циклическим свойством следа, — тогда $G$ и есть градиент. Ни один индекс не выписывается.</aside>

**Дифференциал** $df$ — линейная часть изменения: $f(X + dX) = f(X) + df + o(\lVert dX\rVert)$. Идея метода: у линейной части по одному коэффициенту на каждый элемент $dX$, и скалярное произведение через след собирает эти коэффициенты в матрицу:

$$
\boxed{\; df = \operatorname{tr}\big(G^\top dX\big) \ \text{ для любого } dX \quad \Longleftrightarrow \quad \frac{\partial f}{\partial X} = G \;}
$$

$$
\begin{aligned}
df &= \sum_{i,j} \frac{\partial f}{\partial X_{ij}}\, dX_{ij} && \text{линейная часть, по одной координате} \\
&= \sum_{i,j} \Big(\frac{\partial f}{\partial X}\Big)_{ij} dX_{ij} && \text{соглашение о форме} \\
&= \operatorname{tr}\Big(\Big(\frac{\partial f}{\partial X}\Big)^{\!\top} dX\Big) && \operatorname{tr}(A^\top B) = \textstyle\sum_{ij} A_{ij} B_{ij} .
\end{aligned}
$$

Обратно, если $df = \operatorname{tr}(G^\top dX)$ для любого $dX$, то $dX = E_{ij}$ даёт $G_{ij} = \partial f/\partial X_{ij}$. Для векторной переменной то же утверждение читается как $df = g^\top dx \Leftrightarrow \nabla f = g$.

Дифференциалы подчиняются нескольким правилам; каждое получается раскрытием $f(X + dX)$ и отбрасыванием произведений двух малых изменений:

| Правило | Почему |
| --- | --- |
| $dA = 0$ для константы $A$ | она не меняется |
| $d(\alpha X + \beta Y) = \alpha\, dX + \beta\, dY$ | линейность |
| $d(XY) = (dX)\,Y + X\,(dY)$ | $(X + dX)(Y + dY) - XY = (dX)Y + X(dY) + (dX)(dY)$, а последнее слагаемое второго порядка |
| $d(X^\top) = (dX)^\top$, $\ d\operatorname{tr}X = \operatorname{tr}dX$ | транспонирование и след линейны |
| $d\,\varphi(x) = \varphi'(x) \odot dx$ для поэлементной $\varphi$ | по одной переменной на элемент |

Преобразования выполняют три факта о следе: скаляр равен своему следу, $\operatorname{tr}(AB) = \operatorname{tr}(BA)$ (поэтому $\operatorname{tr}(ABC) = \operatorname{tr}(CAB) = \operatorname{tr}(BCA)$ — **циклическое свойство** (cyclic property)) и $\operatorname{tr}(A^\top) = \operatorname{tr}A$. Рецепт: вычислить $df$ по правилам, циклическим свойством перенести $dX$ в правый конец следа, чтобы получить $df = \operatorname{tr}(M\, dX)$, и считать ответ $\partial f/\partial X = M^\top$.

## Линейные и квадратичные формы \{#linear-and-quadratic-forms\}

Идея: дифференциал линейной формы — та же форма, применённая к $dx$, а квадратичная форма даёт по слагаемому на каждое из двух мест, где стоит $x$.

$$
\boxed{\; \frac{\partial\, a^\top x}{\partial x} = a, \qquad \frac{\partial\, x^\top Ax}{\partial x} = (A + A^\top)\,x \ \ \big(= 2Ax \text{ для симметричной } A\big) \;}
$$

$$
\begin{aligned}
d(a^\top x) &= a^\top dx && a \text{ — константа} \\
d(x^\top Ax) &= (dx)^\top Ax + x^\top A\, dx && \text{правило произведения} \\
&= x^\top A^\top dx + x^\top A\, dx && \text{скаляр равен своему транспонированию} \\
&= \big((A + A^\top)x\big)^\top dx && \text{собираем и считываем градиент.}
\end{aligned}
$$

**Разобранный пример.** $A = \begin{pmatrix} 1 & 2 \\ 0 & 3\end{pmatrix}$ и $x = (1, 2)$: $x^\top Ax = x_1^2 + 2x_1x_2 + 3x_2^2 = 17$, а $(A + A^\top)x = \begin{pmatrix} 2 & 2 \\ 2 & 6\end{pmatrix}\begin{pmatrix} 1 \\ 2\end{pmatrix} = (6, 14)$. Частные производные $2x_1 + 2x_2 = 6$ и $2x_1 + 6x_2 = 14$ совпадают с этим. Сокращённая формула $2Ax = (10, 12)$ была бы неверна: ей нужна симметричная $A$.

## Метод наименьших квадратов \{#least-squares\}

Идея: пройти через остаток $r = Ax - b$. Квадрат нормы меняется на $2r^\top dr$, а остаток — на $A\, dx$.

$$
\boxed{\; \frac{\partial}{\partial x}\lVert Ax - b\rVert^2 = 2A^\top(Ax - b), \qquad \nabla^2 = 2A^\top A \;}
$$

$$
\begin{aligned}
d(r^\top r) &= (dr)^\top r + r^\top dr = 2\,r^\top dr && \text{правило произведения; скаляр равен своему транспонированию} \\
&= 2\,r^\top A\, dx && dr = A\, dx \\
&= \big(2A^\top r\big)^\top dx && \text{считываем градиент} \\
d\big(2A^\top r\big) &= 2A^\top A\, dx && \text{гессиан — якобиан градиента.}
\end{aligned}
$$

**Разобранный пример.** С той же $A$, $b = (1, 1)$ и $x = (1, 2)$: $Ax = (5, 6)$, $r = (4, 5)$, $\lVert r\rVert^2 = 41$, а градиент $2A^\top r = 2\,(4,\ 2 \cdot 4 + 3 \cdot 5) = (8, 46)$.

**Сверка с заметкой о методе наименьших квадратов.** При $A = X$ — матрице плана (design matrix) — и $b = y$ это градиент $2X^\top(Xw - y)$ и гессиан $2X^\top X$ из [заметки о методе наименьших квадратов](/ru/notes/ml/least-squares#the-normal-equations), а приравнивание градиента к нулю даёт её нормальные уравнения. В её примере с четырьмя точками у $X$ столбцы $(1, 1, 1, 1)$ и $(0, 1, 2, 3)$, а $y = (1, 3, 2, 5)$. Градиент при $w = 0$ равен $-2X^\top y = (-22, -44)$, а при $\hat{w} = (1.1, 1.1)$ он равен $0$.

## След произведения матриц \{#traces-of-matrix-products\}

Идея: когда переменная — матрица, след уже имеет вид $\operatorname{tr}(M\, dX)$ или приводится к нему циклическим свойством.

$$
\boxed{\; \frac{\partial \operatorname{tr}(AX)}{\partial X} = A^\top, \qquad \frac{\partial \operatorname{tr}(X^\top A X)}{\partial X} = (A + A^\top)\,X, \qquad \frac{\partial \lVert X\rVert_F^2}{\partial X} = 2X \;}
$$

$$
\begin{aligned}
d\operatorname{tr}(AX) &= \operatorname{tr}(A\, dX) && \text{линейность; считываем } M = A \\
d\operatorname{tr}(X^\top A X) &= \operatorname{tr}\big((dX)^\top A X\big) + \operatorname{tr}\big(X^\top A\, dX\big) && \text{правило произведения} \\
&= \operatorname{tr}\big(X^\top A^\top dX\big) + \operatorname{tr}\big(X^\top A\, dX\big) && \operatorname{tr}(B^\top) = \operatorname{tr}B \\
&= \operatorname{tr}\big(X^\top (A + A^\top)\, dX\big) && \text{собираем; } M = X^\top(A + A^\top) .
\end{aligned}
$$

Градиенты равны $M^\top$: $A^\top$ и $(A + A^\top)X$. Квадрат нормы Фробениуса — это $\operatorname{tr}(X^\top X)$, случай $A = I$, с градиентом $2X$; это производная штрафа затухания весов (weight decay) $\lambda\lVert W\rVert_F^2$ из [заметки о регуляризации](/ru/notes/ml/regularization).

**Разобранный пример.** Для $A = \begin{pmatrix} 1 & 2 \\ 3 & 4\end{pmatrix}$ имеем $\operatorname{tr}(AX) = \sum_{ij} A_{ji} X_{ij}$, поэтому коэффициент при $X_{12}$ равен $A_{21} = 3$ — элементу $(1, 2)$ матрицы $A^\top$. Без соглашения легко угадать $A$ и получить 2.

## Логарифм определителя \{#the-log-determinant\}

Идея: разложить $X + dX = X(I + X^{-1}dX)$ и воспользоваться тем, что в первом порядке определитель матрицы, близкой к единичной, равен 1 плюс след её отличия от единичной. Сначала этот факт. Для малой $E$

$$
\det(I + E) = 1 + \operatorname{tr}E + O\big(\lVert E\rVert^2\big) .
$$

По формуле Лейбница $\det M = \sum_\sigma \operatorname{sgn}\sigma \prod_i M_{i\sigma(i)}$ тождественная перестановка даёт $\prod_i (1 + E_{ii}) = 1 + \sum_i E_{ii} + \dots$, где многоточие — произведения двух и более элементов $E$. Любая другая перестановка сдвигает хотя бы два индекса, поэтому её произведение содержит хотя бы два внедиагональных элемента $E$ и имеет второй порядок. Для обратимой $X$:

$$
\boxed{\; d\det X = \det X \cdot \operatorname{tr}\big(X^{-1} dX\big), \qquad \frac{\partial \log\lvert\det X\rvert}{\partial X} = X^{-\top} \ \ \big(= X^{-1} \text{ для симметричной } X\big) \;}
$$

$$
\begin{aligned}
\det(X + dX) &= \det\big(X(I + X^{-1}dX)\big) && X \text{ обратима} \\
&= \det X \cdot \det\big(I + X^{-1}dX\big) && \text{определитель произведения} \\
&= \det X \cdot \big(1 + \operatorname{tr}(X^{-1}dX) + O(\lVert dX\rVert^2)\big) && \text{факт выше при } E = X^{-1}dX \\
d\log\lvert\det X\rvert &= \frac{d\det X}{\det X} = \operatorname{tr}\big(X^{-1}dX\big) && d\log\lvert t\rvert = dt/t \text{ при } t \ne 0 ;\ M = X^{-1} .
\end{aligned}
$$

Считывая ответ, получаем $\partial \det X/\partial X = \det X \cdot X^{-\top}$ — матрицу алгебраических дополнений — и $\partial \log\lvert\det X\rvert/\partial X = X^{-\top}$. Правило произведения для определителей и их смысл как объёма разобраны в [заметке об определителях](/ru/notes/math/determinants-and-eigenvalues#the-determinant-how-a-map-scales-volume).

**Разобранный пример.** У $X = \begin{pmatrix} 2 & 1 \\ 0.5 & 1.5\end{pmatrix}$ определитель $\det X = 2.5$ и $X^{-1} = \begin{pmatrix} 0.6 & -0.4 \\ -0.2 & 0.8\end{pmatrix}$, поэтому $\partial \det X/\partial X = 2.5\, X^{-\top} = \begin{pmatrix} 1.5 & -0.5 \\ -1 & 2\end{pmatrix}$ — алгебраические дополнения. Увеличение $X_{11}$ на $0.1$ увеличивает определитель ровно на $0.15$, до $2.65$, потому что определитель линеен по каждому отдельному элементу. Для изменения всех элементов, $dX = \begin{pmatrix} 0.1 & 0.05 \\ -0.05 & 0.1\end{pmatrix}$, след равен $\operatorname{tr}(X^{-1}dX) = 0.6 \cdot 0.1 + (-0.4)(-0.05) + (-0.2)(0.05) + 0.8 \cdot 0.1 = 0.15$, и предсказание первого порядка равно $2.5 \cdot 1.15 = 2.875$. Точное значение $\det(X + dX) = 2.8875$. Разница $0.0125$ равна $\det(dX)$: для матриц $2 \times 2$ точно выполнено $\det(X + E) = \det X + \det X \operatorname{tr}(X^{-1}E) + \det E$, и последнее слагаемое — остаток второго порядка.

Логарифм определителя появляется везде, где плотность нормируют или преобразуют: $-\tfrac12\log\det\Sigma$ в логарифме правдоподобия [многомерной гауссианы](/ru/notes/probability/multivariate-gaussian#the-density), $\log\lvert\det J\rvert$ в [нормализующих потоках](/ru/notes/generative-models/normalizing-flows#change-of-variables) (normalizing flows), обоснованность (evidence) в [байесовской линейной регрессии](/ru/notes/bayesian-methods/bayesian-linear-regression#tools-matrix-derivatives-and-gaussian-identities) и в [гауссовских процессах](/ru/notes/bayesian-methods/gaussian-processes#the-gradient), градиенты которой используют ровно это тождество и следующее.

## Обратная матрица \{#the-inverse\}

Идея: продифференцировать тождество $XX^{-1} = I$, правая часть которого не меняется.

$$
\boxed{\; d\big(X^{-1}\big) = -X^{-1}\,(dX)\,X^{-1}, \qquad \frac{\partial\, a^\top X^{-1}b}{\partial X} = -X^{-\top}a\,b^\top X^{-\top} \;}
$$

$$
\begin{aligned}
0 &= dI = d\big(XX^{-1}\big) && I \text{ — константа} \\
&= (dX)\,X^{-1} + X\, d\big(X^{-1}\big) && \text{правило произведения} \\
d\big(X^{-1}\big) &= -X^{-1}(dX)\,X^{-1} && \text{умножаем на } X^{-1} \text{ слева} \\
d\big(a^\top X^{-1}b\big) &= -a^\top X^{-1}(dX)\,X^{-1}b = -\operatorname{tr}\big(X^{-1}b\,a^\top X^{-1}\, dX\big) && \text{скаляр равен своему следу; циклическое свойство.}
\end{aligned}
$$

Значит, $M = -X^{-1}ba^\top X^{-1}$, а градиент $M^\top = -X^{-\top}ab^\top X^{-\top}$. Для матриц $1 \times 1$ первая формула — знакомое $d(1/x) = -dx/x^2$.

**Разобранный пример.** С той же $X$, $a = (1, 2)$ и $b = (1, 1)$: $X^{-1}b = (0.2, 0.6)$, поэтому $a^\top X^{-1}b = 0.2 + 1.2 = 1.4$. Градиент — внешнее произведение $X^{-\top}a = (0.2, 1.2)$ и $X^{-1}b = (0.2, 0.6)$ со знаком минус:

$$
\frac{\partial\, a^\top X^{-1}b}{\partial X} = -\begin{pmatrix} 0.2 \\ 1.2\end{pmatrix}\begin{pmatrix} 0.2 & 0.6\end{pmatrix} = \begin{pmatrix} -0.04 & -0.12 \\ -0.24 & -0.72\end{pmatrix} .
$$

Значит, увеличение $X_{22}$ на $0.01$ должно уменьшить значение примерно на $0.0072$.

**Применение: ковариация гауссианы по методу максимального правдоподобия.** Два тождества вместе дают ковариацию по методу максимального правдоподобия в две строки. Для точек $x_1, \dots, x_n$ с известным средним $\mu$ обозначим $S = \sum_i (x_i - \mu)(x_i - \mu)^\top$. Идея: логарифм правдоподобия — логарифм определителя плюс след $\Sigma^{-1}S$, и его дифференциал обращается в ноль, когда два слагаемых уравновешиваются:

$$
\boxed{\; \hat\Sigma = \frac1n S = \frac1n \sum_{i=1}^n (x_i - \mu)(x_i - \mu)^\top \;}
$$

$$
\begin{aligned}
\ell(\Sigma) &= -\tfrac n2 \log\det\Sigma - \tfrac12 \sum_i (x_i - \mu)^\top \Sigma^{-1}(x_i - \mu) + \text{const} && \text{сумма логарифмов гауссовской плотности} \\
&= -\tfrac n2 \log\det\Sigma - \tfrac12 \operatorname{tr}\big(\Sigma^{-1}S\big) + \text{const} && \text{скаляр равен своему следу; циклическое свойство} \\
d\ell &= -\tfrac n2 \operatorname{tr}\big(\Sigma^{-1}d\Sigma\big) + \tfrac12 \operatorname{tr}\big(\Sigma^{-1}(d\Sigma)\,\Sigma^{-1}S\big) && \text{логарифм определителя и обратная матрица} \\
&= \operatorname{tr}\Big(\big(-\tfrac n2 \Sigma^{-1} + \tfrac12 \Sigma^{-1}S\Sigma^{-1}\big)\, d\Sigma\Big) && \text{циклическое свойство} .
\end{aligned}
$$

Дифференциал обращается в ноль при любом $d\Sigma$, когда $\Sigma^{-1}S\Sigma^{-1} = n\Sigma^{-1}$, то есть $\Sigma = S/n$. Для трёх точек $(1, 0)$, $(-1, 1)$ и $(0, -1)$ со средним $0$ получаем $S = \begin{pmatrix} 2 & -1 \\ -1 & 2\end{pmatrix}$ и $\hat\Sigma = S/3$. Множитель $1/n$ вместо $1/(n - 1)$ — смещение метода максимального правдоподобия, разобранное в [заметке об оценках](/ru/notes/probability/estimators#the-sample-variance-and-n-1), и та же оценка — M-шаг [EM-алгоритма](/ru/notes/ml/em-algorithm) для каждой компоненты.

## Кросс-энтропия с softmax \{#the-softmax-cross-entropy\}

Для оценок $z \in \mathbb R^K$ вероятности равны $p = \operatorname{softmax}(z)$, $p_k = e^{z_k}/\sum_j e^{z_j}$, а функция потерь для метки $y$ в виде one-hot-вектора — $L = -\sum_k y_k \log p_k$. Идея: $\log p_k$ равен $z_k$ минус log-sum-exp $\operatorname{lse}(z) = \log\sum_j e^{z_j}$, дифференциал которого равен $p^\top dz$, а слагаемое с меткой линейно. Для линейного слоя $z = Wx + b$:

$$
\boxed{\; \nabla_{z} L = p - y, \qquad \frac{\partial L}{\partial W} = (p - y)\,x^\top, \qquad \frac{\partial L}{\partial b} = p - y \;}
$$

$$
\begin{aligned}
L &= -\sum_k y_k \big(z_k - \operatorname{lse}(z)\big) = -y^\top z + \operatorname{lse}(z) && \log p_k = z_k - \operatorname{lse}(z);\ \textstyle\sum_k y_k = 1 \\
dL &= -y^\top dz + \frac{\sum_k e^{z_k} dz_k}{\sum_j e^{z_j}} && d\log u = du/u,\ d e^{z} = e^{z} dz \\
&= (p - y)^\top dz && \text{определение } p \\
&= (p - y)^\top (dW)\,x + (p - y)^\top db && dz = (dW)\,x + db \\
&= \operatorname{tr}\big(x\,(p - y)^\top dW\big) + (p - y)^\top db && \text{циклическое свойство; } M = x(p - y)^\top .
\end{aligned}
$$

**Разобранный пример.** $z = (2, 1, 0.1)$, истинный класс первый, $y = (1, 0, 0)$: $p = (0.659, 0.242, 0.099)$, $L = -\log 0.659 = 0.417$ и $\nabla_{z} L = (-0.341, 0.242, 0.099)$. Сумма компонент равна 0, потому что $\mathbf 1^\top p = \mathbf 1^\top y = 1$: прибавление одной и той же константы ко всем оценкам ничего не меняет. При входе $x = (1, -2)$ градиент по весам — внешнее произведение $(p - y)x^\top$ со строками $(-0.341, 0.682)$, $(0.242, -0.485)$ и $(0.099, -0.197)$.

Путь через якобиан softmax даёт тот же результат с большей работой: $dp = \big(\operatorname{diag}(p) - pp^\top\big) dz$ — гессиан log-sum-exp из [заметки о выпуклости](/ru/notes/math/convex-sets-and-functions), умноженный на градиент $-y/p$ функции потерь по $p$. Поэтому библиотеки реализуют softmax и кросс-энтропию как одну слитую операцию, которая к тому же численно устойчивее. Для батча, объекты которого — строки $X$, $Z = XW^\top + \mathbf 1b^\top$, те же шаги дают $\partial L/\partial W = (P - Y)^\top X$; это $X^\top(P - Y)$ из [раздела о softmax в заметке о логистической регрессии](/ru/notes/ml/logistic-regression#several-classes-the-softmax), где веса хранятся столбцами, а не строками.

## Сверка с логистической регрессией \{#the-check-against-logistic-regression\}

В бинарной логистической регрессии $p_i = \sigma(z_i)$, $z = Xw$ и $L(w) = -\sum_i \big[y_i \log p_i + (1 - y_i)\log(1 - p_i)\big]$. Идея: дифференциал каждого слагаемого равен $(p_i - y_i)\, dz_i$ — бинарный случай $p - y$, — а вероятности меняются на $p_i(1 - p_i)\, dz_i$:

$$
\boxed{\; \nabla L(w) = X^\top(p - y), \qquad \nabla^2 L(w) = X^\top S X, \quad S = \operatorname{diag}\big(p_i(1 - p_i)\big) \;}
$$

$$
\begin{aligned}
d\big[-\log\sigma(z)\big] &= -(1 - \sigma(z))\, dz, \quad d\big[-\log(1 - \sigma(z))\big] = \sigma(z)\, dz && \sigma' = \sigma(1 - \sigma) \\
dL &= \sum_i (p_i - y_i)\, dz_i = (p - y)^\top X\, dw && \text{оба случая дают } (p_i - y_i)\,dz_i;\ dz = X dw \\
d\big(X^\top(p - y)\big) &= X^\top dp = X^\top S\, dz = X^\top S X\, dw && dp_i = p_i(1 - p_i)\, dz_i .
\end{aligned}
$$

Это градиент и гессиан из [заметки о логистической регрессии](/ru/notes/ml/logistic-regression#the-gradient-residuals-times-inputs). В её разобранном примере — один признак $x = (2, -1, 0.5)$, метки $y = (1, 0, 0)$ и $w = 1$ — остатки равны $p - y = (-0.119, 0.269, 0.622)$, градиент равен $-0.196$, а гессиан $\sum_i p_i(1 - p_i)\, x_i^2 = 0.675$.

<aside class="callout"><strong>Проверьте себя.</strong> (1) Найдите $\partial\, a^\top Xb/\partial X$. (2) Найдите $\nabla_{x}\, \tfrac12 x^\top Ax - b^\top x$ для симметричной $A$ и его нуль. (3) Чему равна $\partial \log\det(\alpha I + M)/\partial\alpha$ для симметричной $M$ с собственными значениями $\lambda_j$?<details><summary>Ответы</summary>(1) $d(a^\top Xb) = a^\top (dX)b = \operatorname{tr}(ba^\top dX)$, поэтому градиент равен $ab^\top$ и имеет форму $X$. (2) $Ax - b$; он равен нулю при $x = A^{-1}b$, если $A$ обратима: минимизация положительно определённой квадратичной функции — это решение линейной системы. (3) $d\log\det(\alpha I + M) = \operatorname{tr}\big((\alpha I + M)^{-1} I\big)\, d\alpha$, поэтому производная равна $\operatorname{tr}(\alpha I + M)^{-1} = \sum_j 1/(\alpha + \lambda_j)$.</details></aside>

| --- | --- | --- |
| Что записывается | каждый элемент $\partial f/\partial X_{ij}$ как сумма по индексам | одно матричное выражение $df$ |

## Ограничения \{#limitations\}

- **Раскладки в разных источниках различаются.** Тождество, скопированное из текста в другой раскладке, молча транспонируется; проверять его стоит по $\partial(a^\top x)/\partial x$ и по формам.
- **Структурированные матрицы.** Формулы считают все элементы $X$ независимыми. Когда $X$ обязана быть симметричной, производная по её различным элементам учитывает каждый внедиагональный элемент дважды, и источники записывают это по-разному ([Petersen and Pedersen, 2012](#references), раздел 2.8). Для оптимизатора, обновляющего все $n^2$ элементов, правильны формулы этой заметки, а для симметричной $X$ градиенты $X^{-1}$ и $\Sigma^{-1}S\Sigma^{-1}$ и так симметричны.
- **Производные матричных функций от матриц — массивы с четырьмя индексами.** Метод избегает их, оставляя в конце каждой цепочки скаляр, каким всегда является функция потерь. Собственные и сингулярные числа дифференцируемы лишь там, где они различны.
- **Формула — не алгоритм.** В численном коде $X^{-1}$ и $\det X$ не следует строить явно: решение линейной системы заменяет $X^{-1}b$, а разложение Холецкого даёт $\log\det$ как удвоенную сумму логарифмов своей диагонали, как объясняет [заметка об обусловленности](/ru/notes/math/conditioning-and-stability).
- **Для кода инструмент — автоматическое дифференцирование.** Выводы дают замкнутые формулы, гессианы для метода Ньютона и способ проверить, что возвращает autograd.

## Что нужно запомнить \{#what-you-should-remember\}

- Градиенты имеют форму переменной; якобианы — выходы × входы.
- $df = \operatorname{tr}(M\, dX) \Rightarrow \partial f/\partial X = M^\top$. Сначала правило произведения для дифференциалов, затем циклическое свойство следа.
- Тождества, каждое из которых выведено в заметке:

| $f$ | $\partial f/\partial x$ или $\partial f/\partial X$ |
| --- | --- |
| $a^\top x$ | $a$ |
| $x^\top Ax$ | $(A + A^\top)x$ |
| $\lVert Ax - b\rVert^2$ | $2A^\top(Ax - b)$ |
| $\operatorname{tr}(AX)$ | $A^\top$ |
| $\operatorname{tr}(X^\top AX)$ | $(A + A^\top)X$ |
| $\log\lvert\det X\rvert$ | $X^{-\top}$ |
| $a^\top X^{-1}b$ | $-X^{-\top}ab^\top X^{-\top}$ |
| $-y^\top \log\operatorname{softmax}(Wx + b)$ | $(p - y)x^\top$ по $W$, $\ p - y$ по $b$ |

- Метод наименьших квадратов: $\nabla = 2X^\top(Xw - y)$, $\nabla^2 = 2X^\top X$. Логистическая регрессия: $\nabla = X^\top(p - y)$, $\nabla^2 = X^\top SX$. Ковариация гауссианы по методу максимального правдоподобия равна $S/n$.

## Код \{#code\}

Каждое тождество заметки проверяется центральными разностями с помощью функции, которая по очереди возмущает каждый элемент вектора или матрицы; случайные матрицы фиксированы начальным значением генератора. Последние цифры могут отличаться на разных платформах.

```python
import numpy as np

rng = np.random.default_rng(0)

def num_grad(f, X, h=1e-6):
    """Central differences in every entry of X; the result has the shape of X."""
    G = np.zeros_like(X, dtype=float)
    for idx in np.ndindex(X.shape):
        E = np.zeros_like(X, dtype=float); E[idx] = h
        G[idx] = (f(X + E) - f(X - E)) / (2 * h)
    return G

def check(name, f, X, G):
    print(f'{name:14s} max error {np.abs(num_grad(f, X) - G).max():.1e}')

# разобранные примеры
A = np.array([[1., 2], [0, 3]]); x = np.array([1., 2]); b = np.array([1., 1])
print(x @ A @ x, (A + A.T) @ x, 2 * A @ x, 2 * A.T @ (A @ x - b))   # 17.0 [ 6. 14.] [10. 12.] [ 8. 46.]
X = np.array([[2., 1], [0.5, 1.5]]); Xi = np.linalg.inv(X); dX = np.array([[0.1, 0.05], [-0.05, 0.1]])
print(np.linalg.det(X).round(6), (np.linalg.det(X) * Xi.T).round(6), np.trace(Xi @ dX).round(6),
      (np.linalg.det(X) * (1 + np.trace(Xi @ dX))).round(6), np.linalg.det(X + dX).round(6), np.linalg.det(dX).round(6))
# 2.5 [[ 1.5 -0.5] [-1.   2. ]] 0.15 2.875 2.8875 0.0125
a = np.array([1., 2]); print(round(a @ Xi @ b, 6), (-Xi.T @ np.outer(a, b) @ Xi.T).round(6))   # 1.4 [[-0.04 -0.12] [-0.24 -0.72]]

# каждое тождество на случайных матрицах
n = 4
a, b, x = rng.normal(size=n), rng.normal(size=n), rng.normal(size=n)
A, B = rng.normal(size=(n, n)), rng.normal(size=(n, n))
X = rng.normal(size=(n, n)) + n * np.eye(n)                         # заведомо обратима
check('a^T x', lambda v: a @ v, x, a)
check('x^T A x', lambda v: v @ A @ v, x, (A + A.T) @ x)
check('|Ax - b|^2', lambda v: np.sum((A @ v - b) ** 2), x, 2 * A.T @ (A @ x - b))
check('tr(AX)', lambda M: np.trace(A @ M), X, A.T)
check('tr(X^T A X)', lambda M: np.trace(M.T @ A @ M), X, (A + A.T) @ X)
check('log|det X|', lambda M: np.linalg.slogdet(M)[1], X, np.linalg.inv(X).T)
Xi = np.linalg.inv(X)
check('a^T X^-1 b', lambda M: a @ np.linalg.solve(M, b), X, -Xi.T @ np.outer(a, b) @ Xi.T)
# каждая строка печатает max error от 3e-11 до 7e-09: совпадение с точностью центральных разностей
# сам d(X^-1): изменение обратной матрицы в первом порядке совпадает с -X^-1 dX X^-1
E = 1e-6 * rng.normal(size=(n, n))
print(f'{np.abs(np.linalg.inv(X + E) - Xi - (-Xi @ E @ Xi)).max():.1e}')   # около 1e-13: второй порядок по E

# кросс-энтропия с softmax: разобранный пример, затем случайный слой
softmax = lambda z: np.exp(z - z.max()) / np.exp(z - z.max()).sum()
z = np.array([2., 1, 0.1]); y = np.array([1., 0, 0]); p = softmax(z)
print(p.round(3), round(-np.log(p[0]), 3), (p - y).round(3), np.outer(p - y, [1, -2]).round(3))
# [0.659 0.242 0.099] 0.417 [-0.341  0.242  0.099] [[-0.341  0.682] [ 0.242 -0.485] [ 0.099 -0.197]]
K, d = 3, 5
W, bb, xx = rng.normal(size=(K, d)), rng.normal(size=K), rng.normal(size=d)
ce = lambda W_, b_: -np.log(softmax(W_ @ xx + b_)[1])                 # истинный класс 1
p = softmax(W @ xx + bb); y = np.eye(K)[1]
check('CE, W', lambda M: ce(M, bb), W, np.outer(p - y, xx))
check('CE, b', lambda v: ce(W, v), bb, p - y)
# CE, W max error 2.4e-10 | CE, b max error 1.5e-10

# метод наименьших квадратов на четырёх точках из заметки о нём
Xd = np.column_stack([np.ones(4), [0., 1, 2, 3]]); yd = np.array([1., 3, 2, 5])
print(2 * Xd.T @ (Xd @ np.zeros(2) - yd), (2 * Xd.T @ (Xd @ np.array([1.1, 1.1]) - yd)).round(12) + 0)   # [-22. -44.] [0. 0.]

# логистическая регрессия: разобранный пример из её заметки, затем случайная матрица плана
sig = lambda t: 1 / (1 + np.exp(-t))
xl, yl = np.array([2., -1, 0.5]), np.array([1., 0, 0]); pl = sig(xl)
print((pl - yl).round(3), round(xl @ (pl - yl), 3), round(np.sum(pl * (1 - pl) * xl ** 2), 3))   # [-0.119  0.269  0.622] -0.196 0.675
Xr, yr, w = rng.normal(size=(20, 3)), rng.integers(0, 2, 20).astype(float), rng.normal(size=3)
nll = lambda v: -np.sum(yr * np.log(sig(Xr @ v)) + (1 - yr) * np.log(1 - sig(Xr @ v)))
pr = sig(Xr @ w)
check('logistic grad', nll, w, Xr.T @ (pr - yr))
grad_l = lambda v: Xr.T @ (sig(Xr @ v) - yr)
H_num = np.column_stack([(grad_l(w + 1e-6 * e) - grad_l(w - 1e-6 * e)) / 2e-6 for e in np.eye(3)])   # якобиан градиента
print(f'{"logistic Hess":14s} max error {np.abs(H_num - Xr.T @ np.diag(pr * (1 - pr)) @ Xr).max():.1e}')
# logistic grad max error 2.0e-09 | logistic Hess max error 7.2e-10

# ковариация гауссианы по методу максимального правдоподобия: градиент обращается в ноль в S / n
P3 = np.array([[1., 0], [-1, 1], [0, -1]]); S = P3.T @ P3
ell = lambda Sig: -1.5 * np.linalg.slogdet(Sig)[1] - 0.5 * np.trace(np.linalg.solve(Sig, S))
G_at = lambda Sig: -1.5 * np.linalg.inv(Sig) + 0.5 * np.linalg.inv(Sig) @ S @ np.linalg.inv(Sig)
check('Gaussian ell', ell, np.eye(2), G_at(np.eye(2)))   # max error 2.6e-10
print((S / 3).round(3), np.abs(num_grad(ell, S / 3)).max() < 1e-8)   # [[ 0.667 -0.333] [-0.333  0.667]] True
```
