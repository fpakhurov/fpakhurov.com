Подгоним гауссиану к данным методом максимального правдоподобия. Ковариационная матрица $\Sigma$ находится там, где обращается в ноль производная логарифма правдоподобия

$$
\ell(\Sigma) = -\frac n2 \log\det\Sigma - \frac12 \operatorname{tr}\big(\Sigma^{-1}S\big)
$$

Здесь $n$ — число точек, а $S$ — матрица их разброса относительно среднего; её определение дано ниже. Чему равна производная логарифма определителя по матрице? А производная обратной матрицы?

[Предыдущая заметка](/ru/notes/math/gradients-jacobians-hessians) дифференцировала по одной координате за раз, и для небольших выражений это работает. В квадратичной форме $x^\top Ax = \sum_i \sum_j x_i A_{ij} x_j$ производная по $x_k$ собирает слагаемые с $i = k$ и слагаемые с $j = k$:

$$
\frac{\partial}{\partial x_k}\, x^\top Ax = (Ax)_k + (A^\top x)_k .
$$

Для $\log\det\Sigma$ тот же путь требует разложения определителя по алгебраическим дополнениям (cofactor expansion), а $\Sigma^{-1}$ задана лишь неявно, равенством $\Sigma\Sigma^{-1} = I$. Даже когда элементы найдены верно, их нужно снова собрать в матрицу какой-то формы. Функции потерь машинного обучения сплошь записаны именно так: $\lVert Xw - y\rVert^2$, кросс-энтропия $\operatorname{softmax}(Wx)$, гауссиана выше. Мы хотим дифференцировать их как целые выражения, так же как дифференцируем $\log x$ или $1/x$ для числа.

## Раскладка: какую форму имеет производная \{#layout-what-shape-a-derivative-has\}

Учебники расходятся в том, чем считать производную скаляра по вектору-столбцу: столбцом или строкой. Все курсы сайта пользуются одним соглашением:

- для скалярной $f$ от вектора $x$ градиент $\partial f/\partial x = \nabla f(x)$ — столбец той же формы, что $x$;
- для скалярной $f$ от матрицы $X$ производная $\partial f/\partial X$ имеет форму $X$, её элементы — $\partial f/\partial X_{ij}$;
- для векторной функции $f$ от $x$ якобиан $\partial f/\partial x$ имеет размер $m \times n$, выходы × входы.

Для градиентов это **раскладка знаменателя** (denominator layout): производная располагается так же, как переменная в знаменателе. Для якобианов это **раскладка числителя** (numerator layout), поэтому градиент скаляра — транспонированный якобиан размера $1 \times n$. [Заметка о методе наименьших квадратов](/ru/notes/ml/least-squares#the-normal-equations) записывает свой градиент $2X^\top(Xw - y)$ столбцом, а [сопряжённые величины обратного распространения ошибки](/ru/notes/ml/backpropagation#the-chain-rule-in-matrix-form) имеют форму своих переменных. *The Matrix Cookbook* использует то же соглашение для скаляров ([Petersen and Pedersen, 2012](#references)).

Причина выбрать именно его такова: обновление $W \leftarrow W - \eta\, \partial L/\partial W$ имеет смысл, только когда $\partial L/\partial W$ имеет форму $W$. Источник в чистой раскладке числителя пишет $\partial(a^\top x)/\partial x = a^\top$, то есть строку. По одной этой формуле видно, какой раскладкой пользуется источник.

## Метод дифференциалов \{#the-differential-method\}

**Дифференциал** $df$ скалярной функции — линейная часть её изменения: $f(X + dX) = f(X) + df + o(\lVert dX\rVert)$, где $dX$ — малое изменение $X$, матрица той же формы. У линейной части по одному коэффициенту на каждый элемент $dX$. Соглашение о раскладке ставит коэффициент при $dX_{ij}$ в позицию $(i, j)$, а тождество $\operatorname{tr}(A^\top B) = \sum_{ij} A_{ij} B_{ij}$ превращает сумму произведений в след:

$$
\begin{aligned}
df &= \sum_{i,j} \frac{\partial f}{\partial X_{ij}}\, dX_{ij} \\
&= \operatorname{tr}\Big(\Big(\frac{\partial f}{\partial X}\Big)^{\!\top} dX\Big) .
\end{aligned}
$$

Обратно, если $df = \operatorname{tr}(G^\top dX)$ при любом $dX$, то выбор $dX = E_{ij}$, матрицы с единственной единицей в позиции $(i, j)$, даёт $G_{ij} = \partial f/\partial X_{ij}$. Поэтому градиент можно считать с любого выражения нужного вида:

$$
\boxed{\; df = \operatorname{tr}\big(G^\top dX\big) \ \text{при любом } dX \iff \frac{\partial f}{\partial X} = G \;}
$$

Для векторной переменной то же утверждение читается как $df = g^\top dx \iff \nabla f = g$. [Merkulov (2024)](#references) записывает его через скалярное произведение, $df = \langle \nabla f, dx\rangle$, а след и есть это скалярное произведение для матриц.

Дифференциалы подчиняются нескольким правилам. Каждое получается раскрытием $f(X + dX)$ и отбрасыванием произведений двух малых изменений.

| Правило | Почему |
| --- | --- |
| $dA = 0$ для константы $A$ | она не меняется |
| $d(\alpha X + \beta Y) = \alpha\, dX + \beta\, dY$ | линейность |
| $d(XY) = (dX)\,Y + X\,(dY)$ | слагаемое $(dX)(dY)$ второго порядка |
| $d(X^\top) = (dX)^\top$, $\ d\operatorname{tr}X = \operatorname{tr}dX$ | оба отображения линейны |
| $d\,\varphi(x) = \varphi'(x) \odot dx$ для поэлементной $\varphi$ | по одной переменной на элемент |

Здесь $\odot$ — поэлементное произведение. Преобразования выполняют три факта о следе: скаляр равен своему следу, $\operatorname{tr}(A^\top) = \operatorname{tr}A$ и $\operatorname{tr}(AB) = \operatorname{tr}(BA)$, откуда $\operatorname{tr}(ABC) = \operatorname{tr}(CAB)$ — **циклическое свойство** (cyclic property). Вывод тогда состоит из трёх шагов:

1. вычислить $df$ по правилам;
2. циклическим свойством перенести $dX$ в правый конец следа, $df = \operatorname{tr}(M\, dX)$;
3. считать ответ $\partial f/\partial X = M^\top$.

## Линейные и квадратичные формы \{#linear-and-quadratic-forms\}

Линейная форма меняется на ту же форму, применённую к изменению: $d(a^\top x) = a^\top dx$, поэтому её градиент равен $a$. В квадратичной форме $x$ стоит в двух местах, и правило произведения даёт по слагаемому на каждое:

$$
\begin{aligned}
d(x^\top Ax) &= (dx)^\top Ax + x^\top A\, dx && \text{правило произведения} \\
&= x^\top A^\top dx + x^\top A\, dx && \text{транспонируем скаляр} \\
&= \big((A + A^\top)x\big)^\top dx .
\end{aligned}
$$

Градиент равен $(A + A^\top)x$, как и в покоординатном вычислении выше. Для симметричной $A$ он равен $2Ax$, и только тогда.

Возьмём $A$ со строками $(1, 2)$ и $(0, 3)$ и $x = (1, 2)$. Тогда $x^\top Ax = x_1^2 + 2x_1x_2 + 3x_2^2 = 17$, а у $A + A^\top$ строки $(2, 2)$ и $(2, 6)$, поэтому градиент равен $(6, 14)$. Частные производные $2x_1 + 2x_2 = 6$ и $2x_1 + 6x_2 = 14$ с ним совпадают. Сокращённая формула $2Ax = (10, 12)$ неверна, потому что эта $A$ не симметрична.

## Метод наименьших квадратов \{#least-squares\}

Почему градиент $\lVert Ax - b\rVert^2$ равен $2A^\top(Ax - b)$? Пройдём через остаток $r = Ax - b$, который меняется на $dr = A\, dx$:

$$
\begin{aligned}
d(r^\top r) &= 2\,r^\top dr && \text{правило произведения} \\
&= 2\,r^\top A\, dx \\
&= \big(2A^\top r\big)^\top dx , \\
d\big(2A^\top r\big) &= 2A^\top A\, dx .
\end{aligned}
$$

Третья строка даёт градиент $2A^\top(Ax - b)$. Гессиан — это якобиан градиента, поэтому последняя строка даёт $\nabla^2 = 2A^\top A$.

С той же $A$, $b = (1, 1)$ и $x = (1, 2)$: $Ax = (5, 6)$, $r = (4, 5)$, $\lVert r\rVert^2 = 41$, а градиент $2A^\top r = (8, 46)$. При $A = X$, матрице плана (design matrix), и $b = y$ это градиент $2X^\top(Xw - y)$ и гессиан $2X^\top X$ из [заметки о методе наименьших квадратов](/ru/notes/ml/least-squares#the-normal-equations), а приравнивание градиента к нулю даёт её нормальные уравнения. В её примере с четырьмя точками у $X$ столбцы $(1, 1, 1, 1)$ и $(0, 1, 2, 3)$, а $y = (1, 3, 2, 5)$. Градиент равен $(-22, -44)$ при $w = 0$ и нулю при $\hat w = (1.1, 1.1)$.

## След произведения матриц \{#traces-of-matrix-products\}

Когда переменная — матрица, след уже стоит в выражении. Для $\operatorname{tr}(AX)$ дифференциал равен $\operatorname{tr}(A\, dX)$, так что $M = A$, а градиент равен $A^\top$. Для $\operatorname{tr}(X^\top AX)$ правило произведения даёт два слагаемых. Транспонировав первое внутри его следа, мы ставим $dX$ в правый конец обоих:

$$
\begin{aligned}
d\operatorname{tr}(X^\top A X) &= \operatorname{tr}\big((dX)^\top A X\big) + \operatorname{tr}\big(X^\top A\, dX\big) \\
&= \operatorname{tr}\big(X^\top A^\top dX\big) + \operatorname{tr}\big(X^\top A\, dX\big) \\
&= \operatorname{tr}\big(X^\top (A + A^\top)\, dX\big) .
\end{aligned}
$$

Значит, $M = X^\top(A + A^\top)$, а градиент равен $(A + A^\top)X$. Квадрат нормы Фробениуса $\lVert X\rVert_F^2 = \operatorname{tr}(X^\top X)$ — случай $A = I$ с градиентом $2X$: это производная штрафа затухания весов (weight decay) $\lambda\lVert W\rVert_F^2$ из [заметки о регуляризации](/ru/notes/ml/regularization).

Транспонирование в $\partial\operatorname{tr}(AX)/\partial X = A^\top$ легко потерять. Для $A$ со строками $(1, 2)$ и $(3, 4)$ имеем $\operatorname{tr}(AX) = \sum_{ij} A_{ji} X_{ij}$, поэтому коэффициент при $X_{12}$ равен $A_{21} = 3$, то есть элементу $(1, 2)$ матрицы $A^\top$. Если угадать ответ $A$, получится 2.

## Логарифм определителя \{#the-log-determinant\}

Столбцы $X$ натягивают параллелограмм, а в $n$ измерениях параллелепипед, объёма $\lvert\det X\rvert$. Насколько меняется объём, когда столбцы немного сдвигаются? Сначала нам понадобится один факт. Для малой матрицы $E$

$$
\det(I + E) = 1 + \operatorname{tr}E + O\big(\lVert E\rVert^2\big) .
$$

По формуле Лейбница $\det M = \sum_\sigma \operatorname{sgn}\sigma \prod_i M_{i\sigma(i)}$ тождественная перестановка даёт $\prod_i (1 + E_{ii}) = 1 + \sum_i E_{ii}$ плюс произведения двух и более элементов $E$. Любая другая перестановка сдвигает хотя бы два индекса, поэтому её произведение содержит хотя бы два внедиагональных элемента $E$ и имеет второй порядок. Для обратимой $X$ разложим $X + dX = X(I + X^{-1}dX)$ и применим этот факт при $E = X^{-1}dX$:

$$
\begin{aligned}
\det(X + dX) &= \det X \,\det\big(I + X^{-1}dX\big) \\
&= \det X \,\big(1 + \operatorname{tr}(X^{-1}dX)\big) + O\big(\lVert dX\rVert^2\big) .
\end{aligned}
$$

Линейная часть и есть дифференциал, а деление на $\det X$ даёт дифференциал логарифма, поскольку $d\log\lvert t\rvert = dt/t$:

$$
\begin{aligned}
d\det X &= \det X \cdot \operatorname{tr}\big(X^{-1}dX\big) , \\
d\log\lvert\det X\rvert &= \operatorname{tr}\big(X^{-1}dX\big) .
\end{aligned}
$$

Считывая ответ, получаем $\partial \log\lvert\det X\rvert/\partial X = X^{-\top}$, где $X^{-\top} = (X^{-1})^\top$, и $\partial\det X/\partial X = \det X \cdot X^{-\top}$. Для симметричной $X$ первая производная равна $X^{-1}$. Вторая — матрица алгебраических дополнений: [Strang (2018)](#references) приходит к ней с другой стороны, потому что определитель линеен по каждой строке, а коэффициент при $X_{ij}$ в нём и есть алгебраическое дополнение.

Разберём пример: у $X$ строки $(2, 1)$ и $(0.5, 1.5)$, у изменения $dX$ — строки $(0.1, 0.05)$ и $(-0.05, 0.1)$.

| Величина | Значение |
| --- | --- |
| $\det X$ | $2.5$ |
| $X^{-1}$, по строкам | $(0.6, -0.4)$, $(-0.2, 0.8)$ |
| $\partial\det X/\partial X = 2.5\,X^{-\top}$, по строкам | $(1.5, -0.5)$, $(-1, 2)$ |
| $\operatorname{tr}(X^{-1}dX)$ | $0.15$ |
| предсказание первого порядка $2.5 \cdot 1.15$ | $2.875$ |
| точное $\det(X + dX)$ | $2.8875$ |

В первом порядке площадь растёт на 15%. Оставшиеся $0.0125$ — это $\det(dX)$: для матриц $2 \times 2$ точно выполнено $\det(X + E) = \det X\,\big(1 + \operatorname{tr}(X^{-1}E)\big) + \det E$. Если увеличить только $X_{11}$ на $0.1$, определитель вырастет ровно на $1.5 \cdot 0.1 = 0.15$, потому что он линеен по каждому отдельному элементу.

Логарифм определителя появляется везде, где плотность нормируют или преобразуют: $-\tfrac12\log\det\Sigma$ в логарифме правдоподобия [многомерной гауссианы](/ru/notes/probability/multivariate-gaussian#the-density), $\log\lvert\det J\rvert$ в [нормализующих потоках](/ru/notes/generative-models/normalizing-flows#change-of-variables) (normalizing flows), обоснованность (evidence) [байесовской линейной регрессии](/ru/notes/bayesian-methods/bayesian-linear-regression#tools-matrix-derivatives-and-gaussian-identities) и [гауссовских процессов](/ru/notes/bayesian-methods/gaussian-processes#the-gradient). Её градиенты используют это тождество и следующее.

## Обратная матрица \{#the-inverse\}

Обратная матрица определяется равенством $XX^{-1} = I$. Продифференцируем обе части; правая часть не меняется:

$$
\begin{aligned}
0 &= d\big(XX^{-1}\big) \\
&= (dX)\,X^{-1} + X\, d\big(X^{-1}\big) .
\end{aligned}
$$

Умножив на $X^{-1}$ слева, получаем

$$
d\big(X^{-1}\big) = -X^{-1}(dX)\,X^{-1} .
$$

Для матриц $1 \times 1$ это знакомое $d(1/x) = -dx/x^2$. Скаляр, построенный из обратной матрицы, например $a^\top X^{-1}b$ для фиксированных векторов $a$ и $b$, дифференцируется в два шага:

$$
\begin{aligned}
d\big(a^\top X^{-1}b\big) &= -a^\top X^{-1}(dX)\,X^{-1}b \\
&= -\operatorname{tr}\big(X^{-1}b\,a^\top X^{-1}\, dX\big) && \text{циклическое свойство}
\end{aligned}
$$

Значит, $M = -X^{-1}ba^\top X^{-1}$, а градиент равен $M^\top = -X^{-\top}ab^\top X^{-\top}$.

С той же $X$, $a = (1, 2)$ и $b = (1, 1)$: $X^{-1}b = (0.2, 0.6)$ и $a^\top X^{-1}b = 1.4$. Градиент — внешнее произведение $X^{-\top}a = (0.2, 1.2)$ и $X^{-1}b$ со знаком минус:

$$
\frac{\partial\, a^\top X^{-1}b}{\partial X} = -\begin{pmatrix} 0.2 \\ 1.2\end{pmatrix}\begin{pmatrix} 0.2 & 0.6\end{pmatrix} = \begin{pmatrix} -0.04 & -0.12 \\ -0.24 & -0.72\end{pmatrix} .
$$

Значит, увеличение $X_{22}$ на $0.01$ должно уменьшить значение примерно на $0.0072$.

## Снова ковариация гауссианы \{#back-to-the-gaussian-covariance\}

Теперь задача из начала заметки решается в несколько строк. Для точек $x_1, \dots, x_n$ с известным средним $\mu$ обозначим $S = \sum_i (x_i - \mu)(x_i - \mu)^\top$. Каждое квадратичное слагаемое в логарифме гауссовской плотности — скаляр, а значит, равно своему следу, и циклическое свойство собирает сумму в один след. С точностью до константы

$$
\begin{aligned}
\ell(\Sigma) &= -\frac n2 \log\det\Sigma - \frac12 \sum_{i=1}^n (x_i - \mu)^\top \Sigma^{-1}(x_i - \mu) \\
&= -\frac n2 \log\det\Sigma - \frac12 \operatorname{tr}\big(\Sigma^{-1}S\big) .
\end{aligned}
$$

Первое слагаемое дифференцируется по правилу для логарифма определителя, второе — по правилу для обратной матрицы:

$$
\begin{aligned}
d\ell &= -\frac n2 \operatorname{tr}\big(\Sigma^{-1}d\Sigma\big) \\
&\quad + \frac12 \operatorname{tr}\big(\Sigma^{-1}(d\Sigma)\,\Sigma^{-1}S\big) \\
&= \frac12 \operatorname{tr}\Big(\big(\Sigma^{-1}S\Sigma^{-1} - n\Sigma^{-1}\big)\, d\Sigma\Big) .
\end{aligned}
$$

Дифференциал обращается в ноль при любом $d\Sigma$, когда $\Sigma^{-1}S\Sigma^{-1} = n\Sigma^{-1}$, то есть в точке

$$
\hat\Sigma = \frac1n S = \frac1n \sum_{i=1}^n (x_i - \mu)(x_i - \mu)^\top .
$$

Если записать логарифм правдоподобия через обратную ковариационную матрицу (precision) $\Lambda = \Sigma^{-1}$, он равен $\tfrac n2 \log\det\Lambda - \tfrac12\operatorname{tr}(\Lambda S)$, и одно правило для логарифма определителя даёт $\Lambda^{-1} = S/n$. Именно в такой форме упражнение ставит [Merkulov (2024)](#references).

Для трёх точек $(1, 0)$, $(-1, 1)$ и $(0, -1)$ со средним $0$ у $S$ строки $(2, -1)$ и $(-1, 2)$, и $\hat\Sigma = S/3$. Множитель $1/n$ вместо $1/(n - 1)$ — смещение метода максимального правдоподобия, разобранное в [заметке об оценках](/ru/notes/probability/estimators#the-sample-variance-and-n-1). Та же оценка, взвешенная по ответственностям, — M-шаг [EM-алгоритма](/ru/notes/ml/em-algorithm) для каждой компоненты.

## Кросс-энтропия с softmax \{#the-softmax-cross-entropy\}

Для оценок $z \in \mathbb R^K$ вероятности равны $p = \operatorname{softmax}(z)$, где $p_k = e^{z_k}/\sum_j e^{z_j}$, а функция потерь для метки $y$ в виде one-hot-вектора равна $L = -\sum_k y_k \log p_k$. Дифференциал получается коротким благодаря двум фактам. Во-первых, $\log p_k = z_k - \operatorname{lse}(z)$, где $\operatorname{lse}(z) = \log\sum_j e^{z_j}$ — функция log-sum-exp, и $\sum_k y_k = 1$, поэтому $L = -y^\top z + \operatorname{lse}(z)$. Во-вторых, $\partial\operatorname{lse}/\partial z_k = e^{z_k}/\sum_j e^{z_j} = p_k$. Для линейного слоя $z = Wx + b$:

$$
\begin{aligned}
dL &= -y^\top dz + p^\top dz \\
&= (p - y)^\top dz \\
&= (p - y)^\top (dW)\,x + (p - y)^\top db \\
&= \operatorname{tr}\big(x\,(p - y)^\top dW\big) + (p - y)^\top db .
\end{aligned}
$$

Значит, $\nabla_z L = p - y$, $\partial L/\partial W = (p - y)\,x^\top$ и $\partial L/\partial b = p - y$.

Возьмём $z = (2, 1, 0.1)$ с истинным первым классом, $y = (1, 0, 0)$, и вход $x = (1, -2)$:

| Величина | Значение |
| --- | --- |
| $p = \operatorname{softmax}(z)$ | $(0.659, 0.242, 0.099)$ |
| $L = -\log p_1$ | $0.417$ |
| $\nabla_z L = p - y$ | $(-0.341, 0.242, 0.099)$ |
| $\partial L/\partial W = (p - y)x^\top$, по строкам | $(-0.341, 0.682)$, $(0.242, -0.485)$, $(0.099, -0.197)$ |

Компоненты $p - y$ в сумме дают 0, потому что $\mathbf 1^\top p = \mathbf 1^\top y = 1$, где $\mathbf 1$ — вектор из единиц: прибавление одной и той же константы ко всем оценкам ничего не меняет. С обратным знаком тот же результат — функция вклада (score) softmax-стратегии: $\nabla_z \log p_a = y - p$ для выбранного действия $a$. Именно этот множитель [градиент по стратегии](/ru/notes/agents/policy-gradients#the-policy-gradient-theorem) умножает на отдачу.

Путь через якобиан softmax, $dp = \big(\operatorname{diag}(p) - pp^\top\big)\, dz$, с последующим градиентом $-y/p$ функции потерь по $p$ даёт тот же результат ценой большей работы. Поэтому библиотеки объединяют softmax и кросс-энтропию в одну операцию, которая к тому же численно устойчивее. Для батча, объекты которого записаны строками $X$, $Z = XW^\top + \mathbf 1b^\top$, те же шаги дают $\partial L/\partial W = (P - Y)^\top X$. Это $X^\top(P - Y)$ из [заметки о логистической регрессии](/ru/notes/ml/logistic-regression#several-classes-the-softmax), где веса хранятся столбцами, а не строками.

## Сверка с логистической регрессией \{#the-check-against-logistic-regression\}

В бинарной логистической регрессии $p_i = \sigma(z_i)$, $z = Xw$, а функция потерь равна $L(w) = -\sum_i \big[y_i \log p_i + (1 - y_i)\log(1 - p_i)\big]$. Из $\sigma' = \sigma(1 - \sigma)$ следует, как меняются слагаемые двух видов:

$$
\begin{aligned}
d\big[-\log\sigma(z)\big] &= -\big(1 - \sigma(z)\big)\, dz , \\
d\big[-\log\big(1 - \sigma(z)\big)\big] &= \sigma(z)\, dz .
\end{aligned}
$$

При любой метке слагаемое меняется на $(p_i - y_i)\, dz_i$ — бинарный случай $p - y$. С учётом $dz = X\,dw$ и $dp_i = p_i(1 - p_i)\, dz_i$:

$$
\begin{aligned}
dL &= (p - y)^\top X\, dw , \\
d\big(X^\top(p - y)\big) &= X^\top S X\, dw ,
\end{aligned}
$$

где $S = \operatorname{diag}\big(p_i(1 - p_i)\big)$. Значит, $\nabla L = X^\top(p - y)$ и $\nabla^2 L = X^\top S X$ — это градиент и гессиан из [заметки о логистической регрессии](/ru/notes/ml/logistic-regression#the-gradient-residuals-times-inputs). В её разобранном примере с одним признаком $x = (2, -1, 0.5)$, метками $y = (1, 0, 0)$ и $w = 1$ остатки равны $p - y = (-0.119, 0.269, 0.622)$, градиент равен $-0.196$, а гессиан $\sum_i p_i(1 - p_i)\, x_i^2 = 0.675$.

## Где это ломается \{#where-it-breaks\}

Все формулы выше считают элементы $X$ независимыми переменными. Ковариационная матрица симметрична, и если её параметры — только различные элементы, формулы дают неверное число. Возьмём $\Sigma$ со строками $(2, s)$ и $(s, 2)$ при $s = 1$, так что $\log\det\Sigma = \log(4 - s^2)$. Производная по единственному параметру $s$ равна

$$
\frac{d}{ds}\log(4 - s^2) = -\frac{2s}{4 - s^2} = -\frac23 .
$$

Формула $\partial\log\det\Sigma/\partial\Sigma = \Sigma^{-1}$ даёт $-\tfrac13$ в позиции $(1, 2)$. Но при изменении $s$ сдвигаются оба элемента, $(1, 2)$ и $(2, 1)$, поэтому истинная производная равна сумме двух, $2(\Sigma^{-1})_{12}$. В общем случае градиент по различным элементам симметричной матрицы равен $G + G^\top - \operatorname{diag}(G)$, где $G$ — градиент, посчитанный так, будто все $n^2$ элементов независимы ([Petersen and Pedersen, 2012](#references), раздел 2.8). Оптимизатору, который обновляет все $n^2$ элементов, нужны формулы в том виде, в каком они выведены здесь. Для симметричной $\Sigma$ градиенты $\Sigma^{-1}$ и $\Sigma^{-1}S\Sigma^{-1}$ и так симметричны, поэтому итерации остаются симметричными.

Вторая частая ошибка связана с раскладками. Тождество, скопированное из текста в раскладке числителя, приходит транспонированным; его стоит проверить по $\partial(a^\top x)/\partial x$ и по формам. У матричных функций от матриц производные — массивы с четырьмя индексами, и метод обходит их, оставляя в конце каждой цепочки скалярную функцию потерь. Наконец, формула ещё не алгоритм: численный код вычисляет $X^{-1}b$ решением линейной системы, а $\log\det\Sigma$ — через множитель Холецкого (Cholesky factor), как объясняет [заметка об обусловленности](/ru/notes/math/conditioning-and-stability). В коде обучения градиенты вычисляет [автоматическое дифференцирование](/ru/notes/ml/backpropagation). Тождества дают замкнутые формулы, гессианы для метода Ньютона и проверку того, что возвращает autograd.

## Что нужно запомнить \{#what-you-should-remember\}

- Градиенты имеют форму переменной; якобианы — выходы × входы.
- $df = \operatorname{tr}(M\, dX)$ означает $\partial f/\partial X = M^\top$. К этому виду приводят правило произведения и циклическое свойство следа.
- $\nabla(x^\top Ax) = (A + A^\top)x$; $\ \nabla\lVert Ax - b\rVert^2 = 2A^\top(Ax - b)$; $\ \partial\operatorname{tr}(AX)/\partial X = A^\top$.
- $d\log\lvert\det X\rvert = \operatorname{tr}(X^{-1}dX)$ и $d(X^{-1}) = -X^{-1}(dX)X^{-1}$.
- Кросс-энтропия с softmax: $\nabla_z L = p - y$, $\ \partial L/\partial W = (p - y)x^\top$.
- Для симметричных параметров каждый внедиагональный элемент учитывается дважды.

## Код \{#code\}

Каждое тождество заметки проверяется центральными разностями с помощью функции, которая по очереди возмущает каждый элемент вектора или матрицы; случайные матрицы фиксированы начальным значением генератора. Последние цифры могут отличаться на разных платформах.

```python
import numpy as np

rng = np.random.default_rng(0)

def num_grad(f, X, h=1e-6):
    """Central differences in every entry of X; the result has the shape of X."""
    G = np.zeros_like(X, dtype=float)
    for idx in np.ndindex(X.shape):
        E = np.zeros_like(X, dtype=float); E[idx] = h
        G[idx] = (f(X + E) - f(X - E)) / (2 * h)
    return G

def check(name, f, X, G):
    print(f'{name:14s} max error {np.abs(num_grad(f, X) - G).max():.1e}')

# разобранные примеры
A = np.array([[1., 2], [0, 3]]); x = np.array([1., 2]); b = np.array([1., 1])
print(x @ A @ x, (A + A.T) @ x, 2 * A @ x, 2 * A.T @ (A @ x - b))   # 17.0 [ 6. 14.] [10. 12.] [ 8. 46.]
X = np.array([[2., 1], [0.5, 1.5]]); Xi = np.linalg.inv(X); dX = np.array([[0.1, 0.05], [-0.05, 0.1]])
print(np.linalg.det(X).round(6), (np.linalg.det(X) * Xi.T).round(6), np.trace(Xi @ dX).round(6),
      (np.linalg.det(X) * (1 + np.trace(Xi @ dX))).round(6), np.linalg.det(X + dX).round(6), np.linalg.det(dX).round(6))
# 2.5 [[ 1.5 -0.5] [-1.   2. ]] 0.15 2.875 2.8875 0.0125
a = np.array([1., 2]); print(round(a @ Xi @ b, 6), (-Xi.T @ np.outer(a, b) @ Xi.T).round(6))   # 1.4 [[-0.04 -0.12] [-0.24 -0.72]]

# каждое тождество на случайных матрицах
n = 4
a, b, x = rng.normal(size=n), rng.normal(size=n), rng.normal(size=n)
A, B = rng.normal(size=(n, n)), rng.normal(size=(n, n))
X = rng.normal(size=(n, n)) + n * np.eye(n)                         # заведомо обратима
check('a^T x', lambda v: a @ v, x, a)
check('x^T A x', lambda v: v @ A @ v, x, (A + A.T) @ x)
check('|Ax - b|^2', lambda v: np.sum((A @ v - b) ** 2), x, 2 * A.T @ (A @ x - b))
check('tr(AX)', lambda M: np.trace(A @ M), X, A.T)
check('tr(X^T A X)', lambda M: np.trace(M.T @ A @ M), X, (A + A.T) @ X)
check('log|det X|', lambda M: np.linalg.slogdet(M)[1], X, np.linalg.inv(X).T)
Xi = np.linalg.inv(X)
check('a^T X^-1 b', lambda M: a @ np.linalg.solve(M, b), X, -Xi.T @ np.outer(a, b) @ Xi.T)
# каждая строка печатает max error от 3e-11 до 7e-09: совпадение с точностью центральных разностей
# сам d(X^-1): изменение обратной матрицы в первом порядке совпадает с -X^-1 dX X^-1
E = 1e-6 * rng.normal(size=(n, n))
print(f'{np.abs(np.linalg.inv(X + E) - Xi - (-Xi @ E @ Xi)).max():.1e}')   # 7.0e-14: второй порядок по E

# кросс-энтропия с softmax: разобранный пример, затем случайный слой
softmax = lambda z: np.exp(z - z.max()) / np.exp(z - z.max()).sum()
z = np.array([2., 1, 0.1]); y = np.array([1., 0, 0]); p = softmax(z)
print(p.round(3), round(-np.log(p[0]), 3), (p - y).round(3), np.outer(p - y, [1, -2]).round(3))
# [0.659 0.242 0.099] 0.417 [-0.341  0.242  0.099] [[-0.341  0.682] [ 0.242 -0.485] [ 0.099 -0.197]]
K, d = 3, 5
W, bb, xx = rng.normal(size=(K, d)), rng.normal(size=K), rng.normal(size=d)
ce = lambda W_, b_: -np.log(softmax(W_ @ xx + b_)[1])                 # истинный класс 1
p = softmax(W @ xx + bb); y = np.eye(K)[1]
check('CE, W', lambda M: ce(M, bb), W, np.outer(p - y, xx))
check('CE, b', lambda v: ce(W, v), bb, p - y)
# CE, W max error 2.4e-10 | CE, b max error 1.5e-10

# метод наименьших квадратов на четырёх точках из заметки о нём
Xd = np.column_stack([np.ones(4), [0., 1, 2, 3]]); yd = np.array([1., 3, 2, 5])
print(2 * Xd.T @ (Xd @ np.zeros(2) - yd), (2 * Xd.T @ (Xd @ np.array([1.1, 1.1]) - yd)).round(12) + 0)   # [-22. -44.] [0. 0.]

# логистическая регрессия: разобранный пример из её заметки, затем случайная матрица плана
sig = lambda t: 1 / (1 + np.exp(-t))
xl, yl = np.array([2., -1, 0.5]), np.array([1., 0, 0]); pl = sig(xl)
print((pl - yl).round(3), round(xl @ (pl - yl), 3), round(np.sum(pl * (1 - pl) * xl ** 2), 3))   # [-0.119  0.269  0.622] -0.196 0.675
Xr, yr, w = rng.normal(size=(20, 3)), rng.integers(0, 2, 20).astype(float), rng.normal(size=3)
nll = lambda v: -np.sum(yr * np.log(sig(Xr @ v)) + (1 - yr) * np.log(1 - sig(Xr @ v)))
pr = sig(Xr @ w)
check('logistic grad', nll, w, Xr.T @ (pr - yr))
grad_l = lambda v: Xr.T @ (sig(Xr @ v) - yr)
H_num = np.column_stack([(grad_l(w + 1e-6 * e) - grad_l(w - 1e-6 * e)) / 2e-6 for e in np.eye(3)])   # якобиан градиента
print(f'{"logistic Hess":14s} max error {np.abs(H_num - Xr.T @ np.diag(pr * (1 - pr)) @ Xr).max():.1e}')
# logistic grad max error 2.0e-09 | logistic Hess max error 7.2e-10

# ковариация гауссианы по методу максимального правдоподобия: градиент обращается в ноль в S / n
P3 = np.array([[1., 0], [-1, 1], [0, -1]]); S = P3.T @ P3
ell = lambda Sig: -1.5 * np.linalg.slogdet(Sig)[1] - 0.5 * np.trace(np.linalg.solve(Sig, S))
G_at = lambda Sig: -1.5 * np.linalg.inv(Sig) + 0.5 * np.linalg.inv(Sig) @ S @ np.linalg.inv(Sig)
check('Gaussian ell', ell, np.eye(2), G_at(np.eye(2)))   # max error 2.6e-10
print((S / 3).round(3), np.abs(num_grad(ell, S / 3)).max() < 1e-8)   # [[ 0.667 -0.333] [-0.333  0.667]] True

# где это ломается: симметричная матрица с одним общим внедиагональным параметром s
logdet_s = lambda s: np.linalg.slogdet(np.array([[2., s], [s, 2.]]))[1]
h = 1e-6
print(round((logdet_s(1 + h) - logdet_s(1 - h)) / (2 * h), 4), np.linalg.inv([[2., 1], [1, 2]])[0, 1].round(4))
# -0.6667 -0.3333: производная по s вдвое больше элемента (1, 2) обратной матрицы
```
