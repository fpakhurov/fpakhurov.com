[Предыдущая заметка](/ru/notes/math/derivatives-and-taylor-series) приблизила функцию одной переменной касательной и добавила кривизну по формуле Тейлора. Функция потерь в машинном обучении зависит от целого вектора весов, а слой сети отображает вектор в вектор. Эта заметка переносит те же идеи на много измерений. Производная скалярной функции становится вектором — **градиентом** (gradient), который указывает направление наискорейшего подъёма и пересекает линии уровня под прямым углом. Производная векторной функции становится матрицей — **матрицей Якоби**, или **якобианом** (Jacobian), а цепное правило становится произведением якобианов, и именно его вычисляет обратное распространение ошибки. Вторая производная становится симметричной матрицей — **матрицей Гессе**, или **гессианом** (Hessian), собственные значения которой отличают минимум от максимума и от седла.

**Обозначения.** Векторы обозначаются строчными буквами и записываются столбцами, матрицы — прописными. $x = (x_1, \dots, x_n) \in \mathbb R^n$, а $e_1, \dots, e_n$ — стандартный базис. $\langle a, b\rangle = a^\top b$ — скалярное произведение, $\lVert \cdot \rVert$ — евклидова норма из [заметки о скалярном произведении](/ru/notes/math/inner-products-and-orthogonality); для матрицы $\lVert A\rVert$ — операторная норма, наибольшее сингулярное число из [заметки о сингулярном разложении](/ru/notes/math/singular-value-decomposition). Функция $f: \mathbb R^n \to \mathbb R$ — скалярная; функция $f: \mathbb R^n \to \mathbb R^m$ — векторная, с компонентами $f_1, \dots, f_m$, и указанная вместе с ней область значений говорит, какая из двух имеется в виду. $\partial_i f = \partial f/\partial x_i$ — частная производная, $\nabla f(x)$ — градиент (вектор-столбец), $J_{f}(x)$ — якобиан ($m \times n$), $\nabla^2 f(x)$ — гессиан ($n \times n$). Остаток $r(h)$ есть $o(\lVert h\rVert)$, если $\lVert r(h)\rVert/\lVert h\rVert \to 0$ при $h \to 0$.

## Отправная точка: по одной координате \{#baseline-one-coordinate-at-a-time\}

Проще всего продифференцировать функцию нескольких переменных, заморозив все переменные, кроме одной. **Частная производная** (partial derivative) $\partial_i f(x)$ — это обычная производная $t \mapsto f(x + te_i)$ при $t = 0$. Сквозной пример заметки — квадратичная функция двух переменных:

$$
q(x) = x_1^2 + x_1 x_2 + 2x_2^2 .
$$

Её частные производные $\partial_1 q = 2x_1 + x_2$ и $\partial_2 q = x_1 + 4x_2$; в точке $x = (1, 1)$ они равны $3$ и $5$.

Частные производные смотрят только вдоль осей, и этого недостаточно. Функция $g(x_1, x_2) = x_1 x_2/(x_1^2 + x_2^2)$, доопределённая значением $g(0) = 0$, обращается в ноль на обеих осях, поэтому обе её частные производные в $0$ равны 0. Но на диагонали $x_1 = x_2 \ne 0$ она равна $\tfrac12$: $g$ даже не непрерывна в начале координат, и никакая плоскость её там не приближает. Производная функции нескольких переменных должна описывать сразу все направления.

## Градиент: наилучшее линейное приближение \{#the-gradient-the-best-linear-approximation\}

Идея та же, что в предыдущей заметке, только приращение теперь вектор: $f$ **дифференцируема** в $x$, если вблизи $x$ она равна линейной функции приращения плюс ошибка, малая по сравнению с длиной приращения. Линейная функция от $h \in \mathbb R^n$ — это скалярное произведение с фиксированным вектором, и этот вектор есть градиент:

$$
\boxed{\; f(x + h) = f(x) + \langle \nabla f(x), h\rangle + r(h), \qquad \frac{r(h)}{\lVert h\rVert} \to 0 \text{ при } h \to 0 \;}
$$

Подстановка $h = te_i$ показывает, что $i$-я компонента $\nabla f(x)$ равна $\partial_i f(x)$, так что градиент — вектор частных производных, $\nabla f = (\partial_1 f, \dots, \partial_n f)$. Дифференцируемость требует большего, чем их существование, как показывает функция $g$ выше; удобное достаточное условие — все частные производные существуют вблизи $x$ и непрерывны в $x$ ([Deisenroth, Faisal and Ong, 2020](#references), раздел 5.2). Ему удовлетворяют все функции этой заметки и любая гладкая функция потерь. Для квадратичной функции $q$ получаем $\nabla q(1, 1) = (3, 5)$.

<aside class="callout"><strong>Ключевая идея.</strong> Дифференцируемая функция многих переменных вблизи точки есть линейное отображение плюс ошибка меньшего порядка. Для скалярной функции линейное отображение — скалярное произведение с градиентом; для векторной — умножение на матрицу Якоби. Градиент отвечает на вопрос «куда вверх и насколько круто», якобиан — «как сдвигается и растягивается малая область», а цепное правило составляет композицию этих линейных отображений, перемножая матрицы.</aside>

## Производные по направлению \{#directional-derivatives\}

**Производная по направлению** (directional derivative) вдоль единичного вектора $u$ — скорость изменения $f$ при движении из $x$ вдоль $u$, $D_{u} f(x) = \lim_{t \to 0} \big(f(x + tu) - f(x)\big)/t$. Идея: вдоль прямой линейная часть $f$ меняется со скоростью $\langle \nabla f, u\rangle$, а остаток слишком мал, чтобы на что-то влиять:

$$
\boxed{\; D_{u} f(x) = \langle \nabla f(x), u\rangle \;}
$$

Подставим $h = tu$ в определение дифференцируемости и разделим на $t$:

$$
\begin{aligned}
\frac{f(x + tu) - f(x)}{t} &= \frac{\langle \nabla f(x), tu\rangle + r(tu)}{t} && \text{дифференцируемость при } h = tu \\
&= \langle \nabla f(x), u\rangle + \frac{r(tu)}{\lVert tu\rVert} \cdot \frac{\lvert t\rvert}{t} && \text{линейность; } \lVert tu\rVert = \lvert t\rvert \text{ для единичного } u \\
&\to \langle \nabla f(x), u\rangle && \text{второй множитель равен } \pm 1 \text{, первый стремится к } 0 .
\end{aligned}
$$

**Разобранный пример.** Для $q$ в точке $(1, 1)$ и $u = (0.6, 0.8)$ получаем $D_{u} q = 3 \cdot 0.6 + 5 \cdot 0.8 = 5.8$. Центральная разность с $t = 10^{-3}$, $\big(q(x + tu) - q(x - tu)\big)/(2t)$, даёт $5.8$ с точностью до двенадцати цифр, потому что $q$ квадратична, а центральная разность точна для квадратичных функций с точностью до округления.

## Градиент указывает вверх, поперёк линий уровня \{#the-gradient-points-uphill-across-the-level-sets\}

Два геометрических факта делают градиент центральным объектом оптимизации. Идея обоих: производная по направлению — скалярное произведение, а скалярное произведение с фиксированным вектором наибольшее вдоль этого вектора и равно нулю поперёк него. **Множество уровня** (level set) функции $f$ — это $\{x : f(x) = c\}$; на плоскости это линия уровня.

$$
\boxed{\; \max_{\lVert u\rVert = 1} D_{u} f(x) = \lVert \nabla f(x)\rVert \ \text{ при } \ u = \frac{\nabla f(x)}{\lVert \nabla f(x)\rVert}, \qquad \nabla f(x) \perp \text{ множеству уровня, проходящему через } x \;}
$$

**Наискорейший подъём** (steepest ascent). Пусть $\nabla f(x) \ne 0$. Для любого единичного вектора $u$:

$$
\begin{aligned}
D_{u} f(x) &= \langle \nabla f(x), u\rangle && \text{производная по направлению} \\
&\le \lVert \nabla f(x)\rVert\, \lVert u\rVert && \text{неравенство Коши–Буняковского} \\
&= \lVert \nabla f(x)\rVert && \lVert u\rVert = 1 .
\end{aligned}
$$

Равенство в неравенстве Коши–Буняковского достигается ровно тогда, когда $u$ — неотрицательное кратное $\nabla f(x)$, что для единичного вектора означает $u = \nabla f/\lVert \nabla f\rVert$. То же рассуждение для $-u$ показывает, что наискорейший *спуск* идёт вдоль $-\nabla f$ со скоростью $-\lVert \nabla f\rVert$: это направление шага [градиентного спуска](/ru/notes/ml/gradient-descent#which-way-is-downhill).

**Перпендикулярность множеству уровня.** Пусть $\gamma(t)$ — дифференцируемая кривая, остающаяся в множестве уровня $\{f = c\}$, с $\gamma(0) = x$ и скоростью $\gamma'(0) = v$ — касательным вектором множества уровня в $x$. Тогда:

$$
\begin{aligned}
0 &= \frac{f(\gamma(t)) - f(\gamma(0))}{t} && f = c \text{ вдоль кривой} \\
&= \Big\langle \nabla f(x), \frac{\gamma(t) - x}{t}\Big\rangle + \frac{r\big(\gamma(t) - x\big)}{t} && \text{дифференцируемость при } h = \gamma(t) - x \\
&\to \langle \nabla f(x), v\rangle && \text{при } t \to 0 .
\end{aligned}
$$

В последней строке разностное отношение для $\gamma$ стремится к $v$, а член с остатком стремится к 0, потому что $\lVert \gamma(t) - x\rVert/\lvert t\rvert$ остаётся ограниченным, а $r(h)/\lVert h\rVert \to 0$. Значит, градиент ортогонален каждому касательному направлению множества уровня.

**Разобранный пример.** Линия уровня $q = 4$ проходит через $(1, 1)$, поскольку $1 + 1 + 2 = 4$. Градиент там равен $(3, 5)$, его длина $\sqrt{34} = 5.831$ — наибольшая скорость роста по всем направлениям; направление $(0.6, 0.8)$ из предыдущего примера, близкое к направлению градиента $(0.514, 0.857)$, дало чуть меньше, $5.8$. Касательное направление $(5, -3)/\sqrt{34}$ даёт $D = (15 - 15)/\sqrt{34} = 0$: в первом порядке $q$ вдоль линии уровня не меняется.

## Якобиан векторной функции \{#the-jacobian-of-a-vector-function\}

Векторная функция $f: \mathbb R^n \to \mathbb R^m$ дифференцируема в $x$, если она приближается линейным отображением, которое теперь задаётся матрицей $m \times n$:

$$
f(x + h) = f(x) + J_{f}(x)\, h + r(h), \qquad \big(J_{f}(x)\big)_{ij} = \frac{\partial f_i}{\partial x_j}(x), \qquad r(h) = o(\lVert h\rVert) .
$$

Строка $i$ **якобиана** — это $\nabla f_i^\top$, градиент $i$-го выхода; столбец $j$ — это $\partial f/\partial x_j$, отклик всех выходов на $j$-й вход. Форма — выходы × входы, как у матрицы любого линейного отображения в [заметке о линейных отображениях](/ru/notes/math/vectors-and-linear-maps). Для скалярной функции якобиан — строка $1 \times n$, $\nabla f^\top$. Из двух якобианов состоит нейронная сеть: у линейного слоя $z = Wh + b$ якобиан по $h$ равен $W$, а у поэлементной активации $\varphi$ якобиан диагональный, $\operatorname{diag}\big(\varphi'(z)\big)$.

**Разобранный пример.** Отображение $F(x_1, x_2) = (x_1^2 - x_2^2,\ 2x_1 x_2)$ — возведение в квадрат комплексного числа $x_1 + i x_2$ — имеет якобиан

$$
J_{F}(x) = \begin{pmatrix} 2x_1 & -2x_2 \\ 2x_2 & 2x_1 \end{pmatrix}, \qquad J_{F}(1, 0.5) = \begin{pmatrix} 2 & -1 \\ 1 & 2 \end{pmatrix} .
$$

В точке $(1, 0.5)$ эта матрица равна повороту на $\arctan(1/2) = 26.6°$, умноженному на $\sqrt 5$, и её определитель равен 5. Поэтому вблизи этой точки $F$ поворачивает малый квадрат на $26.6°$, растягивает его в $\sqrt 5 = 2.236$ раза и умножает его площадь на 5 — множитель из раздела об [определителе как объёме](/ru/notes/math/determinants-and-eigenvalues#the-determinant-how-a-map-scales-volume). Для квадрата со стороной $0.2$ с центром $(1, 0.5)$ точная площадь искривлённого образа равна $0.2011$ против $5 \cdot 0.04 = 0.2$ у линейного отображения; для стороны $0.1$ отношение площадей равно $5.007$ и стремится к $\lvert\det J\rvert = 5$ по мере уменьшения квадрата. Этот локальный множитель площади и есть $\lvert \det J\rvert$ в замене переменных из [заметки о кратных интегралах](/ru/notes/math/multiple-integrals).

## Цепное правило: произведение якобианов \{#the-chain-rule-a-product-of-jacobians\}

Идея: композиция двух отображений есть композиция их линейных приближений, а композиция линейных отображений — произведение их матриц. Для $f: \mathbb R^n \to \mathbb R^m$, дифференцируемой в $x$, и $g: \mathbb R^m \to \mathbb R^p$, дифференцируемой в $y = f(x)$:

$$
\boxed{\; J_{g \circ f}(x) = J_{g}\big(f(x)\big)\, J_{f}(x) \qquad (p \times n) = (p \times m)(m \times n) \;}
$$

Обозначим $k = f(x + h) - f(x) = J_{f}h + r_{f}(h)$ — сдвиг, который $h$ вызывает во входе $g$; оба якобиана берутся в своих точках. Тогда:

$$
\begin{aligned}
g(f(x + h)) - g(f(x)) &= g(y + k) - g(y) && \text{определения } y, k \\
&= J_{g}k + r_{g}(k) && \text{дифференцируемость } g \text{ в } y \\
&= J_{g} J_{f}h + J_{g}r_{f}(h) + r_{g}(k) && \text{подставляем } k .
\end{aligned}
$$

Первый член линеен по $h$; два других есть $o(\lVert h\rVert)$. Второй не больше $\lVert J_{g}\rVert\, \lVert r_{f}(h)\rVert$. Для третьего $\lVert k\rVert \le \lVert J_{f}\rVert\, \lVert h\rVert + \lVert r_{f}(h)\rVert$, так что $\lVert k\rVert/\lVert h\rVert$ остаётся ограниченным и $k \to 0$, а $r_{g}(k)/\lVert k\rVert \to 0$ (при $k = 0$ член равен $0$). Значит, линейная часть композиции есть $J_{g} J_{f}$.

**Скалярная функция потерь в конце.** Когда последняя функция — скалярная функция потерь $\ell: \mathbb R^m \to \mathbb R$, её якобиан — строка $\nabla \ell^\top$, и транспонирование цепного правила даёт

$$
\nabla(\ell \circ f)(x) = J_{f}(x)^\top\, \nabla \ell\big(f(x)\big) .
$$

Для сети, то есть цепочки слоёв, градиент функции потерь — это градиент на выходе, умноженный на транспонированные якобианы слоёв от последнего к первому. Умножение в этом порядке оставляет каждый промежуточный результат вектором и никогда не строит якобиан как матрицу; это дифференцирование в обратном режиме. [Заметка об обратном распространении ошибки](/ru/notes/ml/backpropagation#the-chain-rule-in-matrix-form) расписывает его для линейных слоёв и активаций с указанием форм и объясняет, [почему оно стоит примерно одного прямого прохода](/ru/notes/ml/backpropagation#why-reverse-mode-costs-about-one-forward-pass); [autograd в PyTorch](/ru/notes/deep-learning/pytorch-and-autograd#the-computational-graph) записывает цепочку как граф и выполняет её автоматически.

**Разобранный пример.** Возьмём $F$ из предыдущего раздела и $\ell(v) = v_1 + v_2^2$. В точке $x = (1, 0.5)$ имеем $v = F(x) = (0.75, 1)$ и $\nabla \ell(v) = (1, 2v_2) = (1, 2)$, поэтому

$$
\nabla(\ell \circ F)(1, 0.5) = \begin{pmatrix} 2 & 1 \\ -1 & 2 \end{pmatrix}\begin{pmatrix} 1 \\ 2 \end{pmatrix} = \begin{pmatrix} 4 \\ 3 \end{pmatrix} .
$$

Прямой путь даёт то же. Композиция равна $x_1^2 - x_2^2 + 4x_1^2 x_2^2$, её частные производные $2x_1 + 8x_1 x_2^2 = 2 + 2 = 4$ и $-2x_2 + 8x_1^2 x_2 = -1 + 4 = 3$.

## Гессиан и разложение Тейлора второго порядка \{#the-hessian-and-the-second-order-taylor-expansion\}

**Гессиан** собирает вторые частные производные, $\big(\nabla^2 f(x)\big)_{ij} = \partial^2 f/\partial x_i \partial x_j$; это якобиан градиента. Если вторые частные производные непрерывны, порядок дифференцирования не важен (теорема Шварца), поэтому гессиан **симметричен**. Идея разложения: ограничим $f$ на отрезок от $x$ до $x + h$, применим там формулу Тейлора для одной переменной и прочитаем производные по одной переменной как градиент и гессиан. Для $f$ с непрерывными вторыми производными:

$$
\boxed{\; f(x + h) = f(x) + \langle \nabla f(x), h\rangle + \tfrac12\, h^\top \nabla^2 f(x)\, h + o\big(\lVert h\rVert^2\big) \;}
$$

Пусть $\phi(t) = f(x + th)$. Цепное правило даёт $\phi'(t) = \sum_i \partial_i f(x + th)\, h_i$, а применённое ещё раз к каждой $\partial_i f$ — $\phi''(t) = \sum_i \sum_j \partial_j \partial_i f(x + th)\, h_j h_i = h^\top \nabla^2 f(x + th)\, h$. Тогда:

$$
\begin{aligned}
f(x + h) &= \phi(1) && \text{определение } \phi \\
&= \phi(0) + \phi'(0) + \tfrac12 \phi''(\tau) && \text{формула Тейлора для одной переменной при } n = 1,\ \tau \in (0, 1) \\
&= f(x) + \langle \nabla f(x), h\rangle + \tfrac12\, h^\top \nabla^2 f(x + \tau h)\, h && \text{производные } \phi \\
&= f(x) + \langle \nabla f(x), h\rangle + \tfrac12\, h^\top \nabla^2 f(x)\, h + o\big(\lVert h\rVert^2\big) && \nabla^2 f \text{ непрерывен.}
\end{aligned}
$$

Последний шаг заменяет гессиан в точке $x + \tau h$ гессианом в точке $x$; разница не больше $\tfrac12 \lVert \nabla^2 f(x + \tau h) - \nabla^2 f(x)\rVert\, \lVert h\rVert^2$, а норма разности стремится к 0 вместе с $h$.

У квадратичной функции $f(x) = \tfrac12 x^\top Ax + b^\top x$ с симметричной $A$ градиент $\nabla f = Ax + b$ и постоянный гессиан $A$, и её разложение точное. Гессианы двух стандартных функций потерь такого вида или близки к нему: $2X^\top X$ для [метода наименьших квадратов](/ru/notes/ml/least-squares#the-normal-equations) и $X^\top S X$ для [логистической регрессии](/ru/notes/ml/logistic-regression#the-gradient-residuals-times-inputs); [заметка о матричном дифференцировании](/ru/notes/math/matrix-calculus) выводит оба.

**Разобранный пример.** У кубической функции $c(x) = x_1^3 - 3x_1 + x_2^2$

$$
\nabla c(x) = \begin{pmatrix} 3x_1^2 - 3 \\ 2x_2 \end{pmatrix}, \qquad \nabla^2 c(x) = \begin{pmatrix} 6x_1 & 0 \\ 0 & 2 \end{pmatrix} .
$$

В точке $x = (1.2, 0.5)$ имеем $c = -1.622$, $\nabla c = (1.32, 1)$ и $\nabla^2 c = \operatorname{diag}(7.2, 2)$. Для шага $h = (0.1, -0.2)$ линейное приближение даёт $-1.622 + 0.132 - 0.2 = -1.690$, а квадратичный член добавляет $\tfrac12(7.2 \cdot 0.01 + 2 \cdot 0.04) = 0.076$, что даёт $-1.614$. Точное значение $c(1.3, 0.3) = -1.613$. Ошибки равны $0.077$ и $0.001$; вторая совпадает с $h_1^3 = 0.001$ — кубическим членом, который разложение второго порядка отбрасывает.

## Классификация критических точек по собственным значениям гессиана \{#classifying-critical-points-by-the-hessians-eigenvalues\}

В **критической точке** (critical point) $x^*$, где $\nabla f(x^*) = 0$, линейный член исчезает, и поведение $f$ рядом определяет квадратичная форма $h^\top \nabla^2 f\, h$. По [спектральной теореме](/ru/notes/math/symmetric-matrices) симметричный гессиан равен $Q\Lambda Q^\top$ с ортонормированными собственными векторами $q_i$ и вещественными собственными значениями $\lambda_i$, поэтому $h^\top \nabla^2 f\, h = \sum_i \lambda_i (q_i^\top h)^2$: вдоль каждого собственного вектора $f$ выгибается вверх или вниз в зависимости от знака его собственного значения. Идея признака: если все собственные значения положительны, $f$ выгибается вверх по всем направлениям.

$$
\boxed{\; \nabla f(x^*) = 0 \text{ и } \begin{cases} \text{все } \lambda_i > 0 & \Rightarrow \text{строгий локальный минимум} \\ \text{все } \lambda_i < 0 & \Rightarrow \text{строгий локальный максимум} \\ \text{одни } \lambda_i > 0,\ \text{другие } \lambda_j < 0 & \Rightarrow \text{седловая точка} \\ \text{иначе (нулевое собственное значение)} & \Rightarrow \text{вывода нет} \end{cases} \;}
$$

Для минимума, где $\lambda_{\min} > 0$ — наименьшее собственное значение:

$$
\begin{aligned}
f(x^* + h) - f(x^*) &= \tfrac12\, h^\top \nabla^2 f(x^*)\, h + o\big(\lVert h\rVert^2\big) && \text{формула Тейлора второго порядка, } \nabla f(x^*) = 0 \\
&= \tfrac12 \sum_i \lambda_i\, (q_i^\top h)^2 + o\big(\lVert h\rVert^2\big) && \text{спектральное разложение} \\
&\ge \tfrac12\, \lambda_{\min} \sum_i (q_i^\top h)^2 + o\big(\lVert h\rVert^2\big) && \lambda_i \ge \lambda_{\min} \\
&= \tfrac12\, \lambda_{\min} \lVert h\rVert^2 + o\big(\lVert h\rVert^2\big) && Q \text{ ортогональна и сохраняет длины} \\
&> 0 \quad \text{при малых } h \ne 0 && \text{остаток становится меньше } \tfrac14 \lambda_{\min} \lVert h\rVert^2 .
\end{aligned}
$$

Максимум — то же рассуждение для $-f$. В седле шаг $h = tq_+$ вдоль собственного вектора с $\lambda_+ > 0$ меняет $f$ на $\tfrac12 \lambda_+ t^2 + o(t^2) > 0$, а шаг вдоль $q_-$ с $\lambda_- < 0$ — на отрицательную величину, так что $x^*$ не минимум и не максимум. При нулевом собственном значении квадратичный член плоский в некотором направлении, и решают члены высших порядков: у $x_1^4 + x_2^2$ и $-x_1^4 + x_2^2$ в начале координат один и тот же гессиан $\operatorname{diag}(0, 2)$, но у первой там минимум, а у второй седло.

**Разобранный пример.** У кубической функции $c$ градиент $\nabla c = 0$ там, где $x_1^2 = 1$ и $x_2 = 0$: в $(1, 0)$ и $(-1, 0)$. В $(1, 0)$ гессиан равен $\operatorname{diag}(6, 2)$, оба собственных значения положительны: строгий локальный минимум, $c = -2$. В $(-1, 0)$ он равен $\operatorname{diag}(-6, 2)$: седло с $c = 2$, максимум вдоль $x_1$ и минимум вдоль $x_2$. Минимум лишь локальный, поскольку $c \to -\infty$ при $x_1 \to -\infty$.

Так машинное обучение и читает свои функции потерь. Гессиан, всюду положительно полуопределённый, делает функцию потерь выпуклой, и тогда каждая критическая точка — глобальный минимум: это доказывает [заметка о выпуклости](/ru/notes/math/convex-sets-and-functions), а стандартный пример — логистическая функция потерь с гессианом $X^\top S X$. Собственные значения задают и скорость методов первого порядка: на квадратичной функции градиентному спуску нужен шаг меньше $2/\lambda_{\max}$, а скорость сходимости определяется отношением $\lambda_{\max}/\lambda_{\min}$; метод Ньютона перемасштабирует шаг обратным гессианом, как показывает [заметка о безусловной оптимизации](/ru/notes/math/unconstrained-optimization). Функции потерь нейронных сетей невыпуклы. [Dauphin et al. (2014)](#references) на основе результатов о случайных функциях и экспериментов с небольшими сетями утверждают, что в высокой размерности большинство критических точек с высоким значением функции потерь — седла, а не локальные минимумы, и поэтому выход из седел становится центральным вопросом для оптимизаторов.

## Ограничения \{#limitations\}

- **Гессиан велик.** У сети с $10^6$ весами гессиан содержит $10^{12}$ элементов — слишком много, чтобы построить или хранить. Методы второго порядка работают с произведениями гессиана на вектор, которые стоят примерно как несколько градиентов ([Pearlmutter, 1994](#references)), или с приближениями гессиана.
- **Признак второго порядка может молчать.** Нулевое собственное значение оставляет решение членам высших порядков, а у перепараметризованных сетей много плоских направлений: например, перемасштабирование весов на входе и на выходе ReLU-нейрона не меняет функцию.
- **Дифференцируемость может нарушаться.** У ReLU, кусочно-линейной функции потерь (hinge loss) и нормы $\ell_1$ есть изломы, где градиента не существует и теория этой заметки неприменима; [заметка о выпуклости](/ru/notes/math/convex-sets-and-functions) работает с ними через субградиенты.
- **Всё локально.** Нулевой градиент и положительно определённый гессиан гарантируют лишь локальный минимум. Без выпуклости ничто в этой заметке не говорит, насколько он хорош.

## Что нужно запомнить \{#what-you-should-remember\}

- $f$ дифференцируема в $x$, если $f(x + h) = f(x) + \langle \nabla f(x), h\rangle + o(\lVert h\rVert)$; градиент — вектор частных производных, но одни частные производные не гарантируют дифференцируемости.
- $D_{u} f = \langle \nabla f, u\rangle$. Градиент — направление наискорейшего подъёма со скоростью $\lVert \nabla f\rVert$, и он перпендикулярен линиям уровня.
- Якобиан имеет форму выходы × входы; его определитель — локальный множитель, с которым отображение меняет площади или объёмы.
- Цепное правило: $J_{g \circ f} = J_{g} J_{f}$; для скалярной функции потерь в конце $\nabla(\ell \circ f) = J_{f}^\top \nabla \ell$, и обратное распространение ошибки вычисляет это от функции потерь назад.
- $f(x + h) \approx f(x) + \langle \nabla f, h\rangle + \tfrac12 h^\top \nabla^2 f\, h$; в критической точке положительные собственные значения означают минимум, отрицательные — максимум, разные знаки — седло, а нулевое собственное значение не позволяет сделать вывод.

## Код \{#code\}

Каждая производная из заметки проверяется центральными разностями: градиент и производная по направлению для $q$, якобиан и цепное правило для $F$, разложение второго порядка и критические точки $c$, площадь образа малого квадрата и произведение гессиана на вектор, вычисленное по двум градиентам. Последние цифры могут отличаться на разных платформах.

```python
import numpy as np
from scipy import integrate

def num_grad(f, x, h=1e-6):
    """Central differences, one coordinate at a time."""
    E = np.eye(len(x))
    return np.array([(f(x + h * e) - f(x - h * e)) / (2 * h) for e in E])

def num_jac(F, x, h=1e-6):
    """Column j is the central difference of F along e_j."""
    return np.column_stack([(F(x + h * e) - F(x - h * e)) / (2 * h) for e in np.eye(len(x))])

# квадратичная функция q: градиент, производная по направлению, наискорейший подъём, касательная к линии уровня
q = lambda x: x[0] ** 2 + x[0] * x[1] + 2 * x[1] ** 2
grad_q = lambda x: np.array([2 * x[0] + x[1], x[0] + 4 * x[1]])
x = np.array([1.0, 1.0])
u = np.array([0.6, 0.8]); tangent = np.array([5.0, -3.0]) / np.sqrt(34)
print(q(x), grad_q(x), num_grad(q, x).round(8), round(grad_q(x) @ u, 6), round(np.linalg.norm(grad_q(x)), 3), grad_q(x) @ tangent)
# 4.0 [3. 5.] [3. 5.] 5.8 5.831 0.0
angle = np.degrees(np.arccos(grad_q(x) @ x / np.linalg.norm(grad_q(x)) / np.linalg.norm(x)))
print(round(angle, 1))   # 14.0: направление спуска не указывает на минимум

# якобиан F(x) = (x1^2 - x2^2, 2 x1 x2) и цепное правило с l(v) = v1 + v2^2
F = lambda x: np.array([x[0] ** 2 - x[1] ** 2, 2 * x[0] * x[1]])
J_F = lambda x: np.array([[2 * x[0], -2 * x[1]], [2 * x[1], 2 * x[0]]])
ell = lambda v: v[0] + v[1] ** 2
p = np.array([1.0, 0.5])
print(J_F(p), np.abs(num_jac(F, p) - J_F(p)).max() < 1e-8, round(np.linalg.det(J_F(p)), 6))   # [[ 2. -1.] [ 1.  2.]] True 5.0
print(J_F(p).T @ np.array([1, 2 * F(p)[1]]), num_grad(lambda x: ell(F(x)), p).round(8))   # [4. 3.] [4. 3.]

# площадь образа квадрата со стороной s с центром p — интеграл |det J| = 4(x1^2 + x2^2) по квадрату
for s in (0.2, 0.1):
    area = integrate.dblquad(lambda y, x: 4 * (x * x + y * y), 1 - s / 2, 1 + s / 2, 0.5 - s / 2, 0.5 + s / 2)[0]
    print(s, round(area, 4), round(area / s ** 2, 3))   # 0.2 0.2011 5.027 | 0.1 0.0501 5.007

# кубическая функция c: формула Тейлора второго порядка в (1.2, 0.5) с шагом (0.1, -0.2), затем её критические точки
c = lambda x: x[0] ** 3 - 3 * x[0] + x[1] ** 2
grad_c = lambda x: np.array([3 * x[0] ** 2 - 3, 2 * x[1]])
hess_c = lambda x: np.array([[6 * x[0], 0.0], [0.0, 2.0]])
x0, h = np.array([1.2, 0.5]), np.array([0.1, -0.2])
lin = c(x0) + grad_c(x0) @ h; quad = lin + 0.5 * h @ hess_c(x0) @ h
print(round(c(x0), 3), round(lin, 3), round(quad, 3), round(c(x0 + h), 3), round(c(x0 + h) - lin, 3), round(c(x0 + h) - quad, 6))
# -1.622 -1.69 -1.614 -1.613 0.077 0.001
print(np.abs(num_jac(grad_c, x0) - hess_c(x0)).max() < 1e-6)   # True: гессиан — якобиан градиента
for xs in (np.array([1.0, 0.0]), np.array([-1.0, 0.0])):
    lam = np.linalg.eigvalsh(hess_c(xs))
    kind = 'minimum' if lam.min() > 0 else 'maximum' if lam.max() < 0 else 'saddle' if lam.min() < 0 < lam.max() else 'undecided'
    print(xs, grad_c(xs), lam, c(xs), kind)
# [1. 0.] [0. 0.] [2. 6.] -2.0 minimum | [-1.  0.] [0. 0.] [-6.  2.] 2.0 saddle

# произведение гессиана на вектор по двум градиентам, без построения гессиана
v = np.array([0.3, -0.7]); eps = 1e-6
print(((grad_c(x0 + eps * v) - grad_c(x0 - eps * v)) / (2 * eps)).round(6), hess_c(x0) @ v)   # [ 2.16 -1.4 ] [ 2.16 -1.4 ]
```
