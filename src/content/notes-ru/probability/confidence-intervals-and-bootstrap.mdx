Два успеха среди шестнадцати наблюдений дают оценку вероятности 0.125. Симметричный интервал вокруг этой оценки уходит ниже нуля. Если обрезать его границу, диапазон станет правдоподобнее. Но остаётся более важный вопрос: как часто эта конструкция содержит истинную вероятность при получении новой выборки?

Для интервала нужны правило сбора выборки и оцениваемая величина. Будем различать неопределённость среднего по генеральной совокупности и разброс отдельных наблюдений. Каждая гарантия зависит от модели, по которой мы её рассчитываем.

## Что означают 95% \{#what-95-means\}

Обозначим через $X$ всю случайную выборку, через $\theta$ фиксированный параметр генеральной совокупности, а через $C(X)$ интервал, рассчитанный по заранее выбранной процедуре. При $0<\alpha<1$ доверительный уровень $1-\alpha$ требует неравенства для **покрытия** (coverage):

$$
\Pr_\theta\{\theta\in C(X)\}\geq1-\alpha
$$

для каждого значения параметра, допускаемого моделью. При смене выборки интервал меняется. Уже полученный интервал либо содержит фиксированный параметр, либо не содержит его. Утверждение о покрытии относится к повторному получению выборок при заявленных предположениях ([Neyman, 1937](#references), §II(a)).

Процедура с уровнем 95% не обещает ровно девятнадцать попаданий в каждых двадцати повторениях. Если независимые повторения имеют покрытие 0.95, математическое ожидание индикатора попадания равно 0.95. По закону больших чисел наблюдаемая доля попаданий приближается к этому значению. Байесовский интервал, напротив, задаёт апостериорную вероятность для параметра при выбранных правдоподобии и априорном распределении. Границы иногда совпадают, но вероятностные утверждения относятся к разным случайным объектам.

Одного покрытия недостаточно для полезности. Вся вещественная прямая всегда содержит вещественный параметр. Нам также нужен достаточно узкий интервал, чтобы различить интересующий эффект. Увеличение выборки может сократить случайную неопределённость, но не устраняет смещение отбора и не исправляет неверное определение целевой совокупности.

## Интервалы из нормального приближения \{#intervals-from-the-normal-approximation\}

Пусть независимые наблюдения имеют распределение $\mathcal N(\mu,\sigma^2)$ с известным положительным $\sigma$. Среднее распределено точно нормально. Стандартизация даёт **пивотальную величину** (pivot), распределение которой не зависит от неизвестного среднего:

$$
Z=\frac{\bar X-\mu}{\sigma/\sqrt n}\sim\mathcal N(0,1).
$$

Обозначим через $z=z_{1-\alpha/2}$ квантиль стандартного нормального распределения с накопленной вероятностью $1-\alpha/2$. Решая неравенство $-z\leq Z\leq z$ относительно $\mu$, получаем

$$
\begin{aligned}
h&=z\frac{\sigma}{\sqrt n},\\
C(X)&=[\bar X-h,\bar X+h].
\end{aligned}
$$

В нормальной модели это точный интервал. Для произвольных независимых одинаково распределённых наблюдений с конечной положительной дисперсией центральная предельная теорема мотивирует приближённый интервал при большом $n$. Подстановка оценки стандартной ошибки не делает хвосты распределения конечной выборки точно гауссовскими.

В учебном примере с известным шумом наблюдаемое среднее равно 2.8, $n=25$, а $\sigma=1.5$. Стандартная ошибка равна 0.3. При $z\approx1.959964$ получаем 95%-й интервал $[2.2120,3.3880]$. Эти границы относятся к среднему; отдельное будущее измерение меняется гораздо сильнее, чем среднее двадцати пяти измерений.

Если $n\geq2$ нормальных наблюдений имеют неизвестную дисперсию, используем выборочную дисперсию $S^2$ с делителем $n-1$. Замена $\sigma$ на $S$ добавляет случайность в знаменатель. В нормальной модели

$$
T=\frac{\bar X-\mu}{S/\sqrt n}\sim t_{n-1}.
$$

Более тяжёлые хвосты учитывают эту неопределённость ([Student, 1908](#references), §III). Чтобы увидеть механизм, повернём стандартизованную гауссовскую выборку в направление среднего и $n-1$ перпендикулярных направлений остатков. Координаты останутся независимыми стандартными нормальными величинами. Квадрат длины вектора остатков имеет распределение хи-квадрат с $n-1$ степенями свободы и независим от координаты среднего. Отношение этой координаты к корню из квадрата длины остатков, делённого на $n-1$, определяет распределение Стьюдента.

Для условных нормальных измерений $6,7,9,10,13$ расчёт даёт:

| Величина | Значение |
| --- | --- |
| Выборочное среднее | 9 |
| Выборочная дисперсия | 7.5 |
| Стандартная ошибка | 1.224745 |
| Квантиль 97.5% распределения $t_4$ | 2.776445 |
| 95%-й интервал | $[5.5996,12.4004]$ |

При пяти наблюдениях увеличение критического значения существенно. Эта гарантия для малой выборки опирается на нормальность. Квантиль Стьюдента не заставляет сильно асимметричную выборку из пяти точек вести себя как нормальную.

Для бернуллиевских наблюдений выборочная доля равна $\hat p=K/n$. **Интервал Вальда** (Wald interval) подставляет эту оценку в формулу ошибки:

$$
\hat p\ \pm\ z\sqrt{\frac{\hat p(1-\hat p)}{n}}.
$$

При $K=0$ его ширина равна нулю. Причина сбоя — интерпретация отсутствия успехов как свидетельства отсутствия выборочной изменчивости. **Интервал Уилсона** (Wilson interval) оставляет в стандартной ошибке проверяемую вероятность $p$ и сохраняет значения, удовлетворяющие условию

$$
(\hat p-p)^2\leq\frac{z^2p(1-p)}{n}.
$$

Положим $a=z^2/n$. Раскрывая скобки и собирая степени $p$, получаем

$$
(1+a)p^2-(2\hat p+a)p+\hat p^2\leq0.
$$

Сохраняемые значения лежат между корнями квадратного трёхчлена. Центр $c$ и полуширина $h$ равны

$$
\begin{aligned}
c&=\frac{\hat p+a/2}{1+a},\\
h&=\frac{z}{1+a}\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}.
\end{aligned}
$$

Это построение через обращение скор-критерия у [Wilson (1927)](#references), с. 209–211. Нормальное критическое значение по-прежнему делает интервал приближённым. При $K=2,n=16$ Вальд даёт $[-0.0370,0.2870]$, а Уилсон — $[0.0350,0.3602]$.

Покрытие можно проверить без симуляции. При фиксированной истинной вероятности $p$ каждый возможный счёт имеет биномиальную вероятность. Сложим вероятности тех исходов, чьи интервалы содержат $p$:

$$
\begin{aligned}
b_k(p)&=\binom{16}{k}p^k(1-p)^{16-k},\\
\Pr_p\{p\in C(K)\}
&=\sum_{k=0}^{16}\mathbf1\{p\in C(k)\}b_k(p).
\end{aligned}
$$

При $p=0.1$ точные суммы равны 0.8114 для Вальда и 0.9316 для Уилсона. В этом примере Уилсон заметно улучшает покрытие, но оно всё ещё ниже номинальных 0.95. Пересечение интервала Вальда с $[0,1]$ не меняет того, содержит ли он допустимое $p$; косметическое обрезание не исправляет покрытие.

## Бутстрэп \{#the-bootstrap\}

Для сложной статистики удобная формула выборочного распределения может отсутствовать. **Непараметрический бутстрэп** (nonparametric bootstrap) заменяет неизвестное распределение совокупности эмпирическим: каждой наблюдаемой строке присваивается масса $1/n$. Затем независимо выбираются $n$ строк с возвращением, и статистика пересчитывается ([Efron, 1979](#references), §2).

При условии уже наблюдённой выборки распределение повторной выборки полностью определено. Одна строка может встретиться несколько раз. Если выбрать каждую строку ровно один раз в другом порядке, выборочное среднее не изменится; такой способ не оценивает его выборочную изменчивость.

Для новых учебных значений $1,2,4,8$ существует $4^4=256$ равновероятных упорядоченных бутстрэп-выборок. Их средние образуют конечное распределение с математическим ожиданием 3.75. У каждого повторно выбранного наблюдения эмпирическая дисперсия, поэтому независимость даёт

$$
\begin{aligned}
\operatorname{Var}_*(X^*)&=\frac14\sum_{i=1}^4(x_i-3.75)^2\\
&=7.1875,\\
\operatorname{Var}_*(\bar X^*)&=\frac{7.1875}{4}\\
&=1.796875.
\end{aligned}
$$

Звёздочка означает вероятность при фиксированных наблюдённых значениях. Бутстрэп-оценка стандартной ошибки равна 1.340476. Она использует дисперсию эмпирического распределения с делителем $n$; привычная оценка дисперсии генеральной совокупности использует делитель $n-1$. На четырёх наблюдениях разница заметна.

**Процентильный интервал** (percentile interval) использует нижний и верхний квантили бутстрэп-статистики. Определим квантиль как наименьшее значение, в котором накопленная вероятность достигает требуемого уровня. Перебор всех 256 выборок даёт квантили 2.5% и 97.5%, равные 1.5 и 6.5. Получаем интервал $[1.5,6.5]$. Полный перебор устраняет численную ошибку повторного случайного выбора. Он не устанавливает 95%-е покрытие параметра совокупности для столь малого набора данных.

Когда перебор невозможен, генерируем $B$ независимых бутстрэп-выборок. Рост $B$ точнее приближает распределение, заданное наблюдённой выборкой. Рост исходного объёма $n$ добавляет информацию о генеральной совокупности. Эти действия уменьшают разные источники неопределённости. Смещение и асимметрия могут делать простой процентильный интервал ненадёжным даже при очень большом $B$.

## Когда бутстрэп не работает \{#when-the-bootstrap-fails\}

Рассмотрим двенадцать независимых бернуллиевских наблюдений с истинной вероятностью успеха 0.08. Вероятность увидеть только нули равна

$$
\Pr\{K=0\}=0.92^{12}\approx0.367666.
$$

При условии такой наблюдённой выборки каждое бутстрэп-среднее равно нулю. Процентильный интервал $[0,0]$ не содержит 0.08. Увеличение числа повторных выборок не создаёт успех, отсутствующий в эмпирическом распределении. Это конкретная проблема носителя на малой выборке; нулевая оценка стандартной ошибки не обязательно означает знание истинного параметра.

Единица повторного выбора также должна соответствовать независимости. Повторные измерения одного человека нельзя считать измерениями разных независимых людей. Подходящий кластерный бутстрэп выбирает независимые кластеры целиком; для временного ряда нужна схема, сохраняющая существенную временную зависимость. Выбор кластеров или блоков требует предположений и достаточного числа независимых единиц. Произвольная группировка не даёт гарантии.

## Сравнение двух моделей на одной тестовой выборке \{#comparing-two-models-on-one-test-set\}

Если две фиксированные модели предсказывают одни и те же независимые одинаково распределённые тестовые объекты, их потери образуют пары. Пусть $D_i=L_{A,i}-L_{B,i}$; положительное значение означает преимущество модели B. Целевая величина — ожидаемая разность потерь на новом объекте из той же совокупности. Её оценка и стандартная ошибка равны

$$
\begin{aligned}
\bar D&=\frac1n\sum_{i=1}^nD_i,\\
s_D^2&=\frac1{n-1}\sum_{i=1}^n(D_i-\bar D)^2,\\
\widehat{\operatorname{SE}}(\bar D)&=\frac{s_D}{\sqrt n}.
\end{aligned}
$$

Для двенадцати вымышленных объектов возьмём три разности $+1$, одну $-1$ и восемь нулей. Средняя разность равна $1/6$, выборочная дисперсия — $1/3$, стандартная ошибка — $1/6$. Интервал из нормального приближения составляет примерно $[-0.1600,0.4933]$. Для двенадцати дискретных разностей это грубая характеристика неопределённости, без точной 95%-й гарантии.

Парность важна, потому что

$$
\begin{aligned}
\operatorname{Var}(L_A-L_B)
&=\operatorname{Var}(L_A)+\operatorname{Var}(L_B)\\
&\quad-2\operatorname{Cov}(L_A,L_B).
\end{aligned}
$$

Повторно выбираем целые строки с обеими потерями или сами разности. Раздельный повторный выбор потерь двух моделей удаляет ковариацию и соответствует другой схеме получения данных. Интервал условен относительно уже обученных моделей: он не учитывает изменчивость при переобучении. Выбор моделей после просмотра этой же тестовой выборки добавляет оптимистическое смещение, которое повторный выбор строк не устраняет.

## Что изменилось \{#what-changed\}

Точечная оценка дополняется процедурой с измеримой частотой ошибок. Пивотальная величина выводит интервал из известного распределения; обращение скор-критерия меняет множество параметров, совместимых с приближённой пивотальной величиной; бутстрэп оценивает выборочную изменчивость по эмпирическому распределению. Каждый подход требует собственной проверки калибровки.

## Ограничения \{#limitations\}

Все рассмотренные интервалы предполагают, что наблюдения или единицы повторного выбора представляют целевую совокупность. Ни узкие границы, ни большой объём данных не компенсируют систематические пропуски, утечку или сдвиг распределения. Нормальное и процентильное приближения могут быть неточны в малых выборках, у границ параметров или для нестабильных статистик. Метод, целевая величина, объём выборки и единица наблюдения делают заявленную неопределённость понятной.

## Что нужно запомнить \{#what-you-should-remember\}

- Покрытие — свойство всей процедуры построения интервала.
- Точные нормальные интервалы и интервалы Стьюдента требуют заявленных распределительных предположений.
- Правдоподобная граница не устанавливает номинальное покрытие.
- Точность бутстрэпа ограничена информацией в наблюдённой выборке.
- Парные сравнения сохраняют совместную структуру строк.

## Код \{#code\}

Небольшой расчёт на стандартной библиотеке перебирает всё распределение бутстрэп-среднего и проверяет стандартную ошибку парной разности. Вывод содержит 1.340476, $[1.5,6.5]$ и 0.166667.

```python
from collections import Counter
from itertools import product
from math import sqrt

x = [1, 2, 4, 8]
counts = Counter(sum(row) / 4 for row in product(x, repeat=4))
mean = sum(value * count for value, count in counts.items()) / 256
variance = sum((value - mean)**2 * count for value, count in counts.items()) / 256

def quantile(level):
    cumulative = 0
    for value, count in sorted(counts.items()):
        cumulative += count
        if cumulative / 256 >= level:
            return value

print(f"Bootstrap SE: {sqrt(variance):.6f}")
print("Percentile interval:", [quantile(.025), quantile(.975)])
d = [1, 1, 1, -1] + [0] * 8
average = sum(d) / len(d)
s2 = sum((value - average)**2 for value in d) / (len(d) - 1)
print(f"Paired SE: {sqrt(s2 / len(d)):.6f}")
```

```text
Bootstrap SE: 1.340476
Percentile interval: [1.5, 6.5]
Paired SE: 0.166667
```
