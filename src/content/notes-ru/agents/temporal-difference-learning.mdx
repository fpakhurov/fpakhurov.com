Сервис может наблюдать результат решения, не зная вероятностей всех возможных результатов. В [заметке об MDP](/ru/notes/agents/markov-decision-processes) эти вероятности были доступны для обновления Беллмана. Здесь агент получает переход, обновляет оценку и решает, что попробовать дальше. Важны два выбора: какой опыт собирать и какую часть будущего результата ждать.

Используем три небольших вымышленных примера: бинарную обратную связь для четырёх вариантов, двухэтапную обработку задачи и непрерывно работающий сервис с пополняемым ресурсом. Их условия, рисунки и точные расчёты подготовлены для этой заметки с помощью ИИ. Это учебные примеры, а не измерения работающей системы. [Код](#code) перечисляет исходы без загрузки данных и запуска симулятора.

В момент $t$ агент видит состояние $S_t$, выбирает действие $A_t$, затем наблюдает награду $R_{t+1}$ и состояние $S_{t+1}$. Стратегия $\pi(a\mid s)$ задаёт вероятности действий. Дисконтирование обозначаем $\gamma$, отдачу конечного эпизода — $G_t=\sum_{j=0}^{T-t-1}\gamma^jR_{t+j+1}$, а ценность — $V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]$. Текущие таблицы $V$ и $Q$ содержат оценки; верхние индексы $\pi$ и $\star$ обозначают истинные ценности стратегии и оптимальные ценности. В непрерывном примере $\gamma=4/5<1$; терминальные состояния эпизодических примеров имеют нулевую ценность.

В задаче с конечным горизонтом включаем время или остаток горизонта в состояние, если от него зависит дальнейшая отдача; иначе ценность нужно индексировать также временем. Здесь используется это соглашение о состоянии.

## Отправная точка: итерации по ценностям нужна модель \{#baseline-value-iteration-needs-the-model\}

Известная модель позволяет точно усреднить возможные продолжения. Для оптимальных ценностей действий

$$
Q^\star(s,a)=\mathbb E\left[R_{t+1}+\gamma\max_bQ^\star(S_{t+1},b)\mid S_t=s,A_t=a\right].
$$

Без модели агент не может непосредственно вычислить это ожидание. Но он может наблюдать одну награду и следующее состояние, составить выборочную цель и поправить свою оценку. Арифметика такая же, как у инкрементного среднего:

$$
\begin{gathered}
\bar x_n=\bar x_{n-1}+\frac1n(x_n-\bar x_{n-1}), \\
v\leftarrow v+\alpha(y-v).
\end{gathered}
$$

Первое равенство точно усредняет наблюдения; во втором вес усреднения заменён выбранным размером шага. Постоянный $\alpha$ ослабляет вклад старых наблюдений. Это позволяет отслеживать меняющуюся цель, но не удовлетворяет условиям убывающего шага, которые понадобятся для сходимости. Дополнительная трудность: цель содержит другую оценку ценности, тоже меняющуюся во время обучения.

## Сначала исследование: многорукий бандит \{#exploration-first-the-multi-armed-bandit\}

Прежде чем учитывать будущие состояния, рассмотрим четыре варианта со стационарными независимыми потоками наград. Каждая награда равна 0 или 1. Агент не знает средних $\mu_a$ и выбирает, какой поток наблюдать следующим. Жадный выбор может перестать пробовать хороший вариант после неудачных первых наблюдений. При постоянном ε-жадном исследовании агент с вероятностью $\varepsilon>0$ выбирает равномерно, а иначе использует наибольшее выборочное среднее.

Для такого стационарного бандита при постоянном ε-жадном исследовании каждый вариант почти наверное выбирается бесконечно часто. Его выборочное среднее тогда сходится. Если некоторые варианты неоптимальны, случайный выбор продолжает приносить ожидаемые потери на каждом будущем решении. Обозначив $\Delta_a=\max_b\mu_b-\mu_a$, получим ожидаемое сожаление:

$$
L_T=\sum_a\Delta_a\,\mathbb E[N_T(a)].
$$

Одно только постоянное равномерное исследование вносит $T\varepsilon\sum_a\Delta_a/4$. Поэтому постоянный ε в общем случае сохраняет линейное сожаление; это не утверждение о расписании с уменьшающимся ε.

**UCB1** добавляет редко выбранным вариантам бонус неопределённости. Попробовав каждый вариант хотя бы раз, на решении $t$ выбираем

$$
A_t\in\arg\max_a\left[\widehat\mu_a+\sqrt{\frac{2\ln t}{N_a}}\right],
$$

где счётчики и средние используют решения до $t$. Бонус следует из концентрационной оценки для ограниченных наград; это не эмпирическое стандартное отклонение. Для независимых стационарных наград в $[0,1]$ [Auer, Cesa-Bianchi и Fischer (2002), теорема 1](#references) доказывают логарифмическую оценку ожидаемого сожаления, зависящую от разрывов средних. Коэффициент и предпосылки существенны: произвольный бонус, зависимая или меняющаяся обратная связь не наследуют эту теорему.

| Вариант | Попытки | Успехи | Среднее | Оценка UCB1 |

Жадный выбор берёт вариант 1, а UCB1 — 4. Его высокая оценка выражает неопределённость, а не вероятность успеха выше единицы. Счётчики заданы как условия: скрытых истинных средних здесь нет, и мы не утверждаем, что вариант 4 действительно лучший. В MDP исследование должно ещё и достигать состояний; случайный выбор действий в состоянии, до которого агент не добрался, не даст его данных.

## Предсказание методом Монте-Карло \{#monte-carlo-prediction\}

В задаче предсказания стратегия фиксирована, нужно оценить её ценности. В примере обработки выбора действий нет. Приём задачи $I$ даёт награду $-1$ и ведёт в этап $A$ с вероятностью $3/4$ или в этап $M$ с вероятностью $1/4$. Этап $A$ завершается наградой 0 или 4 с равными вероятностями; этап $M$ — наградой 1 или 3 с равными вероятностями. Каждый эпизод состоит из двух переходов, $\gamma=4/5$.

Оба следующих этапа имеют ожидаемую награду 2. Поэтому

$$
\begin{gathered}
V^\pi(A)=V^\pi(M)=2, \\
V^\pi(I)=-1+\frac45\cdot2=\frac35.
\end{gathered}
$$

Цель **Монте-Карло** ждёт полной отдачи. После приёма возможны четыре отдачи с такими вероятностями:

$$
\begin{gathered}
G_0\in\left\{-1,\frac{11}{5},-\frac15,\frac75\right\}, \\
p=\left(\frac38,\frac38,\frac18,\frac18\right).
\end{gathered}
$$

Обновление $V(I)\leftarrow V(I)+\alpha(G_0-V(I))$ использует несмещённую цель для $V^\pi(I)$. Это ничего не говорит о близости отдельной выбранной цели к ценности. Предсказание по полной отдаче должно ждать завершения; для непрерывных задач нужна другая конструкция, например конечный горизонт с оценкой хвоста. Длинные эпизоды не всегда имеют большую дисперсию отдачи: важны корреляции наград, дисконтирование и распределение наград.

## TD(0): учить догадку по догадке \{#td0-learning-a-guess-from-a-guess\}

Уравнение ожидания Беллмана заменяет случайное будущее после следующего состояния его условным средним. **TD(0)** подставляет вместо этого среднего текущую таблицу ценностей и обновляет оценку сразу:

$$
\begin{gathered}
y_t=R_{t+1}+\gamma V(S_{t+1}), \\
\delta_t=y_t-V(S_t), \\
V(S_t)\leftarrow V(S_t)+\alpha\delta_t.
\end{gathered}
$$

Использование обученной оценки внутри цели называется **бутстрэппингом**. [Sutton (1988), §§2.2–2.3 и 5.1](#references) развивает предсказание на временных разностях и расширение на накопленные награды. Терминальное следующее состояние вносит ноль. Искусственное ограничение времени отличается от настоящего завершения, если изучаемый процесс должен был продолжиться.

<span id="fig-td-backup"></span>

В одном наблюдённом эпизоде приём ведёт в $A$, после чего задача завершается наградой 4. Пусть изначально $V(I)=0$, $V(A)=3$ и $\alpha=1/4$. TD может обновить ценность приёма после первого перехода:

$$
\begin{gathered}
y_0=-1+\frac45\cdot3=\frac75, \\
V(I)\leftarrow0+\frac14\cdot\frac75=\frac7{20}=0.35.
\end{gathered}
$$

Монте-Карло ждёт награды 4, получает $G_0=11/5$ и изменил бы ту же начальную оценку приёма до $11/20=0.55$. Ни одно одношаговое обновление не равно истинной ценности $3/5$. TD срабатывает раньше, потому что использует оценку 3; Монте-Карло — позже, потому что использует наблюдённую финальную награду 4.

## Какая цель лучше: смещение против дисперсии \{#which-target-is-better-bias-against-variance\}

Сравнивая распределения следующих целей, считаем $V$ фиксированной. В марковском процессе при фиксированной стратегии условное смещение TD равно

$$
\mathbb E[y_t\mid S_t=s]-V^\pi(s)
=\gamma\,\mathbb E[V(S_{t+1})-V^\pi(S_{t+1})\mid S_t=s].
$$

Точные ценности следующих состояний устраняют это смещение. Более того, цель TD с точными ценностями — условное ожидание отдачи при известных первой награде и следующем состоянии. Закон полной дисперсии тогда даёт дисперсию не больше дисперсии отдачи, если обе существуют. Замена этих ценностей произвольными оценками убирает гарантию.

В нашем примере среднее Монте-Карло равно $3/5$, а дисперсия — $52/25=2.08$. При точных ценностях продолжения TD всегда равна $3/5$, поэтому её дисперсия нулевая. Теперь намеренно возьмём $V(A)=10$ и $V(M)=-6$. Цели TD станут равны 7 и $-29/5$ с вероятностями $3/4$ и $1/4$. Их среднее — $19/5$, смещение — $16/5=3.2$, а дисперсия — $768/25=30.72$.

Пример сравнивает распределения целей, а не кривые обучения. Более короткий наблюдаемый горизонт сам по себе не обеспечивает меньшую дисперсию или среднеквадратичную ошибку. На обученную таблицу влияют также размер шага, ошибка аппроксимации и доступный опыт.

Полезное точное тождество справедливо для **фиксированной** таблицы ценностей и нулевой терминальной ценности. Если раскрыть каждую $\delta_k=R_{k+1}+\gamma V(S_{k+1})-V(S_k)$, промежуточные ценности сократятся:

$$
G_t-V(S_t)=\sum_{j=0}^{T-t-1}\gamma^j\delta_{t+j}.
$$

Это тождество между ошибками, а не равенство обычных обновлений параметров Монте-Карло и онлайн-TD(0). Онлайн-обновления могут менять таблицу между слагаемыми; повторные состояния делают различие заметным. Следы приемлемости ниже задают, как поздние ошибки влияют на более ранние состояния. [Заметка о градиентах стратегии](/ru/notes/agents/policy-gradients) использует родственную взвешенную сумму для оценки преимуществ.

На фиксированных данных ноль **суммы** табличных обновлений по остаткам TD решает эмпирическую систему Беллмана, а усреднение полных отдач даёт эмпирические ценности Монте-Карло. При дисконтировании и полностью заданной эмпирической модели переходов первая система имеет единственное решение. Повторное предъявление отдельных сэмплов с постоянным шагом не обязано точно достичь этого нуля, а ни одна эмпирическая оценка не гарантированно лучше на неизвестном истинном процессе.

## От предсказания к управлению: SARSA и Q-обучение \{#from-prediction-to-control-sarsa-and-q-learning\}

Ценности действий позволяют сравнивать действия без обращения к модели переходов. Оба метода обновляют $Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha(y_t-Q(S_t,A_t))$, но используют разные цели:

$$
\begin{aligned}
y_t^{\rm SARSA}&=R_{t+1}+\gamma Q(S_{t+1},A_{t+1}),\\
y_t^{\rm Q}&=R_{t+1}+\gamma\max_b Q(S_{t+1},b),\\
y_t^{\rm expected\ SARSA}&=R_{t+1}+\gamma\sum_b\pi(b\mid S_{t+1})Q(S_{t+1},b).
\end{aligned}
$$

**SARSA** использует следующее действие, действительно выбранное поведенческой стратегией, включая исследование. Пять величин в названии — состояние, действие, награда, следующее состояние, следующее действие. Это обучение по текущей стратегии, on-policy. Ожидаемая SARSA усредняет по стратегии, убирая случайность выбора следующего действия; случайность среды остаётся. **Q-обучение** использует жадную цель, даже если фактическое следующее действие исследовательское: это отличие off-policy, а не обещание достаточности любого покрытия данных. См. [Singh и соавт. (2000), §2.1](#references) и [Watkins и Dayan (1992), §2](#references).

Для локальной проверки арифметики пусть переход даёт награду 2, оценки действий следующего состояния равны 3 и $-2$, обновляемая запись сейчас равна 1, $\gamma=4/5$, а $\alpha=1/4$. Q-обучение использует цель 4.4 и обновляет запись до 1.85. Если следующее действие SARSA оценено в $-2$, её цель равна 0.4, а новая запись — 0.85. При ε-жадном $\varepsilon=1/5$ вероятности следующих действий равны 0.9 и 0.1; ожидаемая SARSA использует цель 4 и обновляет запись до 1.75. Это заданные текущие оценки, а не предельные ценности.

Реализация выбирает следующее действие до обновления SARSA и выполняет именно его. Для настоящего терминального перехода каждый метод использует только непосредственную награду. В остальных случаях взаимодействие продолжается; изменение цели не меняет наблюдённую награду.

## Пополняемый ресурс: что учат методы по текущей стратегии и вне стратегии \{#cliff-walking-what-on-policy-and-off-policy-learn\}

Рассмотрим непрерывно работающий сервис с уровнем ресурса $s\in\{0,1,2\}$. Действие 0 заряжает ресурс; действие 1 выполняет задачу. Полная модель дана здесь только для расчёта точного ориентира обучения:

| Состояние | Зарядка: следующее состояние, награда | Работа: следующее состояние, награда |
| --- | --- | --- |
| 0 | 1, −1/5 | 0, −6 |
| 1 | 2, −1/5 | 0, 2 |
| 2 | 2, −1/5 | 1, 5/2 |

Награды измеряются в условных единицах полезности. Работа без ресурса штрафуется; зарядка при полном ресурсе всё равно тратит время. Терминального состояния и сброса нет, $\gamma=4/5$. Детерминированная **основа** $g=(g(0),g(1),g(2))$ выбирает по одному действию для каждого состояния. Равномерная ε-жадная смесь вокруг неё задаёт

$$
\pi_{g,\varepsilon}(a\mid s)=(1-\varepsilon)\mathbb 1[a=g(s)]+\frac\varepsilon2.
$$

Основ восемь. Для каждой вычисляем матрицу переходов и ожидаемые награды, затем решаем

$$
(I-\gamma P_{g,\varepsilon})V_{g,\varepsilon}=r_{g,\varepsilon}.
$$

Дисконтированная система обратима. Код сравнивает все состояния и проверяет остатки Беллмана; он не делает вывод о лучшей стратегии из одного начального состояния, откуда часть остальных может быть недостижима.

Без исследования оптимальна основа $(0,1,1)$: заряжаться при нуле, иначе работать. Её ценности равны $(35/9,46/9,593/90)$. Но при постоянном $\varepsilon=1/5$ действие, отличное от основного, всё равно выбирается с вероятностью $1/10$. Лучшей становится основа $(0,0,1)$, которая заряжается и на уровне 1. Её ценности:

$$
\left(\frac{26751}{9890},\frac{976}{215},\frac{118217}{19780}\right).
$$

<EnergyPolicy />

Из уровня 1 исследование вокруг оптимума без исследования даёт $784/215\approx3.647$. Выбор лучшей основы для той же доли исследования даёт $976/215\approx4.540$. Более ранняя зарядка меняет распределение будущих состояний и уменьшает риск работы при нуле. Если исследование отключить, исходный оптимум имеет там ценность $46/9\approx5.111$; прямое сравнение этого числа с исследующей стратегией меняло бы условия оценки.

Это точные оценки стратегий, а не тест SARSA за конечное число шагов. Они показывают, почему оценка постоянно исследующего поведения может предпочитать другое действие, чем оптимизация стратегии для жадного применения. SARSA не сходится автоматически к лучшей исследующей стратегии при любом произвольном правиле исследования; [Singh и соавт. (2000), §3.2](#references) дают условия для постоянной рандомизации по рангам. При исчезающем исследовании сходимость к неограниченному оптимуму всё равно требует условий ниже.

## Когда оценки сходятся \{#when-the-estimates-converge\}

Ограничимся конечными табличными стационарными MDP с ограниченными наградами и $0\leq\gamma<1$. Для каждого обновляемого состояния или записи «состояние–действие» размеры шага должны удовлетворять

$$
\begin{gathered}
0<\alpha_n\leq1, \\
\sum_n\alpha_n=\infty, \\
\sum_n\alpha_n^2<\infty.
\end{gathered}
$$

Здесь $n$ считает обновления именно этой записи, а не все глобальные шаги среды. Расписание $\alpha_n=1/n$ удовлетворяет этим суммам. Первая сумма не даёт обучению остановиться слишком рано; вторая контролирует накопление шума сэмплирования.

- Табличное TD(0) при фиксированной стратегии сходится к её ценности, если все необходимые состояния продолжают наблюдаться и выполнены условия стохастической аппроксимации. Это задача сжатия для фиксированной стратегии, а не результат для произвольно меняющейся стратегии.
- Табличное Q-обучение почти наверное сходится к оптимальным ценностям действий при бесконечном числе корректных наблюдений **каждой** пары «состояние–действие» и указанных условиях на шаги. Поведение может отличаться от целевой стратегии, но должно обеспечивать нужное покрытие.
- Для сходимости SARSA к оптимальным ценностям дополнительно требуется **жадность в пределе при бесконечном исследовании (GLIE)**. Одного $\varepsilon_t\to0$ недостаточно: исследование может исчезнуть до того, как нужные действия или состояния наберут достаточно посещений.

Точные результаты приведены у [Watkins и Dayan (1992)](#references), [Jaakkola, Jordan и Singh (1993)](#references), [Singh и соавт. (2000), теорема 1](#references). Мы не переносим дисконтированное утверждение на любую недисконтированную эпизодическую задачу из одного лишь предположения завершения. Условия правильности стратегий и другие предпосылки требуют отдельной проверки.

Постоянный положительный шаг нарушает суммируемость квадратов и в общем случае сохраняет шум; детерминированные частные случаи всё же могут сходиться. Эти теоремы не дают ни полезного бюджета конечной выборки, ни универсальной скорости в зависимости от горизонта. Замена таблицы нейросетью тоже меняет математическую задачу.

## Между одним шагом и всем эпизодом: n-шаговые отдачи и следы приемлемости \{#between-one-step-and-the-whole-episode-n-step-returns-and-eligibility-traces\}

Для фиксированной функции ценности n-шаговая цель использует наблюдённые награды до выбранного горизонта, затем бутстрэппинг, если эпизод ещё идёт:

$$
\begin{gathered}
G_{t:t+n}=\sum_{j=0}^{n-1}\gamma^jR_{t+j+1}+\gamma^nV(S_{t+n}), \\
t+n<T.
\end{gathered}
$$

Когда горизонт достигает терминального момента, используем полную отдачу $G_t$. Более длинный горизонт заменяет часть ошибки оценки ценности дополнительными случайными наградами. Смещение и дисперсия не обязаны меняться монотонно с горизонтом.

При конечном оставшемся числе переходов $N=T-t$ **λ-отдача** может явно учитывать завершение:

$$
\begin{gathered}
G_t^\lambda=(1-\lambda)\sum_{n=1}^{N-1}\lambda^{n-1}G_{t:t+n}+\lambda^{N-1}G_t, \\
0\leq\lambda\leq1.
\end{gathered}
$$

Последнее слагаемое несёт оставшуюся массу вероятности. При $\lambda=0$ получается одношаговая цель, а при $\lambda=1$ — полная отдача. Если остался один переход, выражение просто равно $G_t$. В бесконечном ряде для непрерывной задачи геометрические веса суммируются в единицу только при $0\leq\lambda<1$; подстановка 1 в этот ряд не определяет его граничный случай.

Отдельная траектория из трёх переходов имеет награды $(-1,2,3)$, фиксированные ценности $(1/2,3/2,-1/4,0)$ и $\gamma=4/5$. Цели для горизонтов 1, 2 и 3 равны $1/5$, $11/25$ и $63/25$. При $\lambda=1/2$ их веса — $1/2,1/4,1/4$, что даёт $G_0^\lambda=21/25=0.84$.

**Следы приемлемости** накапливают, насколько поздняя ошибка TD должна влиять на ранее посещённые состояния. В начале каждого эпизода следы нулевые; накапливающие табличные следы используют

$$
\begin{gathered}
z_t(s)=\gamma\lambda z_{t-1}(s)+\mathbb 1[s=S_t], \\
V(s)\leftarrow V(s)+\alpha\delta_tz_t(s).
\end{gathered}
$$

При фиксированных ценностях $G_t^\lambda-V(S_t)=\sum_{j=0}^{N-1}(\gamma\lambda)^j\delta_{t+j}$. В нашей траектории ошибки TD равны $(-3/10,3/10,13/4)$; их взвешенная сумма — $0.34$, точно $0.84-0.5$. Если накопить эти поправки и применить их после эпизода, получим соответствующее обновление прямого представления. Обычное онлайн-TD(λ) немедленно меняет $V$, поэтому равенство на конечном шаге с таким фиксированным прямым представлением не возникает автоматически. [Sutton (1988), §§2.2–2.3 и 5.2](#references) различает обновления после последовательности и внутри неё.

| --- | --- | --- |
| Точное обновление Беллмана | Известные вероятности переходов и средние награды | Верность модели |
| Цель Монте-Карло | Наблюдённую отдачу до завершения | Фиксированную оцениваемую стратегию, конечные моменты |
| Цель TD | Следующую награду и оценку продолжения | Ошибку бутстрэппинга и покрытие |
| Цель SARSA | Фактически выбранное следующее действие | Совпадение поведения и цели |
| Цель Q-обучения | Жадную ценность следующего действия | Покрытие off-policy и условия сходимости |

## Ограничения \{#limitations\}

Конечные примеры изолируют механизмы. Они не предсказывают качество на текстах, изображениях или непрерывных пространствах состояний. Для проверки наш точный оценщик использует известную модель, тогда как агент видел бы только выбранные переходы. Табличные ценности не обобщаются на непосещённые состояния, а ε-жадное исследование может тратить действия на заведомо плохие варианты. Переход можно сохранить и использовать повторно; ни TD, ни Q-обучение не требуют выбрасывать его после одного обновления.

Никакая кривая обучения в этой заметке не устанавливает универсального порядка качества алгоритмов. Бутстрэппинг, максимум зашумлённых оценок, меняющиеся стратегии и аппроксимация функций вносят разные ошибки. В частности, максимум несмещённых зашумлённых оценок действий может создавать смещение вверх; следующая заметка обсуждает методы, разделяющие выбор и оценку.

## Что нужно запомнить \{#what-you-should-remember\}

- Выборочная цель заменяет недоступное ожидание Беллмана; агенту всё ещё нужно собирать полезный опыт.
- Монте-Карло ждёт отдачи. TD обновляется раньше с помощью другой оценки; преимущество по дисперсии требует условий.
- SARSA оценивает следующее фактически выбранное действие. Q-обучение нацелено на жадное продолжение даже во время исследования.
- Постоянное исследование может менять оптимальное поведение: пример ресурса показывает это при одинаковых условиях оценки.
- Для сходимости нужны покрытие, подходящие шаги и, для оптимальной SARSA, GLIE. λ-отдача конечного эпизода сохраняет вес терминального хвоста.

## Код \{#code\}

Самостоятельный пример Python использует только стандартную библиотеку. Он решает восемь основ стратегий при двух долях исследования в точных дробях, проверяет моменты целей предсказания и вычисляет срез UCB. Логарифмы с плавающей точкой влияют только на показанные оценки UCB. Код не обучает агента и не требует стороннего датасета.

```python
from fractions import Fraction as F
from itertools import product
from math import log, sqrt


def solve(matrix, rhs):
    rows = [list(row) + [b] for row, b in zip(matrix, rhs)]
    n = len(rows)
    for col in range(n):
        pivot = next(i for i in range(col, n) if rows[i][col])
        rows[col], rows[pivot] = rows[pivot], rows[col]
        divisor = rows[col][col]
        rows[col] = [x / divisor for x in rows[col]]
        for i in range(n):
            if i != col:
                multiplier = rows[i][col]
                rows[i] = [x - multiplier * y for x, y in zip(rows[i], rows[col])]
    return [row[-1] for row in rows]


def step(state, action):
    if action == 0:  # charge
        return min(2, state + 1), -F(1, 5)
    return max(0, state - 1), [-F(6), F(2), F(5, 2)][state]


def evaluate(skeleton, epsilon):
    gamma = F(4, 5)
    matrix = [[F(i == j) for j in range(3)] for i in range(3)]
    reward = [F(0) for _ in range(3)]
    for s in range(3):
        for a in range(2):
            probability = epsilon / 2 + (1 - epsilon) * (a == skeleton[s])
            nxt, r = step(s, a)
            matrix[s][nxt] -= gamma * probability
            reward[s] += probability * r
    return solve(matrix, reward)


def best(epsilon):
    candidates = [(p, evaluate(p, epsilon)) for p in product(range(2), repeat=3)]
    return max(candidates, key=lambda item: sum(item[1]))


def moments(outcomes):
    mean = sum(p * x for p, x in outcomes)
    return mean, sum(p * (x - mean) ** 2 for p, x in outcomes)


def demo():
    for epsilon in (F(0), F(1, 5)):
        policy, values = best(epsilon)
        print('epsilon', epsilon, 'skeleton', policy, 'V', [str(x) for x in values])
    print('exploring optimal skeleton: V(1)', evaluate((0, 1, 1), F(1, 5))[1])
    mc = [(F(3, 8), -F(1)), (F(3, 8), F(11, 5)),
          (F(1, 8), -F(1, 5)), (F(1, 8), F(7, 5))]
    print('MC mean, variance', [str(x) for x in moments(mc)])
    print('wrong TD mean, variance', [str(x) for x in moments([(F(3, 4), F(7)), (F(1, 4), -F(29, 5))])])
    scores = [hits / n + sqrt(2 * log(41) / n) for n, hits in zip([18, 12, 6, 4], [11, 5, 2, 1])]
    print('UCB1 scores', [round(x, 6) for x in scores])


demo()
```

```text
epsilon 1/5 skeleton (0, 0, 1) V ['26751/9890', '976/215', '118217/19780']
exploring optimal skeleton: V(1) 784/215
MC mean, variance ['3/5', '52/25']
wrong TD mean, variance ['19/5', '768/25']
UCB1 scores [1.253465, 1.203387, 1.445924, 1.612639]
```
