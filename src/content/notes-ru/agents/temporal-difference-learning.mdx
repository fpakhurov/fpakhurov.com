Заметка [Марковские процессы принятия решений](/ru/notes/agents/markov-decision-processes) вычисляла оптимальные ценности проходами обновлений Беллмана, и каждое обновление читало вероятности переходов $P(s' \mid s, a)$ и награды $R(s, a, s')$. [Заметка об играх](/ru/notes/agents/games-and-tree-search) ослабила это требование лишь немного: поиску по дереву методом Монте-Карло не нужны выписанные вероятности, но нужен симулятор, который можно вернуть в любую позицию. У большинства агентов нет ни того, ни другого. Робот не знает трения пола, торговый агент не знает рынка, а агент на языковой модели не знает, что вернёт инструмент, пока его не вызовет. Что они могут — действовать и смотреть, что происходит, по одному переходу за раз. **Обучение с подкреплением** (reinforcement learning) изучает агентов, которые учатся хорошо действовать на таком опыте. В этой заметке строятся его первые алгоритмы: как исследовать, когда ценности неизвестны, как оценивать ценности по сэмплированным эпизодам и как та же идея даёт SARSA и Q-обучение — два базовых метода управления.

**Обозначения.** Мы сохраняем обозначения заметки об MDP: состояния $s$, действия $a$, переходы $P(s' \mid s, a)$, награды $R(s, a, s')$, коэффициент дисконтирования $\gamma$, случайные состояние, действие и награда $S_t, A_t, R_{t+1}$ на шаге $t$, стратегия $\pi(a \mid s)$, отдача $G_t$, ценности $V^\pi, Q^\pi$ и оптимальные ценности $V^\star, Q^\star$. Новые здесь: текущие оценки агента $V(s)$ и $Q(s, a)$ (без верхнего индекса), размер шага $\alpha \in (0, 1]$, ошибка TD $\delta_t$ и вероятность исследования $\varepsilon$. **Переход** (transition) — это кортеж $(S_t, A_t, R_{t+1}, S_{t+1})$, который агент наблюдает после одного шага. В эпизодических задачах, которые заканчиваются с вероятностью 1, мы допускаем $\gamma = 1$.

## Отправная точка: итерации по ценностям нужна модель \{#baseline-value-iteration-needs-the-model\}

Оптимальные ценности действий удовлетворяют уравнению оптимальности Беллмана из [заметки об MDP](/ru/notes/agents/markov-decision-processes#the-bellman-optimality-equation), записанному для $Q^\star$:

$$
Q^\star(s, a) = \sum_{s'} P(s' \mid s, a) \Big( R(s, a, s') + \gamma \max_{a'} Q^\star(s', a') \Big).
$$

Итерация по ценностям вычисляет сумму справа точно, для каждого состояния и действия. Агент, который не знает $P$, этого не может. Но он может выполнить действие $a$ в состоянии $s$ и увидеть одно следующее состояние $S_{t+1}$ и одну награду $R_{t+1}$, а выражение в скобках, вычисленное на этом сэмпле, имеет правильное математическое ожидание:

$$
\mathbb E\Big[ R_{t+1} + \gamma \max_{a'} Q^\star(S_{t+1}, a') \,\Big|\, S_t = s, A_t = a \Big] = Q^\star(s, a).
$$

Сумма, взвешенная неизвестными вероятностями, — это математическое ожидание, а математическое ожидание можно оценить усреднением сэмплов, как в [методах Монте-Карло](/ru/notes/probability/monte-carlo#plain-monte-carlo-and-its-error) курса теории вероятностей. Среднее даже не нужно хранить как сумму. Среднее $n$ чисел $x_1, \dots, x_n$ обновляется по одному сэмплу:

$$
\begin{aligned}
\bar x_n &= \frac1n \sum_{i=1}^{n} x_i = \frac1n \Big( x_n + (n - 1)\, \bar x_{n-1} \Big) && \text{отделяем последнее слагаемое} \\
&= \bar x_{n-1} + \frac1n \big( x_n - \bar x_{n-1} \big). && \text{перегруппировка}
\end{aligned}
$$

Каждый алгоритм этой заметки имеет такой вид: *оценка ← оценка + шаг × (цель − оценка)*. С шагом $1/n$ оценка — точное выборочное среднее; с постоянным шагом $\alpha$ это экспоненциально взвешенное среднее, которое забывает старые сэмплы, что подходит для целей, меняющихся по мере обучения агента. С сэмплами приходят две проблемы, и по ним построена заметка. Агент сам выбирает, какие действия сэмплировать, поэтому должен решать, сколько исследовать. И в уравнении выше цель содержит саму $Q^\star$, которая неизвестна, поэтому агент должен учиться на целях, построенных на его собственных оценках.

## Сначала исследование: многорукий бандит \{#exploration-first-the-multi-armed-bandit\}

Сведём задачу к одному состоянию. У **многорукого бандита** (multi-armed bandit) $k$ действий, или рук; дёрнуть руку $a$ — значит получить случайную награду с неизвестным средним $q^\star(a)$. За $T$ дёрганий агент хочет получить как можно больше награды. Его оценка каждой руки — выборочное среднее $Q_t(a)$ наград, которые он видел от этой руки, после $N_t(a)$ дёрганий. Потеря по сравнению с тем, чтобы всегда дёргать лучшую руку, — **сожаление** (regret) — равна

$$
L_T = T \max_a q^\star(a) - \mathbb E\Big[\sum_{t=1}^{T} R_t\Big] = \sum_a \Delta_a\, \mathbb E[N_T(a)], \qquad \Delta_a = \max_b q^\star(b) - q^\star(a),
$$

где вторая форма получается группировкой дёрганий по рукам: каждое дёргание руки $a$ в среднем теряет $\Delta_a$. Хорошая стратегия редко дёргает плохие руки, а узнать, какие руки плохие, она может, только дёргая их. Это **дилемма исследования и использования** (exploration–exploitation dilemma) в чистом виде.

**Жадный выбор.** Всегда дёргать руку с наибольшей оценкой. Одна неудачная первая награда от лучшей руки может сделать её оценку низкой, и тогда её больше никогда не дёрнут, так что оценка никогда не будет исправлена. Жадный выбор может ошибаться вечно, и его сожаление растёт линейно по $T$.

**ε-жадный выбор** (ε-greedy). С вероятностью $\varepsilon$ дёрнуть руку, выбранную равномерно случайно, иначе действовать жадно. Тогда каждая рука дёргается бесконечно часто, поэтому по [закону больших чисел](/ru/notes/probability/law-of-large-numbers) каждая оценка сходится к своему среднему, и жадный выбор становится верным. Цена в том, что доля $\varepsilon (k - 1)/k$ дёрганий навсегда уходит неверным рукам: сожаление всё равно растёт линейно, только медленнее.

**Верхняя доверительная граница** (upper confidence bound, UCB). Дёргать руку, оценка которой *могла бы* правдоподобно оказаться наибольшей:

$$
\boxed{\; A_t = \arg\max_a \Big[\, Q_t(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \,\Big] \;}
$$

причём руки, которые ни разу не дёргали, пробуются первыми. Бонус — ширина доверительного интервала: стандартная ошибка выборочного среднего убывает как $1/\sqrt{N_t(a)}$, а медленно растущий $\ln t$ гарантирует, что к каждой руке рано или поздно вернутся. Принцип называется **оптимизмом перед лицом неопределённости** (optimism in the face of uncertainty): действовать так, будто каждая рука настолько хороша, насколько ещё позволяют данные. Рука, которую дёрнули из-за её бонуса, либо оказывается хорошей, и агент выигрывает, либо оказывается плохой, и её бонус уменьшается. При наградах в $[0, 1]$ и $c = \sqrt 2$ сожаление этого правила, UCB1, не превосходит константы, умноженной на $\sum_{a : \Delta_a > 0} \ln T / \Delta_a$, при любом $T$ ([Auer, Cesa-Bianchi and Fischer, 2002](#references)), и никакая стратегия не может на всех бандитах добиться сожаления, растущего медленнее логарифма ([Lai and Robbins, 1985](#references)).

**Разобранный пример.** При $t = 100$ у трёх рук оценки $Q = (1.2, 1.0, 0.3)$ после $N = (80, 15, 5)$ дёрганий, и $c = 2$. Бонусы равны $2\sqrt{\ln 100 / 80} = 0.480$, $2\sqrt{\ln 100 / 15} = 1.108$ и $2 \sqrt{\ln 100 / 5} = 1.919$, так что суммы равны $1.680$, $2.108$ и $2.219$. UCB дёргает третью руку, с наименьшей оценкой, потому что пять дёрганий говорят о ней слишком мало, чтобы её исключить. Жадный выбор дёрнул бы первую; ε-жадный с $\varepsilon = 0.1$ дёрнул бы третью с вероятностью $0.1/3$.

Стандартная проверка этих правил — **испытательный стенд из десятируких бандитов** (10-armed testbed) ([Sutton and Barto, 2018](#references), раздел 2.3): 2000 случайных бандитов, средние рук которых взяты из $\mathcal N(0, 1)$, а награды — из $\mathcal N(q^\star(a), 1)$.

<BanditCurves />

Жадный выбор выходит на плато около $1.0$ и выбирает лучшую руку лишь примерно на трети шагов. Немного исследования, $\varepsilon = 0.01$, уже поднимает среднее примерно до $1.3$, а $\varepsilon = 0.1$ исследует достаточно быстро, чтобы за тысячу шагов найти лучшую руку в 80% случаев, но продолжает платить за свои случайные дёргания. После первых шагов UCB — лучший из четырёх, примерно $1.48$. Хуже всех он в первые десять шагов, где должен попробовать каждую руку по разу.

В MDP задача о бандите возникает в каждом состоянии, с той сложностью, что ценность действия зависит от того, что агент будет делать дальше. Алгоритмы ниже используют ε-жадное исследование: оно грубое, но простое и работает в любом пространстве состояний. Идея UCB также лежит в основе поиска по дереву, где [UCT](/ru/notes/agents/games-and-tree-search#selection-as-a-bandit-problem-ucb1-and-uct) применяет её к выбору хода в каждом узле, и бонусов по счётчикам посещений, которые используются для исследования в больших пространствах состояний; хорошо исследовать, когда состояния никогда не повторяются, — открытая задача.

## Предсказание методом Монте-Карло \{#monte-carlo-prediction\}

Прежде чем заняться управлением, возьмём задачу проще — **предсказание** (prediction): оценить $V^\pi$ для фиксированной стратегии $\pi$ по эпизодам, которые порождает $\pi$. Ценность — это ожидаемая отдача, $V^\pi(s) = \mathbb E_\pi[G_t \mid S_t = s]$, поэтому самая прямая оценка ждёт конца эпизода, вычисляет отдачу $G_t$, которая последовала за каждым посещением состояния, и сдвигает оценку к ней:

$$
V(S_t) \leftarrow V(S_t) + \alpha \big( G_t - V(S_t) \big).
$$

Это **предсказание методом Монте-Карло** (Monte Carlo prediction) ([Sutton and Barto, 2018](#references), глава 5). Его цель — несмещённый сэмпл ценности по определению $V^\pi$, и он ничего не использует о структуре задачи: марковское свойство не нужно. Его слабости — две стороны одного факта. Он должен ждать конца эпизода, что бесполезно в задачах, которые никогда не кончаются. И $G_t$ складывает каждую случайную награду и каждый случайный переход до самого конца, поэтому её дисперсия растёт с длиной эпизода.

## TD(0): учить догадку по догадке \{#td0-learning-a-guess-from-a-guess\}

Уравнение ожидания Беллмана из [заметки об MDP](/ru/notes/agents/markov-decision-processes#the-bellman-expectation-equation) говорит, что ценность состояния — это ожидаемая награда за один шаг плюс дисконтированная ценность следующего состояния:

$$
V^\pi(s) = \mathbb E_\pi\big[ R_{t+1} + \gamma V^\pi(S_{t+1}) \,\big|\, S_t = s \big].
$$

Возьмём один сэмпл математического ожидания и заменим неизвестную $V^\pi(S_{t+1})$ текущей оценкой. Получается обновление **TD(0)** из [Sutton (1988)](#references):

$$
\boxed{\; V(S_t) \leftarrow V(S_t) + \alpha\, \delta_t, \qquad \delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \;}
$$

где $V(S_{t+1}) = 0$, когда $S_{t+1}$ терминальное. Величина $\delta_t$ — **ошибка временной разности**, или ошибка TD (temporal-difference error): разность двух оценок одной и той же ценности, сделанных в последовательные моменты, одной до шага и одной после него. Использование оценки внутри цели называется **бутстрэппингом** (bootstrapping).

<aside class="callout"><strong>Ключевая идея.</strong> Функция ценности должна быть согласована сама с собой: ценность состояния равна ожидаемой награде за один шаг плюс дисконтированная ценность следующего состояния. Обучение на временных разностях (TD) не ждёт настоящей отдачи. После каждого шага оно измеряет, насколько текущие оценки далеки от этой согласованности, и приближает их к ней. Цель — догадка, но догадка, сделанная на шаг позже, с ещё одной настоящей наградой внутри.</aside>

Сквозной пример — **случайное блуждание** (random walk) ([Sutton and Barto, 2018](#references), пример 6.2): пять состояний от A до E в ряд, старт в C; каждый шаг идёт влево или вправо с вероятностью $1/2$; выход слева даёт награду 0, выход справа — награду 1, и $\gamma = 1$. Ценность состояния — вероятность выйти справа, которая по [задаче о разорении игрока](/ru/notes/probability/markov-chains#hitting-probabilities-the-gamblers-ruin) равна $1/6, 2/6, \dots, 5/6$ от A до E. Один шаг обучения в середине тренировки:

<TdBackup />

1. **Действие.** В C блуждание делает шаг вправо, в D, с наградой $R_{t+1} = 0$.
2. **Цель TD.** Награда плюс оценка следующего состояния: $0 + 1 \cdot V(\text{D}) = 0.60$.
3. **Ошибка TD.** Цель минус текущая оценка: $\delta_t = 0.60 - 0.50 = 0.10$.
4. **Обновление сразу.** При $\alpha = 0.1$ получаем $V(\text{C}) \leftarrow 0.50 + 0.1 \cdot 0.10 = 0.51$, и агент продолжает из D.
5. **Для контраста — Монте-Карло.** Он ждёт. Этот эпизод доходит до E и выходит справа, так что $G_t = 1$ и $V(\text{C}) \leftarrow 0.50 + 0.1 \cdot (1 - 0.50) = 0.55$, но только после того, как эпизод закончился.

## Какая цель лучше: смещение против дисперсии \{#which-target-is-better-bias-against-variance\}

Две цели оценивают одну и ту же ценность с разными ошибками.

**Цель Монте-Карло несмещённая.** $\mathbb E_\pi[G_t \mid S_t = s] = V^\pi(s)$ по определению. Её дисперсия включает случайность каждого оставшегося шага.

**Цель TD смещена, пока оценки неверны.** По линейности и уравнению Беллмана

$$
\begin{aligned}
\mathbb E_\pi\big[ R_{t+1} + \gamma V(S_{t+1}) \mid S_t = s \big]
&= \mathbb E_\pi\big[ R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t = s \big] + \gamma\, \mathbb E_\pi\big[ V(S_{t+1}) - V^\pi(S_{t+1}) \mid S_t = s \big] && \text{прибавляем и вычитаем } \gamma V^\pi \\
&= V^\pi(s) + \gamma\, \mathbb E_\pi\big[ V(S_{t+1}) - V^\pi(S_{t+1}) \mid S_t = s \big]. && \text{уравнение ожидания Беллмана}
\end{aligned}
$$

Смещение — дисконтированная ошибка оценок на шаг вперёд, и оно исчезает, когда они становятся верными. Дисперсия цели происходит от одной награды и одного перехода.

**Две ошибки связаны точно.** Зафиксируем $V$ на время эпизода, который кончается на шаге $T$. Ошибка Монте-Карло — дисконтированная сумма ошибок TD по пути:

$$
\begin{aligned}
G_t - V(S_t) &= R_{t+1} + \gamma G_{t+1} - V(S_t) && G_t = R_{t+1} + \gamma G_{t+1} \\
&= \big( R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \big) + \gamma \big( G_{t+1} - V(S_{t+1}) \big) && \text{прибавляем и вычитаем } \gamma V(S_{t+1}) \\
&= \delta_t + \gamma \big( G_{t+1} - V(S_{t+1}) \big) && \text{определение } \delta_t \\
&= \delta_t + \gamma \delta_{t+1} + \gamma^2 \big( G_{t+2} - V(S_{t+2}) \big) = \dots = \sum_{k=0}^{T - t - 1} \gamma^k \delta_{t+k}, && \text{повторяем; } G_T = V(S_T) = 0
\end{aligned}
$$

так что обновление Монте-Карло — это сумма всех обновлений TD за эпизод, применённая в конце. TD применяет каждую часть, как только она известна, и благодаря бутстрэппингу передаёт то, что узнало о $S_{t+1}$, состоянию $S_t$, не дожидаясь, пока остаток эпизода повторится. То же тождество возвращается в заметке [Градиент по стратегии и методы «актор–критик»](/ru/notes/agents/policy-gradients), где взвешенный вариант этой суммы становится обобщённой оценкой преимущества.

После 100 эпизодов у TD(0) с $\alpha = 0.05$ ошибка около $0.035$, а у лучшей из двух кривых Монте-Карло — около $0.08$. Размер шага в обоих методах обменивает скорость на точность: при большом $\alpha$ ошибка быстро падает, а затем колеблется на более высоком уровне, потому что каждая новая цель сдвигает оценку на фиксированную долю, сколько бы данных ни было до неё.

**К чему два метода сходятся на фиксированном батче.** Пусть опыт — фиксированный набор эпизодов, и каждый метод применяется к нему снова и снова, пока оценки не перестанут меняться. Тогда Монте-Карло даёт среднюю отдачу, наблюдавшуюся после каждого состояния. TD(0) даёт ценности марковской цепи, вероятности переходов которой — наблюдённые частоты, то есть **модели максимального правдоподобия** (maximum-likelihood model) по данным; это решение называют принципом определённой эквивалентности (certainty equivalence) ([Sutton, 1988](#references); [Sutton and Barto, 2018](#references), раздел 6.3). Ответы могут сильно различаться. Пусть есть восемь эпизодов: один прошёл A → B и закончился наградой 0, шесть начались в B и закончились наградой 1, и один начался в B и закончился наградой 0. Оба метода дают $V(\text{B}) = 6/8 = 0.75$. Для A Монте-Карло даёт 0 — отдачу единственного эпизода из A, — а TD даёт $0 + V(\text{B}) = 0.75$, потому что каждый наблюдённый шаг из A вёл в B. Если процесс марковский, ответ TD лучше: он использует переходы из B, наблюдённые в других эпизодах.

## От предсказания к управлению: SARSA и Q-обучение \{#from-prediction-to-control-sarsa-and-q-learning\}

Чтобы улучшать стратегию без модели, агенту нужны ценности действий. Жадное улучшение по $V$ требует $\sum_{s'} P(s' \mid s, a)(\dots)$, а для этого нужна $P$; жадное улучшение по $Q$ — это просто $\arg\max_a Q(s, a)$. Поэтому методы **управления** (control) учат $Q$ и действуют ε-жадно по отношению к ней, так что оценка и улучшение чередуются на каждом шаге, как в итерации по стратегиям, но без ожидания конца оценки.

**SARSA** применяет TD(0) к ценностям действий. Она использует пять величин $(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})$, которые дали ей имя ([Rummery and Niranjan, 1994](#references)):

$$
Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \big[ R_{t+1} + \gamma\, Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \big],
$$

где $A_{t+1}$ — действие, которое агент действительно выполнит следующим, взятое из его ε-жадной стратегии. Цель — сэмпл уравнения ожидания Беллмана для $Q^\pi$, где $\pi$ — стратегия, которой агент следует. SARSA учится **по текущей стратегии** (on-policy): она учит ценность стратегии, порождающей данные, вместе с исследованием.

**Q-обучение** (Q-learning) ([Watkins, 1989](#references); [Watkins and Dayan, 1992](#references)) заменяет следующее действие лучшим:

$$
\boxed{\; Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \Big[ R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a) - Q(S_t, A_t) \Big] \;}
$$

Цель — сэмпл уравнения оптимальности Беллмана из раздела об отправной точке. Математическое ожидание в этом уравнении берётся только по среде — по следующему состоянию и награде при заданных $(s, a)$, — а не по следующему действию агента. Поэтому поведение может быть любым, лишь бы оно продолжало посещать каждое состояние и действие: Q-обучение учится **вне стратегии** (off-policy) и учит $Q^\star$, ценности жадной стратегии, следуя исследующей. Между двумя методами лежит **ожидаемая SARSA** (expected SARSA), цель которой усредняет следующее действие по стратегии, $R_{t+1} + \gamma \sum_a \pi(a \mid S_{t+1}) Q(S_{t+1}, a)$; Q-обучение — это ожидаемая SARSA с жадной целевой стратегией.

Весь агент — это цикл:

1. Инициализировать $Q(s, a)$, например нулями, и наблюдать начальное состояние $S_0$.
2. Выбрать $A_t$ ε-жадно по $Q(S_t, \cdot)$, выполнить его, наблюдать $R_{t+1}$ и $S_{t+1}$.
3. Обновить $Q(S_t, A_t)$ с целью выбранного метода (для SARSA сначала выбрать $A_{t+1}$, затем использовать его и в цели, и как следующее действие).
4. Если $S_{t+1}$ терминальное, начать новый эпизод; иначе положить $t \leftarrow t + 1$ и перейти к шагу 2.

## Блуждание у обрыва: что учат методы по текущей стратегии и вне стратегии \{#cliff-walking-what-on-policy-and-off-policy-learn\}

Разница между двумя методами видна на сетке, где исследование опасно ([Sutton and Barto, 2018](#references), пример 6.6), — в **блуждании у обрыва** (cliff walking). В сетке 4 ряда и 12 столбцов. Агент стартует в левом нижнем углу и должен дойти до правого нижнего. Десять клеток между ними — обрыв: шаг в него даёт $-100$ и отправляет агента обратно на старт. Каждый другой шаг даёт $-1$, $\gamma = 1$, оба агента исследуют с $\varepsilon = 0.1$ и учатся с $\alpha = 0.5$.

<CliffWalking />

Q-обучение учит $Q^\star$, жадный путь которой идёт прямо вдоль края обрыва: 13 шагов, отдача $-13$. Но агент не следует жадному пути; он следует ε-жадному, а на пути рядом с обрывом один случайный шаг из сорока — шаг вниз. Точная ожидаемая отдача ε-жадного поведения по $Q^\star$ равна $-45.8$, и кривая Q-обучения держится около $-50$. SARSA учит ценность стратегии, которой следует, со случайными шагами, и состояния вдоль края кажутся ей плохими. Она выбирает путь на ряд выше, 15 шагов которого стоят на два больше, но оставляют ряд между агентом и обрывом. У лучшей ε-жадной стратегии ожидаемая отдача $-20.7$; кривая SARSA, оценки которой постоянный шаг $0.5$ оставляет шумными, держится около $-27$.

**Разобранный пример: одно обновление у обрыва.** Возьмём клетку во втором ряду снизу и седьмом столбце, на краю, и шаг вправо в неё из соседней клетки с наградой $-1$. При предельных ценностях $Q^\star$ в новой клетке равна $-6$ для шага вправо, $-8$ для шагов вверх и влево и $-113$ для шага вниз — это $-100$ за падение плюс $-13$ за путь от старта. Цель Q-обучения: $-1 + \max_a Q^\star = -1 - 6 = -7$. Следующее действие SARSA жадное с вероятностью $0.925$ и каждое другое — с вероятностью $0.025$, поэтому её цель в среднем равна

$$
-1 + 0.925 \cdot (-6) + 0.025 \cdot (-8 - 8 - 113) = -1 - 5.55 - 3.225 = -9.775 .
$$

Каждая клетка на краю несёт этот лишний $-2.8$ — ожидаемую цену случайного падения, — и жадный выбор SARSA обходит их стороной.

Какой ответ верен, зависит от того, для чего нужны ценности. Если после обучения исследование выключат, Q-обучение нашло лучшую стратегию. Если агент должен продолжать учиться, пока действует, как робот или развёрнутая система, осторожность SARSA того стоит: она оптимизирует то, что происходит на самом деле. Если $\varepsilon$ со временем убывает до нуля, оба метода сходятся к оптимальному пути.

## Когда оценки сходятся \{#when-the-estimates-converge\}

У табличных методов есть гарантии. Мы их формулируем, но не доказываем; доказательства рассматривают каждое обновление как стохастическую аппроксимацию в смысле [Robbins and Monro (1951)](#references) неподвижной точки сжатия, например оператора Беллмана из [заметки об MDP](/ru/notes/agents/markov-decision-processes#value-iteration). Предположим, что MDP конечен, награды ограничены и $\gamma < 1$ или эпизоды кончаются с вероятностью 1, а размеры шага $\alpha_t(s, a)$, свои для каждой пары, удовлетворяют условиям

$$
\sum_{t} \alpha_t(s, a) = \infty, \qquad \sum_{t} \alpha_t(s, a)^2 < \infty,
$$

например $\alpha = 1/N(s, a)$ — единица, делённая на число посещений. Первое условие позволяет оценкам пройти любое расстояние; второе заставляет шум целей усредниться. Тогда:

- **Предсказание TD(0)** сходится к $V^\pi$ с вероятностью 1, если каждое состояние посещается бесконечно часто ([Sutton, 1988](#references); [Dayan, 1992](#references); [Jaakkola, Jordan and Singh, 1994](#references)).
- **Q-обучение** сходится к $Q^\star$ с вероятностью 1, если каждая пара «состояние–действие» обновляется бесконечно часто, какой бы ни была поведенческая стратегия (behaviour policy) ([Watkins and Dayan, 1992](#references); [Tsitsiklis, 1994](#references)).
- **SARSA** сходится к $Q^\star$ с вероятностью 1, если, кроме того, стратегия **жадная в пределе при бесконечном исследовании** (greedy in the limit with infinite exploration, GLIE): каждая пара пробуется бесконечно часто, и стратегия становится жадной, например ε-жадная с $\varepsilon$, убывающим как единица, делённая на число посещений состояния ([Singh, Jaakkola, Littman and Szepesvári, 2000](#references)).

На практике важны три оговорки. При постоянном $\alpha$, как на рисунках, оценки не сходятся, а продолжают колебаться вокруг предела. Гарантии ничего не говорят о скорости: при $\alpha = 1/N$ время, нужное Q-обучению, может расти экспоненциально по $1/(1 - \gamma)$, а шаги $1/N^\omega$ с $\omega \in (1/2, 1)$ делают его полиномиальным ([Even-Dar and Mansour, 2003](#references)). И всё опирается на таблицу: одну отдельную оценку на состояние. С аппроксимацией функций гарантии перестают действовать — это тема следующей заметки.

## Между одним шагом и всем эпизодом: n-шаговые отдачи и следы приемлемости \{#between-one-step-and-the-whole-episode-n-step-returns-and-eligibility-traces\}

TD(0) смотрит на один шаг вперёд, а Монте-Карло — до конца. **n-шаговая отдача** (n-step return) смотрит на $n$ шагов вперёд и затем применяет бутстрэппинг:

$$
G_{t:t+n} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n}),
$$

причём $G_{t:t+n} = G_t$, если эпизод кончается раньше $t + n$. $n = 1$ — это TD(0), а $n = \infty$ — Монте-Карло; между ними с ростом $n$ смещение падает, а дисперсия растёт, и промежуточные значения часто учатся быстрее всего ([Sutton and Barto, 2018](#references), глава 7).

Вместо выбора одного $n$ **λ-отдача** (λ-return) усредняет их все с геометрически убывающими весами:

$$
G_t^\lambda = (1 - \lambda) \sum_{n=1}^{\infty} \lambda^{n-1} G_{t:t+n}, \qquad \lambda \in [0, 1],
$$

и веса $(1 - \lambda)\lambda^{n-1}$ в сумме дают 1. При $\lambda = 0.5$ одно-, двух- и трёхшаговая отдачи получают $0.5$, $0.25$ и $0.125$; при $\lambda = 0.9$ — $0.1$, $0.09$ и $0.081$, и хвост тянется далеко в эпизод. $\lambda = 0$ — это TD(0), а $\lambda = 1$ — Монте-Карло.

λ-отдача смотрит в будущее, но её можно вычислить, глядя назад. **TD(λ)** хранит для каждого состояния **след приемлемости** (eligibility trace) $z(s)$ — затухающую память о том, как недавно и как часто оно посещалось. На каждом шаге все следы затухают в $\gamma\lambda$ раз, след текущего состояния растёт на 1, и каждое состояние обновляется пропорционально своему следу:

$$
z(s) \leftarrow \gamma \lambda\, z(s) + \mathbb 1[s = S_t], \qquad V(s) \leftarrow V(s) + \alpha\, \delta_t\, z(s) \quad \text{для всех } s .
$$

Так одна ошибка TD сразу засчитывается всем недавно посещённым состояниям, самому недавнему — больше всех. В сумме за эпизод при фиксированной $V$ эти обновления равны обновлениям к λ-отдачам — это тождество предыдущего раздела с $\gamma\lambda$ вместо $\gamma$ ([Sutton, 1988](#references); [Sutton and Barto, 2018](#references), глава 12). Та же смесь горизонтов снова появляется в многошаговых целях глубоких Q-сетей и в оценке преимущества в методах градиента по стратегии.

| | итерация по ценностям | обучение TD |

## Ограничения \{#limitations\}

- **Одна оценка на состояние.** Таблицы не обобщают: у состояния, которое ни разу не посещалось, произвольная ценность, а два почти одинаковых состояния учатся по отдельности. У настольных игр, изображений и текстов состояний гораздо больше, чем может вместить любая таблица.
- **ε-жадный выбор исследует вслепую.** Он тратит на действия, про которые известно, что они ужасны, столько же усилий, сколько на многообещающие, а в задачах, где награда требует длинной точной последовательности действий, случайное исследование практически никогда её не находит.
- **Размеры шага и доли исследования нужно настраивать.** Гарантии справедливы для убывающих расписаний; на практике берут константы, и результаты от них зависят, как показывают рисунки.
- **Q-обучение переоценивает.** Максимум зашумлённых оценок смещён вверх; следующая заметка лечит это двойным Q-обучением (Double Q-learning).
- **Неэффективность по сэмплам.** Каждый переход используется один раз и выбрасывается. Воспроизведение сохранённых переходов или обучение модели и планирование с ней — два средства из следующих заметок.

## Что нужно запомнить \{#what-you-should-remember\}

- Без модели агент оценивает математические ожидания усреднением сэмплов: *оценка ← оценка + α (цель − оценка)*.
- Исследование необходимо, потому что агент сам выбирает свои данные. Жадный выбор может ошибаться вечно; у ε-жадного линейное сожаление; оптимистичный бонус UCB $c\sqrt{\ln t / N_t(a)}$ даёт на бандитах логарифмическое сожаление.
- Монте-Карло использует отдачу: несмещённо, высокая дисперсия, только в конце эпизода. TD(0) использует $R_{t+1} + \gamma V(S_{t+1})$: смещено, пока $V$ неверна, низкая дисперсия, после каждого шага. Ошибка Монте-Карло — дисконтированная сумма ошибок TD.
- SARSA учится по текущей стратегии и учит ценность стратегии, которой следует; Q-обучение учится вне стратегии и учит $Q^\star$ при любом достаточно исследующем поведении. В блуждании у обрыва SARSA выбирает безопасный путь, Q-обучение — оптимальный, который обходится ему дороже, пока оно исследует.
- Табличные TD и Q-обучение сходятся с вероятностью 1, когда каждая пара посещается бесконечно часто, а размеры шага удовлетворяют $\sum \alpha = \infty$, $\sum \alpha^2 < \infty$; SARSA нужно ещё и исследование GLIE.
- n-шаговые отдачи и λ-отдача интерполируют между TD(0) и Монте-Карло; следы приемлемости вычисляют λ-отдачу онлайн.

## Код \{#code\}

Испытательный стенд из десятируких бандитов с жадным, ε-жадным выбором и UCB; TD(0) против Монте-Карло с постоянным α на случайном блуждании; SARSA и Q-обучение в блуждании у обрыва; и точные пределы для блуждания у обрыва — из итерации по ценностям и из уравнения Беллмана для лучшей ε-жадной стратегии. Только NumPy, начальные значения генератора фиксированы. Рисунки запускают те же эксперименты при сборке с другим генератором случайных чисел и совпадают с текстом с той точностью, с какой в нём приведены числа; последние знаки также различаются на разных платформах. Скрипт работает около 20 секунд.

```python
import numpy as np

# 1. стенд из десятируких бандитов, векторизованный по 2000 независимым бандитам; оценки — выборочные средние
def bandit(eps=0.0, c=None, runs=2000, steps=1000, k=10, seed=0):
    rng = np.random.default_rng(seed)
    q = rng.normal(size=(runs, k))                              # истинные ценности q*(a)
    Q, N = np.zeros((runs, k)), np.zeros((runs, k))
    rows, reward, optimal = np.arange(runs), np.zeros(steps), np.zeros(steps)
    for t in range(steps):
        if c is None:                                           # epsilon-жадный выбор, равенства разрешаются случайно
            greedy = np.argmax(Q + 1e-9 * rng.random((runs, k)), axis=1)
            a = np.where(rng.random(runs) < eps, rng.integers(k, size=runs), greedy)
        else:                                                   # UCB: сначала руки, которые ещё не пробовали
            bonus = np.where(N > 0, c * np.sqrt(np.log(t + 1) / np.maximum(N, 1)), np.inf)
            a = np.argmax(Q + bonus + 1e-9 * rng.random((runs, k)), axis=1)
        R = q[rows, a] + rng.normal(size=runs)
        N[rows, a] += 1
        Q[rows, a] += (R - Q[rows, a]) / N[rows, a]             # инкрементное выборочное среднее
        reward[t], optimal[t] = R.mean(), (a == q.argmax(1)).mean()
    return reward, optimal

for name, kw in [('greedy', {}), ('eps=0.01', {'eps': 0.01}), ('eps=0.1', {'eps': 0.1}), ('UCB c=2', {'c': 2})]:
    rew, opt = bandit(**kw)
    print(f'{name:9s} reward steps 901-1000 {rew[900:].mean():.2f}  optimal action {opt[900:].mean():.2f}')

# 2. предсказание на случайном блуждании A..E (старт в C, награда 1 за выход справа): TD(0) против MC с постоянным alpha
true_v = np.arange(1, 6) / 6
def walk(method, alpha, runs=100, episodes=100, seed=0):
    rng, rms = np.random.default_rng(seed), np.zeros(episodes + 1)
    for _ in range(runs):
        V = np.full(5, 0.5)
        rms[0] += np.sqrt(np.mean((V - true_v) ** 2)) / runs
        for ep in range(1, episodes + 1):
            s, visited = 2, [2]
            while True:
                s2 = s + (1 if rng.random() < 0.5 else -1)
                r, done = float(s2 == 5), s2 in (-1, 5)
                if method == 'td':                              # V(s) += alpha [r + V(s') - V(s)]
                    V[s] += alpha * (r + (0.0 if done else V[s2]) - V[s])
                if done:
                    break
                s = s2; visited.append(s)
            if method == 'mc':                                  # V(s) += alpha [G - V(s)], G = r на выходе
                for x in visited:
                    V[x] += alpha * (r - V[x])
            rms[ep] += np.sqrt(np.mean((V - true_v) ** 2)) / runs
    return rms

for method, alpha in [('td', 0.05), ('td', 0.1), ('mc', 0.02), ('mc', 0.04)]:
    e = walk(method, alpha)
    print(method, alpha, 'RMS after 10, 50, 100 episodes:', ' '.join(f'{e[i]:.3f}' for i in (10, 50, 100)))

# 3. блуждание у обрыва: сетка 4 x 12, -1 за шаг, -100 и возврат на старт за шаг в обрыв
ROWS, COLS, START, GOAL = 4, 12, 36, 47
MOVES = [(-1, 0), (0, 1), (1, 0), (0, -1)]                      # вверх, вправо, вниз, влево
def step(s, a):
    r, c = divmod(s, COLS)
    r, c = min(ROWS - 1, max(0, r + MOVES[a][0])), min(COLS - 1, max(0, c + MOVES[a][1]))
    return (START, -100) if r == 3 and 1 <= c <= 10 else (r * COLS + c, -1)

def control(method, runs=100, episodes=500, alpha=0.5, eps=0.1, seed=0):
    rng, returns = np.random.default_rng(seed), np.zeros(episodes)
    def act(Q, s):                                              # epsilon-жадный выбор со случайным разрешением равенств
        if rng.random() < eps:
            return int(rng.integers(4))
        return int(rng.choice(np.flatnonzero(Q[s] == Q[s].max())))
    for _ in range(runs):
        Q = np.zeros((ROWS * COLS, 4))
        for ep in range(episodes):
            s, a, total = START, act(Q, START), 0
            while s != GOAL:
                s2, r = step(s, a)
                a2 = act(Q, s2)
                nxt = 0.0 if s2 == GOAL else (Q[s2, a2] if method == 'sarsa' else Q[s2].max())
                Q[s, a] += alpha * (r + nxt - Q[s, a])          # единственная строка, в которой методы различаются: nxt
                s, a, total = s2, a2, total + r
            returns[ep] += total / runs
    return returns

for method in ('sarsa', 'q'):
    g = control(method)
    print(f'{method:5s} return per episode: episodes 1-50 {g[:50].mean():.1f}, episodes 401-500 {g[400:].mean():.1f}')
# sarsa return per episode: episodes 1-50 -110.1, episodes 401-500 -27.3
# q     return per episode: episodes 1-50 -114.9, episodes 401-500 -49.6

# 4. точные пределы: Q* (итерация по ценностям) и лучшая epsilon-жадная стратегия (её собственное уравнение Беллмана)
def backup(V):
    Q = np.zeros((ROWS * COLS, 4))
    for s in range(ROWS * COLS):
        for a in range(4):
            if s != GOAL:
                s2, r = step(s, a); Q[s, a] = r + V[s2]
    return Q
def eps_value(Q, eps=0.1, iters=5000):                         # ожидаемая отдача epsilon-greedy(Q), gamma = 1
    V = np.zeros(ROWS * COLS)
    pi = np.full((ROWS * COLS, 4), eps / 4); pi[np.arange(ROWS * COLS), Q.argmax(1)] += 1 - eps
    for _ in range(iters):
        V = (pi * backup(V)).sum(1); V[GOAL] = 0
    return V[START]
V = np.zeros(ROWS * COLS)
for _ in range(100):
    V = backup(V).max(1); V[GOAL] = 0
Qstar = backup(V)
U = np.zeros(ROWS * COLS)
for _ in range(5000):
    Qs = backup(U); U = 0.9 * Qs.max(1) + 0.1 * Qs.mean(1); U[GOAL] = 0
print('optimal return', V[START], '| eps-greedy on Q*', round(eps_value(Qstar), 2), '| best eps-greedy policy', round(U[START], 2))
# optimal return -13.0 | eps-greedy on Q* -45.8 | best eps-greedy policy -20.71

s2 = 2 * COLS + 6                                               # разобранный пример: клетка на краю, седьмой столбец
pi = np.full(4, 0.025); pi[Qstar[s2].argmax()] += 0.9
print(Qstar[s2], -1 + Qstar[s2].max(), round(-1 + pi @ Qstar[s2], 3))   # [  -8.   -6. -113.   -8.] -7.0 -9.775
```
