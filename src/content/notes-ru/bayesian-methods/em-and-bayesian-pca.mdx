Перед нами 100 точек в десятимерном пространстве. Собственные значения их выборочной ковариации равны $62.23$, $12.00$ и $4.45$, затем $1.52$, $1.35$ и медленно убывают до $0.39$. Сколько главных компонент содержат данные? [Вероятностный PCA](/ru/notes/ml/dimensionality-reduction#probabilistic-pca) отвечает в терминах правдоподобия, и ответ бесполезен: максимум правдоподобия растёт с каждой добавленной компонентой.

Байесовская модель справляется лучше. Поставим на нагрузки априорное распределение с отдельной обратной дисперсией (precision) для каждого столбца, как [метод релевантных векторов](/ru/notes/bayesian-methods/relevance-vector-machine) делал для весов, и позволим обоснованности (evidence) отключить ненужные столбцы. Теперь обоснованность — интеграл по нагрузкам без замкнутого вида. Инструмент для него — [EM-алгоритм](/ru/notes/ml/em-algorithm) из курса машинного обучения ([Dempster, Laird and Rubin, 1977](#references)), переформулированный как нижняя оценка, на которую опирается вся эта часть курса.

## Вероятностный PCA не может выбрать размерность \{#probabilistic-pca-cannot-choose-its-dimension\}

Вероятностный PCA объясняет каждое наблюдение $x_i \in \mathbb R^d$, центрированное так, что среднее данных равно нулю, $k$-мерным кодом $z_i$:

$$
\begin{aligned}
z_i &\sim \mathcal N(0, I_k), \\
x_i \mid z_i &\sim \mathcal N(W z_i, \sigma^2 I_d), \\
x_i &\sim \mathcal N(0,\; W W^\top + \sigma^2 I_d) ,
\end{aligned}
$$

где $W \in \mathbb R^{d \times k}$ — матрица нагрузок (loading matrix) со столбцами $w_1, \dots, w_k$, а $\sigma^2$ — дисперсия шума. Решение методом максимального правдоподобия известно в замкнутом виде. Пусть $\lambda_1 \ge \dots \ge \lambda_d$ — собственные значения выборочной ковариации $S = \frac1n \sum_i x_i x_i^\top$. Столбцы $W$ порождают подпространство $k$ ведущих собственных векторов $S$, то есть направлений [PCA](/ru/notes/math/singular-value-decomposition#pca-is-the-svd-of-the-centred-data). В решении с ортогональными столбцами столбец $j$ имеет длину $\sqrt{\lambda_j - \sigma^2}$, а $\sigma^2$ равна среднему $d - k$ отброшенных собственных значений.

<details>
<summary>Почему</summary>

Логарифм правдоподобия зависит от данных только через $S$: при $C = W W^\top + \sigma^2 I_d$ он равен $-\frac n2\big(\log\det C + \operatorname{tr}(C^{-1} S)\big)$ с точностью до константы. Пусть собственные векторы $C$ совпадают с собственными векторами $S$, а собственные значения равны $c_j$. Определитель — произведение $c_j$, след равен $\sum_j \lambda_j / c_j$, поэтому логарифм правдоподобия распадается на слагаемые по направлениям, $-\frac n2 (\log c_j + \lambda_j/c_j)$, а производная по $c_j$, $-\frac n2 (1/c_j - \lambda_j/c_j^2)$, обращается в ноль при $c_j = \lambda_j$. Матрица $W$ ранга $k$ свободно задаёт $k$ из них выше $\sigma^2$, $c_j = \lVert w_j \rVert^2 + \sigma^2 = \lambda_j$, что и даёт длины $\sqrt{\lambda_j - \sigma^2}$; остальные $d - k$ равны $\sigma^2$. Приравняв к нулю производную $\sum_{j \gt k} (\log\sigma^2 + \lambda_j/\sigma^2)$ по $\sigma^2$, получаем их среднее. То, что у оптимальной $C$ собственные векторы $S$ и она сохраняет наибольшие собственные значения, доказано в [Tipping and Bishop (1999)](#references), приложения A.1–A.2.

</details>

Выбрать $k$ максимальное правдоподобие не может. Модели вложены друг в друга: модель с $k + 1$ столбцами может обнулить один из них, поэтому максимум логарифма правдоподобия с ростом $k$ не убывает. Данные из начала заметки порождены моделью с тремя латентными измерениями и единичным шумом:

| $k$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| логарифм правдоподобия | $-2052.4$ | $-1885.9$ | $-1813.9$ | $-1806.6$ | $-1799.7$ | $-1793.2$ | $-1790.6$ | $-1786.4$ | $-1783.4$ |

До $k = 3$ прирост равен $166.5$ и $72.0$, дальше — $7.3$, $6.9$ и меньше, но правдоподобие продолжает расти. При $k = 9$ используются все столбцы. Их длины $\sqrt{\lambda_j - \sigma^2}$ равны $7.86$, $3.41$ и $2.02$ для сигнала и от $1.07$ до $0.49$ для шести направлений, в которых есть только шум. Дисперсия шума получается $\sigma^2 = 0.388$, намного меньше истинного значения 1, потому что лишние столбцы поглотили бо́льшую часть шума. Чтобы выбрать $k$ по BIC или по правдоподобию на отложенных данных, нужно обучить модель для каждого $k$ отдельно.

## EM как покоординатный подъём по нижней оценке обоснованности \{#em-as-coordinate-ascent-on-the-evidence-lower-bound\}

Пусть $X = \{x_1, \dots, x_n\}$ — наблюдения, $Z = \{z_1, \dots, z_n\}$ — латентные переменные, а $\theta$ — параметры. Для любого распределения $q(Z)$, положительного всюду, где положительно апостериорное распределение,

$$
\begin{aligned}
\log p(X \mid \theta) &= \mathcal L(q, \theta) + D_{\mathrm{KL}}\big(q \,\|\, p(Z \mid X, \theta)\big), \\
\mathcal L(q, \theta) &= \mathbb E_q\big[\log p(X, Z \mid \theta)\big] - \mathbb E_q\big[\log q(Z)\big] .
\end{aligned}
$$

Это тождество выведено в [заметке об EM](/ru/notes/ml/em-algorithm#where-the-lower-bound-comes-from): запишем $\log p(X \mid \theta) = \log p(X, Z \mid \theta) - \log p(Z \mid X, \theta)$, прибавим и вычтем $\log q(Z)$ и усредним по $q$. KL-дивергенция неотрицательна, поэтому $\mathcal L$, **нижняя оценка обоснованности** (evidence lower bound, ELBO), действительно оценивает логарифм обоснованности снизу и точна ровно тогда, когда $q$ совпадает с апостериорным распределением. В разделе «Код» тождество проверяется для случайно выбранного $q$: обе части равны $-14.691242$.

EM — это [покоординатный подъём](/ru/notes/ml/em-algorithm#em-is-coordinate-ascent-on-the-bound) по $\mathcal L$. **E-шаг** максимизирует по $q$ при фиксированном $\theta$. Поскольку $\log p(X \mid \theta)$ не зависит от $q$, это минимизирует KL-дивергенцию: $q$ становится апостериорным распределением, и зазор закрывается. **M-шаг** максимизирует по $\theta$ при фиксированном $q$. Энтропия $q$ от $\theta$ не зависит, поэтому M-шаг максимизирует математическое ожидание логарифма правдоподобия полных данных $\mathbb E_q[\log p(X, Z \mid \theta)]$.

Зачем добавлять неизвестные? Логарифм правдоподобия смеси гауссиан — сумма по точкам логарифмов сумм по компонентам. Он не распадается на отдельные подгонки, и у него много локальных максимумов: одна лишь перенумерация $K$ компонент превращает один максимум в $K!$. Если бы мы знали, какая компонента породила каждую точку, подгонка распалась бы на подгонку одной гауссианы на компоненту. Латентные переменные выбирают так, чтобы распределение полных данных $p(X, Z \mid \theta)$ лежало в [экспоненциальном семействе](/ru/notes/bayesian-methods/conjugate-priors#the-exponential-family). Тогда $\log p(X, Z \mid \theta)$ — линейная функция естественных параметров минус логарифм статистической суммы, который [выпукл, потому что его гессиан — ковариация](/ru/notes/bayesian-methods/conjugate-priors#derivatives-of-the-log-partition-function); значит, он вогнут. Его среднее по $q$ тоже вогнуто, потому что сумма вогнутых функций с неотрицательными весами вогнута. M-шаг — максимизация вогнутой функции, которую решает [сопоставление моментов](/ru/notes/bayesian-methods/conjugate-priors#derivatives-of-the-log-partition-function) с ожидаемыми достаточными статистиками, в замкнутом виде или несколькими шагами выпуклого оптимизатора.

Априорное распределение на параметрах даёт **MAP-EM**. Логарифм апостериорной плотности параметров равен $\log p(\theta \mid X) = \log p(X \mid \theta) + \log p(\theta) - \log p(X)$, и последнее слагаемое не зависит от $\theta$. Прибавим $\log p(\theta)$ к обеим частям разложения:

$$
\begin{aligned}
\log p(\theta \mid X) + \log p(X) ={}& \mathcal L(q, \theta) + \log p(\theta) \\
&+ D_{\mathrm{KL}}\big(q \,\|\, p(Z \mid X, \theta)\big) .
\end{aligned}
$$

E-шаг не меняется. M-шаг максимизирует $\mathbb E_q[\log p(X, Z \mid \theta)] + \log p(\theta)$, и тот же довод показывает, что логарифм апостериорной плотности не убывает. Так работает априорное распределение на ковариациях гауссовской смеси, одна из защит от вырождающихся компонент: оно превращает M-шаг в регуляризованную подгонку.

Роли можно и поменять. Сделаем веса линейной модели латентной переменной, а априорные обратные дисперсии — параметрами, и EM будет максимизировать обоснованность по обратным дисперсиям. Для метода релевантных векторов это даёт обновление $\alpha_i = 1/(\mu_i^2 + \Sigma_{ii})$, которое [заметка о методе релевантных векторов](/ru/notes/bayesian-methods/relevance-vector-machine#why-mackays-update-converges-faster-than-em) сравнивает с неподвижной точкой Маккая.

Ни один из шагов не обязан решаться точно. **Обобщённый EM** (generalized EM) на M-шаге лишь увеличивает $\mathcal L$, например несколькими градиентными шагами или максимизацией по одной группе параметров за раз, и каждый цикл всё равно увеличивает правдоподобие. E-шаг тоже может быть частичным: инкрементальный EM пересчитывает апостериорное распределение одной точки за раз и соответственно обновляет достаточные статистики M-шага ([Neal and Hinton, 1998](#references); [Bishop, 2006](#references), раздел 9.4). Важно лишь, чтобы каждый шаг поднимал нижнюю оценку.

<aside class="callout"><strong>Ключевая идея.</strong> $\log p(X) = \mathcal L(q) + D_{\mathrm{KL}}(q \,\|\, \text{апостериорное})$. Точный E-шаг EM закрывает зазор. Шаг, который лишь поднимает $\mathcal L$, всё равно ведёт вверх, но ограниченное $q$ оставляет зазор и смещает неподвижную точку.</aside>

## EM для краудсорсинговой разметки \{#em-for-crowd-labels\}

Метки для обучающих данных часто покупают на краудсорсинговых (crowdsourcing) платформах: каждое изображение получают несколько исполнителей, и их ответы расходятся. Голосование большинством считает всех исполнителей одинаково надёжными, а все изображения — одинаково трудными. [Whitehill et al. (2009)](#references) моделируют и то и другое в модели GLAD (generative model of labels, abilities and difficulties — порождающая модель меток, умений и сложностей). Её обучают EM-алгоритмом: истинные метки — латентные переменные, а умения и сложности — параметры.

У объекта $i = 1, \dots, n$ есть неизвестная истинная метка $z_i \in \{0, 1\}$ и **лёгкость** $b_i > 0$; его сложность равна $1/b_i$. У исполнителя $j = 1, \dots, m$ есть **умение** $a_j \in \mathbb R$. Метка $l_{ij}$, которую исполнитель $j$ ставит объекту $i$, верна с вероятностью

$$
p(l_{ij} = z_i \mid z_i, a_j, b_i) = \sigma(a_j b_i) = \frac{1}{1 + e^{-a_j b_i}} .
$$

В статье они обозначены $\alpha$ и $\beta$; в этом курсе эти буквы заняты обратными дисперсиями. Умение 0 — подбрасывание монеты, а отрицательное умение — у исполнителя, который склонен ставить неверную метку, по злому умыслу или по недоразумению. Объект с $b_i \to 0$ — подбрасывание монеты для всех. Метки независимы при данной истинной метке, и исполнитель не обязан размечать каждый объект: обозначим через $J_i$ тех, кто разметил объект $i$.

E-шаг — это взвешенное голосование. По формуле Байеса при априорном распределении $p(z_i = 1) = 1/2$ апостериорный логарифм шансов истинной метки равен сумме логарифмов отношений правдоподобия её меток, поскольку они независимы при данном $z_i$. Метка $l_{ij} = 1$ верна при $z_i = 1$ и неверна при $z_i = 0$, поэтому вносит $\log \sigma(a_j b_i) - \log \sigma(-a_j b_i)$; метка $l_{ij} = 0$ вносит то же с минусом. Наконец, $\sigma(x)/\sigma(-x) = (1 + e^{x})/(1 + e^{-x}) = e^x$:

$$
\begin{aligned}
\log \frac{p(z_i = 1 \mid l, a, b)}{p(z_i = 0 \mid l, a, b)}
&= \sum_{j \in J_i} (2 l_{ij} - 1) \log \frac{\sigma(a_j b_i)}{\sigma(-a_j b_i)} \\
&= b_i \sum_{j \in J_i} a_j\, (2 l_{ij} - 1) .
\end{aligned}
$$

Каждая метка голосует $+1$ или $-1$ с весом, равным умению её исполнителя. При равных умениях это голосование большинством, а исполнитель с отрицательным умением голосует против того, что сказал. Лёгкость умножает всю сумму: она меняет уверенность апостериорного распределения, но никогда не меняет победившую сторону.

Для M-шага обозначим через $c_{ij}$ апостериорную вероятность того, что метка $l_{ij}$ верна, $q_i(z_i = l_{ij})$. Логарифм правдоподобия полных данных — сумма по меткам из $\log \sigma(a_j b_i)$ для верной метки и $\log \sigma(-a_j b_i)$ для неверной. Его математическое ожидание по $q$ заменяет индикатор верной метки на $c_{ij}$:

$$
\begin{aligned}
Q(a, b) = \sum_{i} \sum_{j \in J_i} \Big[&c_{ij} \log \sigma(a_j b_i) \\
&+ (1 - c_{ij}) \log \sigma(-a_j b_i)\Big] + \text{const} .
\end{aligned}
$$

Поскольку $\log \sigma(x) = -\log(1 + e^{-x})$, его производная равна $e^{-x}/(1 + e^{-x}) = \sigma(-x)$, а производная $\log\sigma(-x)$ равна $-\sigma(x)$. С учётом $\sigma(x) + \sigma(-x) = 1$ каждое слагаемое имеет производную $c_{ij}\,\sigma(-x) - (1 - c_{ij})\,\sigma(x) = c_{ij} - \sigma(x)$ по $x = a_j b_i$, и правило дифференцирования сложной функции даёт

$$
\begin{aligned}
\frac{\partial Q}{\partial a_j} &= \sum_{i:\, j \in J_i} b_i \big(c_{ij} - \sigma(a_j b_i)\big), \\
\frac{\partial Q}{\partial b_i} &= \sum_{j \in J_i} a_j \big(c_{ij} - \sigma(a_j b_i)\big) .
\end{aligned}
$$

Это градиент [логистической регрессии](/ru/notes/ml/logistic-regression): наблюдаемая минус предсказанная вероятность верной метки. Замкнутого вида нет, поэтому M-шаг делает несколько градиентных шагов — это обобщённый EM. Whitehill et al. добавляют априорные распределения $a_j \sim \mathcal N(1, 1)$ и $\log b_i \sim \mathcal N(1, 1)$, которые сохраняют $b_i$ положительным и превращают метод в MAP-EM.

**Разобранный пример.** Возьмём 1000 объектов, каждый размечен 3 из 7 исполнителей, выбранными случайно, с умениями $(3, 2, 1.5, 1, 0.5, 0, -1)$: эксперты, средние исполнители, угадывающий и вредитель. Лёгкость равна $e^{\mathcal N(1, 1)}$, как в симуляциях статьи. EM начинает с равных умений, поэтому его первый E-шаг — голосование большинством:

| | голосование большинством | GLAD, 24 итерации EM |
| --- | --- | --- |
| неверных меток из 1000 | 133 | 61 |
| умения | равные | $(1.45, 1.40, 1.43, 1.13, 0.83, 0.09, -1.03)$ |

GLAD исправляет 91 объект, на котором большинство ошиблось, и портит 19, на которых оно было право. Модель находит угадывающего и вредителя, чьи голоса теперь считаются наоборот, но при трёх метках на объект не различает трёх лучших исполнителей.

Две симметрии показывают, что делают априорные распределения. Смена знака у всех умений вместе с переворотом всех истинных меток не меняет правдоподобия: каждая верная метка становится неверной, а $\sigma(a_j b_i)$ и $\sigma(-a_j b_i)$ меняются местами, так что каждый множитель остаётся прежним. Удвоение умений при уменьшении лёгкостей вдвое сохраняет каждое произведение $a_j b_i$, а значит, и правдоподобие. Только априорное среднее 1 у $a_j$ говорит, что исполнители в основном помогают, и задаёт масштаб.

Модель только с умениями, где все $b_i = 1$, на этих данных тоже делает 61 ошибку. При известных умениях лёгкость никогда не меняет победителя голосования; она действует через M-шаг, где градиент по $a_j$ взвешивает объект $i$ множителем $b_i$, так что трудные объекты весят меньше. Здесь две подгонки находят почти пропорциональные умения, $(3.14, 3.06, 3.08, 2.20, 1.52, 0.11, -2.01)$ без лёгкости, и голосования дают похожий результат. Whitehill et al. обнаружили, что это окупается, когда половина объектов трудна: 4.5% ошибок против 8.4% у EM-модели только с умениями и 11.2% у голосования большинством.

## Вариационный EM: когда E-шаг не может быть точным \{#variational-em-when-the-e-step-cannot-be-exact\}

Точному E-шагу нужно апостериорное распределение $p(Z \mid X, \theta)$. Для смеси это таблица ответственностей. Для большинства моделей с многими взаимодействующими латентными переменными это распределение на экспоненциально большом числе конфигураций или непрерывная плотность без замкнутого вида. **Вариационный EM** (variational EM, [Neal and Hinton, 1998](#references)) сохраняет нижнюю оценку и ограничивает E-шаг семейством $\mathcal Q$ распределений, с которыми можно работать:

$$
\begin{aligned}
q^{t+1} &= \arg\max_{q \in \mathcal Q}\, \mathcal L(q, \theta^t) \\
&= \arg\min_{q \in \mathcal Q}\, D_{\mathrm{KL}}\big(q \,\|\, p(Z \mid X, \theta^t)\big), \\
\theta^{t+1} &= \arg\max_\theta\, \mathcal L(q^{t+1}, \theta) .
\end{aligned}
$$

Две формы E-шага — одна и та же задача, потому что $\log p(X \mid \theta^t)$ не зависит от $q$. Каждый шаг по-прежнему увеличивает $\mathcal L$, так что нижняя оценка не убывает. Теряется точность оценки после E-шага: зазор равен наименьшей KL-дивергенции в $\mathcal Q$ и положителен, если $\mathcal Q$ не содержит апостериорного распределения. Обозначим $\ell(\theta) = \log p(X \mid \theta)$. Цепочка монотонности точного EM имеет вид

$$
\ell(\theta^{t+1}) \ge \mathcal L(q^{t+1}, \theta^{t+1}) \ge \mathcal L(q^{t+1}, \theta^t) = \ell(\theta^t) ,
$$

а при ограниченном $q$ её последнее звено превращается в $\le$. Логарифм правдоподобия может уменьшаться, а неподвижная точка максимизирует нижнюю оценку, а не правдоподобие. Нижняя оценка равна правдоподобию минус зазор, который зависит от $\theta$, поэтому её точку максимума тянет к параметрам, при которых апостериорное распределение легко приблизить элементом $\mathcal Q$. Это смещение может быть большим ([Turner and Sahani, 2011](#references)).

**Разобранный пример: жёсткий EM — это вариационный EM.** Возьмём в качестве $\mathcal Q$ точечные массы, $q_i(z_i) = [z_i = \hat z_i]$. Энтропия точечной массы равна нулю, поэтому $\mathcal L = \sum_i \log p(x_i, \hat z_i \mid \theta)$, и максимум достигается, когда каждая точка получает свою наиболее вероятную компоненту. Зазор для одной точки равен

$$
\begin{aligned}
&D_{\mathrm{KL}}\big(q_i \,\|\, p(z_i \mid x_i, \theta)\big) \\
&\quad= \sum_{z} [z = \hat z_i] \log \frac{[z = \hat z_i]}{p(z \mid x_i, \theta)} \\
&\quad= -\log p(\hat z_i \mid x_i, \theta) .
\end{aligned}
$$

Этот E-шаг — шаг назначения в методе k-средних и в [жёстком EM](/ru/notes/ml/em-algorithm#k-means-is-the-hard-equal-variance-limit) (hard EM) из заметки об EM. Значит, жёсткий EM минимизирует ту же KL-дивергенцию, только по самому узкому семейству, точечным массам на назначениях ([Vetrov and Kropotov](#references), лекция 7). Возьмём игрушечную модель той заметки, смесь $\tfrac12 \mathcal N(0, 1) + \tfrac12 \mathcal N(\theta, 1)$ на семи точках, и начнём с $\theta_0 = 0.6$. Первые три точки достаются первой компоненте, последние четыре — второй:

| $x_i$ | $-0.8$ | $-0.2$ | $0.3$ | $0.9$ | $2.1$ | $2.8$ | $3.4$ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| $p(\hat z_i \mid x_i, \theta_0)$ | $0.659$ | $0.574$ | $0.500$ | $0.589$ | $0.746$ | $0.818$ | $0.865$ |
| зазор $-\log p(\hat z_i \mid x_i, \theta_0)$ | $0.417$ | $0.554$ | $0.693$ | $0.529$ | $0.292$ | $0.201$ | $0.145$ |

В сумме зазоры дают $2.83$. M-шаг переносит $\theta$ в среднее четырёх точек, $2.300$. Там логарифм правдоподобия равен $-12.06$, а следующий E-шаг оставляет зазор $0.77$. Жёсткий EM сходится к $\theta = 2.767$ с $\ell = -12.05$ и зазором $0.45$. Точный EM сходится к оценке максимального правдоподобия $\theta = 2.540$ с $\ell = -12.00$ и без зазора. Поначалу жёсткий EM даже поднимается быстрее, $-12.06$ против $-12.83$ после одного M-шага, и всё равно останавливается не там. Он максимизирует собственную нижнюю оценку, которая при $\theta = 2.767$ равна $-12.50$, больше её значения $-12.57$ в оценке максимального правдоподобия.

Точечные массы — самое грубое семейство. [Следующая заметка](/ru/notes/bayesian-methods/variational-inference) использует факторизованные распределения $q(Z) = \prod_j q_j(Z_j)$, для которых у E-шага есть покоординатное обновление в замкнутом виде. Кроме того, там $q$ распространяется и на параметры, так что M-шаг исчезает и приближается всё апостериорное распределение ([Beal, 2003](#references)).

## Байесовский метод главных компонент: обратная дисперсия для каждого столбца \{#bayesian-pca-a-precision-for-every-column\}

Байесовский метод главных компонент (Bayesian PCA, [Bishop, 1999a](#references)) сохраняет вероятностный PCA и добавляет априорное распределение на нагрузки с отдельной обратной дисперсией $\alpha_j$ для каждого столбца:

$$
\begin{aligned}
p(W \mid \alpha) &= \prod_{j=1}^{k} \mathcal N\big(w_j \mid 0,\ \alpha_j^{-1} I_d\big), \\
k &= d - 1 .
\end{aligned}
$$

Это автоматическое определение релевантности (automatic relevance determination, ARD), применённое к латентным измерениям, а не к входным признакам. Большое $\alpha_j$ прижимает столбец $w_j$ к нулю, а нулевой столбец удаляет латентное измерение $j$ из модели, поскольку $W z$ перестаёт зависеть от $z_j$. $k = d - 1$ — столько столбцов, сколько может быть полезно: если оставить их все, $W W^\top + \sigma^2 I$ уже может представить любую ковариационную матрицу. Возьмём $\sigma^2$ равным её наименьшему собственному значению $\lambda_d$, а столбцами — остальные $d - 1$ собственных векторов $v_j$, растянутые до $\sqrt{\lambda_j - \lambda_d}\, v_j$ ([Bishop, 2006](#references), раздел 12.2.3).

В идеале $\alpha$ и $\sigma^2$ выбирались бы максимизацией обоснованности $p(X \mid \alpha, \sigma^2) = \int p(X \mid W, \sigma^2)\, p(W \mid \alpha)\, dW$. Но $W$ входит в ковариацию $x$ квадратично, и у интеграла нет замкнутого вида. Схема Бишопа, та же, что у [Ветрова и Кропотова](#references), приближает обоснованность в духе [приближения Лапласа](/ru/notes/bayesian-methods/laplace-approximation) и чередует два шага:

1. при фиксированном $\alpha$ найти MAP-оценку $W$ и $\sigma^2$ методом MAP-EM с кодами $z_i$ в роли латентных переменных;
2. при фиксированном $W$ положить $\alpha_j = d / \lVert w_j \rVert^2$.

Второе обновление — неподвижная точка обоснованности из метода релевантных векторов, $\alpha_j = \gamma_j / \lVert w_j \rVert^2$, применённая к целому столбцу из $d$ элементов, каждый из которых считается хорошо определённым данными, так что $\gamma_j = d$. Это же значение $\alpha_j$ максимизирует $\log p(w_j \mid \alpha_j) = \frac d2 \log \alpha_j - \frac{\alpha_j}{2} \lVert w_j \rVert^2$ при текущем $w_j$.

E-шаг точен, потому что $z_i$ и $x_i$ совместно гауссовские. Оставим слагаемые $\log p(x_i, z_i)$, содержащие $z_i$, и [выделим полный квадрат](/ru/notes/bayesian-methods/bayesian-linear-regression#3-completing-the-square):

$$
\begin{aligned}
\log p(z_i \mid x_i)
&= -\tfrac12 z_i^\top z_i - \frac{\lVert x_i - W z_i \rVert^2}{2\sigma^2} + \text{const} \\
&= -\tfrac12 z_i^\top \frac{M}{\sigma^2} z_i + z_i^\top \frac{W^\top x_i}{\sigma^2} + \text{const} .
\end{aligned}
$$

Обратная дисперсия равна $M/\sigma^2$, среднее — обратной к ней матрице, умноженной на линейный член, а $\mathbb E[z z^\top]$ — ковариация плюс внешнее произведение среднего на себя:

$$
\begin{aligned}
M &= W^\top W + \sigma^2 I_k, \\
\mathbb E[z_i] &= M^{-1} W^\top x_i, \\
\mathbb E[z_i z_i^\top] &= \sigma^2 M^{-1} + \mathbb E[z_i]\, \mathbb E[z_i]^\top .
\end{aligned}
$$

M-шаг максимизирует $\sum_i \mathbb E\big[\log p(x_i \mid z_i, W, \sigma^2)\big] + \log p(W \mid \alpha)$. Слагаемые с $W$ равны $-\frac{1}{2\sigma^2} \sum_i \mathbb E\lVert x_i - W z_i \rVert^2 - \frac12 \sum_j \alpha_j \lVert w_j \rVert^2$. Обозначим $A = \operatorname{diag}(\alpha_1, \dots, \alpha_k)$ и соберём две суммы статистик E-шага:

$$
\begin{aligned}
G &= \sum_i x_i\, \mathbb E[z_i]^\top, \\
R &= \sum_i \mathbb E[z_i z_i^\top] .
\end{aligned}
$$

Раскроем $\mathbb E\lVert x - W z \rVert^2 = \lVert x \rVert^2 - 2\, \mathbb E[z]^\top W^\top x + \operatorname{tr}\big(\mathbb E[z z^\top] W^\top W\big)$. По [правилам для следа](/ru/notes/math/matrix-calculus#traces-of-matrix-products) градиент $\mathbb E[z]^\top W^\top x$ по $W$ равен $x\, \mathbb E[z]^\top$, а градиент $\operatorname{tr}(R\, W^\top W)$ при симметричной $R$ равен $2 W R$; априорное слагаемое даёт $-W A$. После суммирования по точкам градиент и его нуль дают

$$
\begin{aligned}
0 &= \frac{1}{\sigma^2} \big(G - W R\big) - W A \\
\Longrightarrow\quad G &= W \big(R + \sigma^2 A\big) \\
\Longrightarrow\quad W &= G \big(R + \sigma^2 A\big)^{-1} .
\end{aligned}
$$

При $A = 0$ это EM-алгоритм для вероятностного PCA ([Tipping and Bishop, 1999](#references)); априорное распределение добавляет $\sigma^2 A$, гребневый штраф своей величины для каждого столбца. Дисперсия шума в априорное распределение не входит. Приравняв к нулю производную $-\frac{nd}{2} \log \sigma^2 - \frac{1}{2\sigma^2} \sum_i \mathbb E\lVert x_i - W z_i \rVert^2$ с новым $W$, получаем

$$
\begin{aligned}
\sigma^2 = \frac{1}{nd} \sum_{i=1}^n \Big(&\lVert x_i \rVert^2 - 2\, \mathbb E[z_i]^\top W^\top x_i \\
&+ \operatorname{tr}\big(\mathbb E[z_i z_i^\top]\, W^\top W\big)\Big) .
\end{aligned}
$$

Одна итерация стоит $O(ndk + k^3)$ и никогда не строит ковариацию размера $d \times d$, поэтому при большом $d$ и малом $k$ EM дешевле спектрального разложения. EM для вероятностного PCA справляется и со значениями, пропущенными случайно (missing at random): тогда E-шаг усредняет не только по кодам, но и по пропущенным координатам ([Bishop, 2006](#references), раздел 12.2.2).

### Почему столбец отключается \{#why-a-column-switches-off\}

Возьмём неподвижную точку, в которой оставшиеся столбцы ортогональны и лежат вдоль собственных векторов $S$. Здесь EM приходит именно к такой точке: в разделе «Код» наибольший главный угол между оставшимися столбцами и тремя ведущими собственными векторами меньше $0.01°$. Тогда собственные векторы $C = W W^\top + \sigma^2 I$ совпадают с собственными векторами $S$. Вдоль собственного вектора столбца $j$ с собственным значением $\lambda$ матрицы $S$ и при $u = \lVert w_j \rVert^2$ у $C$ собственное значение $c = u + \sigma^2$, и, как в решении максимального правдоподобия выше, логарифм правдоподобия распадается на слагаемые по отдельным направлениям. Целевая функция MAP для $u$ и её стационарная точка таковы:

$$
\begin{aligned}
f(u) &= -\frac n2 \Big(\log c + \frac{\lambda}{c}\Big) - \frac{\alpha_j}{2}\, u, \\
f'(u) = 0 \iff \alpha_j &= \frac{n(\lambda - c)}{c^2} .
\end{aligned}
$$

Подставим обновление обратной дисперсии $\alpha_j = d/u$ и $c = u + \sigma^2$, раскроем обе части и соберём степени $u$:

$$
\begin{aligned}
n(\lambda - \sigma^2 - u)\, u &= d\,(u + \sigma^2)^2 \\
(n + d)\, u^2 - \big[n(\lambda - \sigma^2) - 2d\sigma^2\big]\, u + d\sigma^4 &= 0 .
\end{aligned}
$$

Произведение корней, $d\sigma^4/(n + d)$, положительно, поэтому оба корня одного знака — знака их суммы, то есть выражения в квадратных скобках, делённого на $n + d$. Корни вещественны, когда дискриминант неотрицателен. Значит, положительный корень есть, только если выражение в скобках положительно, а его квадрат не меньше $4(n + d)\, d\sigma^4$, то есть $n(\lambda - \sigma^2) - 2d\sigma^2 \ge 2\sigma^2\sqrt{d(n + d)}$, или

$$
\boxed{\;\frac{\lambda}{\sigma^2} \;\ge\; 1 + \frac{2\big(d + \sqrt{d(n + d)}\big)}{n}\;}
$$

Ниже порога единственная неподвижная точка — $w_j = 0$ с $\alpha_j = \infty$: столбец отключается. Максимальное правдоподобие сохраняет направление при любом $\lambda > \sigma^2$. Априорное распределение требует дополнительного запаса, который сокращается с ростом $n$: в относительных единицах около $2\sqrt{d/n}$ при $n \gg d$. Выше порога больший корень — это квадрат длины $u = \lVert w_j \rVert^2$, к которому здесь приходит EM. Он меньше значения максимального правдоподобия $\lambda - \sigma^2$, потому что меньше суммы корней, $\big[n(\lambda - \sigma^2) - 2d\sigma^2\big]/(n + d)$.

**Разобранный пример.** Вернёмся к данным из начала заметки, $n = 100$ и $d = 10$. Байесовский метод главных компонент с $k = 9$ столбцами удаляет шесть из них на итерациях EM $55$, $67$, $76$, $124$, $217$ и $218$ (столбец удаляется, когда $\alpha_j$ превышает $10^8$) и заканчивает с $\sigma^2 = 0.977$, близким к истинной дисперсии шума. Порог и третий столбец:

| Величина | Значение |
| --- | --- |
| порог для $\lambda/\sigma^2$ | $1 + 2(10 + \sqrt{1100})/100 = 1.863$ |
| порог для $\lambda$ | $1.863 \cdot 0.977 = 1.82$ |
| квадратное уравнение для $\lambda_3 = 4.45$ | $110\, u^2 - 327.8\, u + 9.545 = 0$ |
| больший корень, $\lVert w_3 \rVert$ | $u = 2.950$, $\lVert w_3 \rVert = 1.717$ |
| максимальное правдоподобие, $\sqrt{\lambda_3 - \sigma^2}$ | $1.86$ |

Третье собственное значение, $4.45$, выше порога, а четвёртое, $1.52$, ниже, поэтому остаются ровно три столбца. Длина третьего — та, которую находит EM. Два других оставшихся столбца имеют длины $7.450$ и $3.136$, тоже большие корни своих квадратных уравнений, и $\alpha = (0.180, 1.017, 3.391)$.

## Где это ломается \{#where-it-breaks\}

Рисунок показывает и первую слабость: EM для байесовского метода главных компонент дёшев на одной итерации, но медленно сходится. Отключение происходит быстро, но затем три оставшихся столбца медленно поворачиваются к собственным векторам, и лишь через несколько тысяч итераций их длины выходят на корни квадратного уравнения. Когда несколько столбцов находятся около порога, результат после фиксированного числа итераций зависит от момента остановки, а от начальной точки может зависеть, какие столбцы останутся.

Вторая слабость в том, что обоснованность только приближается. Обновление $\alpha_j = d/\lVert w_j \rVert^2$ считает каждый элемент столбца хорошо определённым и использует точечную оценку $W$, поэтому порог выше — свойство именно этой схемы. Вариационная трактовка той же модели с факторизованным апостериорным распределением $W$, $z$ и $\alpha$ максимизирует вместо этого настоящую нижнюю оценку обоснованности ([Bishop, 1999b](#references)).

Третья — смещение вариационного EM, разобранное на примере жёсткого EM. Его неподвижные точки максимизируют нижнюю оценку, зазор которой зависит от параметров, поэтому оценки сдвигаются к параметрам с легко приближаемыми апостериорными распределениями: там это $2.767$ вместо $2.540$. Сравнивать модели по их нижним оценкам ещё хуже, потому что у каждой оценки свой неизвестный зазор. Наконец, модель линейна и гауссовская, как и вероятностный PCA: она видит только вторые моменты, а для искривлённых данных нужны смеси вероятностных PCA или нелинейные модели, например VAE.

## Что нужно запомнить \{#what-you-should-remember\}

- $\log p(X \mid \theta) = \mathcal L(q, \theta) + D_{\mathrm{KL}}(q \,\|\, p(Z \mid X, \theta))$ для любого $q$; EM — покоординатный подъём по $\mathcal L$.
- Априорное распределение добавляет $\log p(\theta)$ в M-шаг (MAP-EM); частичные шаги допустимы, если они поднимают $\mathcal L$.
- Краудсорсинговая разметка (GLAD): E-шаг — голосование с весами-умениями, M-шаг — градиент логистической регрессии; знак и масштаб задают априорные распределения.
- Вариационный EM ограничивает $q$: он поднимает нижнюю оценку, правдоподобие может падать, а неподвижная точка смещена. Жёсткий EM — случай точечных масс.
- Байесовский метод главных компонент: своя обратная дисперсия у каждого столбца, M-шаг $W = G(R + \sigma^2 A)^{-1}$, затем $\alpha_j = d/\lVert w_j \rVert^2$.
- Направление сохраняется, только если $\lambda/\sigma^2 \ge 1 + 2(d + \sqrt{d(n + d)})/n$.

## Код \{#code\}

Точный и жёсткий EM на смеси из семи точек, разложение $\log p = \mathcal L + D_{\mathrm{KL}}$ для произвольного $q$, вероятностный PCA методом максимального правдоподобия для каждого $k$ и байесовский метод главных компонент через EM с проверкой неподвижной точки из текста. Только NumPy и SciPy; начальные значения генератора (seed) фиксированы, а точные числа могут немного различаться на разных платформах и версиях библиотек. Скрипт работает около секунды.

```python
import numpy as np
from scipy.stats import norm
from scipy.linalg import subspace_angles

# смесь 0.5 N(0, 1) + 0.5 N(theta, 1) на семи точках: точный EM и вариационный EM с точечными массами (жёсткий EM)
x = np.array([-0.8, -0.2, 0.3, 0.9, 2.1, 2.8, 3.4])
loglik = lambda th: float(np.log(0.5 * norm.pdf(x) + 0.5 * norm.pdf(x - th)).sum())
def bound(th, q):                        # L(q, theta), q — вероятность второй компоненты для каждой точки
    with np.errstate(divide='ignore', invalid='ignore'):
        a = np.where(q < 1, (1 - q) * np.log(0.5 * norm.pdf(x) / (1 - q)), 0.0)
        b = np.where(q > 0, q * np.log(0.5 * norm.pdf(x - th) / q), 0.0)
    return float((a + b).sum())
exact = lambda th: norm.pdf(x - th) / (norm.pdf(x) + norm.pdf(x - th))   # E-шаг: апостериорное распределение
hard = lambda th: (np.abs(x - th) < np.abs(x)).astype(float)             # E-шаг, ограниченный точечными массами
r0, h0 = exact(0.6), hard(0.6)
print(np.where(h0 == 1, r0, 1 - r0).round(3), round(loglik(0.6) - bound(0.6, h0), 2))
# [0.659 0.574 0.5   0.589 0.746 0.818 0.865] 2.83: вероятность выбранной компоненты и зазор
for name, estep in (('exact', exact), ('hard', hard)):
    th, out = 0.6, []
    for it in range(200):
        q = estep(th)
        if it < 2: out.append((round(float(th), 3), round(loglik(th), 2), round(bound(th, q), 2)))
        th = (q * x).sum() / q.sum()                                     # M-шаг: среднее с весами q
    q = estep(th)
    print(name, out, round(float(th), 3), round(loglik(th), 2), round(bound(th, q), 2))
# exact [(0.6, -16.35, -16.35), (1.662, -12.83, -12.83)] 2.54 -12.0 -12.0
# hard [(0.6, -16.35, -19.18), (2.3, -12.06, -12.82)] 2.767 -12.05 -12.5
print(round(bound(2.540, hard(2.540)), 2))                              # -12.57: жёсткая нижняя оценка в оценке максимального правдоподобия

# log p = L + KL выполняется для любого q, а не только для апостериорного
rng = np.random.default_rng(1)
q = rng.uniform(size=7); r = exact(1.0)
kl = (q * np.log(q / r) + (1 - q) * np.log((1 - q) / (1 - r))).sum()

# байесовский PCA: 100 точек в d = 10 измерениях из модели с тремя латентными измерениями и единичным шумом
d, k, n = 10, 3, 100
W_true = rng.normal(size=(d, k)) * np.array([3.0, 2.0, 1.0])
X = rng.normal(size=(n, k)) @ W_true.T + rng.normal(size=(n, d))
X = X - X.mean(axis=0)
lam, V = np.linalg.eigh(X.T @ X / n); lam, V = lam[::-1], V[:, ::-1]
print(lam.round(2))
# [62.23 12.    4.45  1.52  1.35  1.18  0.89  0.84  0.63  0.39]

# вероятностный PCA методом максимального правдоподобия: логарифм правдоподобия только растёт с числом столбцов
def ppca_loglik(q):
    s2 = lam[q:].mean(); c = np.concatenate([lam[:q], np.full(d - q, s2)])
    return -n / 2 * (d * np.log(2 * np.pi) + np.log(c).sum() + (lam / c).sum())
print([round(float(ppca_loglik(q)), 1) for q in range(1, 10)])
# [-2052.4, -1885.9, -1813.9, -1806.6, -1799.7, -1793.2, -1790.6, -1786.4, -1783.4]
s2 = lam[9:].mean(); print(round(float(s2), 3), np.sqrt(lam[:9] - s2).round(2))   # девять столбцов: используются все
# 0.388 [7.86 3.41 2.02 1.07 0.98 0.89 0.71 0.67 0.49]

# EM для MAP-нагрузок с одной обратной дисперсией ARD на столбец, alpha_j = d / ||w_j||^2; столбцы с alpha_j > 1e8 удаляются
q = d - 1
W, s2, alpha = rng.normal(size=(d, q)), 1.0, np.ones(q)
active = np.arange(q); pruned = []
for it in range(1000):
    Wa = W[:, active]; m = len(active)
    Minv = np.linalg.inv(Wa.T @ Wa + s2 * np.eye(m))
    Ez = X @ Wa @ Minv                                   # E[z_i], n x m
    R = n * s2 * Minv + Ez.T @ Ez                        # sum_i E[z_i z_i^T]
    Wa = (X.T @ Ez) @ np.linalg.inv(R + s2 * np.diag(alpha[active]))   # W = G (R + s2 A)^-1
    s2 = (np.sum(X ** 2) - 2 * np.sum(Ez * (X @ Wa)) + np.trace(R @ Wa.T @ Wa)) / (n * d)
    W[:] = 0; W[:, active] = Wa
    alpha[active] = d / (Wa ** 2).sum(axis=0)
    for j in active[alpha[active] > 1e8]: pruned.append((j, it + 1))
    active = active[alpha[active] <= 1e8]
print(len(active), [it for _, it in pruned], round(float(s2), 3))
# 3 [55, 67, 76, 124, 217, 218] 0.977
print(np.sort(np.linalg.norm(W[:, active], axis=0))[::-1].round(3), np.sort(alpha[active]).round(3))
# [7.45  3.136 1.717] [0.18  1.017 3.391]
print(np.degrees(subspace_angles(W[:, active], V[:, :3])).max() < 0.01)   # True: оставшиеся столбцы порождают подпространство ведущих собственных векторов

# неподвижная точка одного столбца вдоль собственного вектора с собственным значением l: (n + d) u^2 - [n (l - s2) - 2 d s2] u + d s2^2 = 0, u = ||w||^2
B = n * (lam[:4] - s2) - 2 * d * s2; disc = B ** 2 - 4 * (n + d) * d * s2 ** 2
print(np.where(disc > 0, np.sqrt((B + np.sqrt(np.maximum(disc, 0))) / (2 * (n + d))), 0).round(3), round(float(1 + 2 * (d + np.sqrt(d * (n + d))) / n), 3))
# [7.45  3.136 1.717 0.   ] 1.863
```

EM для краудсорсинговой разметки: симуляция из разобранного примера, GLAD против голосования большинством и против модели только с умениями, и две симметрии правдоподобия. Работает меньше секунды.

```python
import numpy as np
from scipy.optimize import minimize
from scipy.special import expit, log_expit

# EM для краудсорсинговой разметки (GLAD): исполнитель j правильно размечает объект i с вероятностью sigmoid(a_j b_i)
rng = np.random.default_rng(0)
n, m = 1000, 7                                       # 1000 объектов, 7 исполнителей, 3 метки на объект
a_true = np.array([3.0, 2.0, 1.5, 1.0, 0.5, 0.0, -1.0])   # умения: эксперты, средние, угадывающий, вредитель
b_true = np.exp(rng.normal(1, 1, n))                 # лёгкость b_i > 0; сложность равна 1/b_i
z_true = rng.integers(0, 2, n)
item = np.repeat(np.arange(n), 3)
ann = np.concatenate([rng.choice(m, 3, replace=False) for _ in range(n)])
ok = rng.uniform(size=3 * n) < expit(a_true[ann] * b_true[item])
lab = np.where(ok, z_true[item], 1 - z_true[item])
vote = 2 * lab - 1                                   # +1 за класс 1, -1 за класс 0

def e_step(a, b):                                    # логарифм шансов z_i = 1 — взвешенное голосование sum_j a_j b_i (2 l_ij - 1)
    return expit(np.bincount(item, a[ann] * b[item] * vote, minlength=n))

def m_step(q, a, s, fit_b):
    """A few L-BFGS steps on Q(a, b) + log prior, a_j ~ N(1, 1), s_i = log b_i ~ N(1, 1)."""
    c = np.where(lab == 1, q[item], 1 - q[item])     # апостериорная вероятность того, что каждая метка верна
    def neg(p):
        aj, si = p[:m], (p[m:] if fit_b else s)
        b = np.exp(si); x = aj[ann] * b[item]
        f = (c * log_expit(x) + (1 - c) * log_expit(-x)).sum() - ((aj - 1) ** 2).sum() / 2
        r = c - expit(x)                             # наблюдаемая минус предсказанная вероятность верной метки
        g = [np.bincount(ann, r * b[item], minlength=m) - (aj - 1)]
        if fit_b:
            f -= ((si - 1) ** 2).sum() / 2
            g.append(np.bincount(item, r * aj[ann], minlength=n) * b - (si - 1))
        return -f, -np.concatenate(g)
    p = minimize(neg, np.concatenate([a, s]) if fit_b else a, jac=True, method='L-BFGS-B', options=dict(maxiter=25)).x
    return p[:m], (p[m:] if fit_b else s)

def em(fit_b):
    a, s = np.ones(m), np.zeros(n)                   # равные умения: первый E-шаг — голосование большинством
    q = e_step(a, np.exp(s))
    for it in range(1, 500):
        a, s = m_step(q, a, s, fit_b)
        q, q_old = e_step(a, np.exp(s)), q
        if np.abs(q - q_old).max() < 1e-5: return q, a, s, it

majority = np.bincount(item, vote, minlength=n) > 0
q, a, s, it = em(fit_b=True)
glad = q > 0.5
print((majority != z_true).sum(), (glad != z_true).sum(), it)       # 133 61 24: ошибки голосования большинством и GLAD
print(((majority != z_true) & (glad == z_true)).sum(), ((majority == z_true) & (glad != z_true)).sum())   # 91 19
print(a.round(2))                                    # [ 1.45  1.4   1.43  1.13  0.83  0.09 -1.03]
print((np.bincount(ann, lab == z_true[item]) / np.bincount(ann)).round(2))   # [0.98 0.94 0.94 0.87 0.79 0.53 0.11]: истинная точность каждого исполнителя
print(round(np.corrcoef(s, np.log(b_true))[0, 1], 2))                # 0.43: лёгкость восстанавливается лишь грубо
q1, a1, *_ = em(fit_b=False)                        # только умения, все b_i = 1
print(((q1 > 0.5) != z_true).sum(), a1.round(2))    # 61 [ 3.14  3.06  3.08  2.2   1.52  0.11 -2.01]

# правдоподобие не отличает (a, z) от (-a, 1 - z) и (a, b) от (2a, b/2): знак и масштаб задают только априорные распределения
def loglik(a, b, z):
    x = a[ann] * b[item]
    return np.where(lab == z[item], log_expit(x), log_expit(-x)).sum()
print(np.isclose(loglik(a_true, b_true, z_true), loglik(-a_true, b_true, 1 - z_true)),
      np.isclose(loglik(a_true, b_true, z_true), loglik(2 * a_true, b_true / 2, z_true)))   # True True
```
