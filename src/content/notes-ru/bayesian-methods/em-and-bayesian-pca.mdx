[Предыдущая заметка](/ru/notes/bayesian-methods/laplace-approximation) заменила апостериорное распределение, у которого нет формулы, гауссианой в его моде. В моделях этого раздела есть неизвестные второго рода: кроме параметров, общих для всех наблюдений, у каждого наблюдения есть своя **латентная переменная** (latent variable) — метка кластера или низкоразмерный код. [EM-алгоритм](/ru/notes/ml/em-algorithm) из курса машинного обучения ([Dempster, Laird and Rubin, 1977](#references)) обучает такие модели, когда апостериорное распределение латентных переменных вычисляется точно. Эта заметка переформулирует EM в том виде, на который опирается весь раздел, — как подъём по нижней оценке логарифма обоснованности, по одному блоку за раз, — а затем меняет то, что считается блоками. С априорным распределением на параметрах EM даёт MAP-оценку или настраивает гиперпараметры. Когда апостериорное распределение латентных переменных недоступно, ограничение E-шага вычислимым семейством даёт **вариационный EM** (variational EM). А если дать каждому столбцу матрицы нагрузок свою обратную дисперсию (precision), как в [методе релевантных векторов](/ru/notes/bayesian-methods/relevance-vector-machine), вероятностный метод главных компонент (PPCA) сам выбирает, сколько главных компонент ему нужно: это **байесовский метод главных компонент** (Bayesian PCA).

**Обозначения.** $X = \{x_1, \dots, x_n\}$ — наблюдения в $\mathbb R^d$, центрированные так, что их среднее равно нулю, а $Z = \{z_1, \dots, z_n\}$ — латентные переменные. $\theta$ объединяет параметры, $q(Z)$ — произвольное распределение латентных переменных, $\mathcal L(q, \theta)$ — нижняя оценка обоснованности (evidence lower bound, ELBO), а $D_{\mathrm{KL}}$ — расхождение Кульбака–Лейблера (Kullback–Leibler divergence). Для PCA $k$ — число латентных измерений, $W \in \mathbb R^{d \times k}$ — матрица нагрузок (loading matrix) со столбцами $w_1, \dots, w_k$, $\sigma^2$ — дисперсия шума, $\alpha_j$ — априорная обратная дисперсия столбца $w_j$ и $A = \operatorname{diag}(\alpha_1, \dots, \alpha_k)$. $\lambda_1 \ge \dots \ge \lambda_d$ — собственные значения выборочной ковариации $S = \frac1n \sum_i x_i x_i^\top$.

## Отправная точка: вероятностный PCA с фиксированным числом компонент \{#baseline-probabilistic-pca-with-a-fixed-number-of-components\}

[Вероятностный PCA](/ru/notes/ml/dimensionality-reduction#probabilistic-pca) объясняет каждое наблюдение $k$-мерным кодом:

$$
z_i \sim \mathcal N(0, I_k), \qquad x_i \mid z_i \sim \mathcal N(W z_i, \sigma^2 I_d), \qquad x_i \sim \mathcal N(0,\; W W^\top + \sigma^2 I_d) .
$$

Решение методом максимального правдоподобия известно в замкнутом виде: столбцы $W$ порождают подпространство $k$ ведущих собственных векторов $S$; в решении с ортогональными столбцами столбец $j$ имеет длину $\sqrt{\lambda_j - \sigma^2}$, а $\sigma^2$ — среднее $d - k$ отброшенных собственных значений. Чего максимальное правдоподобие сделать не может, так это выбрать $k$. Модели вложены друг в друга: модель с $k + 1$ столбцами может обнулить один из них, поэтому максимум логарифма правдоподобия с ростом $k$ не убывает.

**Разобранный пример.** В разделе «Код» 100 точек в $d = 10$ измерениях порождаются моделью с тремя латентными измерениями и единичным шумом. Собственные значения $S$ равны $62.23, 12.00, 4.45$, затем $1.52, 1.35, \dots, 0.39$. Максимум логарифма правдоподобия при $k = 1, \dots, 9$ равен

$$
-2052.4,\ -1885.9,\ -1813.9,\ -1806.6,\ -1799.7,\ -1793.2,\ -1790.6,\ -1786.4,\ -1783.4 .
$$

До $k = 3$ он растёт на $166.5$ и $72.0$, дальше — на $7.3$, $6.9$ и меньше, но продолжает расти. При $k = 9$ используются все столбцы: их длины $\sqrt{\lambda_j - \sigma^2}$ равны $7.86, 3.41, 2.02$ для сигнала и $1.07, \dots, 0.49$ для шести направлений, в которых есть только шум, а дисперсия шума получается $\sigma^2 = 0.388$ — намного меньше истинного значения 1, потому что лишние столбцы поглотили бо́льшую часть шума. Чтобы выбрать $k$ по BIC или по правдоподобию на отложенных данных, нужно обучить модель для каждого $k$ отдельно. Байесовский ответ, после короткого отступления про EM, — обучить одну модель с наибольшим $k$ и позволить априорному распределению убрать ненужные ей столбцы.

## EM как покоординатный подъём по нижней оценке обоснованности \{#em-as-coordinate-ascent-on-the-evidence-lower-bound\}

Для любого распределения $q(Z)$, положительного всюду, где положительно апостериорное распределение,

$$
\log p(X \mid \theta) = \underbrace{\mathbb E_{q}\big[\log p(X, Z \mid \theta)\big] - \mathbb E_q\big[\log q(Z)\big]}_{\mathcal L(q, \theta)} \;+\; D_{\mathrm{KL}}\big(q(Z) \,\big\|\, p(Z \mid X, \theta)\big) .
$$

Это тождество выведено в [заметке об EM](/ru/notes/ml/em-algorithm#where-the-lower-bound-comes-from): запишем $\log p(X \mid \theta) = \log p(X, Z \mid \theta) - \log p(Z \mid X, \theta)$, прибавим и вычтем $\log q(Z)$ и усредним по $q$. Поскольку KL-дивергенция неотрицательна, $\mathcal L$ — нижняя оценка логарифма обоснованности, и она точна ровно тогда, когда $q$ совпадает с апостериорным распределением. EM — это [покоординатный подъём](/ru/notes/ml/em-algorithm#em-is-coordinate-ascent-on-the-bound) по $\mathcal L$: **E-шаг** максимизирует по $q$ при фиксированном $\theta$, то есть делает $q$ апостериорным распределением и закрывает зазор; **M-шаг** максимизирует по $\theta$ при фиксированном $q$, то есть максимизирует математическое ожидание логарифма правдоподобия полных данных $\mathbb E_q[\log p(X, Z \mid \theta)]$. Раздел «Код» проверяет тождество для случайно выбранного $q$, который не совпадает с апостериорным распределением: обе части равны $-14.691242$.

Именно это разложение сохраняется во всём разделе; три применения ниже меняют то, что считается блоками.

**Априорное распределение на параметрах: MAP-EM.** Прибавим $\log p(\theta)$ к обеим частям. Апостериорное распределение параметров удовлетворяет равенству $\log p(\theta \mid X) = \log p(X \mid \theta) + \log p(\theta) - \log p(X)$, а последнее слагаемое не зависит от $\theta$, поэтому

$$
\log p(\theta \mid X) + \log p(X) = \mathcal L(q, \theta) + \log p(\theta) + D_{\mathrm{KL}}\big(q \,\|\, p(Z \mid X, \theta)\big) .
$$

E-шаг не меняется; M-шаг максимизирует $\mathbb E_q[\log p(X, Z \mid \theta)] + \log p(\theta)$, и тот же довод о монотонности показывает, что логарифм апостериорной плотности не убывает. Так работает априорное распределение на ковариациях гауссовской смеси — одна из защит от вырождающихся компонент: оно превращает M-шаг в регуляризованную подгонку.

**Параметры как латентные переменные: гиперпараметры через EM.** В [методе релевантных векторов](/ru/notes/bayesian-methods/relevance-vector-machine) у весов $w$ априорное распределение $\mathcal N(0, \operatorname{diag}(\alpha)^{-1})$, а обратные дисперсии $\alpha_j$ выбираются максимизацией обоснованности $p(t \mid \alpha, \beta)$. Будем считать $w$ латентной переменной, а $\alpha$ — параметром. E-шаг даёт гауссовское апостериорное распределение весов $\mathcal N(w \mid \mu, \Sigma)$. На M-шаге от $\alpha$ зависит только априорное распределение:

$$
\mathbb E_q\big[\log p(w \mid \alpha)\big] = \sum_j \Big(\tfrac12 \log \alpha_j - \tfrac12\, \alpha_j\, \mathbb E_q[w_j^2]\Big) + \text{const}, \qquad \alpha_j^{\text{new}} = \frac{1}{\mathbb E_q[w_j^2]} = \frac{1}{\mu_j^2 + \Sigma_{jj}} .
$$

Так EM даёт второй набор обновлений обоснованности, которые гарантированно увеличивают её на каждом шаге. [Tipping (2001](#references), приложение A) выводит оба набора и сообщает, что [обновления неподвижной точки Маккея](/ru/notes/bayesian-methods/relevance-vector-machine#type-ii-maximum-likelihood-mackays-fixed-point) $\alpha_j = \gamma_j/\mu_j^2$ с $\gamma_j = 1 - \alpha_j \Sigma_{jj}$ на практике сходятся намного быстрее, поэтому RVM использует именно их.

<aside class="callout"><strong>Ключевая идея.</strong> Весь раздел держится на одном тождестве: $\log p(X) = \mathcal L(q) + D_{\mathrm{KL}}(q \,\|\, \text{апостериорное})$. EM может позволить себе точное апостериорное распределение, поэтому его E-шаг закрывает зазор. Вариационный EM ограничивает $q$ семейством, с которым умеет работать, и мирится с оставшимся зазором. Байесовский метод главных компонент сохраняет точный E-шаг и ставит на нагрузки априорное распределение с отдельной обратной дисперсией для каждого столбца; тогда обоснованности незачем сохранять столбец, который подгоняет только шум, и такой столбец отключается.</aside>

## Вариационный EM: когда E-шаг не может быть точным \{#variational-em-when-the-e-step-cannot-be-exact\}

Точному E-шагу нужно апостериорное распределение $p(Z \mid X, \theta)$. Для смеси это таблица ответственностей; для большинства моделей с многими взаимодействующими латентными переменными это распределение на экспоненциально большом числе конфигураций или непрерывная плотность без замкнутого вида. **Вариационный EM** ([Neal and Hinton, 1998](#references)) сохраняет нижнюю оценку и ограничивает E-шаг семейством $\mathcal Q$ распределений, с которыми можно работать:

$$
q^{t+1} = \arg\max_{q \in \mathcal Q}\, \mathcal L(q, \theta^t) = \arg\min_{q \in \mathcal Q}\, D_{\mathrm{KL}}\big(q \,\|\, p(Z \mid X, \theta^t)\big), \qquad \theta^{t+1} = \arg\max_\theta\, \mathcal L(q^{t+1}, \theta) .
$$

Две формы E-шага — одна и та же задача, потому что $\log p(X \mid \theta^t)$ не зависит от $q$. Каждый шаг по-прежнему увеличивает $\mathcal L$, так что нижняя оценка не убывает. Теряется точность оценки после E-шага: зазор равен наименьшей KL-дивергенции в $\mathcal Q$, а не нулю, и третье звено цепочки монотонности $\ell(\theta^{t+1}) \ge \mathcal L(q^{t+1}, \theta^{t+1}) \ge \mathcal L(q^{t+1}, \theta^t) = \ell(\theta^t)$ превращается в неравенство, направленное не в ту сторону. Логарифм правдоподобия может уменьшаться, а неподвижная точка максимизирует нижнюю оценку, а не правдоподобие. Поскольку нижняя оценка равна правдоподобию минус зазор, её точку максимума тянет к параметрам, при которых апостериорное распределение легко приблизить элементом $\mathcal Q$, и это смещение может быть большим ([Turner and Sahani, 2011](#references)).

**Разобранный пример: жёсткий EM — это вариационный EM.** Возьмём в качестве $\mathcal Q$ точечные массы, $q_i(z_i) = [z_i = \hat z_i]$. Энтропия точечной массы равна нулю, поэтому $\mathcal L = \sum_i \log p(x_i, \hat z_i \mid \theta)$, и максимум достигается на наиболее вероятной компоненте для каждой точки; зазор равен

$$
D_{\mathrm{KL}}\big(q_i \,\|\, p(z_i \mid x_i, \theta)\big) = \sum_{z} [z = \hat z_i] \log \frac{[z = \hat z_i]}{p(z \mid x_i, \theta)} = -\log p(\hat z_i \mid x_i, \theta) .
$$

Этот E-шаг — шаг назначения в методе k-средних и в жёстком EM (hard EM) из [заметки об EM](/ru/notes/ml/em-algorithm#k-means-is-the-hard-equal-variance-limit). Возьмём игрушечную модель той заметки — смесь $\tfrac12 \mathcal N(0, 1) + \tfrac12 \mathcal N(\theta, 1)$ на семи точках $-0.8, -0.2, 0.3, 0.9, 2.1, 2.8, 3.4$ — и начнём с $\theta_0 = 0.6$. Апостериорные вероятности второй компоненты равны $0.341, 0.426, 0.500, 0.589, 0.746, 0.818, 0.865$; первые три точки достаются первой компоненте, последние четыре — второй, и зазор равен

$$
-\big(\log 0.659 + \log 0.574 + \log 0.500 + \log 0.589 + \log 0.746 + \log 0.818 + \log 0.865\big) = 2.83 .
$$

M-шаг переносит $\theta$ в среднее четырёх точек, $2.300$; там логарифм правдоподобия равен $-12.06$, а следующий E-шаг оставляет зазор $0.77$. Жёсткий EM сходится к $\theta = 2.767$ с $\ell = -12.05$ и зазором $0.45$; точный EM сходится к оценке максимального правдоподобия $\theta = 2.540$ с $\ell = -12.00$ и без зазора. Жёсткий EM поначалу даже поднимается быстрее ($-12.06$ против $-12.83$ после одного M-шага) и всё равно останавливается не там: он максимизирует собственную нижнюю оценку, которая при $\theta = 2.767$ равна $-12.50$, больше её значения $-12.57$ в оценке максимального правдоподобия.

Точечные массы — самое грубое семейство. Следующая заметка использует семейство факторизованных распределений $q(Z) = \prod_j q_j(Z_j)$, для которого у E-шага есть покоординатное обновление в замкнутом виде, и распространяет $q$ и на параметры, так что M-шаг исчезает и приближается всё апостериорное распределение ([Beal, 2003](#references)).

## Байесовский метод главных компонент: обратная дисперсия для каждого столбца \{#bayesian-pca-a-precision-for-every-column\}

Байесовский метод главных компонент ([Bishop, 1999a](#references)) сохраняет вероятностный PCA и добавляет априорное распределение на нагрузки с отдельной обратной дисперсией для каждого столбца:

$$
p(W \mid \alpha) = \prod_{j=1}^{k} \Big(\frac{\alpha_j}{2\pi}\Big)^{d/2} \exp\Big(-\frac{\alpha_j}{2}\, \lVert w_j \rVert^2\Big), \qquad k = d - 1 .
$$

Это автоматическое определение релевантности (automatic relevance determination, ARD), применённое к латентным измерениям, а не к входным признакам. Большое $\alpha_j$ прижимает столбец $w_j$ к нулю, а нулевой столбец удаляет латентное измерение $j$ из модели, поскольку $W z$ перестаёт зависеть от $z_j$. $k = d - 1$ — наибольшее полезное значение: при $k = d$ ковариация $W W^\top + \sigma^2 I$ могла бы поглотить шум в $W$.

В идеале $\alpha$ и $\sigma^2$ выбирались бы максимизацией обоснованности $p(X \mid \alpha, \sigma^2) = \int p(X \mid W, \sigma^2)\, p(W \mid \alpha)\, dW$, но $W$ входит в ковариацию $x$ квадратично, и у интеграла нет замкнутого вида. Схема Бишопа — та же, что и в [лекциях Ветрова и Кропотова](#references), — приближает её в духе [приближения Лапласа](/ru/notes/bayesian-methods/laplace-approximation) и чередует два шага:

1. **MAP-нагрузки.** При фиксированном $\alpha$ найти MAP-оценку $W$ и $\sigma^2$ методом MAP-EM с кодами $z_i$ в роли латентных переменных.
2. **Обратные дисперсии.** При фиксированном $W$ положить $\alpha_j = d / \lVert w_j \rVert^2$.

Второе обновление — это неподвижная точка обоснованности Маккея из метода релевантных векторов, применённая к целому столбцу: $\alpha_j = \gamma_j / \lVert w_j \rVert^2$ с $\gamma_j = d - \alpha_j \operatorname{tr} \Sigma_{w_j}$, где $\Sigma_{w_j}$ — апостериорная ковариация столбца, причём все $d$ элементов столбца считаются хорошо определёнными данными, $\gamma_j = d$. Это же значение $\alpha_j$ максимизирует $\log p(w_j \mid \alpha_j) = \frac d2 \log \alpha_j - \frac{\alpha_j}{2} \lVert w_j \rVert^2$ при текущем $w_j$.

**E-шаг** точен, потому что $z_i$ и $x_i$ совместно гауссовские. По [формуле условного распределения](/ru/notes/probability/multivariate-gaussian#marginals-and-conditionals)

$$
M = W^\top W + \sigma^2 I_k, \qquad \mathbb E[z_i] = M^{-1} W^\top x_i, \qquad \mathbb E[z_i z_i^\top] = \sigma^2 M^{-1} + \mathbb E[z_i]\, \mathbb E[z_i]^\top .
$$

**M-шаг** максимизирует $\sum_i \mathbb E\big[\log p(x_i \mid z_i, W, \sigma^2)\big] + \log p(W \mid \alpha)$. Слагаемые с $W$ равны $-\frac{1}{2\sigma^2} \sum_i \mathbb E\lVert x_i - W z_i \rVert^2 - \frac12 \sum_j \alpha_j \lVert w_j \rVert^2$, и при $\mathbb E\lVert x - W z \rVert^2 = \lVert x \rVert^2 - 2\, \mathbb E[z]^\top W^\top x + \operatorname{tr}\big(\mathbb E[z z^\top] W^\top W\big)$ градиент по $W$ равен

$$
\frac{1}{\sigma^2} \Big(\sum_i x_i\, \mathbb E[z_i]^\top - W \sum_i \mathbb E[z_i z_i^\top]\Big) - W A = 0
\quad\Longrightarrow\quad
W = \Big(\sum_i x_i\, \mathbb E[z_i]^\top\Big) \Big(\sum_i \mathbb E[z_i z_i^\top] + \sigma^2 A\Big)^{-1} .
$$

При $A = 0$ это EM-алгоритм для вероятностного PCA ([Tipping and Bishop, 1999](#references)); априорное распределение добавляет $\sigma^2 A$ — гребневый штраф своей величины для каждого столбца. Дисперсия шума в априорное распределение не входит, и приравнивание к нулю производной $-\frac{nd}{2} \log \sigma^2 - \frac{1}{2\sigma^2} \sum_i \mathbb E\lVert x_i - W z_i \rVert^2$ даёт

$$
\sigma^2 = \frac{1}{nd} \sum_{i=1}^n \Big(\lVert x_i \rVert^2 - 2\, \mathbb E[z_i]^\top W^\top x_i + \operatorname{tr}\big(\mathbb E[z_i z_i^\top]\, W^\top W\big)\Big),
$$

с новым $W$. Одна итерация стоит $O(ndk + k^3)$ и никогда не строит ковариацию размера $d \times d$.

### Почему столбец отключается \{#why-a-column-switches-off\}

В неподвижной точке оставшиеся столбцы лежат вдоль собственных векторов $S$: в разделе «Код» наибольший главный угол между оставшимися столбцами и тремя ведущими собственными векторами меньше $0.01°$. Вдоль одного такого собственного вектора с собственным значением $\lambda$ и $u = \lVert w_j \rVert^2$ ковариация $x$ имеет собственное значение $c = u + \sigma^2$, а логарифм правдоподобия вероятностного PCA распадается на слагаемые по отдельным направлениям. Целевая функция MAP для $u$ равна

$$
-\frac n2 \Big(\log c + \frac{\lambda}{c}\Big) - \frac{\alpha_j}{2}\, u, \qquad \text{стационарна при} \quad \frac{n(\lambda - c)}{c^2} = \alpha_j .
$$

Подстановка обновления обратной дисперсии $\alpha_j = d/u$ даёт $n(\lambda - c)\,u = d\,c^2$ — квадратное уравнение относительно $u$:

$$
(n + d)\, u^2 - \big[n(\lambda - \sigma^2) - 2d\sigma^2\big]\, u + d\sigma^4 = 0 .
$$

Положительный корень у него есть, только если выражение в квадратных скобках положительно, а дискриминант неотрицателен, $n(\lambda - \sigma^2) - 2d\sigma^2 \ge 2\sigma^2\sqrt{d(n + d)}$, то есть

$$
\boxed{\;\frac{\lambda}{\sigma^2} \;\ge\; 1 + \frac{2\big(d + \sqrt{d(n + d)}\big)}{n}\;}
$$

Ниже порога единственная неподвижная точка — $w_j = 0$ с $\alpha_j = \infty$: столбец отключается. Максимальное правдоподобие сохраняет направление при любом $\lambda > \sigma^2$; априорное распределение требует дополнительного запаса, который сокращается с ростом $n$, — в относительных единицах около $2\sqrt{d/n}$ при $n \gg d$. Выше порога больший корень — это квадрат длины $u = \lVert w_j \rVert^2$, к которому приходит EM; он немного меньше значения максимального правдоподобия $\lambda - \sigma^2$.

**Разобранный пример.** Для данных из отправной точки $n = 100$ и $d = 10$ дают порог $1 + 2(10 + \sqrt{1100})/100 = 1.863$. Байесовский метод главных компонент с $k = 9$ столбцами удаляет шесть из них на итерациях EM $55, 67, 76, 124, 217, 218$ (столбец удаляется, когда $\alpha_j$ превышает $10^8$) и заканчивает с $\sigma^2 = 0.977$, близким к истинной дисперсии шума. Порог тогда равен $1.863 \cdot 0.977 = 1.82$: третье собственное значение, $4.45$, выше него, четвёртое, $1.52$, ниже, поэтому остаются ровно три столбца. Для $\lambda = 4.45$ квадратное уравнение имеет вид

$$
110\, u^2 - 327.8\, u + 9.545 = 0, \qquad u = \frac{327.8 + \sqrt{327.8^2 - 4 \cdot 110 \cdot 9.545}}{220} = 2.950, \qquad \lVert w_3 \rVert = 1.717,
$$

и это та длина, которую находит EM, против $\sqrt{\lambda - \sigma^2} = \sqrt{4.45 - 0.977} = 1.86$ у максимального правдоподобия при том же $\sigma^2$. Два других оставшихся столбца имеют длины $7.450$ и $3.136$, тоже заданные большими корнями своих квадратных уравнений, и $\alpha = (0.180, 1.017, 3.391)$.

## Ограничения \{#limitations\}

- **Обоснованность приближается, а не максимизируется.** Обновление $\alpha_j = d/\lVert w_j \rVert^2$ считает каждый элемент столбца хорошо определённым и использует точечную оценку $W$; порог выше — свойство этой схемы. Вариационная трактовка той же модели, с факторизованным апостериорным распределением $W$, $z$ и $\alpha$ вместо точечных оценок, максимизирует настоящую нижнюю оценку обоснованности ([Bishop, 1999b](#references)).
- **Медленная сходимость.** Отключение происходит быстро, но оставшиеся столбцы выравниваются по собственным векторам за тысячи итераций; когда много столбцов близки к порогу, результат после фиксированного числа итераций зависит от момента остановки.
- **Линейность и гауссовость.** Как и вероятностный PCA, модель видит только вторые моменты и линейную структуру; для искривлённых многообразий нужны смеси вероятностных PCA или нелинейные модели, например VAE.
- **Вариационный EM смещён.** Его неподвижные точки максимизируют нижнюю оценку, зазор которой зависит от параметров, поэтому оценки параметров и, что хуже, сравнения моделей по нижней оценке могут быть искажены, и величину искажения по самой нижней оценке узнать нельзя.
- **Локальные оптимумы остаются.** Ни MAP-EM, ни вариационный EM не гарантируют глобального максимума своей целевой функции; когда несколько столбцов близки к порогу, от начальной точки зависит, какие из них останутся.

## Что нужно запомнить \{#what-you-should-remember\}

- Для любого $q$ выполняется $\log p(X \mid \theta) = \mathcal L(q, \theta) + D_{\mathrm{KL}}(q \,\|\, p(Z \mid X, \theta))$; EM — покоординатный подъём по $\mathcal L$, и его точный E-шаг закрывает зазор.
- Априорное распределение на $\theta$ добавляет $\log p(\theta)$ в M-шаг (MAP-EM); если считать веса латентными, а гиперпараметры параметрами, EM превращается в максимизацию обоснованности с $\alpha_j = 1/(\mu_j^2 + \Sigma_{jj})$ для ARD.
- Вариационный EM ограничивает E-шаг семейством $\mathcal Q$; он увеличивает нижнюю оценку, а не правдоподобие, и сходится к смещённой точке. Жёсткий EM — частный случай с точечными массами и зазором $-\log p(\hat z_i \mid x_i, \theta)$ на точку.
- Байесовский метод главных компонент даёт каждому столбцу $W$ свою обратную дисперсию, обучает $W$ и $\sigma^2$ методом MAP-EM с дополнительным членом $\sigma^2 A$ и пересчитывает $\alpha_j = d/\lVert w_j \rVert^2$.
- Направление с выборочным собственным значением $\lambda$ сохраняется, только если $\lambda/\sigma^2 \ge 1 + 2(d + \sqrt{d(n + d)})/n$; иначе его столбец уходит в ноль, и размерность выбирается автоматически.

## Код \{#code\}

Точный и жёсткий EM на смеси из семи точек, разложение $\log p = \mathcal L + D_{\mathrm{KL}}$ для произвольного $q$, вероятностный PCA методом максимального правдоподобия для каждого $k$ и байесовский метод главных компонент через EM с проверкой неподвижной точки из текста. Только NumPy и SciPy; начальные значения генератора (seed) фиксированы, а точные числа могут немного различаться на разных платформах и версиях библиотек. Скрипт работает около секунды.

```python
import numpy as np
from scipy.stats import norm
from scipy.linalg import subspace_angles

# смесь 0.5 N(0, 1) + 0.5 N(theta, 1) на семи точках: точный EM и вариационный EM с точечными массами (жёсткий EM)
x = np.array([-0.8, -0.2, 0.3, 0.9, 2.1, 2.8, 3.4])
loglik = lambda th: float(np.log(0.5 * norm.pdf(x) + 0.5 * norm.pdf(x - th)).sum())
def bound(th, q):                        # L(q, theta), q — вероятность второй компоненты для каждой точки
    with np.errstate(divide='ignore', invalid='ignore'):
        a = np.where(q < 1, (1 - q) * np.log(0.5 * norm.pdf(x) / (1 - q)), 0.0)
        b = np.where(q > 0, q * np.log(0.5 * norm.pdf(x - th) / q), 0.0)
    return float((a + b).sum())
exact = lambda th: norm.pdf(x - th) / (norm.pdf(x) + norm.pdf(x - th))   # E-шаг: апостериорное распределение
hard = lambda th: (np.abs(x - th) < np.abs(x)).astype(float)             # E-шаг, ограниченный точечными массами
for name, estep in (('exact', exact), ('hard', hard)):
    th, out = 0.6, []
    for it in range(200):
        q = estep(th)
        if it < 2: out.append((round(float(th), 3), round(loglik(th), 2), round(bound(th, q), 2)))
        th = (q * x).sum() / q.sum()                                     # M-шаг: среднее с весами q
    q = estep(th)
    print(name, out, round(float(th), 3), round(loglik(th), 2), round(bound(th, q), 2))
# exact [(0.6, -16.35, -16.35), (1.662, -12.83, -12.83)] 2.54 -12.0 -12.0
# hard [(0.6, -16.35, -19.18), (2.3, -12.06, -12.82)] 2.767 -12.05 -12.5

# log p = L + KL выполняется для любого q, а не только для апостериорного распределения
rng = np.random.default_rng(1)
q = rng.uniform(size=7); r = exact(1.0)
kl = (q * np.log(q / r) + (1 - q) * np.log((1 - q) / (1 - r))).sum()
print(round(loglik(1.0), 6), round(bound(1.0, q) + kl, 6))           # -14.691242 -14.691242

# байесовский метод главных компонент: 100 точек в d = 10 измерениях из модели с тремя латентными измерениями и единичным шумом
d, k, n = 10, 3, 100
W_true = rng.normal(size=(d, k)) * np.array([3.0, 2.0, 1.0])
X = rng.normal(size=(n, k)) @ W_true.T + rng.normal(size=(n, d))
X = X - X.mean(axis=0)
lam, V = np.linalg.eigh(X.T @ X / n); lam, V = lam[::-1], V[:, ::-1]
print(lam.round(2))
# [62.23 12.    4.45  1.52  1.35  1.18  0.89  0.84  0.63  0.39]

# вероятностный PCA методом максимального правдоподобия: логарифм правдоподобия только растёт с числом столбцов
def ppca_loglik(q):
    s2 = lam[q:].mean(); c = np.concatenate([lam[:q], np.full(d - q, s2)])
    return -n / 2 * (d * np.log(2 * np.pi) + np.log(c).sum() + (lam / c).sum())
print([round(float(ppca_loglik(q)), 1) for q in range(1, 10)])
# [-2052.4, -1885.9, -1813.9, -1806.6, -1799.7, -1793.2, -1790.6, -1786.4, -1783.4]
s2 = lam[9:].mean(); print(round(float(s2), 3), np.sqrt(lam[:9] - s2).round(2))   # девять столбцов: используется каждый
# 0.388 [7.86 3.41 2.02 1.07 0.98 0.89 0.71 0.67 0.49]

# EM для MAP-нагрузок с одной обратной дисперсией ARD на столбец, alpha_j = d / ||w_j||^2; столбцы с alpha_j > 1e8 удаляются
q = d - 1
W, s2, alpha = rng.normal(size=(d, q)), 1.0, np.ones(q)
active = np.arange(q); pruned = []
for it in range(1000):
    Wa = W[:, active]; m = len(active)
    Minv = np.linalg.inv(Wa.T @ Wa + s2 * np.eye(m))
    Ez = X @ Wa @ Minv                                   # E[z_i], n x m
    Szz = n * s2 * Minv + Ez.T @ Ez                      # sum_i E[z_i z_i^T]
    Wa = (X.T @ Ez) @ np.linalg.inv(Szz + s2 * np.diag(alpha[active]))
    s2 = (np.sum(X ** 2) - 2 * np.sum(Ez * (X @ Wa)) + np.trace(Szz @ Wa.T @ Wa)) / (n * d)
    W[:] = 0; W[:, active] = Wa
    alpha[active] = d / (Wa ** 2).sum(axis=0)
    for j in active[alpha[active] > 1e8]: pruned.append((j, it + 1))
    active = active[alpha[active] <= 1e8]
print(len(active), [it for _, it in pruned], round(float(s2), 3))
# 3 [55, 67, 76, 124, 217, 218] 0.977
print(np.sort(np.linalg.norm(W[:, active], axis=0))[::-1].round(3), np.sort(alpha[active]).round(3))
# [7.45  3.136 1.717] [0.18  1.017 3.391]
print(np.degrees(subspace_angles(W[:, active], V[:, :3])).max() < 0.01)   # True: оставшиеся столбцы порождают подпространство ведущих собственных векторов

# неподвижная точка одного столбца вдоль собственного вектора с собственным значением l: (n + d) u^2 - [n (l - s2) - 2 d s2] u + d s2^2 = 0, u = ||w||^2
B = n * (lam[:4] - s2) - 2 * d * s2; disc = B ** 2 - 4 * (n + d) * d * s2 ** 2
print(np.where(disc > 0, np.sqrt((B + np.sqrt(np.maximum(disc, 0))) / (2 * (n + d))), 0).round(3), round(float(1 + 2 * (d + np.sqrt(d * (n + d))) / n), 3))
# [7.45  3.136 1.717 0.   ] 1.863
```
