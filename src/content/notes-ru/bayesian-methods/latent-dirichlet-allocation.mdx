[Смесь с процессом Дирихле](/ru/notes/bayesian-methods/dirichlet-processes) относила каждую точку данных ровно к одному кластеру. Коллекция документов в эту форму не укладывается. Статья о трансферном рынке футбольного клуба в одном абзаце использует лексику спорта и лексику денег, а тысяча других статей используют те же две лексики в других пропорциях. **Латентное размещение Дирихле** (latent Dirichlet allocation, LDA) [Blei, Ng and Jordan (2003)](#references) моделирует именно это: набор **тем** (topics), каждая из которых — распределение на словах, общий для всей коллекции, и у каждого документа — своя смесь этих тем. Модель собрана из блоков этого курса — априорных распределений Дирихле на категориальных распределениях и латентной метки у каждого наблюдения — и обучается двумя инструментами предыдущего раздела: свёрнутым сэмплером Гиббса (collapsed Gibbs sampler) и вариационным выводом в приближении среднего поля.

**Обозначения.** Корпус из $D$ документов со словарём из $V$ слов; в документе $d$ — $N_d$ слов $w_{d1}, \dots, w_{dN_d}$, каждое — индекс из $\{1, \dots, V\}$. Тем $K$. Тема $k$ — распределение $\phi_k$ на словаре с вероятностями $\phi_{kw}$; у документа $d$ есть доли тем (topic proportions) $\theta_d$ на симплексе из $K$ вероятностей; $z_{dn} \in \{1, \dots, K\}$ — тема $n$-го слова. $\alpha$ и $\beta$ — параметры симметричных априорных распределений Дирихле на $\theta_d$ и $\phi_k$. Счётчики: $n_{dk}$ — число слов документа $d$, отнесённых к теме $k$, $n_{kw}$ — число вхождений слова $w$, отнесённых к теме $k$ во всём корпусе, $n_k = \sum_w n_{kw}$; верхний индекс $-i$ означает «без токена $i$». $\psi$ — дигамма-функция.

## Отправная точка: одна тема на документ \{#baseline-one-topic-per-document\}

Будем считать каждый документ [мешком слов](/ru/notes/nlp/bag-of-words-and-tf-idf) (bag of words), не учитывая порядок слов. Простейшая вероятностная модель таких мешков — **смесь униграмм** (mixture of unigrams) ([Nigam et al., 2000](#references)): выбрать одну тему $k$ для всего документа с вероятностью $\pi_k$, затем сэмплировать все его слова из $\phi_k$, так что $p(w_d) = \sum_k \pi_k \prod_n \phi_{k w_{dn}}$. Это конечная смесь из [заметки о процессах Дирихле](/ru/notes/bayesian-methods/dirichlet-processes#baseline-a-bayesian-mixture-with-k-chosen-in-advance), в которой точками служат документы.

Она не справляется с документами, смешивающими предметы. Возьмём две темы с рисунка ниже, спорт и экономику, и документ из трёх слов «команда гол рынок». Лучшая единственная тема, спорт, объясняет его с вероятностью $0.34 \cdot 0.30 \cdot 0.02 = 0.00204$: слово «рынок» должно прийти из спортивной темы, которая даёт ему 2%. Смесь с собственными для документа долями $0.7$ и $0.3$ даёт каждому слову вероятность $0.7\,\phi_{1w} + 0.3\,\phi_{2w}$, то есть $0.244$, $0.216$ и $0.116$, а документу — $0.0061$, втрое больше. (В этом игрушечном сравнении доли фиксированы; модель ниже задаёт на них априорное распределение.) **Вероятностный латентный семантический анализ** (probabilistic latent semantic analysis, pLSA) [Hofmann (1999)](#references) даёт каждому обучающему документу собственные доли, но как параметры: их число растёт с корпусом, они переобучаются, а у нового документа долей нет вовсе. LDA делает доли случайными, с априорным распределением Дирихле, и это решает обе проблемы.

## Порождающий процесс \{#the-generative-story\}

LDA описывает, как мог быть порождён корпус (generative story):

1. Для каждой темы $k = 1, \dots, K$: сэмплировать распределение на словах $\phi_k \sim \mathrm{Dir}(\beta, \dots, \beta)$.
2. Для каждого документа $d$: сэмплировать его доли тем $\theta_d \sim \mathrm{Dir}(\alpha, \dots, \alpha)$.
3. Для каждой позиции $n$ документа $d$: сэмплировать тему $z_{dn} \sim \mathrm{Categorical}(\theta_d)$,
4. а затем слово $w_{dn} \sim \mathrm{Categorical}(\phi_{z_{dn}})$.

<LdaGenerative />

Совместное распределение всех величин — произведение этих шагов:

$$
p(w, z, \theta, \phi \mid \alpha, \beta) = \prod_{k=1}^K \mathrm{Dir}(\phi_k \mid \beta) \prod_{d=1}^D \Big( \mathrm{Dir}(\theta_d \mid \alpha) \prod_{n=1}^{N_d} \theta_{d z_{dn}}\, \phi_{z_{dn} w_{dn}} \Big) .
$$

Суммирование по теме одного слова даёт вероятность слова в его документе,

$$
p(w_{dn} = w \mid \theta_d, \phi) = \sum_{k=1}^K \theta_{dk}\, \phi_{kw} ,
$$

так что матрица вероятностей слов в документах размера $D \times V$ — произведение матрицы долей размера $D \times K$ и матрицы тем размера $K \times V$: LDA — вероятностное неотрицательное низкоранговое разложение матрицы «документ–слово». **Разобранный пример.** На рисунке $p(\text{гол} \mid d) = 0.7 \cdot 0.30 + 0.3 \cdot 0.02 = 0.216$.

У смеси из заметки о процессах Дирихле один уровень: точки делят кластеры. У LDA их два: слова внутри документа делят темы через $\theta_d$, а документы делят темы через общее $\phi$. Доли — «маленькая» смесь для каждого документа; темы — то, что у корпуса общее.

<aside class="callout"><strong>Ключевая идея.</strong> Каждый документ — смесь тем, а каждая тема — распределение на словах; темы общие для всех документов, доли у каждого свои. С априорными распределениями Дирихле на тех и других сопряжённость позволяет точно проинтегрировать и доли, и темы, и вывод сводится к отнесению каждого токена слова к теме — сэмплированием или вариационным приближением.</aside>

## Вывод: апостериорное распределение на назначениях тем \{#inference-the-posterior-over-topic-assignments\}

Интересующая нас величина — апостериорное распределение $p(z, \theta, \phi \mid w)$: к какой теме относится каждое слово, каковы темы и о чём каждый документ. Его нормирующая константа $p(w) = \sum_z \int\!\!\int p(w, z, \theta, \phi)\, d\theta\, d\phi$ суммирует по $K^{\sum_d N_d}$ назначениям и не выражается в замкнутом виде. Два стандартных приближения — свёрнутый сэмплер Гиббса [Griffiths and Steyvers (2004)](#references) и вариационный метод исходной статьи.

### Свёрнутое сэмплирование по Гиббсу \{#collapsed-gibbs-sampling\}

И $\theta$, и $\phi$ можно проинтегрировать, потому что каждая из них входит только в априорное распределение Дирихле и в категориальные множители: это сопряжённость Дирихле–категориального распределения из [заметки о сопряжённых распределениях](/ru/notes/bayesian-methods/conjugate-priors#dirichlet-categorical). Обозначим $B(a) = \prod_j \Gamma(a_j) / \Gamma(\sum_j a_j)$ нормирующую константу распределения Дирихле, так что $\int \prod_j \pi_j^{a_j - 1}\, d\pi = B(a)$. Для документа $d$, собрав множители, содержащие $\theta_d$,

$$
\int \mathrm{Dir}(\theta_d \mid \alpha) \prod_{n} \theta_{d z_{dn}}\, d\theta_d = \frac{1}{B(\alpha)} \int \prod_k \theta_{dk}^{\,n_{dk} + \alpha - 1}\, d\theta_d = \frac{B(n_{d\cdot} + \alpha)}{B(\alpha)} ,
$$

где $n_{d\cdot} = (n_{d1}, \dots, n_{dK})$, а $B(\alpha)$ — нормирующая константа в точке $(\alpha, \dots, \alpha)$. То же вычисление для каждой темы даёт

$$
p(w, z \mid \alpha, \beta) = \prod_{k=1}^K \frac{B(n_{k\cdot} + \beta)}{B(\beta)} \prod_{d=1}^D \frac{B(n_{d\cdot} + \alpha)}{B(\alpha)} ,
$$

функцию одних только счётчиков. Сэмплер Гиббса пересэмплирует тему одного токена за раз из $p(z_i = k \mid z_{-i}, w) \propto p(w, z_i = k, z_{-i})$. Пусть токен $i$ — слово $v$ в документе $d$. Изменение $z_i$ меняет только три счётчика, $n_{dk}$, $n_{kv}$ и $n_k$, каждый на единицу. Если токен убран, присваивание $z_i = k$ поднимает их с $n^{-i}$ до $n^{-i} + 1$, и меняются такие гамма-функции:

$$
\frac{\Gamma(n_{dk}^{-i} + \alpha + 1)}{\Gamma(n_{dk}^{-i} + \alpha)} \cdot \frac{\Gamma(n_{kv}^{-i} + \beta + 1)}{\Gamma(n_{kv}^{-i} + \beta)} \cdot \frac{\Gamma(n_k^{-i} + V\beta)}{\Gamma(n_k^{-i} + V\beta + 1)} \cdot \frac{\Gamma(N_d - 1 + K\alpha)}{\Gamma(N_d + K\alpha)} .
$$

По $\Gamma(x + 1) = x\, \Gamma(x)$ каждое отношение равно своему аргументу или обратной к нему величине, а последнее не зависит от $k$. Поэтому

$$
\boxed{\ p(z_i = k \mid z_{-i}, w) \;\propto\; \big(n_{dk}^{-i} + \alpha\big)\, \frac{n_{kv}^{-i} + \beta}{n_k^{-i} + V\beta} \ }
$$

([Griffiths and Steyvers, 2004](#references), формула 5). Два множителя — две апостериорные предсказательные вероятности: насколько документ $d$ уже использует тему $k$ и как часто тема $k$ уже порождает слово $v$, каждая сглажена своим априорным распределением. Проход посещает каждый токен, убирает его из счётчиков, сэмплирует новую тему и добавляет его обратно: $O(K)$ работы на токен, и в памяти только целочисленные счётчики. Когда цепь перемешалась, сэмпл $z$ даёт оценки проинтегрированных величин — апостериорные средние при этом сэмпле,

$$
\hat\phi_{kw} = \frac{n_{kw} + \beta}{n_k + V\beta}, \qquad \hat\theta_{dk} = \frac{n_{dk} + \alpha}{N_d + K\alpha} .
$$

Сэмплер — частный случай свёрнутого сэмплирования по Гиббсу из [заметки о сэмплировании по Гиббсу](/ru/notes/bayesian-methods/gibbs-sampling) и близнец сэмплера с рестораном из предыдущей заметки: там точку пересаживали пропорционально размеру кластера, умноженному на его предсказательную плотность, здесь токен — пропорционально тому, насколько документ использует тему, умноженному на предсказательную вероятность слова у этой темы.

**Разобранный пример.** Токен слова «гол» в документе, остальные слова которого — 4 в теме 1 и 2 в теме 2. По корпусу в теме 1 — 500 токенов, из них 30 — «гол»; в теме 2 — 400 токенов, из них 2 — «гол». При $V = 1000$, $\alpha = 0.1$ и $\beta = 0.01$ два ненормированных веса равны $4.1 \cdot 30.01 / 510 = 0.2413$ и $2.1 \cdot 2.01 / 410 = 0.0103$, и токен попадает в тему 1 с вероятностью $0.959$.

Перестановка меток (label switching) здесь безвредна: темы взаимозаменяемы, поэтому одна цепь даёт согласованные метки, пока остаётся в одной моде, но усреднять $\hat\phi$ по нескольким цепям без предварительного сопоставления тем бессмысленно.

### Вариационная альтернатива \{#the-variational-alternative\}

Исходная статья пошла другим путём этого курса — [вариационным выводом в приближении среднего поля](/ru/notes/bayesian-methods/variational-inference#mean-field-and-the-general-update) (mean-field variational inference). С априорным распределением Дирихле на темах, как в её разделе 5.4, факторизованное семейство таково:

$$
q(\theta, z, \phi) = \prod_{k} \mathrm{Dir}(\phi_k \mid \lambda_k) \prod_d \Big( \mathrm{Dir}(\theta_d \mid \gamma_d) \prod_n \mathrm{Categorical}(z_{dn} \mid r_{dn}) \Big) .
$$

Обновление каждого множителя — экспонента от математического ожидания логарифма совместного распределения по остальным множителям. Нужны математические ожидания логарифмов величин с распределением Дирихле, $\mathbb E_q[\log \theta_{dk}] = \psi(\gamma_{dk}) - \psi(\sum_j \gamma_{dj})$, и то же для $\phi$ — свойство экспоненциального семейства. Обновления таковы:

$$
\begin{aligned}
r_{dnk} &\propto \exp\big(\mathbb E_q[\log \theta_{dk}] + \mathbb E_q[\log \phi_{k w_{dn}}]\big), \\
\gamma_{dk} &= \alpha + \sum_{n} r_{dnk}, \\
\lambda_{kw} &= \beta + \sum_{d, n} r_{dnk}\, [w_{dn} = w] .
\end{aligned}
$$

Это обновление Гиббса, в котором счётчики заменены ожидаемыми счётчиками, а вероятности — экспонентами от ожидаемых логарифмов. Покоординатный подъём чередует **локальный шаг**, который итерирует $r_d$ и $\gamma_d$ для каждого документа при фиксированных темах, и **глобальный шаг**, который пересчитывает $\lambda$ по всем ожидаемым счётчикам. Blei et al. обозначают темы $\beta_k$, параметр их априорного распределения $\eta$, а вероятности назначений $\phi_{dn}$, и [следующая заметка](/ru/notes/bayesian-methods/stochastic-variational-inference) следует их обозначениям; $\gamma$ и $\lambda$ в обоих случаях одинаковы. Обновления детерминированы, векторизуются по матрице счётчиков «документ–слово» и снабжены целевой функцией — нижней оценкой обоснованности (ELBO), — по которой можно следить за сходимостью. Взамен они смещены: среднее поле занижает апостериорную дисперсию и, как и сэмплер, может застревать в локальных оптимумах. Если гиперпараметры настроены для каждого метода отдельно, оба дают похожие темы и похожую перплексию на отложенных документах ([Asuncion et al., 2009](#references)).

## Гиперпараметры $\alpha$ и $\beta$ \{#the-hyperparameters-alpha-and-beta\}

Два параметра Дирихле задают, каких документов и тем ожидает модель. При $\alpha \lt 1$ априорное распределение на $\theta_d$ помещает свою массу у вершин и сторон симплекса: каждый документ использует немного тем. При $\alpha = 1$ оно равномерно, а при $\alpha \gt 1$ сосредоточено у центра: каждый документ равномерно смешивает все темы. $\beta$ играет ту же роль для тем: малое $\beta$ даёт темы, сосредоточенные на немногих словах.

<DirichletAlpha />

В апостериорном распределении $\alpha$ — псевдонаблюдение, добавляемое к каждой теме каждого документа. **Разобранный пример.** У документа, десять токенов которого отнесены к трём темам как $8, 2, 0$, оценка равна $\hat\theta = (8.1, 2.1, 0.1)/10.3 = (0.786, 0.204, 0.010)$ при $\alpha = 0.1$ и $(9, 3, 1)/13 = (0.692, 0.231, 0.077)$ при $\alpha = 1$: большее априорное распределение размазывает документ и по теме, которую он ни разу не использовал. У коротких документов, таких как твиты или поисковые запросы, $\alpha$ перевешивает счётчики.

Распространённые значения по умолчанию — $\alpha = 50/K$ и $\beta = 0.1$ ([Griffiths and Steyvers, 2004](#references)) или $\alpha = \beta = 1/K$ (scikit-learn). Гиперпараметры можно и обучать — максимизируя обоснованность итерацией неподвижной точки или сэмплируя их. [Wallach, Mimno and McCallum (2009)](#references) обнаружили, что асимметричное обучаемое априорное распределение на $\theta$, позволяющее некоторым темам быть частыми в каждом документе, заметно улучшает правдоподобие отложенных документов и качество тем, тогда как асимметричное априорное распределение на темах почти ничего не даёт. Эксперимент ниже показывает, насколько важно $\alpha$, когда оно ошибочно в десять раз.

## Оценка качества: перплексия и когерентность \{#evaluation-perplexity-and-coherence\}

Тематическая модель — модель текста, поэтому её можно оценивать как [языковую модель](/ru/notes/nlp/n-gram-language-models#perplexity-from-probability-to-a-number) — по **перплексии** (perplexity) отложенных (held-out) документов:

$$
\mathrm{PPL} = \exp\Big(-\frac{\sum_{d} \log p(w_d)}{\sum_d N_d}\Big) ,
$$

экспоненте от среднего отрицательного логарифма правдоподобия на слово. Перплексия 17 означает, что модель так же неуверенна в каждом слове, как равновероятный выбор из 17 слов. У тематических моделей есть две особые сложности. Во-первых, $p(w_d) = \int p(\theta_d) \prod_n \sum_k \theta_{dk} \phi_{k w_{dn}}\, d\theta_d$ сама вычислительно неразрешима; её оценивают сэмплированием или, как в эксперименте ниже, **дополнением документа** (document completion): $\theta_d$ находят по первой половине тестового документа и вычисляют правдоподобие второй половины ([Wallach et al., 2009](#references)). Разные оценки дают разные числа, поэтому перплексии сравнимы только в рамках одного протокола. Во-вторых, правдоподобие — не то, чего люди ждут от тем. В исследовании, где темы оценивали люди, модели с лучшим правдоподобием отложенных документов часто имели менее интерпретируемые темы ([Chang et al., 2009](#references)).

**Когерентность** (coherence) измеряет интерпретируемость прямо по совместной встречаемости: главные слова хорошей темы встречаются в одних и тех же документах. Когерентность UMass темы с главными словами $v_1, \dots, v_M$ ([Mimno et al., 2011](#references)) равна

$$
C = \sum_{m=2}^{M} \sum_{l=1}^{m-1} \log \frac{D(v_m, v_l) + 1}{D(v_l)} ,
$$

где $D(v)$ — число документов, содержащих $v$, а $D(v, u)$ — содержащих оба слова; $+1$ защищает от логарифма нуля. Каждое слагаемое — сглаженный логарифм условной вероятности того, что документ со словом $v_l$ содержит и $v_m$. **Разобранный пример.** Три главных слова встречаются в 40, 30 и 20 документах, а попарно — в 25 (слова 1 и 2), 15 (1 и 3) и 12 (2 и 3) документах: $C = \log\frac{26}{40} + \log\frac{16}{40} + \log\frac{13}{30} = -0.431 - 0.916 - 0.836 = -2.18$. Чем ближе значение к нулю, тем когерентнее тема. Варианты на основе поточечной взаимной информации (PMI) по большому эталонному корпусу, например «Википедии», лучше согласуются с оценками людей ([Newman et al., 2010](#references)).

## Эксперимент: восстановление известных тем \{#an-experiment-recovering-known-topics\}

Раздел «Код» использует корпус «полосок» (bars) из [Griffiths and Steyvers (2004)](#references): словарь из 25 слов, разложенных на сетке $5 \times 5$, и 10 истинных тем — пять строк и пять столбцов, каждая равномерна на своих пяти словах. 200 обучающих документов по 50 слов порождаются с $\alpha = 0.3$, так что большинство документов использует несколько полосок, и ещё 50 документов отложены. Поскольку истинные темы известны, восстановление можно измерить напрямую: каждая выученная тема сопоставляется с истинной полоской венгерским алгоритмом, а расстояние — полная вариация (total variation) между их распределениями.

- **Свёрнутый сэмплер Гиббса.** 200 проходов с $\alpha = 0.3$, $\beta = 0.1$ из случайных назначений. Логарифм совместного распределения $\log p(w, z)$ поднимается с $-54\,604$ после первого прохода до $-39\,588$ после 10, $-33\,406$ после 50 и $-33\,376$ после 200. Все десять полосок восстановлены, худшая — с полной вариацией $0.070$. Перплексия на отложенных документах при дополнении документа равна $17.11$ против $17.09$ с истинными темами и $25.10$ у униграммной модели — по сути, равномерного распределения на 25 словах. Когерентность UMass пяти главных слов в среднем равна $-3.52$ против $-3.59$ у истинных полосок и $-4.51$ у случайных тем. Когерентность измеряет совместную встречаемость в этом корпусе, а не истину: выученная тема может получить немного больше истинной.
- **Вариационный вывод в приближении среднего поля**, реализованный вручную со 100 раундами локального и глобального шагов, восстанавливает полоски с полной вариацией не больше $0.054$ и перплексией на отложенных документах $17.16$; `LatentDirichletAllocation` из scikit-learn в пакетном режиме, тот же алгоритм, даёт $0.051$ и $17.12$.
- **Концентрация $\alpha$.** Вариационный вывод из пяти случайных начальных состояний для каждого значения; полоска считается восстановленной при полной вариации меньше $0.2$:

| $\alpha$ | восстановлено полосок из 10 | перплексия на отложенных документах |
| --- | --- | --- |
| 0.03 | 0, 0, 0, 0, 0 | 18.5 – 19.5 |
| 0.3 (истинное) | 8, 8, 10, 10, 10 | 17.1 – 17.7 |
| 3 | 6, 2, 10, 10, 9 | 19.6 – 20.5 |

При $\alpha$, в десять раз меньшем истинного, каждый документ вынужден тяготеть к одной теме, и темы становятся типичными сочетаниями полосок, а не полосками. При $\alpha$, в десять раз большем, документы размазаны по всем темам, перплексия страдает, а восстановление зависит от начального состояния. Даже при истинном $\alpha$ два запуска из пяти заканчиваются в локальном оптимуме, в котором пропущены две полоски.
- **Число тем.** При $K = 5$, $10$ и $20$ средняя перплексия на отложенных документах по пяти запускам равна $21.33$, $17.34$ и $17.51$, а средняя когерентность — $-3.51$, $-3.50$ и $-3.64$. Слишком мало тем стоит перплексии; слишком много почти не стоит перплексии, но дробит полоски на менее когерентные куски.

## Что изменилось \{#what-changed\}

| | Смесь униграмм | Латентное размещение Дирихле |
| --- | --- | --- |
| Тем на документ | одна | смесь, $\theta_d \sim \mathrm{Dir}(\alpha)$ |
| Вероятность слова в документе | $\phi_{z_d w}$ | $\sum_k \theta_{dk} \phi_{kw}$ |
| Латентная переменная | одна метка на документ | одна метка на токен слова |
| Новые документы | апостериорное распределение на одной теме | апостериорное распределение на долях |
| Вывод | EM или Гиббс по документам | свёрнутый Гиббс по токенам или вариационный вывод в приближении среднего поля |
| Число параметров | фиксировано, $K V$ | фиксировано, $K V$; $\theta_d$ — латентные переменные, а не параметры, как в pLSA |

## Ограничения \{#limitations\}

- **Мешок слов.** Порядок слов, синтаксис и отрицание игнорируются; «не хорошо» и «хорошо» — одно и то же свидетельство.
- **$K$ нужно выбирать.** Перплексия и когерентность часто расходятся. Иерархический процесс Дирихле делает число тем апостериорной величиной ([Teh et al., 2006](#references)) ценой более сложного сэмплера.
- **Локальные оптимумы и неустойчивость.** Разные начальные состояния дают разные темы, некоторые из них слиты или расколоты, как показывает эксперимент; публикуемые темы нужно проверять на нескольких запусках.
- **Оценка качества не устоялась.** Правдоподобию отложенных документов нужна оценка, и оно не следует за суждениями людей; когерентность зависит от эталонного корпуса. Ни то, ни другое не говорит, полезна ли тема для конкретной задачи.
- **Частые слова доминируют.** Без списка стоп-слов или обучаемого асимметричного априорного распределения в главные слова каждой темы попадают «и» и «в».
- **Масштаб.** Свёрнутый Гиббс посещает каждый токен на каждом проходе, а пакетный вариационный вывод обновляет темы раз за проход по корпусу. Для миллионов документов оба медленны.

## Что нужно запомнить \{#what-you-should-remember\}

- LDA: темы $\phi_k \sim \mathrm{Dir}(\beta)$, доли $\theta_d \sim \mathrm{Dir}(\alpha)$, затем для каждого слова тема $z \sim \theta_d$ и слово $w \sim \phi_z$; $p(w \mid d) = \sum_k \theta_{dk} \phi_{kw}$.
- Сопряжённость Дирихле–категориального распределения позволяет проинтегрировать $\theta$ и $\phi$: $p(w, z) = \prod_k B(n_{k\cdot} + \beta)/B(\beta) \cdot \prod_d B(n_{d\cdot} + \alpha)/B(\alpha)$.
- Свёрнутый Гиббс: $p(z_i = k \mid z_{-i}, w) \propto (n_{dk}^{-i} + \alpha)(n_{kv}^{-i} + \beta)/(n_k^{-i} + V\beta)$; $\phi$ и $\theta$ оцениваются сглаженными счётчиками.
- Вариационный вывод в приближении среднего поля заменяет счётчики ожидаемыми счётчиками, а вероятности — величинами $\exp \mathbb E[\log \cdot]$ с дигамма-функциями; он чередует локальный шаг для каждого документа и глобальный шаг для тем.
- $\alpha \lt 1$ означает немного тем на документ, малое $\beta$ — немного слов на тему; неверное $\alpha$ может скрыть истинные темы.
- Оценивать по перплексии на отложенных документах при явно указанном протоколе и по когерентности; они измеряют разное.

## Код \{#code\}

Свёрнутый сэмплер Гиббса и вариационный вывод в приближении среднего поля для LDA на корпусе полосок, с восстановлением тем, перплексией на отложенных документах, когерентностью UMass и влиянием $\alpha$ и $K$. Скрипт работает около 35 секунд; точные числа могут отличаться на разных платформах и версиях библиотек.

```python
import numpy as np
from scipy.special import digamma, gammaln
from scipy.optimize import linear_sum_assignment
from sklearn.decomposition import LatentDirichletAllocation

rng = np.random.default_rng(0)

# свёрнутое обновление Гиббса для одного токена: две темы, alpha = 0.1, beta = 0.01, V = 1000
p = np.array([(4 + 0.1) * (30 + 0.01) / (500 + 1000 * 0.01), (2 + 0.1) * (2 + 0.01) / (400 + 1000 * 0.01)])
print(p.round(4), (p / p.sum()).round(3))                             # [0.2413 0.0103] [0.959 0.041]

# корпус «полосок»: 25 слов на сетке 5 x 5, 10 тем (5 строк, 5 столбцов), каждая равномерна на своих 5 словах
V, K = 25, 10
grid = np.arange(V).reshape(5, 5)
phi_true = np.zeros((K, V))
for r in range(5):
    phi_true[r, grid[r]] = 0.2                           # горизонтальная полоска
    phi_true[5 + r, grid[:, r]] = 0.2                    # вертикальная полоска
D, N, alpha, beta = 200, 50, 0.3, 0.1
theta_true = rng.dirichlet(np.full(K, alpha), size=D)
docs = [rng.choice(V, size=N, p=theta_true[d] @ phi_true) for d in range(D)]   # w ~ sum_k theta_dk phi_kw
test = [rng.choice(V, size=N, p=t @ phi_true) for t in rng.dirichlet(np.full(K, alpha), size=50)]
counts = np.stack([np.bincount(w, minlength=V) for w in docs])               # счётчики «документ–слово» D x V

def log_joint(ndk, nkw):                                 # log p(w, z) с проинтегрированными theta и phi
    topics = (gammaln(nkw + beta).sum(axis=1) - gammaln(nkw.sum(axis=1) + V * beta)).sum() + K * (gammaln(V * beta) - V * gammaln(beta))
    docs_ = (gammaln(ndk + alpha).sum(axis=1) - gammaln(ndk.sum(axis=1) + K * alpha)).sum() + len(ndk) * (gammaln(K * alpha) - K * gammaln(alpha))
    return topics + docs_

# свёрнутое сэмплирование по Гиббсу (Griffiths and Steyvers, 2004)
def lda_gibbs(docs, K, alpha, beta, sweeps, rng):
    z = [rng.integers(K, size=len(w)) for w in docs]     # случайные начальные темы
    ndk, nkw, nk = np.zeros((len(docs), K)), np.zeros((K, V)), np.zeros(K)
    for d, w in enumerate(docs):
        np.add.at(ndk[d], z[d], 1); np.add.at(nkw, (z[d], w), 1); np.add.at(nk, z[d], 1)
    trace = []
    for sweep in range(sweeps):
        for d, w in enumerate(docs):
            u = rng.random(len(w))
            for i, (v, k) in enumerate(zip(w, z[d])):
                ndk[d, k] -= 1; nkw[k, v] -= 1; nk[k] -= 1                # убираем токен i
                p = (ndk[d] + alpha) * (nkw[:, v] + beta) / (nk + V * beta)
                c = np.cumsum(p)
                k = int(np.searchsorted(c, u[i] * c[-1]))                 # сэмплируем его новую тему
                z[d][i] = k; ndk[d, k] += 1; nkw[k, v] += 1; nk[k] += 1
        trace.append(log_joint(ndk, nkw))
    return ndk, nkw, np.array(trace)

def match(phi):                                          # сопоставляем выученные темы с истинными полосками; расстояния полной вариации
    cost = 0.5 * np.abs(phi[:, None, :] - phi_true[None]).sum(axis=2)
    r, c = linear_sum_assignment(cost)
    return cost[r, c]

def heldout_perplexity(docs, phi, alpha, iters=100):     # дополнение документа: theta по первой половине, правдоподобие второй
    ll, n = 0.0, 0
    for w in docs:
        a, b = w[: len(w) // 2], w[len(w) // 2:]
        th = np.full(len(phi), 1 / len(phi))
        for _ in range(iters):
            r = th[:, None] * phi[:, a]; r /= r.sum(axis=0)
            th = (r.sum(axis=1) + alpha) / (len(a) + len(phi) * alpha)
        ll += np.log(th @ phi[:, b]).sum(); n += len(b)
    return np.exp(-ll / n)

def umass(phi, top=5):                                   # когерентность UMass главных слов, усреднённая по темам
    df = (counts > 0).astype(float)
    co = df.T @ df                                       # co[v, u]: число документов, содержащих и v, и u
    score = []
    for k in range(len(phi)):
        t = np.argsort(-phi[k])[:top]
        score.append(sum(np.log((co[t[m], t[l]] + 1) / co[t[l], t[l]]) for m in range(1, top) for l in range(m)))
    return np.mean(score)

ndk, nkw, trace = lda_gibbs(docs, K, alpha, beta, 200, rng)
print(trace[[0, 9, 49, 199]].round(0))                  # [-54604. -39588. -33406. -33376.]: log p(w, z) растёт, затем выходит на плато
phi_gibbs = (nkw + beta) / (nkw.sum(axis=1, keepdims=True) + V * beta)
print(match(phi_gibbs).max().round(3))                   # 0.07: каждая полоска восстановлена с полной вариацией не больше 7%
uni = (counts.sum(axis=0) + 1.0) / (counts.sum() + V)
print(round(heldout_perplexity(test, phi_gibbs, alpha), 2), round(heldout_perplexity(test, phi_true, alpha), 2),
      round(np.exp(-np.mean([np.log(uni[w]).mean() for w in test])), 2))      # темы Гиббса, истинные темы, униграммы
# 17.11 17.09 25.1
rand = np.array([umass(rng.dirichlet(np.ones(V), size=K)) for _ in range(20)])
print(round(umass(phi_gibbs), 2), round(umass(phi_true), 2), round(rand.mean(), 2))   # -3.52 -3.59 -4.51: выученные, истинные, случайные

# вариационный вывод в приближении среднего поля (Blei, Ng and Jordan, 2003, с априорным распределением Дирихле на темах)
def lda_cavi(counts, K, alpha, beta, iters, rng, inner=20):
    lam = beta + rng.gamma(100.0, 0.01, size=(K, V))     # q(phi_k) = Dir(lam_k)
    gam = np.ones((len(counts), K))                      # q(theta_d) = Dir(gam_d)
    for _ in range(iters):
        Elog_phi = digamma(lam) - digamma(lam.sum(axis=1, keepdims=True))
        for _ in range(inner):                           # локальный шаг: все документы при фиксированных темах
            Elog_theta = digamma(gam) - digamma(gam.sum(axis=1, keepdims=True))
            r = np.exp(Elog_theta[:, None, :] + Elog_phi.T[None])           # D x V x K, ненормированное q(z = k) для каждого типа слова
            r /= r.sum(axis=2, keepdims=True)
            gam = alpha + (counts[:, :, None] * r).sum(axis=1)
        lam = beta + (counts[:, :, None] * r).sum(axis=0).T                 # глобальный шаг: темы
    return lam / lam.sum(axis=1, keepdims=True), gam

phi_vi, gam = lda_cavi(counts, K, alpha, beta, 100, rng)
print(match(phi_vi).max().round(3), round(heldout_perplexity(test, phi_vi, alpha), 2))     # 0.054 17.16
skl = LatentDirichletAllocation(n_components=K, doc_topic_prior=alpha, topic_word_prior=beta, learning_method='batch', max_iter=100, random_state=0).fit(counts)
phi_skl = skl.components_ / skl.components_.sum(axis=1, keepdims=True)
print(match(phi_skl).max().round(3), round(heldout_perplexity(test, phi_skl, alpha), 2))   # 0.051 17.12

# гиперпараметры и число тем: вариационный вывод из пяти случайных начальных состояний для каждого значения
for a in (0.03, 0.3, 3.0):
    fits = [lda_cavi(counts, K, a, beta, 100, np.random.default_rng(s))[0] for s in range(5)]
    print('alpha', a, [int((match(f) < 0.2).sum()) for f in fits], [float(round(heldout_perplexity(test, f, a), 1)) for f in fits])
# alpha 0.03 [0, 0, 0, 0, 0] [18.5, 19.0, 18.9, 19.5, 19.3]
# alpha 0.3 [8, 8, 10, 10, 10] [17.7, 17.7, 17.1, 17.1, 17.1]
# alpha 3.0 [6, 2, 10, 10, 9] [20.2, 20.5, 19.6, 19.6, 19.8]
for k in (5, 10, 20):
    fits = [lda_cavi(counts, k, alpha, beta, 100, np.random.default_rng(s))[0] for s in range(5)]
    print('K', k, round(np.mean([heldout_perplexity(test, f, alpha) for f in fits]), 2), round(np.mean([umass(f) for f in fits]), 2))
# K 5 21.33 -3.51 | K 10 17.34 -3.5 | K 20 17.51 -3.64
```
