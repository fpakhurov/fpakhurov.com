[Стохастический вариационный вывод](/ru/notes/bayesian-methods/stochastic-variational-inference) сделал каждый шаг дешёвым, но каждый шаг всё ещё опирался на формулу: естественный градиент $E_\phi[\eta_g] - \lambda$ существует в замкнутом виде, только когда каждое полное условное распределение принадлежит известному экспоненциальному семейству. Байесовская логистическая регрессия, первая модель курса без сопряжённости, уже нарушает это условие, как и любая модель с нейронной сетью внутри. **Вариационный вывод «чёрного ящика»** (black-box variational inference, BBVI) [Ranganath, Gerrish and Blei (2014)](#references) отказывается от формулы. Градиент нижней оценки обоснованности (ELBO) сам является математическим ожиданием по $q$, поэтому его можно оценить по сэмплам из $q$ для любой модели, логарифм совместной плотности которой можно вычислить. Эта заметка выводит две оценки, которые это делают, — оценку через функцию оценки (score function) и градиент через репараметризацию, — измеряет их дисперсии и показывает, что вариационный автоэнкодер — это вывод «чёрного ящика» с ещё одной идеей: энкодером, который предсказывает вариационные параметры.

**Обозначения.** $p(x, z)$ — совместная плотность данных $x$ и скрытых переменных $z$, и о ней мы предполагаем только то, что можем вычислить $\log p(x, z)$ при любом $z$, а для второй оценки — ещё и его градиент по $z$. $q(z \mid \lambda)$ — вариационное распределение с параметрами $\lambda$; для гауссовского распределения среднего поля $\lambda = (\mu, \sigma)$ и $q = \prod_j \mathcal N(z_j \mid \mu_j, \sigma_j^2)$. ELBO равна $\mathcal L(\lambda) = E_q[\log p(x, z) - \log q(z \mid \lambda)]$, а подынтегральное выражение мы сокращённо обозначаем $f_\lambda(z) = \log p(x, z) - \log q(z \mid \lambda)$. **Функция оценки** (score) распределения $q$ — это $\nabla_\lambda \log q(z \mid \lambda)$. $S$ — число сэмплов Монте-Карло на одну оценку градиента, $\varepsilon$ — стандартный нормальный шум.

## Отправная точка: модель без обновления в замкнутом виде \{#baseline-a-model-without-a-closed-form-update\}

В байесовской логистической регрессии веса $w \sim \mathcal N(0, I)$, а метки $y_i \in \{0, 1\}$ с $p(y_i = 1 \mid w) = \sigma(w^\top x_i)$ — это [логистическая модель](/ru/notes/ml/logistic-regression). При гауссовском $q(w)$ координатному подъёму понадобились бы $E_q[\log \sigma(w^\top x_i)]$ и его производные в замкнутом виде. Их нет: математическое ожидание логарифма сигмоиды по гауссовскому распределению — одномерный интеграл без элементарной первообразной. Обычные способы обойти это зависят от модели. [Приближение Лапласа](/ru/notes/bayesian-methods/laplace-approximation) заменяет апостериорное распределение гауссианой в его моде; квадратичная нижняя оценка логарифма сигмоиды ([Jaakkola and Jordan, 2000](#references)) восстанавливает сопряжённость для этого одного правдоподобия. Каждой новой модели нужен свой вывод, и именно поэтому вариационный вывод был инструментом специалистов. BBVI требует только одного: умения вычислить $\log p(x, z)$ в точке.

<aside class="callout"><strong>Ключевая идея.</strong> Градиент ELBO можно переписать как математическое ожидание по $q$ величины, которую можно вычислить на любом сэмпле. Её среднее по Монте-Карло — несмещённая оценка градиента, и стохастический градиентный подъём с шагами Роббинса–Монро максимизирует тогда ELBO любой модели. Вся трудность переходит в дисперсию оценки: снижение дисперсии или репараметризация сэмплов решают, работает ли метод на практике.</aside>

## Градиент через функцию оценки \{#the-score-function-gradient\}

Продифференцируем ELBO под знаком интеграла. От $\lambda$ зависят и плотность $q$, и подынтегральная функция $f_\lambda$:

$$
\begin{aligned}
\nabla_\lambda \mathcal L &= \nabla_\lambda \int q(z \mid \lambda)\, f_\lambda(z)\, dz = \int \nabla_\lambda q(z \mid \lambda)\, f_\lambda(z)\, dz + \int q(z \mid \lambda)\, \nabla_\lambda f_\lambda(z)\, dz \\
&= \int q(z \mid \lambda)\, \nabla_\lambda \log q(z \mid \lambda)\, f_\lambda(z)\, dz - \int q(z \mid \lambda)\, \nabla_\lambda \log q(z \mid \lambda)\, dz \\
&= E_q\big[\nabla_\lambda \log q(z \mid \lambda)\, f_\lambda(z)\big] - \nabla_\lambda \int q(z \mid \lambda)\, dz = E_q\big[\nabla_\lambda \log q(z \mid \lambda)\, \big(\log p(x, z) - \log q(z \mid \lambda)\big)\big] .
\end{aligned}
$$

Первая строка — правило дифференцирования произведения. Вторая использует тождество для производной логарифма $\nabla_\lambda q = q\, \nabla_\lambda \log q$ в первом интеграле и $\nabla_\lambda f_\lambda = -\nabla_\lambda \log q$ во втором, поскольку $\log p(x, z)$ не зависит от $\lambda$. Последний интеграл — градиент константы 1, поэтому математическое ожидание функции оценки равно нулю: $E_q[\nabla_\lambda \log q] = 0$. Перестановка производной и интеграла требует обычной регулярности, например интегрируемой мажоранты для производной. Оценка Монте-Карло по $S$ сэмплам равна

$$
\boxed{
\begin{aligned}
\hat\nabla_\lambda \mathcal L &= \frac1S \sum_{s=1}^S \nabla_\lambda \log q(z_s \mid \lambda)\, \big(\log p(x, z_s) - \log q(z_s \mid \lambda)\big), \\
z_s &\sim q(z \mid \lambda)
\end{aligned}
}
$$

([Ranganath et al., 2014](#references), формулы 2 и 3). Ей нужны сэмплы из $q$, функция оценки этого распределения и значения $\log p$; модель — «чёрный ящик». В обучении с подкреплением та же оценка называется **REINFORCE** ([Williams, 1992](#references)), с наградой вместо $f_\lambda$; в [заметке о градиенте по стратегии](/ru/notes/agents/policy-gradients#reinforce) курса «ИИ-агенты» она выведена для траекторий, а её дисперсия снижается теми же базовыми линиями, что и ниже. В статистике это метод отношения правдоподобий (likelihood-ratio method).

**Разобранный пример.** Оценим градиент $E_q[z^2]$ по $\mu$ для $q = \mathcal N(\mu, \sigma^2)$ при $\mu = \sigma = 1$; точное значение равно $2\mu = 2$. Функция оценки по $\mu$ равна $(z - \mu)/\sigma^2$, поэтому один сэмпл даёт $(z - \mu) z^2/\sigma^2$. При $z = 1 + \varepsilon$ это $\varepsilon (1 + \varepsilon)^2 = \varepsilon + 2\varepsilon^2 + \varepsilon^3$, со средним $0 + 2 + 0 = 2$. Второй момент равен $E[\varepsilon^2 + 4\varepsilon^4 + \varepsilon^6 + 2\varepsilon^4] = 1 + 12 + 15 + 6 = 34$ (нечётные моменты равны нулю, $E\varepsilon^4 = 3$, $E\varepsilon^6 = 15$), так что дисперсия по одному сэмплу равна $34 - 4 = 30$, в 7.5 раза больше квадрата оцениваемой величины. Миллион сэмплов в разделе «Код» дают среднее $2.005$ и дисперсию $30.1$.

## Снижение дисперсии \{#reducing-the-variance\}

Оценка несмещённая, но дисперсия 30 для величины порядка 2 означает сотни сэмплов на шаг ради полезного направления, а в реальных моделях всё гораздо хуже. Два общих инструмента из [арсенала методов Монте-Карло](/ru/notes/probability/monte-carlo#variance-reduction) снижают её без работы, специфичной для модели.

### Рао-блэкуэллизация: отбросить слагаемые, которые не могут влиять \{#raoblackwellization-drop-the-terms-that-cannot-matter\}

Возьмём $q = \prod_j q(z_j \mid \lambda_j)$ из семейства среднего поля. Функция оценки по $\lambda_j$, $h_j(z_j) = \nabla_{\lambda_j} \log q(z_j \mid \lambda_j)$, зависит только от $z_j$. Для любой функции $g$ остальных переменных независимость при $q$ и нулевое среднее функции оценки дают $E_q[h_j(z_j)\, g(z_{-j})] = E[h_j(z_j)]\, E[g(z_{-j})] = 0$. Поэтому любое слагаемое $\log p(x, z) - \log q(z)$, не содержащее $z_j$, можно удалить из $j$-й компоненты оценки, не меняя её среднего. Остаётся

$$
\nabla_{\lambda_j} \mathcal L = E_q\big[h_j(z_j)\, \big(\log p_j(x, z_{(j)}) - \log q(z_j \mid \lambda_j)\big)\big],
$$

где $\log p_j$ собирает множители совместного распределения, содержащие $z_j$; они зависят только от $z_j$ и его марковского одеяла (Markov blanket) $z_{(j)}$ ([Ranganath et al., 2014](#references), формула 5). Удалённые слагаемые имели нулевое среднее, но вносили дисперсию, поэтому новая оценка имеет меньшую дисперсию. Это разновидность **рао-блэкуэллизации** (Rao–Blackwellization): математическое ожидание по несущественным переменным вычисляется точно, и оно равно нулю.

**Разобранный пример.** $n$ независимых локальных переменных, $z_i \sim \mathcal N(0, 1)$ и $x_i \sim \operatorname{Poisson}(e^{z_i})$ — несопряжённая модель, — с $q(z_i) = \mathcal N(0, 0.5^2)$. Для градиента по $\mu_1$ обычная оценка умножает функцию оценки $z_1$ на все $n$ слагаемых $\log p - \log q$; рао-блэкуэллизованная оставляет только слагаемое $z_1$. В разделе «Код» дисперсия обычной оценки по одному сэмплу равна $8.2$ при $n = 1$, $1921$ при $n = 10$ и $374\,011$ при $n = 100$ и растёт с числом несущественных слагаемых; дисперсия рао-блэкуэллизованной оценки равна $8.2$ при любом $n$. В модели, где каждая переменная входит в каждое слагаемое правдоподобия, как в логистической регрессии, марковское одеяло — это всё, и приём удаляет только энтропийные слагаемые остальных координат.

### Контрольные переменные: вычесть базовую линию \{#control-variates-subtract-a-baseline\}

**Контрольная переменная** (control variate) — это функция $c(z)$ с известным средним, коррелированная с оценкой. Для $\hat g(z) = g(z) - a\,(c(z) - E[c])$ среднее не меняется, а

$$
\begin{aligned}
\operatorname{Var}(\hat g) &= \operatorname{Var}(g) + a^2 \operatorname{Var}(c) - 2a \operatorname{Cov}(g, c), \\
a^* &= \frac{\operatorname{Cov}(g, c)}{\operatorname{Var}(c)},
\end{aligned}
$$

что получается дифференцированием по $a$. BBVI использует саму функцию оценки, $c = h_j$, среднее которой равно нулю, поэтому исправленная компонента равна $h_j(z)\big(f_\lambda(z) - a_j\big)$: подынтегральное выражение минус постоянная **базовая линия** (baseline) $a_j$ ([Ranganath et al., 2014](#references), формулы 7–10). На практике $a_j$ оценивают по тем же $S$ сэмплам, что и градиент. Базовая линия важна, потому что обычная оценка не инвариантна к сдвигу $\log p$ на константу $c$: сдвиг добавляет $c\, h_j(z)$, среднее чего равно нулю, а дисперсия равна $c^2 \operatorname{Var}(h_j)$. Для гауссовского $q$ функция оценки по $\mu_j$ равна $\varepsilon_j/\sigma_j$ с дисперсией $1/\sigma_j^2$, поэтому штраф за большое $|\log p|$ растёт по мере того, как $q$ сужается. Для логистической модели с одним весом из рисунка ниже, в оптимуме ELBO, оптимальная базовая линия снижает дисперсию по одному сэмплу с $94.7$ до $0.20$. Ranganath et al. сообщают, что на их модели медицинских записей пациентов рао-блэкуэллизация снизила дисперсию на несколько порядков, а контрольная переменная снизила её ещё больше (их рисунок 2).

## Градиент через репараметризацию \{#the-reparameterization-gradient\}

Оценка через функцию оценки использует только значения $\log p$. Когда $\log p(x, z)$ дифференцируема по $z$, а сэмпл из $q$ можно получить как дифференцируемую функцию шума, не зависящего от параметров, можно использовать и градиент $\log p$. Для гауссианы $z = \mu + \sigma \odot \varepsilon$ с $\varepsilon \sim \mathcal N(0, I)$ имеет распределение $q$, и случайность больше не зависит от $\lambda$. Тогда

$$
\begin{aligned}
\mathcal L(\lambda) &= E_\varepsilon\big[\log p(x, \mu + \sigma \odot \varepsilon) - \log q(\mu + \sigma \odot \varepsilon \mid \mu, \sigma)\big] \\
&= E_\varepsilon\big[\log p(x, \mu + \sigma \odot \varepsilon)\big] + \sum_j \log \sigma_j + \text{const}, \\
\nabla_\mu \mathcal L &= E_\varepsilon\big[\nabla_z \log p(x, z)\big], \qquad \nabla_{\sigma} \mathcal L = E_\varepsilon\big[\nabla_z \log p(x, z) \odot \varepsilon\big] + 1/\sigma, \qquad z = \mu + \sigma \odot \varepsilon .
\end{aligned}
$$

Вторая строка использует $\log q(\mu + \sigma\varepsilon \mid \mu, \sigma) = -\sum_j \big(\tfrac12 \varepsilon_j^2 + \log \sigma_j\big) - \tfrac D2 \log 2\pi$: энтропия гауссианы зависит только от $\sigma$. Третья строка дифференцирует под знаком математического ожидания, которое теперь берётся по фиксированному распределению, по правилу дифференцирования сложной функции с $\partial z_j/\partial \mu_j = 1$ и $\partial z_j / \partial \sigma_j = \varepsilon_j$; $1/\sigma$ берётся поэлементно. Версия Монте-Карло усредняет $\nabla_z \log p$ по $S$ сэмплам $\varepsilon$:

$$
\boxed{
\begin{aligned}
\hat\nabla_\mu \mathcal L &= \frac1S \sum_{s=1}^S \nabla_z \log p(x, z_s), \\
z_s &= \mu + \sigma \odot \varepsilon_s
\end{aligned}
}
$$

Это **градиент через репараметризацию** (reparameterization gradient; [Kingma and Welling, 2014](#references), раздел 2.4; [Rezende, Mohamed and Wierstra, 2014](#references); [Titsias and Lázaro-Gredilla, 2014](#references)). [Заметка о VAE](/ru/notes/generative-models/vae#the-reparameterization-trick) вводит тот же трюк репараметризации (reparameterization trick) для энкодера; здесь это универсальная оценка градиента для любой дифференцируемой модели.

<TwoEstimators />

1. Один сэмпл: $\varepsilon = 0.5$ даёт $z = \mu + \sigma\varepsilon = 1.5$ при $\mu = \sigma = 1$.
2. Функция оценки: значение $f(z) = z^2 = 2.25$, умноженное на функцию оценки $(z - \mu)/\sigma^2 = 0.5$, даёт $1.125$.
3. Репараметризация: производная $f'(z) = 2z = 3$, умноженная на $\partial z / \partial \mu = 1$, даёт $3$.
4. По многим сэмплам обе оценки в среднем дают истинный градиент 2. Их дисперсии по одному сэмплу равны 30 и $\operatorname{Var}[2(1 + \varepsilon)] = 4$, так что оценке через функцию оценки нужно в 7.5 раза больше сэмплов для той же точности.

Рисунок показывает, почему у репараметризации обычно меньше дисперсия: она переносит наклон подынтегральной функции в точке сэмпла, тогда как оценка через функцию оценки должна восстанавливать наклон по тому, как значения меняются от сэмпла к сэмплу. Для линейной подынтегральной функции $c^\top z$ градиент через репараметризацию равен в точности $c$ на каждом сэмпле, с нулевой дисперсией; оценка через функцию оценки по-прежнему колеблется.

Вдали от оптимума базовая линия помогает меньше, и при $\mu = -1$ три дисперсии равны $523$, $86$ и $2.9$.

Обычная оценка через функцию оценки в 40–2000 раз хуже градиента через репараметризацию в начальной точке и в 7000–12 000 раз хуже при обученном $q$: функция оценки $\varepsilon_j/\sigma_j$ растёт по мере уменьшения $\sigma$, а вместе с ней и штраф за большое значение $|\log p - \log q|$. С базовой линией она выигрывает при обученном $q$ для $d = 2$ и $d = 10$ и проигрывает в $7.5$ раза при $d = 50$; в начальной точке она проигрывает в $4$, $15$ и $70$ раз. Базовая линия — одно число на координату, и она не может следить за тем, как подынтегральная функция меняется вдоль остальных $d - 1$ направлений; градиенту через репараметризацию это не нужно, потому что он дифференцирует.

### Когда применима каждая оценка \{#when-each-estimator-applies\}

*Необязательное углубление: требования двух оценок. Остальная часть заметки от него не зависит.*

Оценке через функцию оценки нужно только $q$, из которого можно сэмплировать и для которого можно вычислить функцию оценки, поэтому она работает для дискретных скрытых переменных, недифференцируемых правдоподобий и симуляторов, плотность которых известна, но не дифференцируема. Градиенту через репараметризацию нужно, чтобы $\log p$ была дифференцируема по $z$, а $q$ записывалось как дифференцируемое преобразование фиксированного шума: для семейств сдвига-масштаба (location-scale) это делается напрямую, для других — через обратную функцию распределения или через неявную репараметризацию (implicit reparameterization). У дискретных переменных такого преобразования нет; для них используют оценку через функцию оценки с сильными контрольными переменными или непрерывную релаксацию (continuous relaxation), которая обменивает дисперсию на смещение (обзор вариантов — [Mohamed et al., 2020](#references), разделы 4, 5 и 7). Вариационный вывод с автоматическим дифференцированием (automatic differentiation variational inference, ADVI; [Kucukelbir et al., 2017](#references)) оформляет путь через репараметризацию для целого класса моделей: он переводит каждую скрытую переменную с ограничениями на действительную прямую, задаёт там гауссовское $q$ и автоматически дифференцирует логарифм плотности модели.

## Алгоритм \{#the-algorithm\}

1. Инициализировать $\lambda$; выбрать расписание шагов $\rho_t$, удовлетворяющее условиям Роббинса–Монро, или адаптивное правило, например AdaGrad, которым пользуются Ranganath et al.
2. Взять $S$ сэмплов из $q(z \mid \lambda)$ или $S$ векторов шума $\varepsilon_s$ для градиента через репараметризацию.
3. Вычислить оценку градиента: через функцию оценки с рао-блэкуэллизацией и базовой линией или через репараметризацию.
4. Шаг: $\lambda \leftarrow \lambda + \rho_t\, \hat\nabla_\lambda \mathcal L$, затем повторить с пункта 2.

При глобальных и локальных переменных на шаге 3 можно также брать подвыборку данных, умножая локальные слагаемые на $N/B$, как в SVI. Тогда оценка **дважды стохастическая** (doubly stochastic; [Titsias and Lázaro-Gredilla, 2014](#references)): она случайна и по мини-батчу, и по сэмплам из $q$, и по-прежнему несмещённая. В разделе «Код» 3000 шагов с градиентом через репараметризацию, по 10 сэмплов и все 200 точек данных на шаг, обучают логистические регрессии из таблицы.

## Амортизированный вывод и VAE \{#amortized-inference-and-the-vae\}

Когда на каждую точку данных приходится одна локальная скрытая переменная, BBVI хранит локальные вариационные параметры $\lambda_i = (\mu_i, \sigma_i)$ для каждого $x_i$ и должен оптимизировать их для каждой точки, в том числе для каждой новой точки при тестировании. **Амортизированный вывод** (amortized inference) заменяет эту таблицу функцией: сеть-**энкодер** с весами $\psi$ выдаёт $\big(\mu_\psi(x_i), \sigma_\psi(x_i)\big)$, и ELBO максимизируется по $\psi$, а не по $\lambda_i$. Стоимость вывода для новой точки падает до одного прямого прохода, а то, что выучено о выводе на одних точках, переносится на другие.

[Вариационный автоэнкодер](/ru/notes/generative-models/vae) — это ровно он, с четырьмя решениями, которые объясняют предыдущие разделы:

- ELBO каждой точки, $E_{q_\psi(z \mid x_i)}[\log p_\theta(x_i \mid z)] - \mathrm{KL}\big(q_\psi(z \mid x_i) \,\Vert\, p(z)\big)$, выведенная в [заметке о VAE](/ru/notes/generative-models/vae#where-the-elbo-comes-from);
- гауссовское $q$ среднего поля и градиент через репараметризацию с $S = 1$ сэмплом на точку — его часть Монте-Карло;
- мини-батчи точек данных, так что оценка дважды стохастическая, как выше;
- параметры модели $\theta$ декодера, обучаемые максимизацией той же ELBO, что делает процедуру вариационным EM-алгоритмом, оба шага которого — шаги стохастического градиента ([Kingma and Welling, 2014](#references), раздел 2.3).

На языке этого курса VAE — это BBVI с градиентом через репараметризацию, амортизированный энкодером, и декодер, параметры которого подбираются по нижней оценке обоснованности; слагаемое KL между двумя гауссианами вычисляется в замкнутом виде, а не по сэмплам, что убирает его долю дисперсии в том же духе, что и рао-блэкуэллизация.

У амортизации есть цена. ELBO, достигаемая энкодером, не может быть выше той, что получается при отдельной оптимизации $\lambda_i$ для каждой точки, потому что выходы энкодера — лишь один частный выбор $\lambda_i$. [Cremer, Li and Duvenaud (2018)](#references) разложили зазор между $\log p(x)$ и ELBO на **зазор аппроксимации** (approximation gap), вызванный семейством $q$, и **зазор амортизации** (amortization gap), вызванный энкодером, и обнаружили, что зазор амортизации часто больше. Несколько шагов оптимизации $\lambda_i$ тестовой точки, начиная с выхода энкодера, возвращают часть его.

## Что изменилось \{#what-changed\}

| | Стохастический вариационный вывод | Вариационный вывод «чёрного ящика» |
| --- | --- | --- |
| Модели | условно сопряжённые | любая модель с вычислимым $\log p(x, z)$ |
| Градиент | естественный градиент в замкнутом виде | оценка Монте-Карло по $q$ |
| Оценки | не нужны | через функцию оценки; через репараметризацию, если $\log p$ дифференцируема |
| Контроль дисперсии | размер мини-батча | рао-блэкуэллизация, базовые линии, репараметризация, больше сэмплов |
| Игрушечный градиент, один сэмпл | — | дисперсия 30 против 4 |
| Локальные параметры | по одному $\phi_i$ на точку | на каждую точку или амортизированные энкодером (VAE) |

## Ограничения \{#limitations\}

- **Дисперсия остаётся узким местом.** Даже со снижением дисперсии оценке через функцию оценки может требоваться много сэмплов на шаг, а длины шагов должны быть достаточно малы для самой шумной компоненты. Сходимость медленнее и менее предсказуема, чем у шагов SVI в замкнутом виде.
- **Репараметризации нужна дифференцируемость.** Она применима к непрерывным скрытым переменным с дифференцируемыми логарифмами плотностей; дискретным переменным нужны оценка через функцию оценки или релаксации со своим смещением.
- **Семейство $q$ по-прежнему ограничивает.** Гауссовское распределение среднего поля не может представить корреляции или несколько мод; BBVI делает пригодными более богатые семейства, например гауссианы с полной ковариацией или нормализующие потоки (normalizing flows), но не выбирает их.
- **ELBO тоже зашумлена.** Контроль сходимости по оценке ELBO методом Монте-Карло требует осторожности, и застывшая целевая функция может означать проблему с длиной шага, а не сходимость.
- **Зазор амортизации.** Энкодер жертвует точностью апостериорного распределения каждой точки ради скорости и обобщения.

## Что нужно запомнить \{#what-you-should-remember\}

- Градиент ELBO равен $E_q\big[\nabla_\lambda \log q(z \mid \lambda)\,(\log p(x, z) - \log q(z \mid \lambda))\big]$, потому что математическое ожидание функции оценки равно нулю; его среднее по Монте-Карло требует только сэмплов из $q$ и значений $\log p$.
- В семействе среднего поля слагаемые, не содержащие $z_j$, можно отбросить из $j$-й компоненты (рао-блэкуэллизация), а из подынтегрального выражения вычесть базовую линию $a_j = \operatorname{Cov}(g_j, h_j)/\operatorname{Var}(h_j)$ (контрольная переменная); оба приёма сохраняют оценку несмещённой.
- Градиент через репараметризацию записывает $z = \mu + \sigma \odot \varepsilon$ и усредняет $\nabla_z \log p(x, z)$; для $E[z^2]$ при $\mu = \sigma = 1$ его дисперсия равна 4 против 30 у оценки через функцию оценки, и его преимущество растёт с размерностью.
- С мини-батчами оценка дважды стохастическая и по-прежнему несмещённая.
- VAE — это BBVI с градиентом через репараметризацию, энкодером, который амортизирует локальные вариационные параметры, и параметрами декодера, подобранными по той же ELBO.

## Код \{#code\}

Игрушечный градиент из разобранного примера, три оценки на логистической модели с одним весом из рисунка, сравнение по размерностям и рао-блэкуэллизация на модели с независимыми локальными переменными. NumPy и SciPy; начальные значения генератора (seed) фиксированы, точные числа могут немного отличаться на разных платформах и версиях библиотек. Скрипт работает около 2 секунд.

```python
import numpy as np
from scipy.optimize import minimize
from scipy.special import gammaln
LOG2PI = np.log(2 * np.pi)

# 1. игрушечная целевая функция E_q[z^2] с q = N(mu, sigma^2) при mu = sigma = 1: истинный градиент по mu равен 2 mu = 2
rng = np.random.default_rng(0)
eps = rng.normal(size=1_000_000); mu, sigma = 1.0, 1.0
z = mu + sigma * eps
g_score = (z - mu) / sigma ** 2 * z ** 2          # функция оценки, умноженная на значение функции
g_reparam = 2 * z * 1.0                            # производная функции, умноженная на dz/dmu = 1
print(g_score.mean().round(3), g_score.var().round(2), g_reparam.mean().round(3), g_reparam.var().round(2))
# 2.005 30.12 2.002 4.01   (точно: 2, 30 и 2, 4)

# 2. один вес, восемь точек: логистическое правдоподобие, априорное N(0, 1), q = N(mu, sigma^2); дисперсии квадратурой
x1 = np.array([-2, -1.5, -1, -0.5, 0.5, 1, 1.5, 2.0]); y1 = np.array([0, 0, 1, 0, 1, 0, 1, 1.0])
e = np.linspace(-9, 9, 6001); we = np.exp(-e ** 2 / 2); we /= we.sum()     # веса сетки для стандартного нормального распределения
logjoint1 = lambda w: (y1 * np.outer(w, x1) - np.logaddexp(0, np.outer(w, x1))).sum(1) - w ** 2 / 2 - LOG2PI / 2
dlogjoint1 = lambda w: ((y1 - 1 / (1 + np.exp(-np.outer(w, x1)))) * x1).sum(1) - w
def elbo1(p):
    w = p[0] + np.exp(p[1]) * e
    return (we * (logjoint1(w) + e ** 2 / 2 + p[1] + LOG2PI / 2)).sum()   # E[log p] - E[log q]
opt = minimize(lambda p: -elbo1(p), [0.0, 0.0]).x; mu1, sg1 = opt[0], np.exp(opt[1])
def variances1(mu, sg):
    w = mu + sg * e; f = logjoint1(w) + e ** 2 / 2 + np.log(sg) + LOG2PI / 2   # log p(x, w) - log q(w)
    h = e / sg                                       # функция оценки q по mu
    a = (we * h * f * h).sum() / (we * h * h).sum()  # оптимальная константа a* = Cov(h f, h) / Var(h)
    var = lambda g: (we * g * g).sum() - (we * g).sum() ** 2
    return var(h * f), var(h * (f - a)), var(dlogjoint1(w))
print(round(mu1, 3), round(sg1, 3), [round(float(v), 2) for v in variances1(mu1, sg1)], [round(float(v), 2) for v in variances1(-1.0, sg1)])
# 0.76 0.535 [94.68, 0.2, 3.6] [523.15, 86.1, 2.87]

# 3. байесовская логистическая регрессия с d весами, 200 точек; q среднего поля; дисперсия градиента по mu по одному сэмплу
def make(d, n=200, seed=0):
    r = np.random.default_rng(seed); X = r.normal(size=(n, d)); w_true = 3 * r.normal(size=d) / np.sqrt(d)
    return X, (r.random(n) < 1 / (1 + np.exp(-X @ w_true))).astype(float)
def logjoint(W, X, y):
    s = W @ X.T
    return (y * s - np.logaddexp(0, s)).sum(1) - 0.5 * (W ** 2).sum(1) - 0.5 * W.shape[1] * LOG2PI
def grad_logjoint(W, X, y):
    return (y - 1 / (1 + np.exp(-W @ X.T))) @ X - W
def fit(X, y, steps=3000, seed=1):             # BBVI с градиентом через репараметризацию, 10 сэмплов на шаг
    d = X.shape[1]; m, log_s = np.zeros(d), np.zeros(d); r = np.random.default_rng(seed)
    for t in range(steps):
        E = r.normal(size=(10, d)); s = np.exp(log_s); G = grad_logjoint(m + s * E, X, y)
        lr = 0.01 / (1 + t / 500)
        m += lr * G.mean(0); log_s += lr * ((G * E * s).mean(0) + 1)   # +1: градиент энтропии по log sigma
    return m, np.exp(log_s)
def variances(X, y, m, s, S=20_000, seed=3):
    E = np.random.default_rng(seed).normal(size=(S, len(m))); W = m + s * E
    f = logjoint(W, X, y) - (-0.5 * E ** 2 - np.log(s) - 0.5 * LOG2PI).sum(1)   # log p(x, w) - log q(w)
    H = E / s                                    # функция оценки по каждому mu_j
    G_score = H * f[:, None]
    a = ((G_score - G_score.mean(0)) * H).mean(0) / (H * H).mean(0)           # по одному весу контрольной переменной на mu_j
    G_cv = G_score - a * H
    G_rep = grad_logjoint(W, X, y)               # log q(m + s e) не зависит от m, поэтому вклад даёт только log p
    return [G.var(0).sum() for G in (G_score, G_cv, G_rep)]
for d in (2, 10, 50):
    X, y = make(d)
    v0 = variances(X, y, np.zeros(d), np.ones(d))
    v1 = variances(X, y, *fit(X, y))
    print(d, ['%.3g' % v for v in v0], ['%.3g' % v for v in v1])
# 2 ['9.49e+04', '9.48e+03', '2.24e+03'] ['8.23e+05', '16.7', '67.8']
# 10 ['1.03e+06', '8.39e+04', '5.44e+03'] ['1.85e+06', '188', '259']
# 50 ['1.79e+07', '6.24e+05', '8.96e+03'] ['7.02e+06', '6.64e+03', '886']

# 4. рао-блэкуэллизация: n независимых локальных переменных, z_i ~ N(0, 1), x_i ~ Poisson(exp(z_i)), q(z_i) = N(0, 0.5^2)
r = np.random.default_rng(4); xp = r.poisson(np.exp(r.normal(size=100))); E = r.normal(size=(20_000, 100)); s = 0.5
Z = s * E                                        # сэмплы из q; log p и log q — суммы по одному слагаемому на каждое i
terms = xp * Z - np.exp(Z) - gammaln(xp + 1) - 0.5 * Z ** 2 - 0.5 * LOG2PI - (-0.5 * E ** 2 - np.log(s) - 0.5 * LOG2PI)
h1 = E[:, 0] / s                                 # функция оценки по mu_1
for n in (1, 10, 100):
    print(n, round(float((h1 * terms[:, :n].sum(1)).var()), 1), round(float((h1 * terms[:, 0]).var()), 1))
# 1 8.2 8.2
# 10 1920.7 8.2
# 100 374010.7 8.2
```

## Дальше \{#next\}

BBVI превращает апостериорный вывод для любой дифференцируемой модели в стохастическую оптимизацию, а VAE применяет его к скрытым переменным с нейронной сетью в роли правдоподобия. Последний шаг курса переворачивает постановку: скрытыми переменными становятся веса самой сети. [Следующая заметка](/ru/notes/bayesian-methods/bayesian-deep-learning) спрашивает, что даёт апостериорное распределение на миллионах весов, и сравнивает путь через репараметризацию (Bayes by Backprop) с более дешёвыми приближениями, которые используются на практике: дропаутом Монте-Карло, глубокими ансамблями и приближением Лапласа.
