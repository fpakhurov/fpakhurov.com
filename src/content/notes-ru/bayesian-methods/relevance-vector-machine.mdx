[Байесовская линейная регрессия](/ru/notes/bayesian-methods/bayesian-linear-regression) задавала одну априорную обратную дисперсию (precision) $\alpha$ для всех весов и выбирала её, максимизируя обоснованность (evidence). Одно число для всех весов сжимает их все по одному правилу и сохраняет в модели каждый признак, релевантный или нет. Эта заметка даёт каждому весу собственную обратную дисперсию $\alpha_i$ и максимизирует обоснованность по всем им. Результат поначалу удивляет: большинство обратных дисперсий уходят в бесконечность, их веса прижимаются к нулю, и модель в итоге использует лишь несколько признаков. Этот механизм называется **автоматическим определением релевантности** (automatic relevance determination, ARD). Применённый к ядерным признакам, по одному на обучающую точку, он даёт **метод релевантных векторов** (relevance vector machine, RVM) [Типпинга (2001)](#references): разреженную ядерную модель, как метод опорных векторов, но с предсказательными дисперсиями и без константы регуляризации, которую нужно подбирать кросс-валидацией.

**Обозначения.** Как в предыдущей заметке: $n$ целевых значений $t$, матрица плана (design matrix) $\Phi \in \mathbb R^{n \times m}$ со строками $\varphi(x_i)^\top$, веса $w$, обратная дисперсия шума $\beta$, апостериорное распределение $\mathcal N(w \mid \mu, \Sigma)$. Новое здесь: столбец $\phi_i \in \mathbb R^n$ матрицы $\Phi$ — значения признака $i$ на всех обучающих входах (а не вектор признаков $\varphi(x)$ одного входа); по одной обратной дисперсии $\alpha_i$ на вес, собранные в $A = \operatorname{diag}(\alpha_1, \dots, \alpha_m)$; и ковариация целевых значений размера $n \times n$ при априорном распределении, $C = \beta^{-1} I + \Phi A^{-1}\Phi^\top$. Для ядерных признаков $K(x, x')$ — ядро, а **релевантные векторы** (relevance vectors) — обучающие входы, ядра которых остаются в модели.

## Отправная точка: плотная ядерная регрессия и метод опорных векторов \{#baseline-dense-kernel-regression-and-the-support-vector-machine\}

Возьмём в качестве признаков ядра с центрами в обучающих входах, $\varphi(x) = \big(1, K(x, x_1), \dots, K(x, x_n)\big)$, так что $m = n + 1$. С одной обратной дисперсией это байесовская линейная регрессия на $n + 1$ признаках, и её апостериорное среднее близко к [ядерной гребневой регрессии](/ru/notes/ml/kernels#kernel-ridge-regression). Все веса ненулевые, поэтому прогноз затрагивает все $n$ обучающих точек, а предсказательная дисперсия $\varphi_*^\top\Sigma\varphi_*$ стоит $O(n^2)$ на каждую новую точку.

[Метод опорных векторов](/ru/notes/ml/support-vector-machines) разрежен: его решение зависит только от опорных векторов — точек с ненулевыми двойственными переменными ([опорные векторы](/ru/notes/ml/support-vector-machines#support-vectors-what-the-dual-variables-tell-you)). Его регрессионный вариант, SVR с $\varepsilon$-нечувствительной функцией потерь (epsilon-insensitive SVR), игнорирует ошибки меньше $\varepsilon$ и оставляет опорными векторами точки на границе этой трубки или вне её. [Типпинг (2001)](#references) перечисляет, чем приходится платить за разреженность:

- число опорных векторов обычно растёт линейно с размером обучающей выборки;
- выход — точечная оценка (в классификации — жёсткое решение) без планки погрешности;
- константы $C$ и $\varepsilon$ нужно подбирать кросс-валидацией;
- ядро должно быть положительно полуопределённым — это условие из раздела о том, [какие функции являются ядрами](/ru/notes/ml/kernels#which-functions-are-kernels).

RVM сохраняет разреженность и снимает все четыре ограничения, меняя только априорное распределение на веса.

## Автоматическое определение релевантности: своя обратная дисперсия у каждого веса \{#automatic-relevance-determination-one-precision-per-weight\}

Заменим априорное распределение $\mathcal N(0, \alpha^{-1} I)$ независимыми гауссианами с собственными обратными дисперсиями:

$$
p(w \mid \alpha) = \prod_{i=1}^m \mathcal N\big(w_i \mid 0,\ \alpha_i^{-1}\big) = \mathcal N\big(w \mid 0,\ A^{-1}\big) .
$$

Нигде в выводе предыдущей заметки не использовалось, что априорная ковариация кратна $I$, поэтому выделение полного квадрата даёт апостериорное распределение с $A$ вместо $\alpha I$, а маргинальное распределение в линейно-гауссовской модели даёт обоснованность:

$$
\boxed{\; \Sigma = \big(A + \beta\Phi^\top\Phi\big)^{-1}, \quad \mu = \beta\,\Sigma\,\Phi^\top t, \qquad p(t \mid \alpha, \beta) = \mathcal N(t \mid 0,\ C), \quad C = \beta^{-1} I + \sum_{i=1}^m \alpha_i^{-1}\, \phi_i \phi_i^\top \;}
$$

Запись $C$ в виде суммы показывает, что делает обратная дисперсия. Каждый признак вносит в ковариацию целевых значений слагаемое $\alpha_i^{-1}\phi_i\phi_i^\top$: малое $\alpha_i$ (широкое априорное распределение) позволяет признаку объяснить большую долю изменчивости вдоль $\phi_i$, а $\alpha_i = \infty$ полностью убирает его слагаемое. При $\alpha_i = \infty$ априорное распределение $w_i$ — точечная масса в нуле, апостериорное тоже, и признак выпадает из модели. Поэтому выбор $\alpha_i$ максимизацией обоснованности — это выбор признаков, которые остаются.

<aside class="callout"><strong>Ключевая идея.</strong> Дадим каждому весу собственную априорную обратную дисперсию и максимизируем обоснованность по всем им. Признаку, который объясняет целевые значения недостаточно хорошо, чтобы окупить добавляемый им разброс в $C$, выгоднее $\alpha_i = \infty$: его вес прижимается к нулю, и он покидает модель. Разреженность не навязывается штрафом — её предпочитает обоснованность.</aside>

Идея появилась для входов нейронных сетей: одна обратная дисперсия на группу весов, выходящих из одного входа ([MacKay, 1994](#references); [Neal, 1996](#references)), — отсюда и название: данные решают, какие входы релевантны. Второй взгляд объясняет, почему получаются нули. Если задать для каждого $\alpha_i$ гамма-распределение в качестве априорного и проинтегрировать по нему, априорное распределение $w_i$ становится $t$-распределением Стьюдента с острым пиком в нуле и тяжёлыми хвостами; при плоских априорных распределениях на гиперпараметры (hyperpriors) получается $p(w_i) \propto 1/\lvert w_i\rvert$ ([Tipping, 2001](#references), раздел 5.1). Как и априорное распределение Лапласа, стоящее за [лассо](/ru/notes/ml/regularization#the-lasso), оно сосредоточивает много массы около нуля, допуская при этом несколько больших весов. RVM не интегрирует по $\alpha_i$, а максимизирует по ним, и поэтому каждый шаг остаётся гауссовским.

## Максимум правдоподобия второго рода: неподвижная точка Маккая \{#type-ii-maximum-likelihood-mackays-fixed-point\}

Логарифм обоснованности имеет тот же вид, что и в предыдущей заметке, только $\frac m2 \log\alpha$ заменяется на $\frac12\sum_i \log\alpha_i$, а $\frac\alpha2\lVert w\rVert^2$ — на $\frac12 w^\top A w$:

$$
\log p(t \mid \alpha, \beta) = \frac12\sum_{i=1}^m \log\alpha_i + \frac n2\log\beta - \frac\beta2\lVert t - \Phi\mu\rVert^2 - \frac12\mu^\top A\mu - \frac12\log\det\Sigma^{-1} - \frac n2\log 2\pi .
$$

Продифференцируем по одному $\alpha_i$. Как и раньше, производная через $\mu$ обращается в ноль, потому что $\mu$ максимизирует показатель экспоненты, а $\partial_{\alpha_i}\log\det(A + \beta\Phi^\top\Phi) = \operatorname{tr}(\Sigma\, e_i e_i^\top) = \Sigma_{ii}$, где $e_i$ — $i$-й единичный вектор. Поэтому

$$
\frac{\partial \log p(t \mid \alpha, \beta)}{\partial \alpha_i} = \frac12\Big(\frac{1}{\alpha_i} - \mu_i^2 - \Sigma_{ii}\Big) .
$$

Приравнивая к нулю и умножая на $2\alpha_i$, получаем $1 - \alpha_i\Sigma_{ii} = \alpha_i \mu_i^2$. Для $\beta$ вывод предыдущей заметки проходит с $\operatorname{tr}(\Sigma\,\beta\Phi^\top\Phi) = \operatorname{tr}\big(\Sigma(\Sigma^{-1} - A)\big) = \sum_i (1 - \alpha_i\Sigma_{ii})$. Вместе это обновления [Маккая (1992)](#references), которые использует [Типпинг (2001)](#references):

$$
\boxed{\; \gamma_i = 1 - \alpha_i\,\Sigma_{ii}, \qquad \alpha_i^{\text{new}} = \frac{\gamma_i}{\mu_i^2}, \qquad \frac{1}{\beta^{\text{new}}} = \frac{\lVert t - \Phi\mu\rVert^2}{n - \sum_i \gamma_i} \;}
$$

$\gamma_i \in [0, 1]$ показывает, насколько хорошо данные определяют вес $i$. Когда $\alpha_i$ велико, преобладает априорное распределение, $\Sigma_{ii} \approx 1/\alpha_i$ и $\gamma_i \approx 0$; когда $\alpha_i$ мало, преобладают данные и $\gamma_i \approx 1$. $\sum_i \gamma_i$ — эффективное число параметров из предыдущей заметки, теперь подсчитанное вес за весом.

Алгоритм чередует шаги:

1. вычислить $\Sigma$ и $\mu$ при текущих $\alpha$ и $\beta$;
2. вычислить $\gamma_i$, затем новые $\alpha_i$ и $\beta$;
3. удалить каждый признак, у которого $\alpha_i$ превышает большой порог (здесь $10^9$): его вес равен нулю с машинной точностью, а удаление уменьшает матрицы шага 1;
4. повторять, пока обратные дисперсии не перестанут меняться.

Альтернатива — EM-алгоритм с $w$ в роли скрытой переменной, M-шаг которого равен $\alpha_i = 1/(\mu_i^2 + \Sigma_{ii})$. EM никогда не уменьшает обоснованность; у обновления Маккая такой гарантии нет, но Типпинг наблюдал, что оно сходится гораздо быстрее, и ни разу не видел, чтобы оно сделало шаг вниз ([Tipping, 2001](#references), приложение A).

**Разобранный пример.** Четыре точки, два ортогональных признака $\phi_1 = (1, 1, 2, 2)$ и $\phi_2 = (1, -1, -1, 1)$, целевые значения $t = (1.05, 0.92, 2.03, 2.02)$, известное $\beta = 100$, и обе обратные дисперсии в начале равны 1. Ортогональные столбцы делают $\Phi^\top\Phi = \operatorname{diag}(10, 4)$ диагональной, поэтому

$$
\Sigma = \operatorname{diag}\Big(\frac{1}{1 + 1000},\ \frac{1}{1 + 400}\Big), \qquad \mu = \Big(\frac{1007}{1001},\ \frac{12}{401}\Big) = (1.006,\ 0.0299),
$$

где $\beta\Phi^\top t = (1007, 12)$. Тогда $\gamma = (1 - 1/1001,\ 1 - 1/401) = (0.999,\ 0.9975)$, и новые обратные дисперсии равны $0.999/1.006^2 = 0.987$ и $0.9975/0.0299^2 = 1114$. Первый признак — это $t$ с точностью до небольшого шума; его обратная дисперсия устанавливается сразу. Второй совпадает только с шумом; его обратная дисперсия подскакивает на три порядка и при следующих обновлениях продолжает расти: $4205$, затем $12\,792$, с множителем, стремящимся к $2.8$, пока после 14 обновлений не превысит $10^9$, и $\phi_2$ не будет отброшен.

1. Апостериорное распределение двух весов при текущих обратных дисперсиях.
2. $\gamma_i$: какую долю априорной дисперсии каждого веса устранили данные.
3. Новые обратные дисперсии $\gamma_i/\mu_i^2$; с ними цикл повторяется.
4. $\alpha_2$ растёт неограниченно, и $\phi_2$ покидает модель; $\alpha_1$ остаётся равным $0.987$.

## Почему большинство обратных дисперсий уходит в бесконечность \{#why-most-precisions-go-to-infinity\}

Неподвижная точка говорит, где оказываются обратные дисперсии, но не объясняет, почему так многие из них оказываются в бесконечности. Ответ даёт взгляд на обоснованность как на функцию одного $\alpha_i$ при фиксированных остальных ([Faul and Tipping, 2002](#references)). Разобьём ковариацию на часть без признака $i$ и его собственное слагаемое, $C = C_{-i} + \alpha_i^{-1}\phi_i\phi_i^\top$, и определим

$$
s_i = \phi_i^\top C_{-i}^{-1}\phi_i, \qquad q_i = \phi_i^\top C_{-i}^{-1} t .
$$

Лемма об определителе и тождество Вудбери для обновления ранга один (случай $m = 1$ тождеств из [предыдущей заметки](/ru/notes/bayesian-methods/bayesian-linear-regression#tools-matrix-derivatives-and-gaussian-identities)) дают

$$
\begin{aligned}
\det C &= \det C_{-i}\,\big(1 + s_i/\alpha_i\big), \\
t^\top C^{-1} t &= t^\top C_{-i}^{-1} t - \frac{q_i^2}{\alpha_i + s_i} ,
\end{aligned}
$$

и подстановка в $\log\mathcal N(t \mid 0, C) = -\frac12\big(n\log 2\pi + \log\det C + t^\top C^{-1}t\big)$ отделяет зависимость от $\alpha_i$:

$$
\log p(t \mid \alpha, \beta) = \log p(t \mid \alpha_{-i}, \beta) + \ell(\alpha_i), \qquad \ell(\alpha_i) = \frac12\Big(\log\frac{\alpha_i}{\alpha_i + s_i} + \frac{q_i^2}{\alpha_i + s_i}\Big) .
$$

Первое слагаемое $\ell$ отрицательно и растёт до 0 при $\alpha_i \to \infty$: это штраф Оккама за разброс, который признак добавляет в $C$. Второе — выигрыш в подгонке, наибольший при малых $\alpha_i$. Дифференцируя, получаем

$$
\ell'(\alpha_i) = \frac12\Big(\frac{s_i}{\alpha_i(\alpha_i + s_i)} - \frac{q_i^2}{(\alpha_i + s_i)^2}\Big) = \frac{s_i^2 - \alpha_i\,(q_i^2 - s_i)}{2\,\alpha_i\,(\alpha_i + s_i)^2} .
$$

Если $q_i^2 \le s_i$, числитель положителен при любом $\alpha_i$, $\ell$ возрастает на всей оси, и наилучшее значение — бесконечность. Если $q_i^2 \gt s_i$, числитель меняет знак один раз, в единственной точке максимума:

$$
\boxed{\; \alpha_i^{\star} = \begin{cases} \dfrac{s_i^2}{q_i^2 - s_i} & \text{если } q_i^2 \gt s_i , \\[2ex] \infty & \text{если } q_i^2 \le s_i . \end{cases} \;}
$$

$q_i$ измеряет, насколько хорошо признак $i$ согласуется с целевыми значениями с точки зрения модели без него, а $s_i$ — какую часть $\phi_i$ модель без него уже может воспроизвести. Признак остаётся, только если квадрат его согласованности превосходит его перекрытие с остальными. В ядерной модели с одной «шапочкой» на обучающую точку соседние «шапочки» — почти один и тот же вектор, поэтому, как только несколько из них попали в модель, остальные добавляют мало нового: их $q_i^2$ опускается ниже $s_i$, и они отбрасываются. В разобранном примере $s_2 = \beta\lVert\phi_2\rVert^2 = 400$ и $q_2 = \beta\,\phi_2^\top t = 12$, так что $q_2^2/s_2 = 0.36$ и $\alpha_2^\star = \infty$; для первого признака $s_1 = 1000$, $q_1 = 1007$ и $\alpha_1^\star = 1000^2/(1007^2 - 1000) = 0.987$ — значение, к которому пришла итерация.

В переменных $u = \alpha_i/s_i$ и $r = q_i^2/s_i$ функция равна $\ell = \frac12\big(\log\frac{u}{1+u} + \frac{r}{1+u}\big)$ — по одной кривой на каждое $r$, с максимумом в $u = 1/(r - 1)$ при $r \gt 1$. В максимуме обоснованности каждая координата находится в своём оптимуме, поэтому оставленные признаки удовлетворяют $q_i^2 \gt s_i$ и $\alpha_i = s_i^2/(q_i^2 - s_i)$, а отброшенные — $q_i^2 \le s_i$; в разделе «Код» оба условия проверяются на примере с sinc ниже. Этот анализ даёт и гораздо более быстрый алгоритм: начать с пустой модели и раз за разом добавлять, повторно оценивать или удалять по одному признаку, каждый раз задавая его $\alpha_i$ равным $\alpha_i^\star$ в замкнутом виде, так что матрицы никогда не выходят за пределы признаков, находящихся в модели ([Tipping and Faul, 2003](#references)).

## RVM на ядерных признаках и метод опорных векторов \{#the-rvm-on-kernel-features-and-the-svm\}

С ядерными признаками $\varphi(x) = (1, K(x, x_1), \dots, K(x, x_n))$ RVM предсказывает с помощью уцелевших признаков — релевантных векторов:

$$
p(t_* \mid x_*, t) = \mathcal N\big(t_* \mid \mu^\top\varphi_*,\ \beta^{-1} + \varphi_*^\top\Sigma\,\varphi_*\big) ,
$$

где $\mu$, $\Sigma$ и $\varphi_*$ ограничены оставленными признаками. Поскольку $K$ лишь задаёт набор базисных функций, оно не обязано быть положительно полуопределённым ядром: $\Phi A^{-1}\Phi^\top$ — допустимая ковариация при любой $\Phi$.

| | $\varepsilon$-нечувствительная SVR | Регрессия RVM |
| --- | --- | --- |
| Разреженность по | опорным векторам на границе $\varepsilon$-трубки или вне её | релевантным векторам, у которых $q_i^2 \gt s_i$ |
| Их число | обычно растёт линейно с $n$ | обычно гораздо меньше |
| Регуляризация | $C$ и $\varepsilon$ кросс-валидацией | $\alpha_i$ и $\beta$ по обоснованности |
| Ядро | положительно полуопределённое | любые базисные функции |
| Выход | точечная оценка | гауссовское предсказательное распределение |
| Обучение | выпуклая задача квадратичного программирования | невыпуклое; $O(m^3)$ на итерацию, в начале $m = n + 1$ |

В сравнениях самого Типпинга на функции sinc $\sin(x)/x$ используются 100 равномерно расположенных точек на $[-10, 10]$ и ядро линейных сплайнов. Без шума SVR с $\varepsilon = 0.01$ использовал 36 опорных векторов, а RVM с уровнем шума, зафиксированным на $0.01$, — 9 релевантных векторов, с максимальными ошибками $0.0100$ и $0.0070$. С равномерным шумом на $[-0.2, 0.2]$ RVM использовал 6 релевантных векторов, а SVR, у которого $C$ и $\varepsilon$ выбраны 5-кратной кросс-валидацией, — 29; среднеквадратичные отклонения от истинной функции составили $0.0245$ и $0.0291$ ([Tipping, 2001](#references), раздел 4.1).

**Разобранный пример.** В нашем собственном прогоне используются те же 100 входов с гауссовским шумом со стандартным отклонением $0.1$, свободный член и по одному гауссовскому ядру $K(x, x') = \exp\big(-(x - x')^2/(2 \cdot 2^2)\big)$ на точку: 101 признак. Начиная со всех $\alpha_i = 1$, неподвижная точка с оцениваемым $\beta$ сделала 378 итераций и оставила 6 ядер с центрами в $-5.96$, $-3.13$, $-0.71$, $5.15$, $8.18$ и $10$; свободный член был отброшен. Оценка уровня шума равна $1/\sqrt\beta = 0.090$, а среднеквадратичное расстояние среднего прогноза от $\sin(x)/x$ на мелкой сетке на $[-10, 10]$ — $0.040$. В оптимуме у каждого оставленного признака $q_i^2/s_i \gt 1$, а у каждого отброшенного $q_i^2/s_i \le 0.944$. На тех же данных SVR с тем же ядром, у которого $C$ и $\varepsilon$ выбраны 5-кратной кросс-валидацией по сетке из 16 пар, выбрал $\varepsilon = 0.01$ — наименьшее из предложенных значений — и оставил опорными векторами 95 из 100 точек, со среднеквадратичным расстоянием $0.050$. Один набор данных и одна сетка не позволяют ранжировать методы; типичен здесь контраст в числе векторов.

Априорное распределение на функциях, которое задаёт RVM, — вырожденный гауссовский процесс всего с шестью базисными функциями; у [гауссовских процессов](/ru/notes/bayesian-methods/gaussian-processes) со стационарным ядром этого недостатка нет.

<aside class="callout"><strong>Проверьте себя.</strong> (1) При текущих обратных дисперсиях у признака $s_i = 50$ и $q_i = 5$. Каково его оптимальное $\alpha_i$? (2) У другого признака $s_i = 50$ и $q_i^2 = 150$. Каково его оптимальное $\alpha_i$ и что с ним происходит, если в модель входит новый признак — почти тот же вектор? (3) Почему RVM может использовать базисные функции, не образующие положительно полуопределённое ядро, а SVM не может?<details><summary>Ответы</summary>(1) $q_i^2 = 25 \le 50 = s_i$, поэтому $\alpha_i^\star = \infty$, и признак отбрасывается. (2) $\alpha_i^\star = 50^2/(150 - 50) = 25$. Почти дубликат в модели уже может воспроизвести большую часть $\phi_i$ и большую часть подгонки, поэтому $s_i$ растёт, а $q_i^2$ уменьшается; как только $q_i^2 \le s_i$, один из двух признаков отбрасывается. (3) В RVM ядро лишь задаёт столбцы $\Phi$; модель линейна, и её априорная ковариация $\Phi A^{-1}\Phi^\top$ положительно полуопределена при любой $\Phi$. Двойственная задача SVM использует $K$ как скалярное произведение, а это требует, чтобы матрица Грама была положительно полуопределённой.</details></aside>

## Что изменилось \{#what-changed\}

| | Байесовская линейная регрессия | ARD и RVM |
| --- | --- | --- |
| Априорное распределение | $\mathcal N(0, \alpha^{-1} I)$ | $\mathcal N(0, A^{-1})$, $A = \operatorname{diag}(\alpha_i)$ |
| Гиперпараметры | два: $\alpha$, $\beta$ | $m + 1$: все $\alpha_i$ и $\beta$ |
| Обновление | $\alpha = \gamma/\lVert\mu\rVert^2$ | $\alpha_i = \gamma_i/\mu_i^2$, $\gamma_i = 1 - \alpha_i\Sigma_{ii}$ |
| Оставленные признаки | все | те, у которых $q_i^2 \gt s_i$ |
| С ядерными признаками | плотная, как ядерная гребневая регрессия | разреженная, как SVM, с планками погрешностей |
| Пример с sinc | 101 признак | 6 релевантных векторов |

## Ограничения \{#limitations\}

- **Чрезмерная уверенность вдали от данных.** С локализованными ядрами предсказательная дисперсия вдали от релевантных векторов опускается до уровня шума — противоположно тому, что должно происходить.
- **Невыпуклая оптимизация.** Обоснованность не вогнута по обратным дисперсиям; разные начальные значения, пороги отбрасывания или правила остановки могут привести к разным наборам релевантных векторов.
- **Стоимость полного алгоритма.** Первые итерации обращают матрицу размера $(n + 1) \times (n + 1)$ — время $O(n^3)$ и память $O(n^2)$, что, как отмечает Типпинг, становится неприемлемым уже при нескольких тысячах обучающих точек; последовательный алгоритм Типпинга и Фаула избегает большей части этих затрат.
- **Параметры ядра.** Обоснованность задаёт $\alpha_i$ и $\beta$, но в базовом алгоритме не задаёт ширину ядра, которую по-прежнему выбирают кросс-валидацией.
- **Точечные оценки многих гиперпараметров.** При одном гиперпараметре на каждый вес максимизация обоснованности вместо интегрирования по обратным дисперсиям — более грубое приближение, чем в предыдущей заметке, и разреженность — свойство именно этого приближения.

## Что нужно запомнить \{#what-you-should-remember\}

- ARD даёт каждому весу собственную априорную обратную дисперсию; апостериорное распределение и обоснованность — те же, что в байесовской линейной регрессии, с $A = \operatorname{diag}(\alpha_i)$ вместо $\alpha I$.
- Неподвижная точка Маккая: $\gamma_i = 1 - \alpha_i\Sigma_{ii}$, $\alpha_i \leftarrow \gamma_i/\mu_i^2$, $1/\beta \leftarrow \lVert t - \Phi\mu\rVert^2/(n - \sum_i\gamma_i)$; признаки с огромными $\alpha_i$ отбрасываются.
- Как функция одной обратной дисперсии логарифм обоснованности равен $\frac12\big(\log\frac{\alpha_i}{\alpha_i + s_i} + \frac{q_i^2}{\alpha_i + s_i}\big)$ плюс константа; его максимум равен $s_i^2/(q_i^2 - s_i)$ при $q_i^2 \gt s_i$ и бесконечности в противном случае. Избыточные признаки эту проверку не проходят.
- RVM — это такая модель на ядерных признаках с центрами в обучающих точках; уцелевшие точки — релевантные векторы.
- По сравнению с SVM: гораздо меньше векторов, есть предсказательная дисперсия, не нужно подбирать $C$ и $\varepsilon$ кросс-валидацией, подходят любые базисные функции; но оптимизация невыпукла, дорога в начале, а вдали от данных модель чрезмерно уверена.

## Код \{#code\}

ARD с неподвижной точкой Маккая, игрушечный пример и его $q$ и $s$, RVM на зашумлённых данных sinc с проверкой условия разреженности в оптимуме и SVR на тех же данных. Скрипт работает около двух секунд; точные числа, а в редких случаях и набор релевантных векторов, могут отличаться на разных платформах и версиях библиотек.

```python
import numpy as np
from sklearn.svm import SVR
from sklearn.model_selection import GridSearchCV
np.set_printoptions(suppress=True)

def rvm(Phi, t, beta=None, iters=5000, prune=1e9, tol=1e-6):
    """Type-II maximum likelihood with one precision per weight (MacKay's fixed point).
    Weights whose precision passes `prune` are removed; beta=None also estimates the noise precision."""
    n, m = Phi.shape
    alpha, keep = np.ones(m), np.arange(m)
    b = 1 / np.var(t) if beta is None else beta
    for it in range(1, iters + 1):
        P = Phi[:, keep]
        S = np.linalg.inv(np.diag(alpha[keep]) + b * P.T @ P)     # апостериорная ковариация оставленных весов
        mu = b * S @ P.T @ t                                       # апостериорное среднее
        gamma = 1 - alpha[keep] * np.diag(S)                       # насколько хорошо определён каждый вес
        new = gamma / mu ** 2                                      # обновление Маккая
        if beta is None:
            b = (n - gamma.sum()) / np.sum((t - P @ mu) ** 2)
        change = np.max(np.abs(np.log(new / alpha[keep])))
        alpha[keep] = new
        alpha[keep[new >= prune]] = np.inf                         # вес прижат к нулю: отбрасываем его
        keep = keep[new < prune]
        if change < tol: break
    P = Phi[:, keep]
    S = np.linalg.inv(np.diag(alpha[keep]) + b * P.T @ P)
    return keep, b * S @ P.T @ t, S, alpha, b, it

# игрушечный пример: два ортогональных признака, обратная дисперсия шума beta = 100 известна, alpha начинается с (1, 1)
Phi = np.array([[1, 1], [1, -1], [2, -1], [2, 1.0]])
t = np.array([1.05, 0.92, 2.03, 2.02])
alpha = np.ones(2)
for k in range(1, 15):
    S = np.linalg.inv(np.diag(alpha) + 100 * Phi.T @ Phi)
    mu = 100 * S @ Phi.T @ t
    gamma = 1 - alpha * np.diag(S)
    alpha = gamma / mu ** 2
    if k <= 2 or k == 14: print(k, mu.round(4), gamma.round(4), alpha.round(3).tolist())
# 1 [1.006  0.0299] [0.999  0.9975] [0.987, 1113.889]
# 2 [1.006  0.0079] [0.999  0.2642] [0.987, 4205.247]
# 14 [1.006 0.   ] [0.999 0.   ] [0.987, 1019386918.681]: alpha_2 превышает 1e9 после 14 обновлений
s, q = 100 * (Phi ** 2).sum(axis=0), 100 * Phi.T @ t            # для ортогональных признаков s_i = beta |phi_i|^2, q_i = beta phi_i . t
print(s, q, (q ** 2 / s).round(2), round(s[0] ** 2 / (q[0] ** 2 - s[0]), 4), round(alpha[0], 4))
# [1000.  400.] [1007.   12.] [1014.05    0.36] 0.9871 0.9871: q^2 > s только для phi_1, и alpha_1 = s^2/(q^2 - s)

# 100 зашумлённых точек sinc(x) = sin(x)/x, свободный член и по одному гауссовскому ядру ширины 2 на точку: m = 101 признак
rng = np.random.default_rng(0)
x = np.linspace(-10, 10, 100)
sinc = lambda x: np.sinc(x / np.pi)
t = sinc(x) + 0.1 * rng.normal(size=100)
K = lambda a, b: np.exp(-(a[:, None] - b[None, :]) ** 2 / (2 * 2.0 ** 2))
feat = lambda z: np.hstack([np.ones((len(z), 1)), K(z, x)])
Phi = feat(x)
keep, mu, S, alpha, beta, it = rvm(Phi, t)
xg = np.linspace(-10, 10, 1000)
Pg = feat(xg)[:, keep]
print(it, len(keep), x[keep - 1].round(2), round(1 / np.sqrt(beta), 4))   # 378 6 [-5.96 -3.13 -0.71 5.15 8.18 10.  ] 0.0902
print(round(np.sqrt(np.mean((Pg @ mu - sinc(xg)) ** 2)), 4))              # 0.0403: среднеквадратичное расстояние до истинной sinc на мелкой сетке
sd = lambda P: np.sqrt(1 / beta + np.einsum('ij,jk,ik->i', P, S, P))
print(sd(Pg).min().round(4), sd(Pg).max().round(4), sd(feat(np.array([15.0]))[:, keep]).round(4))   # 0.0903 0.0993 [0.0903]: в x = 15 модель так же уверена, как везде

# условие разреженности в оптимуме: q_i^2 > s_i ровно для оставленных признаков, alpha_i = s_i^2/(q_i^2 - s_i)
C = np.eye(100) / beta + Phi[:, keep] @ np.diag(1 / alpha[keep]) @ Phi[:, keep].T
r, ok = [], True
for i in range(101):
    phi = Phi[:, i]
    Cm = C - np.outer(phi, phi) / alpha[i] if i in keep else C           # C без признака i
    s_i, q_i = phi @ np.linalg.solve(Cm, phi), phi @ np.linalg.solve(Cm, t)
    r.append(q_i ** 2 / s_i)
    if i in keep: ok &= bool(np.isclose(alpha[i], s_i ** 2 / (q_i ** 2 - s_i), rtol=1e-3))
r = np.array(r)
print(bool(np.all(r[keep] > 1)), bool(np.all(np.delete(r, keep) <= 1 + 1e-6)), ok, np.delete(r, keep).max().round(3))   # True True True 0.944

# регрессия опорных векторов с тем же ядром, C и epsilon выбраны 5-кратной кросс-валидацией
svr = GridSearchCV(SVR(kernel='rbf', gamma=1 / (2 * 2.0 ** 2)), {'C': [0.1, 1, 10, 100], 'epsilon': [0.01, 0.05, 0.1, 0.2]}, cv=5).fit(x[:, None], t)
best = svr.best_estimator_
print(svr.best_params_, len(best.support_), round(np.sqrt(np.mean((best.predict(xg[:, None]) - sinc(xg)) ** 2)), 4))
# {'C': 1, 'epsilon': 0.01} 95 0.0497: 95 из 100 точек — опорные векторы
```

## Дальше \{#next\}

Обоснованность RVM выражалась в замкнутом виде, потому что правдоподобие было гауссовским. В классификации это не так: целевые значения равны 0 или 1, правдоподобие — произведение сигмоид, и ни апостериорное распределение весов, ни обоснованность не выражаются формулой. [Следующая заметка](/ru/notes/bayesian-methods/laplace-approximation) заменяет апостериорное распределение гауссианой с центром в его моде, у которой матрица обратной ковариации равна кривизне в этой точке. Это **приближение Лапласа** (Laplace approximation) даёт байесовскую логистическую регрессию, её смягчённые прогнозы и вариант RVM для классификации.
