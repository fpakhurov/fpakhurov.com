[Предыдущая заметка](/ru/notes/bayesian-methods/em-and-bayesian-pca) закончилась вариационным EM: апостериорное распределение латентных переменных заменялось лучшим элементом вычислимого семейства, а для параметров оставалась точечная оценка. **Вариационный вывод** (variational inference) делает следующий шаг и считает каждое неизвестное — и латентные переменные, и параметры — случайной величиной, апостериорное распределение которой нужно приблизить. Вопрос «какие параметры подходят лучше всего» сменяется вопросом «какое простое распределение ближе всего к апостериорному», а интеграл, не имеющий замкнутого вида, заменяется задачей оптимизации, которую можно решить ([Jordan et al., 1999](#references)). Эта заметка выводит целевую функцию, общее обновление приближения среднего поля, полный пример, в котором для сравнения известен точный ответ, и систематические ошибки этого приближения.

**Обозначения.** $X$ — наблюдения, $Z$ — все неизвестные, разбитые на блоки $Z_1, \dots, Z_m$. $p(X, Z)$ — совместная плотность модели, $p(Z \mid X)$ — апостериорное распределение, $p(X)$ — обоснованность (evidence). $q(Z)$ — приближение, $\mathcal Q$ — семейство, из которого оно выбирается, а $\mathcal L(q)$ — нижняя оценка обоснованности (evidence lower bound, ELBO). $\mathbb E_{-j}[\cdot]$ — математическое ожидание по всем множителям $q$, кроме $q_j$. В примере $x_1, \dots, x_n$ — наблюдения из $\mathcal N(\mu, \lambda^{-1})$ с неизвестными средним $\mu$ и **обратной дисперсией** (precision) $\lambda$, $\bar x$ — их среднее, а $\mathrm{Gamma}(\lambda \mid a, b) = b^a \lambda^{a-1} e^{-b\lambda} / \Gamma(a)$ — плотность гамма-распределения с параметром формы (shape) $a$ и параметром интенсивности (rate) $b$, со средним $a/b$. Как и в [заметке о сопряжённых распределениях](/ru/notes/bayesian-methods/conjugate-priors#normal-gamma-unknown-mean-and-precision), $\mu_0, \kappa_0, a_0, b_0$ — параметры априорного распределения, а $\mu_n, \kappa_n, a_n, b_n$ — параметры точного апостериорного; $\omega$, $\tilde a$ и $\tilde b$ — параметры вариационных множителей.

## Отправная точка: точное апостериорное распределение, когда оно есть \{#baseline-the-exact-posterior-when-there-is-one\}

Формула Байеса даёт апостериорное распределение $p(Z \mid X) = p(X, Z) / p(X)$, и вся трудность сосредоточена в обоснованности $p(X) = \int p(X, Z)\, dZ$. Для [сопряжённой](/ru/notes/bayesian-methods/conjugate-priors) модели этот интеграл известен. Нормальная модель с **нормально-гамма априорным распределением** (normal–gamma prior), обновление которого выведено в [заметке о сопряжённых распределениях](/ru/notes/bayesian-methods/conjugate-priors#normal-gamma-unknown-mean-and-precision),

$$
\begin{aligned}
\mu \mid \lambda &\sim \mathcal N\big(\mu_0, (\kappa_0 \lambda)^{-1}\big), \\
\lambda &\sim \mathrm{Gamma}(a_0, b_0)
\end{aligned}
$$

имеет нормально-гамма апостериорное распределение: $\mu \mid \lambda, X \sim \mathcal N\big(\mu_n, (\kappa_n \lambda)^{-1}\big)$ и $\lambda \mid X \sim \mathrm{Gamma}(a_n, b_n)$, где

$$
\begin{aligned}
\kappa_n &= \kappa_0 + n, \\
\mu_n &= \frac{\kappa_0 \mu_0 + n \bar x}{\kappa_0 + n}, \qquad a_n = a_0 + \frac n2, \\
b_n &= b_0 + \frac12 \sum_{i=1}^n (x_i - \bar x)^2 + \frac{\kappa_0 n (\bar x - \mu_0)^2}{2(\kappa_0 + n)} .
\end{aligned}
$$

**Разобранный пример.** У восьми наблюдений $3.0, -1.6, 1.4, 0.4, 0.5, 0.8, -1.0, 0.8$ среднее $\bar x = 0.5375$ и $\sum_i (x_i - \bar x)^2 = 13.899$. При $\mu_0 = 0$, $\kappa_0 = 1$, $a_0 = b_0 = 2$ у апостериорного распределения $\kappa_n = 9$, $\mu_n = 0.478$, $a_n = 6$ и $b_n = 9.078$. Апостериорное среднее обратной дисперсии равно $a_n/b_n = 0.661$, а маргинальное распределение $\mu$ — $t$-распределение Стьюдента со стандартным отклонением $\sqrt{b_n / ((a_n - 1)\kappa_n)} = 0.449$. Логарифм обоснованности равен $\log p(X) = -15.5113$.

Эта заметка использует нормальную модель потому, что её точное апостериорное распределение известно: с ним можно сверить любое приближение. Модели, встречающиеся на практике, редко так удобны. У байесовской смеси $K$ гауссиан апостериорное распределение содержит по одному сопряжённому слагаемому на каждый из $K^n$ способов разметить точки; при $K = 3$ и $n = 100$ это $3^{100} \approx 5 \cdot 10^{47}$ слагаемых. У нормальной модели, априорное распределение которой делает $\mu$ и $\lambda$ независимыми, а не связывает дисперсию $\mu$ с $\lambda$, апостериорное распределение уже не принадлежит ни одному стандартному семейству. [Приближение Лапласа](/ru/notes/bayesian-methods/laplace-approximation) заменяет такое апостериорное распределение гауссианой, подогнанной в одной точке — в моде. Вариационный вывод подгоняет приближение ко всему распределению.

## Нижняя оценка обоснованности и обратная KL-дивергенция \{#the-evidence-lower-bound-and-the-reverse-kl\}

Для любого $q$, положительного всюду, где положительно апостериорное распределение, разложение из [предыдущей заметки](/ru/notes/bayesian-methods/em-and-bayesian-pca#em-as-coordinate-ascent-on-the-evidence-lower-bound) выполняется, когда в $Z$ собраны все неизвестные:

$$
\log p(X) = \underbrace{\mathbb E_q\big[\log p(X, Z)\big] - \mathbb E_q\big[\log q(Z)\big]}_{\mathcal L(q)} + D_{\mathrm{KL}}\big(q(Z) \,\|\, p(Z \mid X)\big) .
$$

Левая часть не зависит от $q$, поэтому максимизация $\mathcal L$ по семейству $\mathcal Q$ и минимизация KL-дивергенции от $q$ до апостериорного распределения — одна и та же задача. Нижней оценке нужна только совместная плотность $p(X, Z)$, которую записывает модель, и никогда — обоснованность или апостериорное распределение. Поскольку KL-дивергенция неотрицательна, $\mathcal L(q) \le \log p(X)$ для любого $q$, и равенство достигается только на точном апостериорном распределении.

Направление дивергенции вынужденное. Другое направление, $D_{\mathrm{KL}}(p(Z \mid X) \,\|\, q)$, усредняет по апостериорному распределению, а именно этого вычислить нельзя. У выбора направления есть последствия; для одной гауссианы, подгоняемой к двум модам, они разобраны в [курсе генеративных моделей](/ru/notes/generative-models/fitting-distributions-with-kl#forward-kl-covers-both-modes-reverse-kl-picks-one). Обратная дивергенция (reverse KL)

$$
D_{\mathrm{KL}}(q \,\|\, p) = \int q(Z) \log \frac{q(Z)}{p(Z \mid X)}\, dZ
$$

— это среднее по $q$. Она становится очень большой там, где $q$ кладёт массу, а у $p$ её почти нет, и ничего не стоит там, где масса есть у $p$, но нет у $q$. Поэтому оптимальное $q$ остаётся внутри области, где апостериорное распределение велико, — **обнуляющее** поведение (zero-forcing), — а когда у апостериорного распределения несколько разделённых мод, выбирает одну из них, **ищет моду** (mode-seeking). Прямая дивергенция [метода максимального правдоподобия](/ru/notes/generative-models/entropy-and-divergences#kullbackleibler-divergence) поступает наоборот и покрывает всю массу. Для целевого распределения $\tfrac12 \mathcal N(-3, 1) + \tfrac12 \mathcal N(3, 1)$ раздел «Код» находит, что гауссиана, минимизирующая обратную KL-дивергенцию, равна $\mathcal N(\pm 2.984, 1.023^2)$ — одна мода — с $D_{\mathrm{KL}} = 0.689$, близким к $\log 2 = 0.693$: это цена за игнорирование половины массы. Гауссиана, минимизирующая прямую KL-дивергенцию, совпадает с целевым распределением по моментам, $\mathcal N(0, 10)$, и ставит свой пик туда, где у целевого распределения почти ничего нет.

## Среднее поле и общее обновление \{#mean-field-and-the-general-update\}

Семейство **приближения среднего поля** (mean-field) факторизует $q$ по блокам и больше ничего о множителях не предполагает:

$$
q(Z) = \prod_{j=1}^m q_j(Z_j) .
$$

Оптимальный вид каждого множителя выводится, а не выбирается. Зафиксируем все множители, кроме $q_j$. В $\mathcal L(q)$ математическое ожидание $\log p(X, Z)$ по произведению — это математическое ожидание по $q_j$ от математического ожидания по остальным, а энтропия произведения равна сумме энтропий множителей:

$$
\begin{aligned}
\mathcal L(q) &= \int q_j(Z_j)\, \mathbb E_{-j}\big[\log p(X, Z)\big]\, dZ_j - \int q_j(Z_j) \log q_j(Z_j)\, dZ_j - \sum_{i \ne j} \int q_i \log q_i\, dZ_i \\
&= \int q_j(Z_j) \log \frac{\tilde p_j(Z_j)}{q_j(Z_j)}\, dZ_j + \log C_j + \text{const} \;=\; -D_{\mathrm{KL}}\big(q_j \,\|\, \tilde p_j\big) + \log C_j + \text{const},
\end{aligned}
$$

где $\tilde p_j(Z_j) = \exp\big(\mathbb E_{-j}[\log p(X, Z)]\big) / C_j$ — нормированная плотность, $C_j$ — её нормировочная константа, а «const» собирает слагаемые, не содержащие $q_j$. Единственное слагаемое, зависящее от $q_j$, — KL-дивергенция со знаком минус; она максимальна, равна нулю, при $q_j = \tilde p_j$. Поэтому оптимальный множитель при остальных фиксированных равен

$$
\boxed{\;\log q_j^*(Z_j) = \mathbb E_{-j}\big[\log p(X, Z)\big] + \text{const}\;}
$$

где константа определяется нормировкой. Три замечания делают формулу пригодной к применению.

1. **Важны только слагаемые с $Z_j$.** Поскольку $\log p(X, Z) = \log p(Z_j \mid Z_{-j}, X) + \log p(Z_{-j}, X)$ и второе слагаемое не содержит $Z_j$, обновление можно записать и через **полное условное распределение** (complete conditional): $\log q_j^* = \mathbb E_{-j}[\log p(Z_j \mid Z_{-j}, X)] + \text{const}$. [Сэмплер Гиббса](/ru/notes/bayesian-methods/gibbs-sampling) из следующей заметки сэмплирует из того же полного условного распределения, но при текущих значениях остальных блоков, а не усредняя по ним.
2. **Условная сопряжённость даёт замкнутые формулы.** Пусть полное условное распределение $Z_j$ принадлежит [экспоненциальному семейству](/ru/notes/bayesian-methods/conjugate-priors#natural-parameters-and-sufficient-statistics), $p(Z_j \mid Z_{-j}, X) = h(Z_j) \exp\big(\eta_j^\top u(Z_j) - A(\eta_j)\big)$ с естественным параметром $\eta_j = \eta_j(Z_{-j}, X)$. Его логарифм линеен по достаточным статистикам $u(Z_j)$, а $A(\eta_j)$ не содержит $Z_j$, поэтому обновление равно $\log q_j^*(Z_j) = \log h(Z_j) + \mathbb E_{-j}[\eta_j]^\top u(Z_j) + \text{const}$: это элемент того же семейства с естественным параметром $\mathbb E_{-j}[\eta_j(Z_{-j}, X)]$ ([Blei, Kucukelbir and McAuliffe, 2017](#references), раздел 4). Модель не обязана быть сопряжённой целиком; нужно, чтобы каждый блок был сопряжённым при фиксированных остальных.
3. **Покоординатный подъём.** Обновления зависят друг от друга через математические ожидания, поэтому их применяют по кругу: это **покоординатный вариационный вывод** (coordinate ascent variational inference, CAVI). Каждое обновление максимизирует $\mathcal L$ по одному множителю, так что $\mathcal L$ не убывает, а поскольку она ограничена сверху величиной $\log p(X)$, последовательность её значений сходится. В общем случае $\mathcal L$ не является совместно вогнутой по множителям, и предел — локальный оптимум, который может зависеть от начальной точки.

<aside class="callout"><strong>Ключевая идея.</strong> Вариационный вывод заменяет интеграл оптимизацией: среди вычислимых распределений нужно найти распределение с наибольшей нижней оценкой обоснованности, то есть ближайшее к апостериорному по обратной KL-дивергенции, — а эта величина вычисляется по одной совместной плотности. При факторизации среднего поля оптимум каждого множителя при остальных фиксированных имеет замкнутый вид, $\log q_j^* = \mathbb E_{-j}[\log p(X, Z)] + \text{const}$, и циклический перебор множителей поднимает нижнюю оценку.</aside>

## Разобранный пример: гауссиана с неизвестными средним и обратной дисперсией \{#worked-example-a-gaussian-with-unknown-mean-and-precision\}

Возьмём нормальную модель из отправной точки с факторизацией $q(\mu, \lambda) = q(\mu)\, q(\lambda)$ ([Bishop, 2006](#references), раздел 10.1.3). Точное апостериорное распределение не факторизуется, так как условная дисперсия $\mu$ равна $1/(\kappa_n \lambda)$, поэтому приближению есть что терять. Логарифм совместной плотности равен

$$
\log p(X, \mu, \lambda) = \frac n2 \log \lambda - \frac\lambda2 \sum_{i=1}^n (x_i - \mu)^2 + \frac12 \log(\kappa_0 \lambda) - \frac{\kappa_0 \lambda}{2} (\mu - \mu_0)^2 + (a_0 - 1) \log \lambda - b_0 \lambda + \text{const} .
$$

**Множитель $q(\mu)$.** Оставим слагаемые с $\mu$ и усредним по $q(\lambda)$, что лишь заменяет $\lambda$ на $\mathbb E[\lambda]$:

$$
\log q^*(\mu) = -\frac{\mathbb E[\lambda]}{2} \Big(\sum_{i=1}^n (x_i - \mu)^2 + \kappa_0 (\mu - \mu_0)^2\Big) + \text{const} = -\frac{(\kappa_0 + n)\, \mathbb E[\lambda]}{2}\, (\mu - \mu_n)^2 + \text{const},
$$

после выделения полного квадрата: выражение в скобках равно $(\kappa_0 + n)\mu^2 - 2\mu(\kappa_0 \mu_0 + n\bar x) + \text{const}$. Значит, $q^*(\mu) = \mathcal N(\mu \mid \mu_n, \omega^{-1})$ с точным апостериорным средним $\mu_n$ и обратной дисперсией $\omega = (\kappa_0 + n)\, \mathbb E[\lambda]$.

**Множитель $q(\lambda)$.** Оставим слагаемые с $\lambda$ и усредним по $q(\mu)$:

$$
\log q^*(\lambda) = \Big(a_0 - 1 + \frac{n + 1}{2}\Big) \log \lambda - \lambda \Big(b_0 + \frac12\, \mathbb E_\mu\Big[\sum_{i=1}^n (x_i - \mu)^2 + \kappa_0 (\mu - \mu_0)^2\Big]\Big) + \text{const},
$$

а это логарифм гамма-плотности: $q^*(\lambda) = \mathrm{Gamma}(\lambda \mid \tilde a, \tilde b)$ с $\tilde a = a_0 + \frac{n + 1}{2}$ и $\tilde b = b_0 + \frac12\, \mathbb E_\mu[\cdots]$. Математические ожидания по $q(\mu)$ равны $\mathbb E_\mu\big[\sum_i (x_i - \mu)^2\big] = \sum_i (x_i - \mu_n)^2 + n/\omega$ и $\mathbb E_\mu\big[(\mu - \mu_0)^2\big] = (\mu_n - \mu_0)^2 + 1/\omega$. В параметре формы стоит $(n + 1)/2$, а не $n/2$, как у точного апостериорного распределения, потому что свою половину вносит априорное распределение $\mu$, которое тоже зависит от $\lambda$.

**Итерации.** Начнём с $q(\mu) = \mathcal N(1.4, 0.2^2)$ и $q(\lambda)$ со средним $1.2$. Первое обновление $q(\mu)$ делает его среднее равным $0.478$, а обратную дисперсию — $9 \cdot 1.2 = 10.8$. Первое обновление $q(\lambda)$ даёт $\tilde a = 6.5$ и

$$
\begin{aligned}
\tilde b &= 2 + \tfrac12 \big(13.927 + 8/10.8 + 0.478^2 + 1/10.8\big) = 2 + \tfrac12 \cdot 14.988 = 9.494, \\
\mathbb E[\lambda] &= 6.5/9.494 = 0.685 .
\end{aligned}
$$

Нижняя оценка поднимается с $-21.596$ в начале через $-16.867$, $-15.622$, $-15.556$, $-15.553$ после первых четырёх обновлений и устанавливается на $-15.5524$. Логарифм обоснованности равен $-15.5113$; зазор $0.0411$ — это $D_{\mathrm{KL}}(q \,\|\, p)$, и раздел «Код» получает то же значение, вычисляя дивергенцию численным интегрированием.

**Неподвижная точка в замкнутом виде.** После сходимости $\mathbb E[\lambda]$ точно, а дисперсия $\mu$ — нет. Запишем $\sum_i (x_i - \mu_n)^2 + \kappa_0 (\mu_n - \mu_0)^2 = 2(b_n - b_0)$; это тождество следует из $\bar x - \mu_n = \kappa_0(\bar x - \mu_0)/(\kappa_0 + n)$ и $\mu_n - \mu_0 = n(\bar x - \mu_0)/(\kappa_0 + n)$. Тогда

$$
\begin{aligned}
\tilde b &= b_n + \frac{n + \kappa_0}{2\omega} = b_n + \frac{1}{2\, \mathbb E[\lambda]}, \qquad \tilde a = a_n + \frac12, \\
\mathbb E[\lambda] &= \frac{\tilde a}{\tilde b} \;\Longrightarrow\; \mathbb E[\lambda]\, b_n + \frac12 = a_n + \frac12 \;\Longrightarrow\; \mathbb E[\lambda] = \frac{a_n}{b_n} .
\end{aligned}
$$

Среднее обратной дисперсии в точности равно апостериорному среднему, $0.661$. Дисперсия $\mu$ по $q$ равна $1/\omega = b_n/(a_n\kappa_n)$, а точная — $b_n/((a_n - 1)\kappa_n)$:

$$
\frac{\operatorname{Var}_q(\mu)}{\operatorname{Var}_p(\mu)} = \frac{a_n - 1}{a_n} = \frac56 = 0.833, \qquad \text{стандартное отклонение } 0.410 \text{ вместо } 0.449 .
$$

Точное маргинальное распределение $\mu$ — $t$-распределение Стьюдента, то есть смесь гауссиан с дисперсиями $1/(\kappa_n \lambda)$ по неопределённому $\lambda$; малые значения $\lambda$ его расширяют. Факторизованное $q$ использует одну гауссиану со средней обратной дисперсией и теряет этот дополнительный разброс. Ошибка уменьшается с ростом $a_n = a_0 + n/2$: с ростом объёма данных обратная дисперсия определяется точнее, и связь между блоками значит меньше. Стандартное отклонение $\lambda$ тоже немного занижено: $0.259$ против $0.270$.

## В чём ошибается среднее поле \{#what-mean-field-gets-wrong\}

**Оно игнорирует корреляции и занижает дисперсии.** Пусть апостериорное распределение — гауссиана $\mathcal N(m, \Lambda^{-1})$ в двух блоках с матрицей обратной ковариации (precision matrix) $\Lambda$. Общее обновление даёт

$$
\log q_1^*(z_1) = \mathbb E_{z_2}\Big[-\tfrac12 (z - m)^\top \Lambda (z - m)\Big] + \text{const} = -\tfrac12 \Lambda_{11} z_1^2 + z_1 \big(\Lambda_{11} m_1 - \Lambda_{12} (\mathbb E[z_2] - m_2)\big) + \text{const},
$$

поэтому $q_1^* = \mathcal N\big(m_1 - \Lambda_{11}^{-1} \Lambda_{12} (\mathbb E[z_2] - m_2),\; \Lambda_{11}^{-1}\big)$, и симметрично для $q_2$. Средние сходятся к точным средним $m$. Дисперсия каждого множителя равна $1/\Lambda_{11}$ — это дисперсия $z_1$ **при фиксированном** $z_2$, а не маргинальная дисперсия $\Sigma_{11}$, и она никогда не бывает больше. Для единичных дисперсий и корреляции $\rho$ имеем $\Lambda_{11} = 1/(1 - \rho^2)$, и при $\rho = 0.9$ каждый множитель имеет дисперсию $0.19$ вместо 1, стандартное отклонение $0.436$ вместо 1. Дивергенция в оптимуме равна $-\frac12 \log(1 - \rho^2) = 0.830$. Лучшее факторизованное $q$ для прямого направления — произведение точных маргинальных распределений, с дисперсией 1 и той же дивергенцией $0.830$; два направления совпадают здесь только из-за симметрии примера.

Покоординатные обновления средних имеют вид $m_1 \leftarrow \rho\, m_2$ и $m_2 \leftarrow \rho\, m_1$ (при $m = 0$) — это условные средние целевого распределения. Каждый проход умножает расстояние до оптимума на $\rho^2 = 0.81$ — тот же множитель, что замедляет сэмплер Гиббса на этом целевом распределении в [заметке о MCMC](/ru/notes/probability/markov-chain-monte-carlo#gibbs-sampling): из $(-2.4, 2.4)$ сорок проходов оставляют средние равными $0.00058$ и $0.00052$.

<CorrelatedGaussian />

**Оно ищет одну моду.** Апостериорное распределение с разделёнными модами приближается распределением $q$, которое покрывает одну из них, как в примере с двумя модами выше. Апостериорное распределение смеси всегда так устроено: перестановки компонент дают $K!$ эквивалентных мод. Для предсказаний выбор моды не важен, но нижняя оценка тогда теряет около $\log K!$ логарифма обоснованности, и [Bishop (2006](#references), раздел 10.2.4) прибавляет $\log K!$ обратно, прежде чем сравнивать смеси с разными $K$.

**Её нижняя оценка — смещённая мера качества модели.** $\mathcal L(q) = \log p(X) - D_{\mathrm{KL}}(q \,\|\, p)$, и дивергенция у разных моделей разная. Сравнивая две модели по нижним оценкам, мы сравниваем их обоснованности за вычетом двух разных зазоров; такое сравнение надёжно, только когда зазоры малы по сравнению с разницей обоснованностей.

**Её неопределённость систематически завышает уверенность.** Поскольку обратная KL-дивергенция штрафует массу там, где апостериорное распределение мало, дисперсии $q$ обычно получаются слишком маленькими, как в обоих примерах этой заметки. Байесовские доверительные интервалы (credible intervals) среднего поля тогда обычно уже точных, и ошибка не уменьшается с числом итераций — только при более богатом семействе $\mathcal Q$ или с ростом объёма данных.

## За пределами нормальной модели \{#beyond-the-normal-model\}

Тот же рецепт применим к любой модели, блоки которой условно сопряжены. Для байесовской смеси гауссиан с априорным распределением Дирихле на весах и нормальными–Уишарта априорными распределениями на компонентах факторизация $q(Z)\, q(\pi, \mu, \Lambda)$ даёт обновления, похожие на EM: ответственность для каждой точки и компоненты, вычисленная с $\mathbb E[\log \pi_k]$ и $\mathbb E[\log \det \Lambda_k]$ вместо точечных оценок, и множители Дирихле и нормальный–Уишарта, параметры которых равны априорным псевдосчётчикам плюс статистики, взвешенные ответственностями ([Bishop, 2006](#references), раздел 10.2). У компонент, которые объясняют мало точек, веса уходят к нулю, так что, как и в байесовском методе главных компонент, модель, запущенная со слишком большим числом компонент, отключает лишние. [Латентное размещение Дирихле](/ru/notes/bayesian-methods/latent-dirichlet-allocation), которое появится в курсе позже, обучается так же, а [вариационный автоэнкодер](/ru/notes/generative-models/vae#variational-approximation-and-the-elbo) сохраняет нижнюю оценку этой заметки и заменяет множители в замкнутом виде нейронной сетью.

## Ограничения \{#limitations\}

- **Заниженная неопределённость.** Обратная KL-дивергенция и факторизация обе делают $q$ слишком узким, причём во сколько раз — сам метод не сообщает; это показывает только сравнение с более точным методом, например с сэмплером из следующей заметки.
- **Корреляции теряются по построению.** Зависимости между блоками факторизованному $q$ не видны; лекарство — объединить сильно связанные переменные в один блок или взять структурированное семейство.
- **Локальные оптимумы и зависимость от начальной точки.** CAVI поднимается по невогнутой нижней оценке; для смесей и тематических моделей разные начальные точки дают разные ответы, и выбирать между ними можно по нижней оценке.
- **Вывод для каждой модели заново.** Каждой новой модели нужны свои математические ожидания и обновления, а моделям без условной сопряжённости — дополнительные приближения; [методы «чёрного ящика»](/ru/notes/bayesian-methods/black-box-variational-inference) в конце курса снимают это требование ценой зашумлённых градиентов.
- **Полные проходы по данным.** Каждое обновление глобального множителя в CAVI использует все наблюдения; [стохастический вариационный вывод](/ru/notes/bayesian-methods/stochastic-variational-inference), который появится в курсе позже, заменяет эти проходы мини-батчами.

## Что нужно запомнить \{#what-you-should-remember\}

- $\log p(X) = \mathcal L(q) + D_{\mathrm{KL}}(q \,\|\, p(Z \mid X))$ при $\mathcal L(q) = \mathbb E_q[\log p(X, Z)] - \mathbb E_q[\log q]$; максимизация нижней оценки минимизирует обратную KL-дивергенцию и требует только совместной плотности.
- Обратная KL-дивергенция обнуляет приближение вне массы апостериорного распределения и ищет моду; прямая, которой нужно было бы апостериорное распределение, покрывает массу.
- Среднее поле: $q(Z) = \prod_j q_j(Z_j)$, и оптимальный множитель при остальных фиксированных равен $\log q_j^* = \mathbb E_{-j}[\log p(X, Z)] + \text{const}$; при условной сопряжённости каждый множитель принадлежит семейству своего полного условного распределения с усреднёнными естественными параметрами.
- CAVI применяет обновления по кругу; нижняя оценка не убывает и сходится к локальному оптимуму.
- Нормальная модель с нормально-гамма априорным распределением: $q(\mu) = \mathcal N(\mu_n, ((\kappa_0 + n)\mathbb E[\lambda])^{-1})$, $q(\lambda) = \mathrm{Gamma}(a_0 + \frac{n+1}{2}, \tilde b)$; в неподвижной точке $\mathbb E[\lambda]$ точно, а дисперсия $\mu$ занижена в $(a_n - 1)/a_n$ раз.
- Для коррелированной гауссианы среднее поле даёт правильные средние и условные дисперсии $1/\Lambda_{jj}$ вместо маргинальных.

## Код \{#code\}

Точное апостериорное распределение и обоснованность нормальной модели, CAVI с нижней оценкой после каждого обновления, зазор, вычисленный как KL-дивергенция численным интегрированием, отношение дисперсий в замкнутом виде, среднее поле для коррелированной гауссианы и два направления KL на двух модах. Только NumPy и SciPy; точные числа могут немного различаться на разных платформах и версиях библиотек. Скрипт работает несколько секунд, бо́льшую часть времени занимает численное интегрирование.

```python
import numpy as np
from scipy.special import gammaln, digamma
from scipy.stats import norm, gamma
from scipy.integrate import dblquad
from scipy.optimize import minimize

# нормальная модель: x_i ~ N(mu, 1/tau), априорное mu | tau ~ N(mu0, 1/(l0 tau)), tau ~ Gam(a0, b0) (b0 — интенсивность)
# tau — обратная дисперсия lambda из текста, l0 — kappa_0, а lam ниже — обратная дисперсия omega множителя q(mu)
x = np.array([3.0, -1.6, 1.4, 0.4, 0.5, 0.8, -1.0, 0.8])
N, xbar = len(x), x.mean()
mu0, l0, a0, b0 = 0.0, 1.0, 2.0, 2.0

# точное апостериорное распределение: нормально-гамма, и точный логарифм обоснованности
lN, mN, aE = l0 + N, (l0 * mu0 + N * xbar) / (l0 + N), a0 + N / 2
bE = b0 + 0.5 * ((x - xbar) ** 2).sum() + l0 * N * (xbar - mu0) ** 2 / (2 * lN)
logZ = gammaln(aE) - gammaln(a0) + a0 * np.log(b0) - aE * np.log(bE) + 0.5 * np.log(l0 / lN) - N / 2 * np.log(2 * np.pi)
print(round(mN, 3), round(aE / bE, 3), round(np.sqrt(bE / ((aE - 1) * lN)), 3), round(logZ, 4))   # 0.478 0.661 0.449 -15.5113

def elbo(m, lam, a, b):                  # L(q) для q(mu) = N(m, 1/lam), q(tau) = Gam(a, b)
    Elog, Et = digamma(a) - np.log(b), a / b
    Esq, Ep = ((x - m) ** 2).sum() + N / lam, (m - mu0) ** 2 + 1 / lam
    lik = N / 2 * Elog - N / 2 * np.log(2 * np.pi) - Et * Esq / 2
    pmu = 0.5 * (np.log(l0) + Elog - np.log(2 * np.pi)) - l0 * Et * Ep / 2
    ptau = a0 * np.log(b0) - gammaln(a0) + (a0 - 1) * Elog - b0 * Et
    Hmu, Htau = 0.5 * np.log(2 * np.pi * np.e / lam), a - np.log(b) + gammaln(a) + (1 - a) * digamma(a)
    return lik + pmu + ptau + Hmu + Htau

# покоординатный подъём из q(mu) = N(1.4, 0.2^2), q(tau) = Gam(6.5, 6.5 / 1.2)
m, lam, a, b = 1.4, 25.0, 6.5, 6.5 / 1.2
trace = [elbo(m, lam, a, b)]
for sweep in range(30):
    m, lam = mN, lN * a / b                                           # обновление q(mu)
    trace.append(elbo(m, lam, a, b))
    a = a0 + (N + 1) / 2                                              # обновление q(tau)
    b = b0 + 0.5 * (((x - m) ** 2).sum() + N / lam + l0 * ((m - mu0) ** 2 + 1 / lam))
    trace.append(elbo(m, lam, a, b))
    if sweep == 0: print(round(lam, 2), round(a / b, 3))              # 10.8 0.685
print(np.round(trace[:5], 4), bool(np.all(np.diff(trace) >= -1e-12)))
# [-21.5957 -16.8674 -15.622  -15.5562 -15.5527] True
print(round(a / b, 3), round(1 / np.sqrt(lam), 3), round(np.sqrt(a) / b, 3), round(np.sqrt(aE) / bE, 3))
# 0.661 0.41 0.259 0.27: E[tau] точно, стандартные отклонения занижены
print(round(trace[-1], 4), round(logZ - trace[-1], 4))              # -15.5524 0.0411

# зазор равен KL(q || p(mu, tau | x)), здесь — через численное интегрирование
logq = lambda mu, t: norm.logpdf(mu, m, 1 / np.sqrt(lam)) + gamma.logpdf(t, a, scale=1 / b)
logp = lambda mu, t: norm.logpdf(mu, mN, 1 / np.sqrt(lN * t)) + gamma.logpdf(t, aE, scale=1 / bE)
kl = dblquad(lambda mu, t: np.exp(logq(mu, t)) * (logq(mu, t) - logp(mu, t)), 1e-6, 5, -4, 5)[0]
print(round(kl, 4))                                                  # 0.0411
print(round((aE - 1) / aE, 4), round((1 / lam) / (bE / ((aE - 1) * lN)), 4))   # 0.8333 0.8333: Var_q / Var_p = (a_n - 1) / a_n

# коррелированная гауссиана, rho = 0.9: обновления среднего поля m1 <- rho m2, m2 <- rho m1, дисперсии 1 - rho^2
rho = 0.9
m1, m2 = -2.4, 2.4
for sweep in range(40): m1 = rho * m2; m2 = rho * m1
print(round(m1, 5), round(m2, 5), round(1 - rho ** 2, 2), round(-0.5 * np.log(1 - rho ** 2), 3))   # 0.00058 0.00052 0.19 0.83

# одна гауссиана для двух мод, p = 0.5 N(-3, 1) + 0.5 N(3, 1): обратная KL выбирает моду, прямая KL покрывает обе
logp1 = lambda z: np.logaddexp(norm.logpdf(z, -3, 1), norm.logpdf(z, 3, 1)) + np.log(0.5)
zs = np.linspace(-12, 12, 4001); dz = zs[1] - zs[0]
def rev(v):                                  # KL(q || p) для q = N(v[0], exp(v[1])^2), квадратурной формулой
    lq = norm.logpdf(zs, v[0], np.exp(v[1]))
    return np.sum(np.exp(lq) * (lq - logp1(zs))) * dz
for start in ((-1.0, 0.0), (0.5, 0.0)):
    r = minimize(rev, start, method='Nelder-Mead', options={'xatol': 1e-6, 'fatol': 1e-10})
    print(np.round([r.x[0], np.exp(r.x[1]), r.fun], 3))          # [-2.984  1.023  0.689], затем [2.984 1.023 0.689]
print(0.0, round(np.sqrt(1 + 9), 3))         # 0.0 3.162: прямая KL совпадает по моментам, среднее 0 и дисперсия 1 + 3^2
```

Среднее поле работает быстро и детерминированно, а его ошибки систематичны: сообщаемые им дисперсии занижены на величину, которую оно не может измерить.
