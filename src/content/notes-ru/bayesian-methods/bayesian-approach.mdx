Одиннадцать урн помечены $u = 0, 1, \dots, 10$; в урне $u$ лежат $u$ чёрных шаров и $10 - u$ белых. Кто-то выбирает урну наугад, тянет $N = 10$ шаров с возвращением и видит $n_B = 3$ чёрных. Какова вероятность, что следующий шар чёрный? Задача взята из книги [MacKay (2003](#references), раздел 2.3).

Рабочий метод курса машинного обучения отвечает в два шага. Сначала параметр подгоняется [методом максимального правдоподобия](/ru/notes/probability/maximum-likelihood#maximizing-it): доля чёрных шаров в урне $u$ равна $f_u = u/10$, правдоподобие $f_u^{3}(1 - f_u)^{7}$ максимально при $u = 3$, потому что производная $3 \ln f + 7 \ln(1 - f)$, равная $3/f - 7/(1 - f)$, обращается в нуль при $f = 0.3$. Поэтому подогнанной оказывается урна 3. Затем она подставляется (plug-in): следующий шар чёрный с вероятностью $f_3 = 0.3$.

Этот ответ не учитывает, что урны 2 и 4 объясняют данные почти так же хорошо. При меньшем объёме данных недостаток превращается в ошибку. После трёх шаров, и все белые, метод максимального правдоподобия выбирает урну 0 и утверждает, что чёрный шар невозможен.

[Заметка о байесовском выводе](/ru/notes/probability/bayesian-inference) из курса теории вероятностей показала на примере одной монеты другой путь: хранить распределение на параметре, обновлять его по данным и предсказывать, усредняя по нему. Этот курс строит так модели машинного обучения. Модель собирается из нескольких стандартных распределений, всё неизвестное в ней получает распределение, а обучение — это вычисление апостериорного распределения.

## Два прочтения вероятности \{#two-readings-of-probability\}

Правила теории вероятностей, [правила суммы и произведения и формула Байеса](/ru/notes/probability/conditional-probability-and-bayes#bayes-formula), в обоих прочтениях одни и те же. Различается то, о чём говорит вероятность, а значит, и то, каким величинам её можно приписать.

В **частотном** (frequentist) прочтении вероятность — это предельная частота исхода в повторяемом эксперименте. Параметр, например вероятность выпадения орла у монеты, — фиксированное неизвестное число. Распределения у него нет, а утверждения о нём — это утверждения о процедурах: 95-процентный доверительный интервал — это правило, которое накрывает истинное значение в 95% повторных выборок.

В **байесовском** прочтении вероятность — это степень уверенности (degree of belief) в утверждении при имеющейся информации. Ничего не обязано быть повторяемым. У утверждений «это письмо — спам» и «третий вес этой сети положителен» есть вероятность, как только мы сказали, что нам известно. Бросок монеты случаен в том же смысле: зная точный импульс, массу и сопротивление воздуха, его можно было бы рассчитать, и неопределённость возникает только оттого, что мы их не знаем. Тогда любая неизвестная величина, в том числе параметр, может иметь распределение.

Тогда у одного и того же события могут быть разные вероятности для разных наблюдателей. Пассажир, который много месяцев ездит на автобусе в 10:30, знает, что тот приходит в пределах примерно семи минут от расписания; пассажир, чьё приложение отслеживает автобус, знает время прибытия с точностью примерно до трёх минут. Оба описывают одно прибытие распределениями разной ширины, потому что знают разное. Часть случайности может быть неустранимой, как при радиоактивном распаде, но байесовскому прочтению не нужно решать, какая именно.

| | Частотный подход | Байесовский подход |
| --- | --- | --- |
| Вероятность — это | предельная частота | степень уверенности при данной информации |
| Параметр $\theta$ — это | фиксированная неизвестная константа | случайная величина с априорным распределением |
| Вывод даёт | оценку $\hat\theta$ и её поведение на повторных выборках | апостериорное распределение $p(\theta \mid X)$ |
| Типичный метод | максимальное правдоподобие, доверительные интервалы | формула Байеса, байесовские доверительные интервалы (credible intervals), предсказательные средние |
| Когда обоснован | для некоторых моделей точно, в общем случае асимптотически | согласован при любом $n$, если модель и априорное распределение верны |

С последней строкой нужна осторожность. Некоторые частотные процедуры точны при любом объёме выборки. Для нормальных данных [t-интервал](/ru/notes/probability/confidence-intervals-and-bootstrap#intervals-from-the-normal-approximation) накрывает среднее ровно в 95% выборок. Интервал Клоппера–Пирсона для биномиальной доли оставляет каждое значение $p_0$, которое не отвергает ни один из двух односторонних биномиальных критериев гипотезы $p = p_0$ на уровне 2.5%. Тогда истинное значение исключается, только когда его отвергает один из двух критериев, а вероятность этого не больше 5% при любом $n$ ([Clopper and Pearson, 1934](#references)). Формула Байеса, со своей стороны, делает ответы на малых выборках согласованными с моделью и априорным распределением, но не более точными: они хороши ровно настолько, насколько хороши эти двое.

Для машинного обучения эта строка всё равно важна. У глубокой сети или тематической модели параметров больше, чем способна определить любая выборка, поэтому асимптотические аргументы, на которых держится метод максимального правдоподобия, неприменимы. Формула Байеса применима при любом объёме выборки, даже нулевом: тогда апостериорное распределение совпадает с априорным. Когда выборка растёт при фиксированной модели, апостериорное распределение сосредотачивается в оценке максимального правдоподобия по [теореме Бернштейна–фон Мизеса](/ru/notes/probability/bayesian-inference#priors-and-large-samples) при её условиях регулярности, и оба прочтения дают одни и те же ответы. Плата за байесовское прочтение — априорное распределение, которое нужно выбрать и обосновать, и интеграл, который нужно вычислить.

### Почему уверенность подчиняется правилам теории вероятностей \{#why-beliefs-obey-the-rules-of-probability\}

*Необязательное углубление: два аргумента в пользу того, чтобы считать степени уверенности вероятностями. Остальная часть заметки от него не зависит.*

Почему степени уверенности должны складываться и перемножаться, как частоты? Р. Т. Кокс показал в 1946 году: если уверенность выражается вещественными числами, согласуется с обычной логикой, когда утверждения достоверны, и удовлетворяет нескольким требованиям согласованности, то эти числа можно перемасштабировать так, что они будут подчиняться правилам суммы и произведения ([MacKay, 2003](#references), раздел 2.2; [Bishop, 2006](#references), раздел 1.2.3). Теория вероятностей оказывается тогда расширением булевой логики на недостоверные утверждения. Полный вывод обоих правил из этих требований дан у [Jaynes (2003](#references), глава 2).

Второй аргумент использует ставки. Пусть некто оценивает пари, которое платит 1, если $A$ произойдёт, в 0.6, и пари, которое платит 1, если $A$ не произойдёт, тоже в 0.6, так что его степени уверенности в сумме дают 1.2. Букмекер продаёт ему оба пари за 1.2. Выплату 1 приносит ровно одно из них, поэтому он теряет 0.2 при любом исходе. Для любых цен, нарушающих аксиомы теории вероятностей для конечного числа событий, найдётся такой набор пари с гарантированным проигрышем, а для цен, подчиняющихся им, — нет: это теорема де Финетти о голландской книге (Dutch book) ([Vineberg, 2022](#references), разделы 1.1 и 1.3).

## Байесовские рассуждения на числах \{#bayesian-reasoning-with-numbers\}

### Какая урна? \{#which-urn\}

Пусть априорная вероятность каждой урны равна $1/11$. При данной урне вытаскивания независимы, поэтому по правилу произведения конкретная последовательность с $n_B$ чёрными шарами из $N$ имеет при урне $u$ вероятность $f_u^{\,n_B} (1 - f_u)^{N - n_B}$. Формула Байеса для одиннадцати гипотез, с правилом суммы в знаменателе, даёт

$$
p(u \mid n_B, N) = \frac{f_u^{\,n_B} (1 - f_u)^{N - n_B}}{\sum_{v=0}^{10} f_v^{\,n_B} (1 - f_v)^{N - n_B}} ,
$$

где равные априорные вероятности $1/11$ сократились между числителем и каждым слагаемым знаменателя. При $n_B = 3$ из $N = 10$:

| Урна $u$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| $p(u \mid n_B, N)$ | 0.063 | 0.221 | 0.293 | 0.236 | 0.129 | 0.047 | 0.010 | 0.001 |

Урны 0, 9 и 10 исключены или почти исключены. Урна 3 самая вероятная, но на неё приходится меньше трети апостериорной массы.

Вероятность того, что следующий шар чёрный, получается в три шага. Обозначим через $D$ уже увиденные шары:

$$
\begin{aligned}
p(\text{чёрный} \mid D)
&= \sum_{u=0}^{10} p(\text{чёрный}, u \mid D) && \text{(правило суммы)} \\
&= \sum_{u=0}^{10} p(\text{чёрный} \mid u, D)\, p(u \mid D) && \text{(правило произведения)} \\
&= \sum_{u=0}^{10} f_u\, p(u \mid D) && \text{(шары независимы при данном } u) \\
&= 0.333 .
\end{aligned}
$$

Первые две строки — это [формула полной вероятности](/ru/notes/probability/conditional-probability-and-bayes#the-law-of-total-probability), применённая при данном $D$. Третья верна потому, что, когда урна известна, прежние шары ничего не добавляют о следующем.

Это значение и приводит Маккай, против $0.3$ при подстановке. Байесовский ответ больше, потому что апостериорное распределение несимметрично: урны, в которых чёрных шаров больше, чем в урне 3, сохраняют больше массы, чем урны, в которых их меньше.

### Монета с неизвестной несимметричностью \{#a-coin-with-an-unknown-bias\}

Заменим одиннадцать урн континуумом: монета, вероятность орла $f$ у которой может быть любым числом из $[0, 1]$, с равномерным априорным распределением. Апостериорное распределение после $n_B$ орлов в $N$ бросках — $\mathrm{Beta}(1 + n_B,\ 1 + N - n_B)$, [сопряжённое обновление](/ru/notes/probability/bayesian-inference#conjugate-priors-the-beta-binomial) из курса теории вероятностей. Для 3 орлов из 10 это $\mathrm{Beta}(4, 8)$. Те же три шага с интегралом по $f$ дают $p(\text{орёл} \mid D) = \int_0^1 f\, p(f \mid D)\, df$, апостериорное среднее, а среднее распределения $\mathrm{Beta}(a, b)$ равно $a/(a + b)$ ([заметка о байесовском выводе](/ru/notes/probability/bayesian-inference#conjugate-priors-the-beta-binomial)):

$$
\frac{n_B + 1}{N + 2} = \frac{4}{12} = 0.333 ,
$$

это правило Лапласа (rule of succession). Урны были сеткой из одиннадцати значений $f$, и сетка уже даёт непрерывный ответ с точностью до трёх знаков.

Для трёх белых шаров из трёх апостериорное распределение по урнам равно $0.331, 0.241, 0.169, 0.113, \dots$ для $u = 0, 1, 2, 3, \dots$, а вероятность того, что следующий шар чёрный, равна $0.163$: мала, но не нулевая. Модель, которая предсказала 0, а затем увидела чёрный шар, заплатила бы бесконечные логарифмические потери. Предсказательное распределение платит $-\ln 0.163 = 1.82$ ната (nats).

### Последовательное обновление \{#sequential-updating\}

Данные, которые приходят порциями, можно обрабатывать по одной порции. Разобьём десять вытаскиваний из урны на $X_1$, первые пять (два чёрных), и $X_2$, последние пять (один чёрный). Мы хотим выразить апостериорное распределение после обеих порций через $p(\theta \mid X_1)$ — апостериорное распределение, которое у нас уже есть после первой.

Инструмент — формула Байеса с дополнительным условием $x$, которое остаётся справа от каждой черты:

$$
p(y \mid x, z) = \frac{p(z \mid x, y)\, p(y \mid x)}{p(z \mid x)} .
$$

Это обычная формула в мире, где $x$ известен, а знаменатель — снова правило суммы, за которым следует правило произведения.

<details>
<summary>Вывод</summary>

Её можно получить двумя способами. Первый: применим определение условного распределения, затем правило произведения к числителю и знаменателю и сократим $p(x)$:

$$
\begin{aligned}
p(y \mid x, z)
&= \frac{p(x, y, z)}{p(x, z)} && \text{(определение)} \\
&= \frac{p(z \mid x, y)\, p(y \mid x)\, p(x)}{p(z \mid x)\, p(x)} && \text{(правило произведения)} .
\end{aligned}
$$

Второй: при фиксированном $x$ функция $p(\cdot \mid x)$ сама является распределением вероятностей, поэтому подчиняется правилам суммы и произведения, а значит, и формуле Байеса; условие $x$ во всех местах не меняет ни одного шага. Знаменатель получается из правила суммы и затем правила произведения, оба при данном $x$:

$$
\begin{aligned}
p(z \mid x)
&= \int p(z, y \mid x)\, dy \\
&= \int p(z \mid x, y)\, p(y \mid x)\, dy .
\end{aligned}
$$

Если $z$ не зависит от $x$ при данном $y$, первый множитель равен $p(z \mid y)$, и $p(z \mid x) = \int p(z \mid y)\, p(y \mid x)\, dy$: именно этот вид используется дальше.

</details>

Теперь положим $y = \theta$, $x = X_1$, $z = X_2$ и предположим, что порции независимы при данном $\theta$, так что $p(X_2 \mid \theta, X_1) = p(X_2 \mid \theta)$. Тогда

$$
\begin{aligned}
p(\theta \mid X_1, X_2)
&= \frac{p(X_2 \mid \theta, X_1)\, p(\theta \mid X_1)}{p(X_2 \mid X_1)} && \text{(Байес при данном } X_1) \\
&= \frac{p(X_2 \mid \theta)\, p(\theta \mid X_1)}{p(X_2 \mid X_1)} && \text{(независимость при данном } \theta),
\end{aligned}
$$

а нормировочная константа следует из правил суммы и произведения при данном $X_1$ и той же независимости:

$$
p(X_2 \mid X_1) = \int p(X_2 \mid \theta)\, p(\theta \mid X_1)\, d\theta .
$$

Вместе:

$$
\boxed{\;p(\theta \mid X_1, X_2) = \frac{p(X_2 \mid \theta)\, p(\theta \mid X_1)}{\int p(X_2 \mid \theta)\, p(\theta \mid X_1)\, d\theta}\;}
$$

У каждой части своя роль. Апостериорное распределение после первой порции, $p(\theta \mid X_1)$, играет роль априорного. Правдоподобие — это правдоподобие одной второй порции. Нормировочная константа $p(X_2 \mid X_1)$ — предсказательная вероятность второй порции при данной первой, то же усреднение по апостериорному распределению, что и для следующего шара выше. Для урн это сумма по одиннадцати урнам, она равна $0.0455$; обоснованность первой порции $p(X_1) = 0.01515$, и их произведение $0.000689$ равно $p(X_1, X_2)$, обоснованности всех десяти вытаскиваний, как и требует правило произведения.

Разбиение не важно. Подставим формулу Байеса вместо $p(\theta \mid X_1)$ и правило произведения $p(X_2 \mid X_1) = p(X_1, X_2) / p(X_1)$; множитель $p(X_1)$ сокращается:

$$
\begin{aligned}
p(\theta \mid X_1, X_2)
&= \frac{p(X_2 \mid \theta)\, p(X_1 \mid \theta)\, p(\theta)}{p(X_1, X_2)} && \text{(подстановка)} \\
&= \frac{p(X_1, X_2 \mid \theta)\, p(\theta)}{p(X_1, X_2)} && \text{(независимость при данном } \theta) .
\end{aligned}
$$

Это апостериорное распределение по всем данным сразу. Оно симметрично по $X_1$ и $X_2$, поэтому ни разбиение, ни порядок порций его не меняют.

В разделе «Код» апостериорное распределение по урнам обновляется по одному шару и совпадает с ответом для всей выборки с точностью до $10^{-12}$. Между порциями не нужно хранить ничего, кроме апостериорного распределения, поэтому байесовское обучение подходит для потоковых данных. [Стохастический вариационный вывод](/ru/notes/bayesian-methods/stochastic-variational-inference) масштабирует эту идею на миллионы документов.

## Априорное распределение, правдоподобие, апостериорное и предсказательное распределения \{#prior-likelihood-posterior-and-predictive\}

Обозначим через $X = (x_1, \dots, x_n)$ наблюдаемые данные, а через $\theta$ — неизвестные параметры. Общая схема состоит из четырёх объектов. **Априорное распределение** (prior) $p(\theta)$ выражает то, во что верят до данных. **Правдоподобие** (likelihood) $p(X \mid \theta)$ описывает, как порождаются данные при каждом значении параметра. Формула Байеса объединяет их в **апостериорное распределение** (posterior):

$$
\begin{aligned}
p(\theta \mid X) &= \frac{p(X \mid \theta)\, p(\theta)}{p(X)}, \\
p(X) &= \int p(X \mid \theta)\, p(\theta)\, d\theta .
\end{aligned}
$$

Нормировочная константа $p(X)$ называется **обоснованностью** (evidence), или маргинальным правдоподобием (marginal likelihood); её интеграл — это правило суммы по $\theta$, за которым следует правило произведения $p(X, \theta) = p(X \mid \theta)\, p(\theta)$. В курсе теории вероятностей априорное распределение обозначалось $\pi(\theta)$; в этом курсе любая плотность записывается как $p(\cdot)$, а о том, какая именно имеется в виду, говорит аргумент.

Апостериорное и совместное распределения отличаются только этой нормировкой: $p(\theta, X) = p(\theta \mid X)\, p(X)$, а $p(X)$ не зависит от $\theta$. Как функции от $\theta$ они имеют одну форму и один максимум, но интеграл по $\theta$ равен 1 только у апостериорного; у совместного он равен $p(X)$. Поэтому «апостериорное = правдоподобие × априорное» верно лишь с точностью до этой константы: $p(\theta \mid X) \propto p(X \mid \theta)\, p(\theta)$. Для трёх чёрных шаров в десяти вытягиваниях совместная вероятность $p(u, X) = p(X \mid u)/11$ в сумме по урнам даёт $p(X) = 0.000689$. Её наибольшее значение, $0.000202$, достигается на урне 3, как и наибольшая апостериорная вероятность, $0.000202/0.000689 = 0.293$.

Ответ на вопрос о новых данных — это **предсказательное распределение** (predictive distribution), то есть предсказания модели, усреднённые по апостериорному распределению. Оно получается теми же тремя шагами, что и для следующего шара:

$$
\begin{aligned}
p(x_* \mid X)
&= \int p(x_*, \theta \mid X)\, d\theta && \text{(правило суммы)} \\
&= \int p(x_* \mid \theta, X)\, p(\theta \mid X)\, d\theta && \text{(правило произведения)} \\
&= \int p(x_* \mid \theta)\, p(\theta \mid X)\, d\theta .
\end{aligned}
$$

Последняя строка предполагает, что новые и старые данные независимы при данном $\theta$.

Для модели обучения с учителем со входами $X$, целевыми значениями $T = (t_1, \dots, t_n)$ и весами $w$ модель утверждает, что целевые значения независимы при данных входах и весах, поэтому правдоподобие равно $p(T \mid X, w) = \prod_i p(t_i \mid x_i, w)$. Апостериорное распределение задано на весах. Те же три шага дают предсказание для нового входа $x_*$ при двух модельных предположениях: $t_*$ зависит от данных только через $w$, а новый вход сам по себе ничего не говорит о $w$, так что $p(w \mid x_*, X, T) = p(w \mid X, T)$:

$$
p(t_* \mid x_*, X, T) = \int p(t_* \mid x_*, w)\, p(w \mid X, T)\, dw .
$$

Это голосование всех моделей, которые описывают веса, где голос каждой взвешен её апостериорной вероятностью.

Каждый шаг после записи модели — это интеграл. Обоснованность не меняет форму апостериорного распределения, но именно по ней [сравниваются целые модели](/ru/notes/bayesian-methods/bayesian-model-selection). Для немногих пар «априорное распределение — правдоподобие», [сопряжённых пар](/ru/notes/bayesian-methods/conjugate-priors), эти интегралы берутся в замкнутом виде. Для остальных курс строит приближения.

## Что теряет точечная оценка \{#what-a-point-estimate-throws-away\}

Обозначим через $\hat\theta$ точечную оценку, максимального правдоподобия или MAP:

$$
\begin{aligned}
\hat\theta_{\text{ML}} &= \arg\max_\theta\, p(X \mid \theta), \\
\hat\theta_{\text{MAP}} &= \arg\max_\theta\, p(X \mid \theta)\, p(\theta) .
\end{aligned}
$$

В строке MAP из формулы Байеса выброшено $p(X)$: оно не зависит от $\theta$ и поэтому не сдвигает максимум. Для независимых одинаково распределённых данных правдоподобие — произведение по точкам, логарифм превращает его в сумму, а априорное распределение входит один раз на весь набор данных:

$$
\hat\theta_{\text{MAP}} = \arg\max_\theta \Big(\sum_{i=1}^n \log p(x_i \mid \theta) + \log p(\theta)\Big) .
$$

Запись $\prod_i p(x_i \mid \theta)\, p(\theta)$ с априорным распределением внутри произведения учла бы его $n$ раз, как если бы априорным было $p(\theta)^n$. Для гауссовского априорного распределения $\mathcal N(0, \alpha^{-1} I)$ это умножает гребневый штраф $\frac\alpha2 \lVert\theta\rVert^2$ на $n$, потому что $\big(e^{-\alpha\lVert\theta\rVert^2/2}\big)^n = e^{-n\alpha\lVert\theta\rVert^2/2}$.

Пользуясь точечной оценкой, мы заменяем апостериорное распределение пиком в одном значении, $p(\theta \mid X) \approx \delta(\theta - \hat\theta)$. В интеграле для предсказательного распределения дельта-функция выбирает значение подынтегрального выражения в $\hat\theta$, и предсказательное распределение превращается в подстановку $p(x_* \mid \hat\theta)$. Приближение хорошее, когда апостериорное распределение — узкий пик; это режим больших выборок из [теоремы Бернштейна–фон Мизеса](/ru/notes/probability/bayesian-inference#priors-and-large-samples). Вне этого режима теряется несколько вещей.

Первая — неопределённость. После трёх белых шаров и метод максимального правдоподобия, и MAP с равномерным априорным распределением выбирают урну 0 и предсказывают чёрный шар с вероятностью 0, тогда как предсказательное распределение даёт $0.163$. Точечная оценка не может сказать, насколько данные ограничили параметр. Кроме того, предсказательное распределение шире предсказания любой отдельной модели: для среднего нормального распределения его дисперсия равна дисперсии шума плюс апостериорная дисперсия среднего ([заметка о байесовском выводе](/ru/notes/probability/bayesian-inference#predicting-with-the-posterior)), а подстановка сохраняет только первое слагаемое.

Вторая — выбор сводки. Лучшее единственное число зависит от функции потерь, по которой его будут оценивать: апостериорное среднее минимизирует ожидаемую квадратичную ошибку, медиана — ожидаемую абсолютную ошибку, а мода — ожидаемую функцию потерь 0–1 (вывод ниже). После трёх белых шаров мода, медиана и среднее доли $f_u$ равны $0$, $0.1$ и $0.163$: три ответа из одного апостериорного распределения.

<details>
<summary>Вывод</summary>

Пусть $a$ — сообщаемое число, а $m = \mathbb E[\theta \mid X]$. Для квадратичной ошибки прибавим и вычтем $m$ под квадратом; перекрёстный член имеет нулевое апостериорное среднее:

$$
\mathbb E\big[(\theta - a)^2 \mid X\big] = \operatorname{Var}(\theta \mid X) + (m - a)^2 ,
$$

что минимально при $a = m$. Для абсолютной ошибки производная $\lvert \theta - a \rvert$ по $a$ равна $+1$ при $\theta < a$ и $-1$ при $\theta > a$, поэтому производная ожидаемых потерь равна $P(\theta < a \mid X) - P(\theta > a \mid X)$. Она обращается в нуль, где обе вероятности равны $1/2$, то есть в медиане. Для дискретного $\theta$, как у урн, функция потерь 0–1 имеет среднее $1 - P(\theta = a \mid X)$, минимальное в самом вероятном значении. Для непрерывного $\theta$ потери 1 вне окна $\lvert \theta - a \rvert < \varepsilon$ имеют среднее примерно $1 - 2\varepsilon\, p(a \mid X)$ при малом $\varepsilon$, минимальное в моде.

</details>

Кроме того, MAP-оценка меняется при перепараметризации $\theta$, а апостериорное распределение — нет ([заметка о байесовском выводе](/ru/notes/probability/bayesian-inference#map-estimation-and-regularization)). Причина — правило замены переменных: для $\phi = g(\theta)$ плотность $\phi$ равна плотности $\theta$, умноженной на $\lvert d\theta / d\phi \rvert$, а этот множитель меняется вместе с $\phi$ и сдвигает максимум; вероятности же событий переносятся без изменений.

Третья — форма. Апостериорное распределение с несколькими модами, например у смеси, компоненты которой можно перенумеровать, представляется одной из них. Обмануть может даже самая высокая точка. Возьмём плотность $0.9\, \mathcal N(0, 1) + 0.1\, \mathcal N(4, 0.01^2)$. Её мода находится в точке 4, на вершине иглы, в которой лежит десятая часть массы, высотой $0.1/(0.01\sqrt{2\pi}) = 3.99$. Остальные девять десятых лежат в широком горбе около 0 высотой всего $0.9/\sqrt{2\pi} = 0.359$. MAP-оценка сообщает 4 — значение, рядом с которым почти ничего не вероятно.

Четвёртая — объединение источников. При [последовательном обновлении](#sequential-updating) апостериорное распределение по одному набору данных служит априорным для следующего, и результат — апостериорное распределение по обоим. Точечную оценку так передать нельзя. В роли априорного распределения она была бы точечной массой в $\hat\theta$, а поскольку апостериорное распределение — это априорное, умноженное на правдоподобие, оно было бы равно нулю везде, где равно нулю априорное: никакие новые данные его не сдвинут.

Последняя — способ сравнивать модели. Наилучшее правдоподобие $p(X \mid \hat\theta)$ не убывает с ростом модели: бо́льшая модель содержит меньшую как частный случай, а максимум по большему множеству не может быть меньше. Поэтому оно всегда предпочитает самую большую модель. Обоснованность, интеграл по всем значениям параметров, так себя не ведёт.

MAP-оценивание, которое иногда называют «байесовским выводом для бедных» (poor man's Bayes), по-прежнему основной инструмент практики, и [гребневая регрессия и затухание весов — это MAP-оценки](/ru/notes/ml/regularization#the-bayesian-reading). Байесовский подход их не запрещает. Он говорит, что именно они приближают, чтобы мы знали, когда приближение безопасно.

## Модель — это граф из стандартных блоков \{#a-model-is-a-graph-of-standard-blocks\}

В реалистичных моделях много неизвестных: параметры, гиперпараметры, управляющие априорными распределениями, и скрытые переменные, по одной на наблюдение, например номер кластера точки в [гауссовской смеси](/ru/notes/ml/em-algorithm#the-gaussian-mixture-model). Записать их совместное распределение напрямую безнадёжно. **Байесовская сеть** (Bayesian network), или ориентированная графическая модель, записывает его как произведение небольших условных распределений, по одному для каждой переменной при условии её родителей $\mathrm{pa}(v_j)$ в ориентированном ациклическом графе. Пронумеруем переменные так, чтобы родители шли раньше детей. Правило произведения даёт $p(v_1, \dots, v_m) = \prod_j p(v_j \mid v_1, \dots, v_{j-1})$ для любого совместного распределения, а сеть — это предположение, по определению, что каждый множитель зависит только от родителей:

$$
p(v_1, \dots, v_m) = \prod_{j=1}^m p(v_j \mid \mathrm{pa}(v_j)) .
$$

Каждый множитель — стандартный блок: бернуллиевский или категориальный выбор, гауссиана, среднее которой — линейная функция родителей, гамма-распределение для обратной дисперсии, бета-распределение или распределение Дирихле для вероятностей. Повторяющийся блок, например $n$ наблюдений с общим параметром, рисуют один раз внутри прямоугольника — **пластины** (plate) — с $n$ в углу. Наблюдаемые переменные закрашивают.

Вывод — всегда одна и та же операция: взять условное распределение при закрашенных переменных и маргинализовать те, о которых не спрашивают. Определение условного распределения даёт отношение $p(\text{запрос}, \text{наблюдаемые}) / p(\text{наблюдаемые})$, а правило суммы, применённое к числителю и знаменателю, сводит оба к совместному распределению:

$$
p(\text{запрос} \mid \text{наблюдаемые}) = \frac{\sum_{\text{остальные}} p(\text{запрос}, \text{остальные}, \text{наблюдаемые})}{\sum_{\text{запрос}, \text{остальные}} p(\text{запрос}, \text{остальные}, \text{наблюдаемые})} ,
$$

где для непрерывных переменных суммы заменяются интегралами. Параметры — просто ещё несколько ненаблюдаемых вершин, поэтому байесовскому подходу не нужна для них отдельная теория.

### Объяснение другой причиной: разобранный пример \{#explaining-away-a-worked-example\}

В доме стоит охранная сигнализация. Это классический пример, который разбирается и в первой лекции [Ветрова и Кропотова](#references). Кража $B$ и землетрясение $E$ происходят независимо, $P(B = 1) = 0.01$ и $P(E = 1) = 0.02$. Каждое из этих событий может включить сигнализацию $A$, а радио $R$ сообщает о землетрясениях. В графе есть стрелки $B \to A$, $E \to A$ и $E \to R$, а совместное распределение равно $p(b)\, p(e)\, p(a \mid b, e)\, p(r \mid e)$ со следующими таблицами:

| | $b = 0, e = 0$ | $b = 0, e = 1$ | $b = 1, e = 0$ | $b = 1, e = 1$ |
| --- | --- | --- | --- | --- |
| $P(A = 1 \mid b, e)$ | $0.001$ | $0.3$ | $0.9$ | $0.95$ |

и $P(R = 1 \mid E = 1) = 0.8$, $P(R = 1 \mid E = 0) = 0.001$.

<AlarmNetwork />

Когда срабатывает сигнализация, мы сначала маргинализуем землетрясение в таблице сигнализации — по правилам суммы и произведения, причём $P(e \mid b) = P(e)$, так как $B$ и $E$ независимы, — а затем применяем формулу Байеса:

$$
\begin{aligned}
P(A = 1 \mid B = 1) &= 0.98 \cdot 0.9 + 0.02 \cdot 0.95 = 0.901, \\
P(A = 1 \mid B = 0) &= 0.98 \cdot 0.001 + 0.02 \cdot 0.3 = 0.00698, \\
P(B = 1 \mid A = 1) &= \frac{0.901 \cdot 0.01}{0.901 \cdot 0.01 + 0.00698 \cdot 0.99} = 0.566 .
\end{aligned}
$$

Редкое событие становится более вероятным объяснением. Точно так же $P(E = 1 \mid A = 1) = 0.385$.

Затем радио сообщает о землетрясении. Тот же перебор по совместной таблице (раздел «Код») даёт $P(E = 1 \mid A = 1, R = 1) = 0.998$, а вероятность кражи падает обратно до $P(B = 1 \mid A = 1, R = 1) = 0.033$. Землетрясение объясняет сигнализацию, и свидетельство в пользу кражи **объясняется другой причиной** (explaining away).

Граф делает этот механизм видимым. Априори $B$ и $E$ независимы: знание о том, что было землетрясение, оставляет $P(B = 1 \mid E = 1) = 0.01$. Как только наблюдается их общее следствие $A$, они становятся зависимыми, и $P(B = 1 \mid E = 1, A = 1) = 0.031$. [Bishop (2006](#references), раздел 8.2.1) показывает ту же схему на датчике уровня топлива. По этой же причине [апостериорное распределение весов регрессии](/ru/notes/bayesian-methods/bayesian-linear-regression#the-posterior-over-the-weights) коррелировано, даже если их априорное распределение независимо, и у скрытых переменных большинства моделей этого курса нет простого совместного апостериорного распределения.

### Модели курса как композиции \{#the-models-of-this-course-as-compositions\}

Каждая модель курса — композиция одних и тех же немногих блоков, и метод вывода следует из композиции:

| Модель | Блоки | Апостериорное распределение |
| --- | --- | --- |
| Бета–Бернулли, нормальное–гамма | сопряжённое априорное распределение и его правдоподобие | точное, в замкнутом виде |
| Байесовская линейная регрессия | гауссовское априорное распределение на $w$, линейно-гауссовское правдоподобие | точная гауссиана |
| Метод релевантных векторов | то же с отдельной априорной обратной дисперсией для каждого веса | максимизация обоснованности |
| Байесовская логистическая регрессия | гауссовское априорное распределение, бернуллиевское правдоподобие с сигмоидой | приближение Лапласа |
| Гауссовская смесь, вероятностный PCA | категориальная или гауссовская скрытая переменная, гауссовское правдоподобие | EM, вариационный вывод |
| Латентное размещение Дирихле | априорные распределения Дирихле, два категориальных слоя | вариационный вывод, сэмплирование по Гиббсу |
| Вариационный автоэнкодер | гауссовское априорное распределение, правдоподобие, заданное нейросетью | амортизированный вариационный вывод |

## Где это ломается: верное вычисление в неверной модели \{#where-it-breaks-a-correct-computation-in-a-wrong-model\}

Формула Байеса согласованна при условии модели. Исправить модель она не может. Ветров и Кропотов заканчивают пример с сигнализацией тем, что хозяин, успокоенный сообщением по радио, возвращается в ограбленную квартиру. Все вычисления были верны, неверен был граф. Грабители тоже слушают радио, и ночь землетрясения для них удачна, так что $B$ и $E$ никогда не были независимы.

Внесём это в модель в виде игрушечного числа. Пусть в ночь землетрясения кража в двадцать раз вероятнее, $P(B = 1 \mid E = 1) = 0.2$, а $P(B = 1 \mid E = 0) = 0.01$ остаётся прежней. В графе появляется стрелка $E \to B$, и тот же перебор даёт:

| Уверенность | независимые причины | $P(B = 1 \mid E = 1) = 0.2$ |
| --- | --- | --- |
| $P(B = 1)$ | $0.010$ | $0.014$ |
| $P(B = 1 \mid A = 1)$ | $0.566$ | $0.686$ |
| $P(B = 1 \mid A = 1, R = 1)$ | $0.033$ | $0.443$ |

Сообщение по радио, которое делало кражу пренебрежимо маловероятной, теперь оставляет её шансы почти равными. Априорная вероятность кражи почти не сдвинулась, с $0.010$ до $0.014$, поэтому никакая проверка маргинальных частот не выявила бы ошибку. Изменилась только зависимость, а именно на зависимости и держится объяснение другой причиной.

То же происходит с правдоподобием, которое неверно описывает данные. Апостериорное распределение уверенно сосредотачивается на параметре, модель которого ближе всего к истине по KL-дивергенции, — в том же пределе, что и метод максимального правдоподобия. Причина — закон больших чисел: $\frac1n \log p(X \mid \theta)$ стремится к среднему $\log p(x \mid \theta)$ по истинному распределению, а это минус та же KL-дивергенция плюс константа. Поэтому правдоподобие ведёт себя как $e^{-n \mathrm{KL}}$ с точностью до множителя, не зависящего от $\theta$, и подавляет априорное распределение. Условия и доказательство предела даны у [Kleijn и van der Vaart (2012)](#references).

Две другие издержки иного рода. Априорное распределение нужно выбрать, и на малых данных оно определяет ответ, так что его влияние приходится проверять; [заметка о выборе модели](/ru/notes/bayesian-methods/bayesian-model-selection) показывает, что обоснованность зависит от него ещё сильнее, чем апостериорное распределение. Кроме того, интегралы трудны: перебор $m$ бинарных переменных требует $2^m$ слагаемых, а апостериорные распределения непрерывных параметров в замкнутом виде существуют по сути лишь для сопряжённых и линейно-гауссовских моделей. Остальная часть курса посвящена их приближению.

## Что нужно запомнить \{#what-you-should-remember\}

- Байесовское прочтение: вероятность — степень уверенности, и любая неизвестная величина, в том числе параметр, получает распределение.
- Апостериорное ∝ правдоподобие × априорное; обоснованность $p(X)$ нормирует апостериорное распределение и позволяет сравнивать модели.
- Предсказываем усреднением по апостериорному распределению: в задаче об урнах это $0.333$ вместо $0.3$ при подстановке и $0.163$ вместо $0$.
- Для независимых порций данных апостериорное распределение после одной порции служит априорным для следующей.
- Точечная оценка теряет ширину, форму и обоснованность; она безопасна, когда апостериорное распределение — узкий пик.
- Байесовская сеть — произведение блоков, по одному на переменную при условии её родителей. Наблюдение общего следствия делает независимые причины зависимыми, а пропущенная стрелка делает точный ответ неверным.

## Код \{#code\}

Апостериорное распределение по урнам и предсказание, непрерывная монета, три точечные оценки после трёх белых шаров, обманчивая мода, последовательное обновление и его нормировочная константа и сигнализация перебором, с независимыми причинами и с кражами, более вероятными во время землетрясений. Скрипт работает около секунды; точные числа могут отличаться в последнем знаке на разных платформах и версиях библиотек.

```python
import numpy as np
from itertools import product
from scipy import stats

# Какая урна? В урне u лежат u чёрных и 10 - u белых шаров; урна выбирается равновероятно, шары тянут с возвращением
u = np.arange(11)
f = u / 10                                      # доля чёрных шаров в урне u
def urn_posterior(n_black, n_draws, prior=np.full(11, 1 / 11)):
    lik = f ** n_black * (1 - f) ** (n_draws - n_black)
    return lik * prior / (lik * prior).sum()    # формула Байеса для 11 гипотез

post = urn_posterior(3, 10)
print(post.round(3))                            # [0.    0.063 0.221 0.293 0.236 0.129 0.047 0.01  0.001 0.    0.   ]
print(round(post @ f, 3), f[post.argmax()])     # 0.333 0.3: предсказательное распределение против подстановки лучшей урны

# тот же вопрос для непрерывной вероятности и равномерного априорного распределения: Beta(1 + 3, 1 + 7)
print(round(stats.beta(4, 8).mean(), 3))        # 0.333

# три белых шара из трёх: точечные оценки говорят «чёрный никогда»
post = urn_posterior(0, 3)
cdf = post.cumsum()
print(post[:4].round(3), f[post.argmax()], f[np.searchsorted(cdf, 0.5)], round(post @ f, 4))
# [0.331 0.241 0.169 0.113] 0.0 0.1 0.1625: апостериорные мода, медиана и среднее доли чёрных шаров
print(round(-np.log(post @ f), 2))              # 1.82: логарифмические потери предсказательного распределения, если следующий шар чёрный

# обманчивая мода: 0.9 N(0, 1) + 0.1 N(4, 0.01^2), высоты иглы и горба
mix = lambda t: 0.9 * stats.norm.pdf(t, 0, 1) + 0.1 * stats.norm.pdf(t, 4, 0.01)
print(round(mix(4.0), 2), round(mix(0.0), 3), round(0.9 * 0 + 0.1 * 4, 1))   # 3.99 0.359 0.4: мода в 4, среднее 0.4

# последовательное обновление: по одному шару за раз получаем апостериорное распределение для всей выборки
draws = [1, 0, 0, 1, 0, 0, 0, 1, 0, 0]          # 3 чёрных из 10
p = np.full(11, 1 / 11)
for d in draws:
    p = urn_posterior(d, 1, prior=p)
print(np.abs(p - urn_posterior(3, 10)).max() < 1e-12)   # True

# нормировочная константа второго обновления: X1 = первые пять шаров (2 чёрных), X2 = последние пять (1 чёрный)
pX1 = (f ** 2 * (1 - f) ** 3).mean()            # p(X1): правило суммы по урнам с априорной вероятностью 1/11
pX2_X1 = urn_posterior(2, 5) @ (f * (1 - f) ** 4)   # p(X2 | X1) = sum_u p(X2 | u) p(u | X1)
print(round(pX2_X1, 4), round(pX1, 5), round(pX1 * pX2_X1, 6), round((f ** 3 * (1 - f) ** 7).mean(), 6))
# 0.0455 0.01515 0.000689 0.000689: p(X2 | X1), p(X1), их произведение и p(X1, X2)

# сигнализация перебором состояний совместного распределения p(e) p(b | e) p(a | b, e) p(r | e)
pE = 0.02
pA = {(0, 0): 0.001, (0, 1): 0.3, (1, 0): 0.9, (1, 1): 0.95}   # P(a = 1 | b, e)
pR = {0: 0.001, 1: 0.8}                                        # P(r = 1 | e)

def alarm(pB):                                  # pB[e] = P(b = 1 | e); равные значения означают независимые причины
    def joint(b, e, a, r):
        return ((pB[e] if b else 1 - pB[e]) * (pE if e else 1 - pE)
                * (pA[b, e] if a else 1 - pA[b, e]) * (pR[e] if r else 1 - pR[e]))
    def prob(query, evidence):
        states = [dict(zip('bear', s)) for s in product((0, 1), repeat=4)]
        match = lambda s, c: all(s[k] == v for k, v in c.items())
        den = sum(joint(**s) for s in states if match(s, evidence))
        return round(sum(joint(**s) for s in states if match(s, evidence) and match(s, query)) / den, 3)
    return prob

prob = alarm({0: 0.01, 1: 0.01})
print(prob({'b': 1}, {}), prob({'b': 1}, {'a': 1}), prob({'b': 1}, {'a': 1, 'r': 1}))
# 0.01 0.566 0.033: сигнализация повышает уверенность в краже, сообщение по радио объясняет её другой причиной
print(prob({'e': 1}, {'a': 1}), prob({'e': 1}, {'a': 1, 'r': 1}))     # 0.385 0.998
print(prob({'b': 1}, {'e': 1}), prob({'b': 1}, {'e': 1, 'a': 1}))     # 0.01 0.031: независимы, пока не наблюдается сигнализация

# неверный граф: в ночь землетрясения кража в 20 раз вероятнее
prob = alarm({0: 0.01, 1: 0.2})
print(prob({'b': 1}, {}), prob({'b': 1}, {'a': 1}), prob({'b': 1}, {'a': 1, 'r': 1}))
# 0.014 0.686 0.443: сообщение по радио больше не объясняет кражу другой причиной
```

## Дальше \{#next\}

Каждый байесовский ответ в этой заметке был суммой по одиннадцати урнам или шестнадцати состояниям сигнализации. При непрерывных параметрах суммы становятся интегралами, и интеграл в знаменателе формулы Байеса обычно не выражается формулой. [Следующая заметка](/ru/notes/bayesian-methods/conjugate-priors) находит случаи, когда выражается: априорные распределения, которые вместе со своим правдоподобием дают апостериорное распределение из того же семейства, так что обучение сводится к прибавлению счётчиков. Они существуют для каждого члена экспоненциального семейства, в которое входят почти все стандартные блоки этой заметки.
