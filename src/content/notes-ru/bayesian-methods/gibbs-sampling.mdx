[Предыдущая заметка](/ru/notes/bayesian-methods/variational-inference) приблизила апостериорное распределение лучшим факторизованным распределением. Ответ получился быстро и без шума, но с систематической ошибкой: в нормальной модели стандартное отклонение среднего вышло равным $0.410$ вместо $0.449$, и ничто в самом методе этой ошибки не выдавало. **Сэмплирование по Гиббсу** (Gibbs sampling) использует те же ингредиенты — полное условное распределение каждого блока при остальных — по-другому. Вместо того чтобы усреднять логарифм плотности по остальным блокам, оно сэмплирует каждый блок из его условного распределения при текущих значениях остальных. Сэмплы образуют [марковскую цепь](/ru/notes/probability/markov-chain-monte-carlo), распределение которой сходится к точному апостериорному. Эта заметка показывает, почему такое обновление корректно и когда его недостаточно, строит сэмплеры Гиббса для нормальной модели и для байесовской смеси, улучшает их блочной группировкой и сворачиванием и сравнивает два вида ошибки: смещение вариационного вывода и дисперсию сэмплирования.

**Обозначения.** $p(Z)$ — целевое распределение, апостериорное $p(Z \mid X)$, в записи которого данные опущены, а $Z = (Z_1, \dots, Z_m)$ — его блоки; $Z_{-j}$ — все блоки, кроме $Z_j$, а $p(z_j \mid z_{-j})$ — **полное условное распределение** (complete conditional) блока $j$. **Проход** (sweep) обновляет каждый блок один раз. $K(z \to z')$ — переходная плотность цепи. ESS — эффективный размер выборки (effective sample size), а $\hat R$ — потенциальный коэффициент уменьшения масштаба (potential scale reduction factor); обе величины введены в [заметке о MCMC](/ru/notes/probability/markov-chain-monte-carlo#mixing-and-diagnostics). Нормальная модель, её данные $x_1, \dots, x_8$ и её априорное распределение $\mu \mid \lambda \sim \mathcal N(0, 1/\lambda)$, $\lambda \sim \mathrm{Gamma}(2, 2)$ — те же, что в предыдущей заметке.

## Отправная точка: Метрополис–Гастингс со случайным блужданием \{#baseline-metropolishastings-with-a-random-walk\}

[Алгоритм Метрополиса–Гастингса](/ru/notes/probability/markov-chain-monte-carlo#metropolis-hastings) сэмплирует любую плотность, известную с точностью до константы: предложить переход и принять его с вероятностью, которая поправляет на предложение. С предложением в виде случайного блуждания он не учитывает структуру модели, и за это приходится платить. Его размер шага должен подходить сразу всем направлениям: в нормальной модели апостериорные стандартные отклонения равны $0.449$ для $\mu$ и $0.270$ для $\lambda$, а $\lambda$ должна оставаться положительной. В смеси со 100 метками и несколькими непрерывными параметрами совместный случайный сдвиг всего сразу почти всегда отвергается, а один общий размер шага одинаково плох и для дискретных, и для непрерывных блоков.

Модели этого курса собраны из сопряжённых частей. Их полные условные распределения — те самые, что давали замкнутые формулы для множителей среднего поля, — стандартные распределения, из которых можно сэмплировать точно. Сэмплирование по Гиббсу ([Geman and Geman, 1984](#references); [Gelfand and Smith, 1990](#references)) использует их как предложения, которые никогда не отвергаются.

## Обновление Гиббса \{#the-gibbs-update\}

Один проход сэмплера Гиббса с **фиксированным порядком** блоков из текущего состояния $z^{(t)}$:

$$
\begin{aligned}
z_1^{(t+1)} &\sim p\big(z_1 \mid z_2^{(t)}, z_3^{(t)}, \dots, z_m^{(t)}\big), \\
z_2^{(t+1)} &\sim p\big(z_2 \mid z_1^{(t+1)}, z_3^{(t)}, \dots, z_m^{(t)}\big), \\
&\;\;\vdots \\
z_m^{(t+1)} &\sim p\big(z_m \mid z_1^{(t+1)}, \dots, z_{m-1}^{(t+1)}\big) .
\end{aligned}
$$

Каждый блок сэмплируется при **самых новых** значениях остальных. Сэмплер со **случайным порядком** (random scan) вместо этого на каждом шаге выбирает один блок случайно. Условное распределение блока $j$ находится точно так же, как множитель среднего поля, — чтением $\log p(X, Z)$ как функции одного $Z_j$,

$$
\log p(z_j \mid z_{-j}, X) = \log p(X, z) + \text{const},
$$

но остальные блоки при этом зафиксированы на текущих значениях, а не усреднены по $q$. Два метода — близкие родственники: покоординатный вариационный вывод делает множитель равным нормированной $\exp \mathbb E_{-j}[\log p(X, Z)]$, а Гиббс сэмплирует значение из нормированной $\exp \log p(X, z) = p(X, z)$ при текущих значениях остальных.

Использовать самые новые значения — не мелочь. Если обновить все блоки сразу по значениям предыдущего прохода, получится другая цепь с другим стационарным распределением. Для двумерного нормального распределения с корреляцией $0.9$ раздел «Код» находит выборочную корреляцию $0.899$ при последовательном обновлении и $-0.009$ при одновременном: одновременная цепь сэмплирует произведение маргинальных распределений. Причина видна по её ковариации: $\operatorname{Cov}(z_1', z_2') = \rho^2 \operatorname{Cov}(z_2, z_1)$, и единственная неподвижная точка этого соотношения — ноль.

## Почему это корректно \{#why-it-is-valid\}

**Каждое обновление сохраняет целевое распределение.** Пусть текущее состояние $z$ распределено по $p$. Тогда $z_{-j}$ имеет маргинальное распределение $p(z_{-j})$, а новое $z_j'$ берётся из $p(z_j \mid z_{-j})$, поэтому новое состояние $(z_j', z_{-j})$ имеет плотность $p(z_j' \mid z_{-j})\, p(z_{-j}) = p(z_j', z_{-j})$ — снова целевую. В терминах переходной плотности $K_j$ обновления блока $j$

$$
\int K_j(z \to z')\, p(z)\, dz = \int p(z_j' \mid z_{-j}')\, p(z_j, z_{-j}')\, dz_j = p(z_j' \mid z_{-j}')\, p(z_{-j}') = p(z'),
$$

поскольку обновление не меняет $z_{-j}$ ($z_{-j} = z_{-j}'$), а интегрирование совместной плотности по $z_j$ оставляет маргинальную. Проход — композиция таких обновлений, а композиция переходов, каждый из которых сохраняет $p$, сохраняет $p$.

**Каждое обновление — шаг Метрополиса–Гастингса, который всегда принимается.** При предложении $q(z' \mid z) = p(z_j' \mid z_{-j})$ и $z_{-j}' = z_{-j}$ отношение принятия равно

$$
\frac{p(z')\, q(z \mid z')}{p(z)\, q(z' \mid z)} = \frac{p(z_j' \mid z_{-j})\, p(z_{-j}) \cdot p(z_j \mid z_{-j})}{p(z_j \mid z_{-j})\, p(z_{-j}) \cdot p(z_j' \mid z_{-j})} = 1 .
$$

Поэтому каждое отдельное обновление удовлетворяет [условию детального баланса](/ru/notes/probability/markov-chain-monte-carlo#detailed-balance). Систематический проход — фиксированная последовательность обратимых шагов — в общем случае сам не обратим; версия со случайным порядком обратима. Для корректности ни то ни другое не важно: цепи нужна инвариантность.

**Инвариантность — ещё не сходимость.** Цепь должна также уметь попасть в любую область целевого распределения из любой начальной точки — неприводимость (irreducibility) — и не должна зацикливаться — апериодичность. Гиббс двигается вдоль одного блока за раз, и это может не сработать. Пусть $p$ равномерно на объединении квадратов $[0, 1]^2$ и $[-1, 0]^2$, которые касаются только углом. Из точки первого квадрата условное распределение $z_1$ при $z_2 > 0$ равномерно на $[0, 1]$, и условное распределение $z_2$ при $z_1 > 0$ равномерно на $[0, 1]$: цепь никогда не попадает во второй квадрат, и в разделе «Код» она проводит там 0 из 10 000 проходов. Равномерное распределение на каждом из квадратов само по себе стационарно, и цепь, запущенная в одном квадрате, никогда не приближается к $p$ — равной смеси двух. Простое достаточное условие неприводимости — совместная плотность положительна всюду, где положительно произведение её маргинальных плотностей, — это **условие положительности** (positivity condition) ([Robert and Casella, 2004](#references), глава 10). Нормальная модель, плотность которой положительна на $\mathbb R \times (0, \infty)$, ему удовлетворяет.

<aside class="callout"><strong>Ключевая идея.</strong> Сэмплирование по Гиббсу заменяет одно трудное сэмплирование из совместного апостериорного распределения циклом лёгких сэмплирований из полных условных распределений, каждое — при самых новых значениях остальных блоков. Каждый шаг сохраняет апостериорное распределение, поэтому цепь, забыв начальную точку, выдаёт сэмплы из точного апостериорного распределения. Её ошибки случайны, а не систематичны: они уменьшаются как единица, делённая на квадратный корень из эффективного числа сэмплов, тогда как ошибка среднего поля остаётся на месте.</aside>

## Сэмплер Гиббса для нормальной модели \{#a-gibbs-sampler-for-the-normal-model\}

В логарифме совместной плотности нормальной модели, записанном в предыдущей заметке, слагаемые с $\mu$ равны

$$
-\frac\lambda2 \Big(\sum_{i=1}^n (x_i - \mu)^2 + \kappa_0 (\mu - \mu_0)^2\Big),
$$

это квадратичная функция $\mu$ со старшим коэффициентом $-\frac{(\kappa_0 + n)\lambda}{2}$, а слагаемые с $\lambda$ равны

$$
\Big(a_0 - 1 + \frac{n + 1}{2}\Big) \log \lambda - \lambda \Big(b_0 + \frac12 \Big[\sum_{i=1}^n (x_i - \mu)^2 + \kappa_0 (\mu - \mu_0)^2\Big]\Big) .
$$

Поэтому полные условные распределения таковы:

$$
\mu \mid \lambda, X \sim \mathcal N\Big(\mu_n,\; \frac{1}{(\kappa_0 + n)\lambda}\Big), \qquad \lambda \mid \mu, X \sim \mathrm{Gamma}\Big(a_0 + \frac{n + 1}{2},\; b_0 + \frac12 \Big[\sum_{i=1}^n (x_i - \mu)^2 + \kappa_0 (\mu - \mu_0)^2\Big]\Big),
$$

где $\mu_n = (\kappa_0 \mu_0 + n\bar x)/(\kappa_0 + n) = 0.478$. Это множители среднего поля из предыдущей заметки, в которых $\mathbb E[\lambda]$ заменено текущим $\lambda$, а $\mathbb E_\mu[\cdot]$ — значением при текущем $\mu$.

**Разобранный пример.** Начнём в точке $(\mu, \lambda) = (1.7, 1.7)$. Условное распределение $\mu$ — нормальное со средним $0.478$ и обратной дисперсией $9 \cdot 1.7 = 15.3$, стандартное отклонение $0.256$; сэмпл равен $\mu = 0.87$. При этом $\mu$ условное распределение $\lambda$ равно $\mathrm{Gamma}(6.5, 9.78)$, со средним $0.66$; сэмпл равен $\lambda = 0.91$. Один проход перевёл цепь с края апостериорного распределения в его основную массу.

Четыре цепи по 10 000 проходов из разнесённых начальных точек $(-0.5, 0.3)$, $(1.5, 0.3)$, $(-0.5, 1.6)$ и $(1.5, 1.6)$, у каждой из которых отброшены первые 1000 проходов, дают апостериорное среднее $\mu$, равное $0.478$, стандартное отклонение $0.452$ и $\mathbb E[\lambda] = 0.660$ при точных $0.478$, $0.449$ и $0.661$. Ошибка Монте-Карло для стандартного отклонения — около $0.449/\sqrt{2 \cdot 36\,000} = 0.002$, так что разница в $0.003$ — шум ожидаемой величины, и, в отличие от $0.039$ у среднего поля, она уменьшается с удлинением цепей.

Этот сэмплер перемешивается необычно хорошо. Условное среднее $\mu$ равно $\mu_n$ при любом $\lambda$, поэтому последовательные сэмплы $\mu$ некоррелированы — автокорреляция с лагом 1 равна $-0.002$, — и 9000 сэмплов $\mu$ в каждой цепи стоят 9000 независимых; для $\lambda$ автокорреляция с лагом 1 равна $0.05$, а эффективные размеры выборки — от 7737 до 9000. Когда апостериорное распределение сильно связывает блоки, Гиббс работает медленно, как показывает зигзаг в [заметке о MCMC](/ru/notes/probability/markov-chain-monte-carlo#gibbs-sampling) для коррелированной гауссианы: последовательные сэмплы там имеют корреляцию $\rho^2$ — тот же множитель, с которым сходятся средние в приближении среднего поля.

## Блочный и свёрнутый Гиббс \{#blocked-and-collapsed-gibbs\}

Два изменения того, что считать блоком, ускоряют перемешивание сэмплера Гиббса.

**Блочная группировка** (blocking) сэмплирует несколько связанных блоков совместно из их совместного условного распределения. В пределе одного блока сэмплер сэмплирует прямо из апостериорного распределения, и последовательные сэмплы независимы. Для нормальной модели совместное апостериорное распределение нормально-гамма, поэтому блочный сэмплер берёт $\lambda \sim \mathrm{Gamma}(a_n, b_n)$, а затем $\mu \mid \lambda$: 9000 сэмплов из раздела «Код» дают стандартное отклонение $0.448$ и эффективный размер выборки 9000. Для коррелированной гауссианы совместное сэмплирование обеих координат полностью убирает автокорреляцию $\rho^2$. Блочная группировка окупается, когда из совместного условного распределения группы всё ещё легко сэмплировать, а внутри группы переменные сильно связаны.

**Сворачивание** (collapsing) аналитически интегрирует часть переменных и запускает Гиббс на остальных: вместо $p(z_1, z_2, z_3)$ он сэмплирует $p(z_1, z_2) = \int p(z_1, z_2, z_3)\, dz_3$ по её условным распределениям. [Liu (1994)](#references), развивая [Liu, Wong and Kong (1994)](#references), упорядочивает три схемы по нормам их прямых операторов — мере того, как быстро цепи забывают начальную точку: сворачивание не хуже объединения $z_2$ и $z_3$ в один блок, а оно не хуже обновления всех трёх по одной. Проинтегрированные переменные не теряются: при сэмплированных значениях остальных их можно сэмплировать из их условного распределения, а математические ожидания функций от них можно оценивать усреднением их условных математических ожиданий, у которого дисперсия меньше, чем у усреднения сэмплов (Rao–Blackwellization, теорема Рао–Блэкуэлла).

### Свёрнутый сэмплер для байесовской смеси \{#a-collapsed-sampler-for-a-bayesian-mixture\}

*Необязательное углубление: вывод свёрнутого условного распределения. Остальная часть заметки от него не зависит.*

Возьмём смесь $K$ гауссиан в одном измерении с известной дисперсией $\sigma^2$, весами $\pi \sim \mathrm{Dir}(\alpha, \dots, \alpha)$, средними $\mu_k \sim \mathcal N(0, s_0^2)$, метками $z_i \mid \pi \sim \mathrm{Cat}(\pi)$ и $x_i \mid z_i, \mu \sim \mathcal N(\mu_{z_i}, \sigma^2)$. **Стандартный сэмплер** по кругу сэмплирует из трёх условных распределений, каждое из которых сопряжённое: при $n_k$ — числе точек с меткой $k$ —

$$
\pi \mid z \sim \mathrm{Dir}(\alpha + n_1, \dots, \alpha + n_K), \qquad \mu_k \mid z, x \sim \mathcal N(m_k, v_k), \qquad p(z_i = k \mid \pi, \mu, x_i) \propto \pi_k\, \mathcal N(x_i \mid \mu_k, \sigma^2),
$$

где $v_k = (1/s_0^2 + n_k/\sigma^2)^{-1}$ и $m_k = v_k \sum_{i: z_i = k} x_i / \sigma^2$ — нормально-нормальное обновление из [заметки о сопряжённых распределениях](/ru/notes/bayesian-methods/conjugate-priors). При фиксированных $\pi$ и $\mu$ метки независимы, поэтому все они сэмплируются сразу.

**Свёрнутый сэмплер** (collapsed sampler) интегрирует $\pi$ и $\mu$ и сэмплирует одни метки, по одной. По формуле Байеса $p(z_i = k \mid z_{-i}, x) \propto p(z_i = k \mid z_{-i})\, p(x_i \mid z_i = k, z_{-i}, x_{-i})$. Первый множитель — предсказательная вероятность модели Дирихле–категориального распределения, счётчик плюс псевдосчётчик; второй — апостериорная предсказательная плотность $x_i$ в компоненте $k$ при остальных точках с этой меткой, нормальная плотность, дисперсия которой добавляет к шуму неопределённость в $\mu_k$:

$$
p(z_i = k \mid z_{-i}, x) \;\propto\; \frac{n_k^{-i} + \alpha}{n - 1 + K\alpha}\; \mathcal N\big(x_i \mid m_k^{-i},\; \sigma^2 + v_k^{-i}\big),
$$

где $n_k^{-i}$, $m_k^{-i}$ и $v_k^{-i}$ вычислены без точки $i$. Метки больше не являются условно независимыми, поэтому их обновляют по очереди; счётчики делают обновление дешёвым.

**Разобранный пример.** В разделе «Код» 120 точек взяты из трёх кластеров с единичной дисперсией и центрами в $-2.5$, $0$ и $2.5$, при $K = 3$, $\alpha = 1$, $s_0^2 = 25$ и $\sigma^2 = 1$. Оба сэмплера начинают со всех точек в одном кластере и делают 2000 проходов. Метки компонент могут переставляться по ходу работы, поэтому отслеживаемая величина не должна от них зависеть: это размер кластера, в котором лежит первая точка. После прогрева (burn-in) в 200 проходов её 1800 значений стоят 56 независимых у стандартного сэмплера и 213 у свёрнутого. Средние, 42.3 и 40.1 точки, несут большой шум, свойственный столь малому числу эффективных сэмплов. Сравнение идёт на один проход, а свёрнутый проход обходит точки по одной. Тот же свёрнутый сэмплер, в котором веса Дирихле заменены процессом Дирихле, обучает бесконечные смеси из [заметки о процессах Дирихле](/ru/notes/bayesian-methods/dirichlet-processes), а для тематических моделей это стандартный способ обучить [латентное размещение Дирихле](/ru/notes/bayesian-methods/latent-dirichlet-allocation) ([Griffiths and Steyvers, 2004](#references)).

## Проверка сходимости \{#checking-convergence\}

[Заметка о MCMC](/ru/notes/probability/markov-chain-monte-carlo#mixing-and-diagnostics) вводит инструменты; четыре привычки делают их полезными для сэмплеров Гиббса.

1. **Несколько цепей из разнесённых начальных точек.** Отбросьте прогрев и сравните цепи. **Расщеплённый $\hat R$** (split R̂) — вариант потенциального коэффициента уменьшения масштаба из [Gelman and Rubin (1992)](#references) — делит каждую из $M$ цепей пополам и сравнивает $2M$ половин длины $h$: если $W$ — средняя дисперсия внутри половин, а $B$ — дисперсия средних по половинам, умноженная на $h$, то $\hat R = \sqrt{\big(\frac{h - 1}{h} W + \frac1h B\big)/W}$, и он приближается к 1, когда половины согласуются. [Vehtari et al. (2021)](#references) рекомендуют ранговую нормализованную версию и считают признаком проблемы $\hat R \ge 1.01$ или суммарный эффективный размер выборки меньше 400. Четыре цепи нормальной модели дают $\hat R = 1.0000$ и для $\mu$, и для $\lambda$.
2. **Отслеживайте то, что не зависит от меток.** В смесях и других моделях с симметричными метками $\hat R$ среднего компоненты измеряет перестановки меток (label switching), а не сходимость; используйте размеры кластеров, совместное попадание двух точек в один кластер или логарифм правдоподобия.
3. **Сообщайте эффективные размеры выборки, а не число проходов.** 1800 проходов стандартного сэмплера смеси выше стоили 56 независимых сэмплов.
4. **Помните, чего не видит ни одна диагностика.** Область, куда цепи не попадают, не оставляет следа в их выходе. Цепь на двух квадратах в первом квадрате выглядит идеально сошедшейся. Запуск цепей в разных модах или знание о симметриях апостериорного распределения — единственная защита.

## Гиббс или вариационный вывод: смещение против дисперсии \{#gibbs-or-variational-inference-bias-against-variance\}

Среднеквадратичная ошибка оценки раскладывается на квадрат смещения и дисперсию. Два метода этого раздела стоят на двух концах этого разложения.

<BiasVariance />

Среднее поле сразу и без всякой случайности сообщает апостериорное стандартное отклонение $\mu$, равное $0.410$; его ошибка, $0.039$, — смещение, и она не меняется, сколько бы ни работал алгоритм. Оценки Гиббса в пределе не смещены; их ошибка случайна — от $0.28$ до $0.53$ после 10 проходов и от $0.443$ до $0.449$ после 10 000 — и уменьшается примерно как $1/\sqrt n$. При коротком бюджете детерминированный ответ может оказаться ближе; для любой точности сверх его смещения сэмплирование выигрывает за счёт более долгой работы.

| | Вариационный вывод со средним полем | Сэмплирование по Гиббсу |
| --- | --- | --- |
| Использует | $\mathbb E_{-j}[\log p(X, Z)]$ для каждого блока | сэмплы из $p(z_j \mid z_{-j}, X)$ для каждого блока |
| Результат | распределение $q$ в замкнутом виде | коррелированные сэмплы из точного апостериорного распределения, в пределе |
| Ошибка | смещение: слишком узко, одна мода, корреляции потеряны | дисперсия: около $\sigma/\sqrt{\mathrm{ESS}}$ |
| Больше вычислений | после сходимости ничего не улучшают | ошибка продолжает уменьшаться |
| Обоснованность | нижняя оценка $\mathcal L(q)$ | нужен дополнительный метод, например [Chib (1995)](#references) |
| Проверка сходимости | нижняя оценка перестаёт расти | несколько цепей, $\hat R$, ESS |
| Масштабируется на | большие данные, со [стохастической версией](/ru/notes/bayesian-methods/stochastic-variational-inference) позже в курсе | умеренные данные; каждый проход обходит все латентные переменные |
| Нормальная модель, ст. откл. $\mu$ | $0.410$ | $0.452$ по $4 \times 9\,000$ сэмплам (точное $0.449$) |

На практике их используют вместе: вариационный вывод — чтобы быстро обучать большие модели, а длинный запуск Гиббса или гамильтонова Монте-Карло на меньшей задаче — чтобы измерить, насколько ошибается его неопределённость.

| | Метрополис–Гастингс со случайным блужданием | Сэмплирование по Гиббсу |
| --- | --- | --- |
| Предложение | случайный сдвиг всего сразу | точный сэмпл одного блока из его полного условного распределения |
| Принятие | с вероятностью, которая настраивается размером шага | всегда 1 |
| Настройка | размер шага, по каждому направлению | выбор блоков |
| Что нужно | плотность с точностью до константы | условные распределения, из которых можно сэмплировать |
| Не работает, когда | шаг не подходит ни одному направлению | блоки сильно связаны или носитель несвязен вдоль осей |
| Улучшения | лучшие предложения: MALA, HMC | блочная группировка, сворачивание |

## Ограничения \{#limitations\}

- **Связанные блоки медленно перемешиваются.** Движение вдоль одного блока за раз еле ползёт по сильно коррелированным апостериорным распределениям; блочная группировка или репараметризация помогают, но только когда из совместного условного распределения группы всё ещё легко сэмплировать.
- **Условные распределения должны быть доступны.** Без сопряжённости условным распределениям нужны свои сэмплеры — шаги Метрополиса внутри Гиббса или срезающее сэмплирование (slice sampling), — и простота пропадает.
- **Многомодальность.** Цепь может оставаться в одной моде весь запуск, и ни одна диагностика, вычисленная по этой цепи, этого не покажет; типичные случаи — смеси и модели с симметричными метками.
- **Последовательность и медленность на больших данных.** Каждый проход обходит все латентные переменные, а свёрнутые сэмплеры обновляют их по одной; стоимость растёт с объёмом данных, и здесь лучше масштабируются [стохастические вариационные методы](/ru/notes/bayesian-methods/stochastic-variational-inference).
- **Ошибка Монте-Карло реальна.** Результаты содержат шум, который нужно оценивать через эффективные размеры выборки и сообщать.

## Что нужно запомнить \{#what-you-should-remember\}

- Сэмплирование по Гиббсу сэмплирует каждый блок из его полного условного распределения $p(z_j \mid z_{-j})$, всегда при самых новых значениях остальных; условные распределения читаются из $\log p(X, Z)$ так же, как множители среднего поля, но без математического ожидания.
- Каждое обновление сохраняет целевое распределение, $(z_j', z_{-j}) \sim p(z_j' \mid z_{-j})\, p(z_{-j}) = p$, и является шагом Метрополиса–Гастингса с вероятностью принятия 1.
- Чтобы инвариантность стала сходимостью, нужна неприводимость; носитель, несвязный вдоль осей, её нарушает, а положительность плотности её гарантирует.
- Блочная группировка сэмплирует связанные блоки совместно; сворачивание интегрирует переменные и перемешивается не медленнее блочной группировки, которая перемешивается не медленнее обновлений по одной.
- Проверяйте сходимость по нескольким разнесённым цепям, с расщеплённым $\hat R$ ниже 1.01 и эффективными размерами выборки, на величинах, которые не зависят от меток.
- У среднего поля фиксированное смещение и нет шума; у Гиббса в пределе нет смещения, а шум уменьшается как $1/\sqrt{\mathrm{ESS}}$.

## Код \{#code\}

Гиббс для нормальной модели с четырьмя цепями, расщеплённым $\hat R$ и эффективными размерами выборки, блочный сэмплер, приводимое целевое распределение, ошибка одновременных обновлений и стандартный и свёрнутый сэмплеры для байесовской смеси. Только NumPy и SciPy; начальные значения генератора (seed) фиксированы, а точные числа могут различаться на разных платформах и версиях библиотек. Скрипт работает около 12 секунд, почти всё время занимает свёрнутый сэмплер, внутренний цикл которого обходит точки по одной.

```python
import numpy as np
from scipy.special import logsumexp

def ess(a):                                  # эффективный размер выборки, автокорреляции суммируются, пока не упадут ниже 0.05
    a = a - a.mean(); n = len(a)
    r = np.correlate(a, a, 'full')[n - 1:] / (a.var() * n)
    cut = np.argmax(r[1:] < 0.05) + 1
    return n / (1 + 2 * r[1:cut].sum())
def split_rhat(chains):                      # chains: m x n; каждая цепь делится на две половины
    h = chains.shape[1] // 2
    c = np.vstack([chains[:, :h], chains[:, h:2 * h]])
    B, W = h * c.mean(axis=1).var(ddof=1), c.var(axis=1, ddof=1).mean()
    return np.sqrt(((h - 1) / h * W + B / h) / W)

# нормальная модель из заметки о вариационном выводе
x = np.array([3.0, -1.6, 1.4, 0.4, 0.5, 0.8, -1.0, 0.8])
N, mu0, l0, a0, b0 = len(x), 0.0, 1.0, 2.0, 2.0
mN = (l0 * mu0 + x.sum()) / (l0 + N)
aE, bE = a0 + N / 2, b0 + 0.5 * ((x - x.mean()) ** 2).sum() + l0 * N * (x.mean() - mu0) ** 2 / (2 * (l0 + N))

def gibbs(start, sweeps, rng):
    mu, tau = start
    out = np.empty((sweeps, 2))
    for s in range(sweeps):
        mu = rng.normal(mN, 1 / np.sqrt((l0 + N) * tau))                                   # mu | tau, x
        b = b0 + 0.5 * (((x - mu) ** 2).sum() + l0 * (mu - mu0) ** 2)
        tau = rng.gamma(a0 + (N + 1) / 2, 1 / b)                                           # tau | mu, x
        out[s] = mu, tau
    return out
rng = np.random.default_rng(0)
starts = [(-0.5, 0.3), (1.5, 0.3), (-0.5, 1.6), (1.5, 1.6)]
ch = np.stack([gibbs(s, 10000, rng) for s in starts])                                       # 4 x 10000 x 2
keep = ch[:, 1000:]                                                                          # отбросить 1000 проходов прогрева
print(keep[..., 0].mean().round(3), keep[..., 0].std().round(3), keep[..., 1].mean().round(3))   # 0.478 0.452 0.66
print(round(mN, 3), round(np.sqrt(bE / ((aE - 1) * (l0 + N))), 3), round(aE / bE, 3))       # 0.478 0.449 0.661: точные значения
print([f"{split_rhat(keep[..., j]):.4f}" for j in (0, 1)], [int(ess(c[:, 0])) for c in keep], [int(ess(c[:, 1])) for c in keep])
# ['1.0000', '1.0000'] [9000, 9000, 9000, 9000] [9000, 7937, 7737, 7917]
print([round(float(np.corrcoef(keep[0, :-1, j], keep[0, 1:, j])[0, 1]), 3) for j in (0, 1)])   # [-0.002, 0.05]: автокорреляции с лагом 1

# блочная группировка mu и tau: совместное условное распределение — всё нормально-гамма апостериорное, поэтому сэмплы независимы
tau = rng.gamma(aE, 1 / bE, size=9000); mu = rng.normal(mN, 1 / np.sqrt((l0 + N) * tau))
print(mu.std().round(3), int(ess(mu)))                                                       # 0.448 9000

# приводимое целевое распределение: равномерное на двух квадратах, касающихся только углом; Гиббс не покидает первый
z = np.array([0.5, 0.5]); visits = 0
for s in range(10000):
    z[0] = rng.uniform(0, 1) if z[1] > 0 else rng.uniform(-1, 0)
    z[1] = rng.uniform(0, 1) if z[0] > 0 else rng.uniform(-1, 0)
    visits += z[0] < 0
print(visits)                                                                                # 0

# частая ошибка: обновлять обе координаты двумерного нормального распределения (rho = 0.9) по старым значениям, а не по самым новым
rho, z1, z2, seq, par = 0.9, 0.0, 0.0, [], []
for s in range(20000):
    z1 = rng.normal(rho * z2, np.sqrt(1 - rho ** 2)); z2 = rng.normal(rho * z1, np.sqrt(1 - rho ** 2)); seq.append((z1, z2))
y1, y2 = 0.0, 0.0
for s in range(20000):
    y1, y2 = rng.normal(rho * y2, np.sqrt(1 - rho ** 2)), rng.normal(rho * y1, np.sqrt(1 - rho ** 2)); par.append((y1, y2))
print([round(float(np.corrcoef(np.array(c).T)[0, 1]), 3) for c in (seq, par)])              # [0.899, -0.009]

# смесь трёх гауссиан с единичной дисперсией в одном измерении: pi ~ Dir(1, 1, 1), mu_k ~ N(0, 25)
K, s2, t2, alpha = 3, 1.0, 25.0, 1.0
xm = np.concatenate([rng.normal(-2.5, 1, 40), rng.normal(0, 1, 40), rng.normal(2.5, 1, 40)]); n = len(xm)
stat = lambda z: (z == z[0]).sum()          # размер кластера первой точки: не зависит от меток
def standard(T, g):                          # pi, mu и z по очереди
    z, mu, out = np.zeros(n, int), np.zeros(K), []
    for t in range(T):
        nk = np.bincount(z, minlength=K)
        pi = g.dirichlet(alpha + nk)
        for k in range(K):
            v = 1 / (1 / t2 + nk[k] / s2); mu[k] = g.normal(v * xm[z == k].sum() / s2, np.sqrt(v))
        lw = np.log(pi) - 0.5 * (xm[:, None] - mu) ** 2 / s2
        p = np.exp(lw - logsumexp(lw, axis=1, keepdims=True))
        z = (p.cumsum(axis=1) < g.random(n)[:, None]).sum(axis=1)
        out.append(stat(z))
    return np.array(out)
def collapsed(T, g):                         # pi и mu проинтегрированы: z_i | z_-i, по одной точке
    z = np.zeros(n, int); nk = np.bincount(z, minlength=K).astype(float); sk = np.array([xm[z == k].sum() for k in range(K)]); out = []
    for t in range(T):
        for i in range(n):
            nk[z[i]] -= 1; sk[z[i]] -= xm[i]
            v = 1 / (1 / t2 + nk / s2); m = v * sk / s2                   # апостериорное распределение mu_k по остальным точкам
            lw = np.log(nk + alpha) + (-0.5 * np.log(s2 + v) - 0.5 * (xm[i] - m) ** 2 / (s2 + v))
            z[i] = g.choice(K, p=np.exp(lw - logsumexp(lw)))
            nk[z[i]] += 1; sk[z[i]] += xm[i]
        out.append(stat(z))
    return np.array(out)
for f in (standard, collapsed):
    a = f(2000, np.random.default_rng(1))
    print(f.__name__, a[:6], a[200:].mean().round(1), int(ess(a[200:])))
# standard [20 33 40 51 51 55] 42.3 56
# collapsed [91 51 54 53 59 53] 40.1 213
```
