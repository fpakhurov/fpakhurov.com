У данных два кластера, около $-3$ и около $-8$, а модель — одна гауссиана. Если минимизировать KL-дивергенцию от данных к модели, гауссиана остановится в $-5.5$ со стандартным отклонением $2.55$: её самая плотная часть окажется в пустом промежутке, где нет ни одной точки данных. Если поменять аргументы дивергенции местами, гауссиана сядет на один кластер и проигнорирует другой.

Реальные модели никогда не представляют данные точно, поэтому то, какую из этих неудач предпочитает функция потерь, — свойство каждой генеративной модели, обученной с ней. Чтобы это увидеть, мы подгоняем гауссиану $Q$ с обучаемыми параметрами к целевому распределению $P$ градиентным спуском. Функцией потерь служит KL-дивергенция из [заметки об энтропии](/ru/notes/generative-models/entropy-and-divergences), моделью — [обучаемая гауссиана](/ru/notes/generative-models/gaussian-distributions#gaussians-in-pytorch).

## Как обучаются параметры \{#how-the-parameters-are-trained\}

В одномерном случае модель — $Q = \mathcal N(\mu, \sigma^2)$ с параметрами $\theta = (\mu, \log\sigma)$; если хранить $\sigma$ через логарифм, оно остаётся положительным, что бы ни делал оптимизатор. В двумерном случае параметры — среднее и три исходных элемента множителя Холецкого.

Одна итерация цикла подгонки заново строит $Q$ из текущих параметров, вычисляет логарифм её плотности в фиксированных сэмплах $x_i \sim P$ и считает функцию потерь — выборочную оценку $D_{\mathrm{KL}}(P\,\|\,Q)$. Затем обратное распространение ошибки вычисляет градиент функции потерь по каждому параметру, и оптимизатор сдвигает параметры против него. Для обычного градиентного спуска с шагом обучения (learning rate) $\eta$ шаг имеет вид

$$
\begin{aligned}
\mu &\leftarrow \mu - \eta\,\frac{\partial\,\text{loss}}{\partial \mu}, \\
\log\sigma &\leftarrow \log\sigma - \eta\,\frac{\partial\,\text{loss}}{\partial \log\sigma}.
\end{aligned}
$$

[Adam](/ru/notes/ml/stochastic-and-adaptive-optimizers#adam) ([Kingma and Ba, 2015](#references)) движется в похожем направлении, но масштабирует шаг по каждой координате скользящими оценками среднего и величины градиента; приведённые ниже подгонки в PyTorch используют его.

<TrainingLoop />

В PyTorch параметры — тензоры, созданные с `requires_grad=True`, `loss.backward()` заполняет их `.grad`, а `optimizer.step()` делает шаг; у параметров целевого распределения градиента нет, и они остаются фиксированными. ### Функция потерь — оценка KL методом Монте-Карло \{#the-loss-is-a-monte-carlo-estimate-of-kl\}

KL — математическое ожидание по $P$, поэтому её можно оценить средним по сэмплам $x_1, \dots, x_N \sim P$:

$$
\begin{aligned}
D_{\mathrm{KL}}(P\,\|\,Q) &= \mathbb E_{x\sim P}\big[\log p(x) - \log q(x)\big] \\
&\approx \frac1N\sum_{i=1}^{N}\big[\log p(x_i) - \log q(x_i)\big].
\end{aligned}
$$

По закону больших чисел среднее сходится к математическому ожиданию с ростом $N$. Если усреднять $\log_2$ вместо $\ln$, функция потерь выражается в битах; это умножает её и её градиенты на $1/\ln 2 \approx 1.443$.

<MonteCarloKL />

Если сэмплы взяты из другого распределения $R$ с плотностью $r$, каждое слагаемое перевзвешивается на $w_i = p(x_i)/r(x_i)$ — [вес значимости](/ru/notes/probability/monte-carlo#importance-sampling) (importance weight); для этого нужно, чтобы $r > 0$ везде, где $p > 0$.

Оценка может быть отрицательной, хотя KL отрицательной не бывает. Подгоним двумерную гауссиану с полной ковариацией, пять параметров, к 1000 фиксированным сэмплам $\mathcal N\big((-5,-5), \mathbf I\big)$: после 4800 шагов Adam функция потерь равна $-0.0020$ бита. Модель подгоняется к тем же сэмплам, на которых вычисляется функция потерь. Целевое распределение — одна из гауссиан-кандидатов, поэтому в точке максимального правдоподобия среднее $\log q$ по сэмплам не меньше среднего $\log p$. Насколько ниже нуля, следует из теоремы Уилкса ([Wilks, 1938](#references)). Если семейство содержит $P$, логарифм правдоподобия гладкий, а истинные параметры лежат внутри множества параметров, то удвоенный выигрыш в суммарном логарифме правдоподобия подгонки по сравнению с истинными параметрами приближённо распределён как $\chi^2$ с $k$ степенями свободы для $k$ подогнанных параметров. Интуиция такая: вблизи максимума логарифм правдоподобия — квадратичная чаша, а шум выборки сдвигает максимум на $k$ независимых, примерно нормальных величин, и каждая добавляет к выигрышу половину квадрата стандартной нормальной. Функция потерь равна выигрышу со знаком минус, делённому на $N$, а среднее $\chi^2_k$ равно $k$, поэтому

$$
\begin{aligned}
\mathbb E[\text{loss}] &\approx -\frac{\mathbb E[\chi^2_k]}{2N} = -\frac{k}{2N} \\
&= -\frac{5}{2000} = -0.0025 \text{ ната} \\
&= -0.0036 \text{ бита}.
\end{aligned}
$$

В 2000 смоделированных подгонок оценка в среднем равна $-0.0036$ бита со стандартным отклонением $0.0023$, так что $-0.0020$ — типичное значение. Честная оценка дивергенции подогнанной модели требует свежих сэмплов, как отложенные данные для любой модели.

### Чему равны градиенты \{#what-the-gradients-are\}

Для одномерной гауссианы $\log q(x) = -\log\sigma - \tfrac12\log 2\pi - \frac{(x-\mu)^2}{2\sigma^2}$. Слагаемое $\log p(x_i)$ от параметров не зависит, поэтому вклад даёт только $-\log q$ (логарифмы натуральные):

$$
\begin{aligned}
\frac{\partial\,\text{loss}}{\partial \mu} &= -\frac1N\sum_{i=1}^{N}\frac{x_i-\mu}{\sigma^2}, \\
\frac{\partial\,\text{loss}}{\partial \log\sigma} &= \frac1N\sum_{i=1}^{N}\left[1 - \frac{(x_i-\mu)^2}{\sigma^2}\right].
\end{aligned}
$$

Вторая строка использует $\sigma^{-2} = e^{-2\log\sigma}$, производная которого по $\log\sigma$ равна $-2\sigma^{-2}$, и производную $1$ самого $\log\sigma$. Оба градиента обращаются в ноль, когда $\mu$ — выборочное среднее, а $\sigma^2 = \frac1N\sum_i (x_i-\mu)^2$ — смещённая выборочная дисперсия: это оценки максимального правдоподобия, как и предсказывала заметка об энтропии. Градиенту $p$ не нужна; значения $p(x_i)$ лишь делают выводимое число равным KL. На реальных данных, где $p$ неизвестна, мы отбрасываем эту константу и минимизируем отрицательный логарифм правдоподобия $-\frac1N\sum_i \log q(x_i)$.

Куда ведут шаги, показывает точная KL между двумя одномерными гауссианами. Возьмём $D_{\mathrm{KL}} = \mathbb E_P[\log p(x) - \log q(x)]$, запишем оба логарифма плотности, как выше, и воспользуемся равенствами $\mathbb E_P[(x-\mu_P)^2] = \sigma_P^2$ и $\mathbb E_P[(x-\mu)^2] = \sigma_P^2 + (\mu_P-\mu)^2$. Константы $\tfrac12\log 2\pi$ сокращаются, и

$$
\begin{aligned}
&D_{\mathrm{KL}}\big(\mathcal N(\mu_P, \sigma_P^2)\,\|\,\mathcal N(\mu, \sigma^2)\big) \\
&\quad= \log\frac{\sigma}{\sigma_P} + \frac{\sigma_P^2 + (\mu_P - \mu)^2}{2\sigma^2} - \frac12 .
\end{aligned}
$$

Последнее слагаемое — это $-\sigma_P^2/(2\sigma_P^2)$ из $\log p$.

<FittingTrajectory />

При обычном градиентном спуске по $(\mu, \log\sigma)$ траектория показывает приоритеты прямой KL. Пока $Q$ узкая и далеко, большая часть массы $P$ лежит там, где $q \approx 0$, и дешевле всего расширить $Q$: в первые шаги $\sigma$ резко растёт, а $\mu$ лишь медленно сдвигается. Когда $Q$ накрывает $P$, $\mu$ перемещается к цели, а $\sigma$ снова сжимается. Такой порядок задают величины градиентов. Из замкнутой формулы $\partial/\partial\log\sigma = 1 - \big(\sigma_P^2 + (\mu_P-\mu)^2\big)/\sigma^2$ растёт как $(\mu_P-\mu)^2/\sigma^2$, а $\partial/\partial\mu = (\mu-\mu_P)/\sigma^2$ — лишь как $\lvert\mu_P-\mu\rvert/\sigma^2$. Adam, который нормирует шаг по каждой координате, двигает оба параметра с похожей скоростью и приходит в тот же оптимум другим путём.

## Что предполагает KL \{#what-kl-assumes\}

Формула для непрерывных распределений ([Kullback and Leibler, 1951](#references)),

$$
D_{\mathrm{KL}}(P\,\|\,Q) = \int p(x)\,\log\frac{p(x)}{q(x)}\,dx ,
$$

даёт осмысленное конечное число только при условиях (a)–(c) ниже; (d) и (e) — выбор, который нужно делать согласованно ([Cover and Thomas, 2006](#references), §8.5; [Murphy, 2023](#references), §5.1).

### (a) Общий носитель \{#a-common-support\}

**Носитель** (support) распределения — множество его возможных значений, $\operatorname{supp} p = \lbrace x : p(x) > 0\rbrace$. Если $q(x) = 0$ в области, которой $P$ даёт положительную вероятность, там $\log\frac{p(x)}{q(x)} = \infty$, и дивергенция бесконечна. Формально $D_{\mathrm{KL}}(P\,\|\,Q)$ конечна, только если $P$ **абсолютно непрерывно** относительно $Q$, что записывают как $P \ll Q$: где у $P$ есть масса, она должна быть и у $Q$.

Это одна из причин, по которым модели, обучаемые методом максимального правдоподобия, используют всюду положительные плотности, например гауссианы: потеря на сэмпле $-\log q(x_i)$ остаётся конечной в каждой наблюдённой точке. Сама по себе положительность модель не размывает. Но вместе с прямой KL, которая наказывает за любую пропущенную массу, она заставляет модель, неспособную представить данные, размазывать вероятность между модами и вокруг них. Это одно из объяснений размытых сэмплов у моделей изображений, обученных по правдоподобию ([Theis, van den Oord and Bethge, 2016](#references)).

<SupportMismatch />

Условие одностороннее. Точки, где $q(x) > 0$, но $p(x) = 0$, вносят в $D_{\mathrm{KL}}(P\,\|\,Q)$ вклад $0$; они важны только для обратного направления.

### (b) Интегрируемость \{#b-integrability\}

Интеграл должен сходиться, и совпадения носителей для этого мало. Пусть $P$ — стандартное распределение Коши, а $Q = \mathcal N(0, \sigma^2)$. Обе плотности всюду положительны, и при $p(x) = 1/\big(\pi(1 + x^2)\big)$

$$
\log\frac{p(x)}{q(x)} = \frac{x^2}{2\sigma^2} - \log(1 + x^2) + \log\frac{\sqrt{2\pi}\,\sigma}{\pi} .
$$

Под $P$ среднее слагаемое имеет конечное среднее $2\ln 2$, а $\mathbb E_P[x^2] = \infty$, поэтому $D_{\mathrm{KL}}(P\,\|\,Q) = \infty$. Модель с лёгкими хвостами не может подогнать данные с тяжёлыми хвостами по KL.

### (c) Нормированные плотности \{#c-normalized-densities\}

$p$ и $q$ должны быть плотностями или функциями вероятности: неотрицательными и с интегралом 1. Ненормированные оценки, например логиты классификатора, сначала пропускают через softmax, а `log_prob` объекта из `torch.distributions` уже нормирован.

### (d) Направление \{#d-direction\}

KL не симметрична, поэтому нужно решить, какое распределение играет роль истины. **Прямая** KL (forward KL) $D_{\mathrm{KL}}(P\,\|\,Q)$ усредняет по $P$ и наказывает за пропущенные моды: $Q$ должна покрыть всё, где живёт $P$. Это направление метода максимального правдоподобия. **Обратная** KL (reverse KL) $D_{\mathrm{KL}}(Q\,\|\,P)$ усредняет по $Q$ и наказывает за лишнюю массу: $Q$ не должна расползаться туда, где $P \approx 0$. Это направление [вариационного вывода](/ru/notes/bayesian-methods/variational-inference#the-evidence-lower-bound-and-the-reverse-kl) (variational inference), в том числе в [VAE](/ru/notes/generative-models/vae). Эти два направления называют также включающей и исключающей KL (inclusive / exclusive), а их поведение — избегающим нулей (zero-avoiding), или покрывающим моды (mode-covering), и обнуляющим (zero-forcing), или ищущим моду (mode-seeking) ([Murphy, 2023](#references), §5.1.4).

<DirectionPenalties />

Только прямое направление можно оценить по одним данным. Ему нужны сэмплы из $P$ и значения $\log q$ в них; обратному нужно $\log p$, которого реальные данные не дают.

### (e) Непрерывные и дискретные распределения \{#e-continuous-versus-discrete\}

Для дискретных распределений интеграл становится суммой. Смешение двух случаев даёт бесконечную дивергенцию: если у $P$ есть атом в точке $x$, любая $Q$ с плотностью даёт $\lbrace x\rbrace$ нулевую вероятность, поэтому $P \not\ll Q$ и $D_{\mathrm{KL}}(P\,\|\,Q) = \infty$ по условию (a). Поэтому для непрерывных данных метод максимального правдоподобия понимают как выборочную оценку $D_{\mathrm{KL}}(P\,\|\,Q)$ для исходной плотности $p$. Понимать его как KL эмпирического распределения сэмплов можно только для [дискретных исходов](/ru/notes/generative-models/entropy-and-divergences#why-cross-entropy-is-the-loss-we-minimize).

### В коде \{#in-code\}

Гауссиана `Q` всюду положительна, поэтому (a) математически выполняется при любом целевом распределении, и всё же численно условие может нарушиться. Если вычислить `qx = Q.log_prob(x).exp()`, а затем `qx.log2()`, в [32-битной арифметике с плавающей точкой](/ru/notes/acos/floating-point#special-values) произойдёт обращение в 0 при потере точности (underflow), как только $\log q(x)$ опустится ниже примерно $-103$: при $\sigma \approx 1$ это около 14 стандартных отклонений от $\mu$. Функция потерь тогда бесконечна как раз тогда, когда $Q$ стартует далеко от $P$. Если работать прямо с `log_prob`, этого не происходит.

Целевым распределениям с двумя модами ниже нужна та же осторожность. Их логарифм плотности $\log\big(\tfrac12 p_1(x) + \tfrac12 p_2(x)\big)$ вычисляют по логарифмам плотностей компонент $a = \log p_1(x) + \log\tfrac12$ и $b = \log p_2(x) + \log\tfrac12$ как

$$
\operatorname{logaddexp}(a, b) = \max(a, b) + \log\big(1 + e^{-|a - b|}\big),
$$

двухслагаемый случай [устойчивого log-sum-exp](/ru/notes/math/conditioning-and-stability#log-sum-exp-and-the-stable-softmax), который остаётся конечным вдали от обеих компонент.

## Одна гауссиана, две моды \{#one-gaussian-two-modes\}

Если целевое распределение — одна гауссиана, подгонка по KL его восстанавливает. Показателен случай цели, которую семейство **не может представить**. В двумерном случае это смесь с равными весами $\mathcal N\big((-5,-5), \mathbf I\big)$ и $\mathcal N\big((4,4), \mathbf I\big)$, в одномерном —

$$
P = \tfrac12\,\mathcal N(-3,\, 0.5^2) + \tfrac12\,\mathcal N(-8,\, 0.5^2),
$$

а модель стартует с $Q = \mathcal N(0, 1)$. Мы сравниваем четыре функции потерь: прямую KL, обратную KL, JS и функцию потерь наименьших квадратов (least-squares loss) на значениях плотности. Ни одна не удовлетворительна, каждая по своей причине, и те же компромиссы встречаются во всех генеративных моделях ([Huszár, 2015](#references); [Theis, van den Oord and Bethge, 2016](#references); [Isachenko, лекция 5](#references)).

### Вдали от цели доминирует пропущенная мода \{#far-from-the-target-the-missed-mode-dominates\}

Начальная $Q = \mathcal N(0, 1)$ едва достаёт до дальней моды в $-8$, в восьми стандартных отклонениях от своего среднего. Там $\log\frac{p(x)}{q(x)}$ огромен, и эта мода доминирует во всей дивергенции, $17.9$ ната. Для гауссовской $Q$ прямая KL остаётся конечной, и её градиент по $\mu$, $(\mu - \mathbb E_P[x])/\sigma^2 = 5.5$, велик. Перекрытие важно для ограниченных функций потерь, JS и наименьших квадратов: без него их градиенты почти исчезают.

### Прямая KL покрывает обе моды, обратная выбирает одну \{#forward-kl-covers-both-modes-reverse-kl-picks-one\}

Минимизация $D_{\mathrm{KL}}(P\,\|\,Q)$ заставляет одну гауссиану накрыть обе моды широким разбросом. Запишем прямую KL как

$$
D_{\mathrm{KL}}(P\,\|\,Q) = -H(P) - \mathbb E_P[\log q(x)] .
$$

От $Q$ зависит только второе слагаемое, а у гауссианы $\log q$ зависит от $x$ только через $x$ и $xx^{\top}$. Минимизация по $\boldsymbol\mu$ и $\boldsymbol\Sigma$ даёт точное сопоставление моментов (moment matching) ([Bishop, 2006](#references), §10.7); вывод ниже:

$$
\begin{aligned}
\boldsymbol\mu^\ast &= \mathbb E_P[x], \\
\boldsymbol\Sigma^\ast &= \operatorname{Cov}_P[x] .
\end{aligned}
$$

<details>
<summary>Вывод</summary>

Обозначим $\mathbf m = \mathbb E_P[x]$ и $\mathbf C = \operatorname{Cov}_P[x]$ и будем считать $\mathbf C$ положительно определённой. Для $q = \mathcal N(\boldsymbol\mu, \boldsymbol\Sigma)$ в $d$ измерениях

$$
\begin{aligned}
-\mathbb E_P[\log q(x)] ={}& \tfrac12\log\det(2\pi\boldsymbol\Sigma) \\
&+ \tfrac12\,\mathbb E_P\big[(x - \boldsymbol\mu)^{\top}\boldsymbol\Sigma^{-1}(x - \boldsymbol\mu)\big] .
\end{aligned}
$$

Разложим $x - \boldsymbol\mu = (x - \mathbf m) + (\mathbf m - \boldsymbol\mu)$. Перекрёстное слагаемое в среднем равно нулю, потому что $\mathbb E_P[x - \mathbf m] = 0$, а скаляр равен своему следу, $\mathbb E[v^{\top}\boldsymbol\Sigma^{-1}v] = \operatorname{tr}\big(\boldsymbol\Sigma^{-1}\mathbb E[vv^{\top}]\big)$, поэтому

$$
\begin{aligned}
&\mathbb E_P\big[(x - \boldsymbol\mu)^{\top}\boldsymbol\Sigma^{-1}(x - \boldsymbol\mu)\big] \\
&\quad= \operatorname{tr}(\boldsymbol\Sigma^{-1}\mathbf C) + (\mathbf m - \boldsymbol\mu)^{\top}\boldsymbol\Sigma^{-1}(\mathbf m - \boldsymbol\mu) .
\end{aligned}
$$

Последнее слагаемое $\ge 0$ и равно нулю только при $\boldsymbol\mu = \mathbf m$; это фиксирует среднее. Для ковариации пусть $\lambda_1, \dots, \lambda_d > 0$ — собственные значения $\mathbf A = \mathbf C^{-1/2}\boldsymbol\Sigma\,\mathbf C^{-1/2}$. Циклическое свойство следа даёт $\operatorname{tr}(\boldsymbol\Sigma^{-1}\mathbf C) = \operatorname{tr}(\mathbf A^{-1}) = \sum_i 1/\lambda_i$, а $\det\boldsymbol\Sigma = \det\mathbf C \cdot \prod_i \lambda_i$, так что часть, зависящая от $\boldsymbol\Sigma$, равна

$$
\tfrac12\log\det\mathbf C + \tfrac12\sum_{i=1}^d \Big(\log\lambda_i + \frac{1}{\lambda_i}\Big) .
$$

У каждого слагаемого $\log\lambda + 1/\lambda$ производная $(\lambda - 1)/\lambda^2$ отрицательна при $\lambda < 1$ и положительна при $\lambda > 1$, поэтому минимум — при $\lambda = 1$. Все собственные значения, равные 1, означают $\mathbf A = \mathbf I$, то есть $\boldsymbol\Sigma = \mathbf C$.

</details>

Для одномерной цели $\mu^\ast = -5.5$ и, по [закону полной дисперсии](/ru/notes/probability/conditional-expectation#the-law-of-total-variance), $\sigma^{\ast2} = 0.25 + 2.5^2 = 6.5$, так что $\sigma^\ast \approx 2.55$: средняя дисперсия внутри компоненты равна $0.25$, а разброс двух средних вокруг $-5.5$ добавляет $2.5^2$. Для двумерной цели оптимум имеет среднее $(-0.5, -0.5)$. Тот же закон складывает ковариацию $\mathbf I$ внутри компоненты с ковариацией двух средних, которые отстоят от него на $\pm(4.5, 4.5)$ и добавляют $4.5^2 = 20.25$ к каждому элементу:

$$
\boldsymbol\Sigma^\ast = \begin{pmatrix} 21.25 & 20.25 \\ 20.25 & 21.25\end{pmatrix},
$$

то есть это одна вытянутая гауссиана вдоль диагонали через обе моды, самая плотная в пустом промежутке. Её дивергенция равна $1.170$ ната, или $1.688$ бита. Подгонка с Adam (шаг обучения $0.1$, 2000 фиксированных сэмплов, старт с $\mathcal N(\mathbf 0, \mathbf I)$) приходит к этой картине с оценкой $1.669$ бита после 4800 шагов; разница в $0.019$ бита меньше стандартного отклонения оценки по 2000 сэмплам, около $0.023$ бита.

Обратная дивергенция $D_{\mathrm{KL}}(Q\,\|\,P)$ усредняет по сэмплам $Q$. Она наказывает за массу там, где $P$ мало, и не замечает частей $P$, которые $Q$ пропускает, поэтому $Q$ садится на одну моду ([Bishop, 2006](#references), §10.1.2; [Minka, 2005](#references)). Для двух равных, хорошо разделённых мод положение точно на одной из них стоит всего $\ln 2$. Если $Q$ остаётся возле первой компоненты $p_1$, где вторая пренебрежимо мала, то там $p \approx p_1/2$ и

$$
\begin{aligned}
D_{\mathrm{KL}}(Q\,\|\,P) &\approx \mathbb E_Q\Big[\log\frac{q(x)}{p_1(x)/2}\Big] \\
&= \ln 2 + D_{\mathrm{KL}}(Q\,\|\,p_1) .
\end{aligned}
$$

Второе слагаемое равно нулю при $Q = p_1$ и положительно иначе, поэтому лучшая гауссиана — сама мода, со значением $\ln 2$.

### JS тоже не покрывает моды \{#js-does-not-cover-the-modes-either\}

JS никогда не обращается в бесконечность и всё же теряет моду. Для одномерной цели лучшая одиночная гауссиана по симметричной JS, найденная перебором по сетке, сидит точно на одной моде: $0.216$ ната против $0.255$ у гауссианы с сопоставленными моментами. Точно на одной моде, $Q = p_1$, смесь равна $M = \tfrac12(P + Q) = \tfrac34 p_1 + \tfrac14 p_2$. Моды отстоят на десять стандартных отклонений, поэтому там, где у одной компоненты есть масса, другая пренебрежимо мала, и каждое логарифмическое отношение на своей моде постоянно:

$$
\begin{aligned}
D_{\mathrm{KL}}(Q\,\|\,M) &\approx \log_2\tfrac{1}{3/4} = \log_2\tfrac43, \\
D_{\mathrm{KL}}(P\,\|\,M) &\approx \tfrac12\log_2\tfrac{1/2}{3/4} + \tfrac12\log_2\tfrac{1/2}{1/4} \\
&= \tfrac12\log_2\tfrac43 .
\end{aligned}
$$

Их среднее равно

$$
D_{\mathrm{JS}} \approx \tfrac34\log_2\tfrac43 \approx 0.311 \text{ бита}.
$$

Обученные запуски с этим согласуются. Подгонка двумерной смеси с Adam (шаг обучения $0.1$, 5000 шагов, 5000 свежих сэмплов на шаг), начатая с $\boldsymbol\mu = (-2,-2)$, заканчивается около $(-4.99, -5.06)$ с почти единичной ковариацией, на моде в $(-5,-5)$. В одномерном случае обычный градиентный спуск из $\mathcal N(0, 1)$ после 1800 шагов заканчивается в $\mu = -2.995$, $\sigma = 0.495$, на ближней моде; пиковая плотность $Q$ там, $0.81$, вдвое больше пиковой плотности цели, $0.40$. Оба запуска минимизировали взвешенный вариант $0.7\,D_{\mathrm{KL}}(P\,\|\,M) + 0.3\,D_{\mathrm{KL}}(Q\,\|\,M)$. С двумя слагаемыми выше его значение на одной моде равно $(0.7 \cdot \tfrac12 + 0.3)\log_2\tfrac43 = 0.65\log_2\tfrac43 \approx 0.270$ бита. У итоговой одномерной гауссианы ровно это значение, $0.270$ бита при численном интегрировании. Последняя оценка двумерного запуска, $0.2734$ бита, — выборочная, и её стандартное отклонение при 5000 сэмплах около $0.008$ бита, так что она совпадает с $0.270$ с точностью до шума.

Каждая половина JS — математическое ожидание по своему распределению:

$$
\begin{aligned}
D_{\mathrm{JS}}(P\,\|\,Q) &= \tfrac12\,\mathbb E_{x\sim P}\Big[\log\frac{p(x)}{m(x)}\Big] \\
&\quad + \tfrac12\,\mathbb E_{y\sim Q}\Big[\log\frac{q(y)}{m(y)}\Big],
\end{aligned}
$$

где $m = \tfrac12(p + q)$ вычисляется через `logaddexp`. Для оценки нужны сэмплы и из $P$, и из $Q$. Второе слагаемое зависит от параметров $Q$ ещё и через сэмплы $y_j$, поэтому их нужно брать с помощью [трюка репараметризации](/ru/notes/generative-models/gaussian-distributions#the-reparameterization-view) (reparameterization trick), $y = \mu + \sigma\varepsilon$; в запусках выше сэмплы брались без него, так что их градиенты эту зависимость не учитывают.

У ограниченности есть и вторая цена. Когда $Q$ и $P$ почти не перекрываются, JS уже близка к своему максимуму $\ln 2$ и почти не меняется. В начальной $\mathcal N(0, 1)$ она равна $0.645$ ната, $93\%$ от $\ln 2$, а её градиент по $\mu$ равен $0.070$ против $5.5$ у прямой KL. То же насыщение даёт исходному минимаксному GAN затухающие градиенты генератора ([Arjovsky and Bottou, 2017](#references), теорема 2.4; см. [заметку о GAN](/ru/notes/generative-models/gans#step-2-substitute-the-optimal-discriminator-and-recognize-js) и [GAN Вассерштейна](/ru/notes/generative-models/wgan)).

### Функция потерь наименьших квадратов на плотностях чувствительна к масштабу \{#a-least-squares-loss-on-densities-is-sensitive-to-scale\}

Наивная альтернатива — сравнивать значения плотностей напрямую, в сэмплах $x_i \sim P$:

$$
\mathcal L_{\mathrm{LS}} = \frac1N \sum_{i=1}^{N} \bigl(q(x_i) - p(x_i)\bigr)^2 .
$$

Значения плотности зависят от единиц измерения данных. Растяжение каждой координаты в $c$ раз делит все плотности на $c^{d}$ в $d$ измерениях, и функция потерь уменьшается в $c^{2d}$ раз. Постоянный множитель Adam поглощает, но не вторую проблему: когда $Q$ не перекрывается с $P$, в точках данных $q(x_i) \approx 0$, и функция потерь стоит около константы $\mathbb E_P[p(x)^2]$ почти без градиента. У KL нет ни той, ни другой проблемы. Отношение $p/q$ при масштабировании не меняется, а $-\log q(x_i)$ вдали от $\mu$ растёт как $(x_i-\mu)^2/2\sigma^2$, так что притяжение усиливается по мере удаления $Q$.

У функции потерь наименьших квадратов к тому же несколько минимумов. В одномерном случае её глобальный минимум, $0.0470$, — широкая гауссиана с $\sigma \approx 2.53$, близкая к гауссиане с сопоставленными моментами, а гауссиана на одной моде, $\mathcal N(-3.01, 1.21^2)$, — локальный минимум со значением $0.0495$. В двумерном случае гауссиана на одной моде, $\mathcal N\big((4,4), 1.58^2\,\mathbf I\big)$, — локальный минимум со значением $0.00113$, а глобальный, $0.00102$, имеет центр в $(-0.5,-0.5)$ и вытянут вдоль диагонали (стандартное отклонение $6.5$ вдоль неё и $0.43$ поперёк). Подгонка с Adam, начатая с $\mathcal N\big((1,1), \mathbf I\big)$, которая перекрывается только с модой в $(4,4)$, заканчивается на этой моде и шире её; другая мода почти не даёт градиента, потому что там $q \approx 0$.

### Сравнение четырёх функций потерь \{#the-four-losses-side-by-side\}

Для одномерной цели, натуральные логарифмы; у функции потерь наименьших квадратов размерность квадрата плотности.

| Одна гауссиана $Q$ | $D_{\mathrm{KL}}(P\,\Vert\,Q)$ | $D_{\mathrm{KL}}(Q\,\Vert\,P)$ | $D_{\mathrm{JS}}$ | LS |
| --- | --- | --- | --- | --- |
| начальная $\mathcal N(0, 1)$ | $17.88$ | $19.50$ | $0.645$ | $0.0901$ |
| с сопоставленными моментами $\mathcal N(-5.5,\, 6.5)$ | $\mathbf{0.936}$ | $3.709$ | $0.255$ | $\mathbf{0.0470}$ |
| на одной моде $\mathcal N(-3,\, 0.5^2)$ | $24.31$ | $\mathbf{0.693}$ | $\mathbf{0.216}$ | $0.0919$ |
| $\lvert\partial/\partial\mu\rvert$ в начальной $Q$ | $5.5$ | $12.0$ | $0.070$ | $0.0045$ |

Полужирным выделен лучший кандидат для каждой функции потерь; для обеих KL и для JS он же — глобальный оптимум по всем $(\mu, \sigma)$. Прямая KL и наименьшие квадраты (LS) предпочитают широкую гауссиану, обратная KL и JS — одну моду. Последняя строка показывает, насколько сильно каждая функция потерь тянет начальную $Q$: KL — сильно, JS и наименьшие квадраты — почти никак.

Подгонка по прямой KL с Adam (шаг обучения $0.01$, 1000 фиксированных сэмплов) приходит к гауссиане с сопоставленными моментами, $\mu = -5.494$ и $\sigma = 2.566$, с оценкой $1.300$ бита против точных $0.936$ ната, или $1.350$ бита. Разница, $0.050$ бита, в 1.6 раза больше стандартного отклонения оценки по 1000 сэмплам, равного $0.032$ бита.

Семейства курса наследуют эти предпочтения. Потоки и авторегрессионные модели обучаются методом максимального правдоподобия, то есть по прямой KL, и скорее размазывают массу, чем теряют моду. Энкодер VAE подгоняется в обратном направлении и склонен недопокрывать своё апостериорное распределение. Исходный GAN при оптимальном дискриминаторе минимизирует JS, и его сэмплы чёткие, а моды теряются; в GAN поочерёдная оптимизация добавляет ещё и собственный [коллапс мод](/ru/notes/generative-models/gans#mode-collapse-and-how-to-fight-it) (mode collapse).

## Что нужно запомнить \{#what-you-should-remember\}

- Функция потерь — среднее Монте-Карло от $\log p - \log q$ по сэмплам $P$; её градиенту нужно только $\log q$, и это делает её методом максимального правдоподобия.
- Оценка на обучающих сэмплах смещена вниз примерно на $k/(2N)$ ната для $k$ параметров.
- KL конечна, только если у $Q$ есть масса везде, где она есть у $P$, хвосты интегрируемы и обе плотности нормированы.
- Прямая KL покрывает каждую моду и размывает; обратная KL и JS выбирают одну моду и остаются чёткими.
- JS насыщается на уровне $\ln 2$, а наименьшие квадраты зависят от единиц измерения; вдали от данных обе почти не дают градиента.

## Код \{#code\}

Одномерная подгонка из этой заметки на NumPy: вместо автоматического дифференцирования — градиенты из раздела «Чему равны градиенты», затем таблица четырёх функций потерь, посчитанная численным интегрированием. Нужны NumPy и SciPy, код работает несколько секунд.

```python
import numpy as np
from scipy.stats import norm

# целевое P: смесь N(-3, 0.5^2) и N(-8, 0.5^2) с равными весами; половина сэмплов из каждой
rng = np.random.default_rng(0)
x = np.concatenate([rng.normal(-3, 0.5, 500), rng.normal(-8, 0.5, 500)])
log_p = lambda t: np.logaddexp(np.log(0.5) + norm.logpdf(t, -3, 0.5),
                               np.log(0.5) + norm.logpdf(t, -8, 0.5))

# прямая KL на фиксированных сэмплах, обычный градиентный спуск по (mu, log sigma) из Q = N(0, 1)
mu, log_s, lr = 0.0, 0.0, 0.05
for step in range(3000):
    s = np.exp(log_s)
    g_mu = -np.mean(x - mu) / s**2                 # d loss / d mu
    g_log_s = np.mean(1 - (x - mu)**2 / s**2)      # d loss / d log sigma
    mu, log_s = mu - lr * g_mu, log_s - lr * g_log_s
s = np.exp(log_s)
kl = np.mean(log_p(x) - norm.logpdf(x, mu, s))     # функция потерь в натах
print(round(mu, 3), round(s, 3), round(x.mean(), 3), round(x.std(), 3), round(kl, 3))

# четыре функции потерь для трёх гауссиан-кандидатов, численным интегрированием
grid = np.linspace(-40, 30, 400_001)
dx = grid[1] - grid[0]
lp = log_p(grid)
p = np.exp(lp)
def losses(m, s):
    lq = norm.logpdf(grid, m, s)
    q = np.exp(lq)
    lm = np.logaddexp(lp, lq) - np.log(2)          # логарифм смеси M = (P + Q) / 2
    fwd = np.sum(p * (lp - lq)) * dx
    rev = np.sum(q * (lq - lp)) * dx
    js = 0.5 * np.sum(p * (lp - lm)) * dx + 0.5 * np.sum(q * (lq - lm)) * dx
    ls = np.sum(p * (q - p)**2) * dx
    return np.round([fwd, rev, js, ls], 4)
for m, sd in [(0, 1), (-5.5, np.sqrt(6.5)), (-3, 0.5)]:
    print(losses(m, sd))
```

```text
[17.875  19.5     0.6455  0.0901]
[0.9359 3.7091 0.2554 0.047 ]
[24.3069  0.6931  0.2158  0.0919]
```

Градиентный спуск останавливается точно в выборочном среднем и смещённом выборочном стандартном отклонении, то есть в оценке максимального правдоподобия, с оценкой KL $0.961$ ната против точных $0.936$ у гауссианы с сопоставленными моментами.
