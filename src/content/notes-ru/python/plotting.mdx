## Отправная точка: последовательность вызовов pyplot \{#baseline-a-sequence-of-pyplot-calls\}

Самая короткая программа на Matplotlib — последовательность вызовов модуля `pyplot`:

```python
plt.plot([0, 1, 2, 3], [0, 1, 4, 9])
plt.xlabel("x")
plt.ylabel("x squared")
plt.savefig("square.png")
```

Каждый вызов меняет «текущий рисунок»: `plt.plot` создаёт его, если рисунка нет, и рисует на нём линию, `plt.xlabel` подписывает ось x того графика, который сейчас текущий, а `plt.savefig` записывает его в файл. Этот стиль пришёл из MATLAB, которому Matplotlib изначально подражал, и он годится для одного графика, набранного в ноутбуке. Он ломается, как только графиков два: в сетке из четырёх `plt.xlabel` подписывает только тот график, который оказался текущим, то есть последний созданный или затронутый. Состояние глобальное и скрытое, как [глобальное состояние генератора случайных чисел](/ru/notes/python/numpy-arrays#random-numbers) у `np.random.seed`: что делает вызов, зависит от того, что выполнялось до него, в вашем коде или в библиотеке.

## Объект Figure и его Axes \{#the-figure-and-its-axes\}

<aside class="callout"><strong>Ключевая идея.</strong> Рисунок Matplotlib — это дерево объектов, которые называются **художниками** (artists). В корне — объект `Figure`, весь холст. Он содержит один или несколько объектов `Axes`, каждый — область графика со своей системой координат. Объект Axes содержит художников, рисующих данные (`Line2D` для линий, `PathCollection` для точек диаграммы рассеяния, прямоугольники `Rectangle` для столбцов, `AxesImage` для изображений), два объекта `Axis`, которые рисуют деления и их подписи, объекты `Text` для заголовка и `Legend`. Чтобы нарисовать рисунок, **бэкенд** (backend) обходит дерево и отрисовывает каждого художника — в пиксели или в векторные фигуры.</aside>

<FigureTree />

`Axes` (область графика) и `Axis` (одна координатная ось с делениями) — разные объекты с обманчиво похожими именами. Дерево можно изучить напрямую:

```text
>>> fig, ax = plt.subplots()
>>> type(fig).__name__, type(ax).__name__, fig.axes == [ax]
('Figure', 'Axes', True)
>>> lines = ax.plot([0, 1, 2], [0, 1, 4], label="data")
>>> type(lines).__name__, type(lines[0]).__name__, len(ax.lines)
('list', 'Line2D', 1)
>>> title = ax.set_title("squares")
>>> type(ax.xaxis).__name__, type(ax.title).__name__
('XAxis', 'Text')
>>> fig.get_size_inches(), fig.dpi
(array([6.4, 4.8]), 100.0)
```

Построчно: `plt.subplots()` создаёт объект Figure с одним Axes и возвращает оба. `ax.plot` возвращает список добавленных им художников `Line2D`, по одному на линию, и Axes хранит их в `ax.lines`. Заголовок — художник `Text`, ось x — `XAxis`. У каждого художника есть свойства, которые можно менять после рисования: `lines[0].set_color("red")`, `ax.title.set_fontsize(14)`. Размер рисунка задаётся в дюймах, по умолчанию 6.4 на 4.8, а разрешение — в точках на дюйм (dpi); при 100 dpi холст имеет $640 \times 480$ пикселей.

## Объектно-ориентированный API против pyplot \{#the-object-oriented-api-against-pyplot\}

**Правило.** Обращаться к Matplotlib можно двумя способами:

- **функции pyplot** (`plt.plot`, `plt.xlabel`, `plt.title`) действуют на текущий рисунок и текущий объект Axes, которые возвращают `plt.gcf()` и `plt.gca()`;
- **методы** (`ax.plot`, `ax.set_xlabel`, `ax.set_title`) действуют на объект, который вы назвали.

Используйте pyplot, чтобы создавать рисунки (`plt.subplots`) и закрывать их (`plt.close`), а для всего остального — методы. Имена различаются регулярно: функциям pyplot `plt.xlabel(...)`, `plt.title(...)`, `plt.xlim(...)` соответствуют методы `ax.set_xlabel(...)`, `ax.set_title(...)`, `ax.set_xlim(...)`; `ax.set(xlabel=..., title=...)` задаёт несколько свойств сразу.

```text
>>> fig, axs = plt.subplots(2, 2)
>>> axs.shape, plt.gca() is axs[1, 1]
((2, 2), True)
>>> label = plt.xlabel("x")
>>> axs[1, 1].get_xlabel(), axs[0, 0].get_xlabel()
('x', '')
```

`plt.subplots(2, 2)` возвращает объект Figure и массив NumPy $2 \times 2$ из объектов Axes, который индексируется как любой массив. Текущий Axes — последний созданный, `axs[1, 1]`, поэтому `plt.xlabel` подписывает только его. С методами вопроса нет: `axs[0, 0].set_xlabel("x")` подписывает тот график, который вы назвали. Код, который строит рисунки в функциях, циклах или библиотеках, должен принимать аргумент `ax` и рисовать на нём; именно так `df.plot(ax=ax)` из pandas и функции seaborn встраиваются в созданный вами рисунок. Объектно-ориентированный стиль — тот, который [документация Matplotlib рекомендует](#references) для всего, что сложнее беглого взгляда.

## Виды графиков \{#plot-types\}

Каждый метод рисования добавляет художников в Axes и возвращает их.

| Метод | Рисует | Для чего | Возвращает |
| --- | --- | --- | --- |
| `ax.plot(x, y)` | линии через точки | величина, которая меняется непрерывно: кривая, временной ряд, функция потерь по эпохам | список `Line2D` |
| `ax.scatter(x, y)` | по маркеру на точку | связь между двумя переменными | `PathCollection` |
| `ax.hist(x, bins)` | столбцы со счётчиками | распределение одной переменной | счётчики, границы интервалов, `BarContainer` |
| `ax.imshow(A)` | матрицу как изображение | изображения, тепловые карты, матрицы ошибок | `AxesImage` |
| `ax.errorbar(x, y, yerr)` | точки с планками погрешностей | оценки с их неопределённостью | `ErrorbarContainer` |

```text
>>> fig, ax = plt.subplots()
>>> rng = np.random.default_rng(0)
>>> counts, edges, bars = ax.hist(rng.normal(size=1000), bins=5)
>>> counts, edges.round(2)
(array([  9., 124., 496., 330.,  41.]), array([-3.9 , -2.51, -1.11,  0.28,  1.67,  3.07]))
>>> im = ax.imshow(np.arange(6).reshape(2, 3))
>>> type(im).__name__, im.get_array().shape
('AxesImage', (2, 3))
```

`hist` вычисляет гистограмму и рисует её: пять интервалов равной ширины между наименьшим и наибольшим из 1000 сэмплов и счётчики в каждом. Счётчики возвращаются, так что гистограмму можно проверить числами, а не только на глаз. `imshow` рисует матрицу, по одной цветной клетке на элемент; строка 0 по умолчанию наверху, как в изображении, а не внизу, как на графике. Для изображения реальных данных `ax.imshow(A, cmap="viridis")` вместе с `fig.colorbar(im, ax=ax)` добавляет шкалу, которая говорит, что означает каждый цвет.

## Подписи, легенды, шкалы и сетки графиков \{#labels-legends-scales-and-subplots\}

**Подписи.** `ax.set_xlabel` и `ax.set_ylabel` называют величину и её единицу, `ax.set_title` — то, что показывает график. **Легенды.** Дайте каждому ряду данных `label=` и вызовите `ax.legend()`, который соберёт подписанных художников этого Axes. Когда линий всего две или три, текстовая подпись в конце каждой линии, `ax.text(x, y, "train")`, избавляет читателя от путешествия к легенде.

**Шкалы.** `ax.set_yscale("log")` (и `set_xscale`) размещает $y$ на расстоянии, пропорциональном $\log y$. Логарифмическая шкала нужна, когда значения охватывают несколько порядков величины или когда отношения важнее разностей: графики времени в заметках о [NumPy](/ru/notes/python/numpy-arrays#measured-a-loop-against-a-vector) и [pandas](/ru/notes/python/pandas#pitfall-row-loops-are-slow) построены в логарифмическом масштабе по обеим осям, где стоимость, пропорциональная $n$, — прямая с наклоном 1, а постоянное отношение — постоянный вертикальный зазор. Функцию потерь, падающую с 2.3 до 0.01, тоже лучше читать на логарифмической оси; на линейной каждая эпоха после первых нескольких выглядит горизонтальной. Логарифмическая ось не может показать ноль и отрицательные значения.

**Сетки графиков.** `plt.subplots(nrows, ncols, figsize=(w, h), sharex=True, layout="constrained")` создаёт сетку. `sharex` и `sharey` дают графикам одинаковые пределы, и именно это делает их сравнимыми с одного взгляда; `layout="constrained"` сдвигает графики так, чтобы подписи и заголовки не перекрывались. Размер результата в пикселях — размер рисунка в дюймах, умноженный на dpi: `figsize=(4, 3)` при 100 dpi — это $400 \times 300$ пикселей.

## Сохранение рисунков без экрана \{#saving-figures-headless\}

**Бэкенды.** Бэкенд превращает дерево художников в результат. **Интерактивные** бэкенды (`macosx`, `QtAgg`, `TkAgg`) открывают окно и требуют дисплея. **Неинтерактивные** бэкенды пишут файлы: `Agg` отрисовывает PNG с помощью библиотеки Anti-Grain Geometry, а бэкенды `svg` и `pdf` пишут векторные файлы. На сервере, в контейнере или в тесте дисплея нет, поэтому скрипты используют `Agg`: `matplotlib.use("Agg")` до импорта `pyplot` или переменную окружения `MPLBACKEND=Agg`. На этом Mac по умолчанию стоит `macosx`; не найдя дисплея, Matplotlib сам переходит на `Agg`.

**Правило сохранения.** `fig.savefig(path)` выбирает формат по расширению файла:

- **PNG** — растровый формат: сетка пикселей, $\text{inches} \times \text{dpi}$ по каждой стороне. Его размер зависит от числа пикселей и от того, насколько хорошо они сжимаются, а не от того, сколько точек нарисовано. При увеличении он размывается. Для печати передавайте `dpi=200` или больше.
- **SVG** и **PDF** — векторные форматы: они хранят каждую линию, маркер и глиф как фигуру, поэтому остаются чёткими при любом увеличении, а их текст доступен для поиска. Их размер растёт с числом нарисованных элементов.

<FileSize />

Рисунок это измеряет: диаграмма рассеяния из $n$ точек, $4 \times 3$ дюйма при 100 dpi, сохранённая в каждом формате. PNG при любом $n$ не превышает примерно 20 КБ; SVG растёт примерно на 106 байт на точку, а PDF — примерно на 15, так что при 100 000 точек SVG занимает 10.6 МБ. Используйте векторный формат для линейных графиков и схем с немногими элементами, PNG — для изображений и графиков с многими тысячами точек (или `rasterized=True` для плотного художника, что встраивает его как пиксели внутрь векторного файла).

**Типичная ошибка.** pyplot хранит каждый созданный им рисунок в реестре, пока не вызван `plt.close`, поэтому цикл, который на каждой итерации создаёт рисунок и только сохраняет его, держит их все в памяти:

```text
>>> plt.close("all")
>>> for k in range(21):
...     fig = plt.figure()
...
<python-input-1>:2: RuntimeWarning: More than 20 figures have been opened. Figures created through the pyplot interface (`matplotlib.pyplot.figure`) are retained until explicitly closed and may consume too much memory. (To control this warning, see the rcParam `figure.max_open_warning`). Consider using `matplotlib.pyplot.close()`.
>>> len(plt.get_fignums())
21
>>> plt.close("all")
>>> len(plt.get_fignums())
0
```

Вызывайте `plt.close(fig)` после `savefig` в любом цикле. Другой вариант — `matplotlib.figure.Figure()` создаёт рисунок вне реестра pyplot, и он освобождается, как любой объект Python, когда исчезает последняя ссылка ([как CPython выполняет код](/ru/notes/python/how-cpython-runs-code)).

## Список проверок для ясного рисунка \{#a-checklist-for-a-clear-figure\}

Рисунок — это аргумент. Эти правила следуют из того, что читателю нужно сделать, чтобы извлечь из него аргумент ([Rougier, Droettboom and Bourne, 2014](#references)):

1. **Одно сообщение.** Решите, что должен показать рисунок, до того как его рисовать, и запишите это как заголовок или первое предложение подписи. Всё остальное служит этому сообщению.
2. **Подписывайте оси величиной и её единицей.** «время (мс)», а не «t». Читатель, который видит только рисунок, должен знать, что на нём изображено.
3. **Выбирайте шкалу под вопрос.** Линейная — для разностей, логарифмическая — для отношений и для данных, охватывающих порядки величины. Ось столбчатой диаграммы начинайте с нуля, потому что длина столбца и есть значение.
4. **Облегчайте сравнение.** Помещайте сравниваемое на один Axes или на соседние графики с общими осями, рядом вдоль той оси, по которой идёт сравнение.
5. **Подписывайте напрямую, когда можно,** текстом рядом с каждой линией; иначе используйте легенду в месте, где она не закрывает данные.
6. **Используйте цвет со смыслом,** единообразно во всех рисунках и из палитры, безопасной для дальтоников; стандартный цикл цветов Matplotlib и `viridis` подходят. Никогда не делайте цвет единственным способом различить два ряда на рисунке, который могут напечатать в оттенках серого: меняйте также маркер или стиль линии.
7. **Показывайте неопределённость и говорите, что это такое.** Планка погрешности может быть стандартным отклонением, стандартной ошибкой или 95%-ным доверительным интервалом; они различаются в разы, и подпись должна сказать, что именно показано ([доверительные интервалы](/ru/notes/probability/confidence-intervals-and-bootstrap)).
8. **Подбирайте текст под итоговый размер.** Делайте рисунок того размера, в котором его покажут (`figsize` в дюймах), чтобы шрифт читался без увеличения; рисунок, уменьшенный до ширины колонки, уменьшает вместе с собой и текст.
9. **Делайте его воспроизводимым.** Рисуйте его скриптом с фиксированным начальным значением генератора и сохраняйте через `savefig`, а не снимком экрана. Код, который делает рисунок, — часть результата.

## Курс в одном абзаце \{#the-course-in-one-paragraph\}

Программа на Python — это последовательность инструкций, которую интерпретатор компилирует в байт-код и выполняет, а её данные — объекты, на которые ссылаются имена: присваивание связывает имя и ничего не копирует (**Первые шаги**). Встроенные контейнеры — это такие объекты, устроенные ради определённой стоимости операций: динамический массив для списков и хеш-таблица для словарей и множеств, а каждый цикл `for` выполняет протокол итератора над одним из них (**Структуры данных**). Классы позволяют новым объектам участвовать в тех же протоколах через специальные методы, а замыкания, декораторы, модули и аннотации типов организуют код так, чтобы его можно было читать и использовать повторно (**Абстракции**). Тесты и профилировщики говорят, верен ли код и куда уходит его время (**Надёжный код**). Под этим всем CPython выполняет байт-код на стеке значений, освобождает объекты подсчётом ссылок и выполняет одновременно только один поток Python, если он не собран без GIL, и это определяет, что медленно и что может выполняться параллельно (**Как это устроено**). Научный стек отвечает на эту стоимость: массив NumPy выносит цикл по числам из интерпретатора в скомпилированный код над сырой памятью, pandas собирает именованные столбцы таких массивов в таблицу, а Matplotlib превращает массивы в рисунки (**Научный Python**). Это инструменты, которыми считают следующие курсы. [Курс математики](/ru/notes/math/vectors-and-linear-maps) даёт векторы и матрицы, которые хранит NumPy, [курс теории вероятностей](/ru/notes/probability/what-probability-is) — случайные величины, сэмплы которых выдаёт `default_rng`, а [курс машинного обучения](/ru/notes/ml/what-machine-learning-is) использует все три в запускаемом скрипте в конце каждой заметки. Что выполняется ниже интерпретатора, разбирает [курс по архитектуре компьютера и операционным системам](/ru/notes/acos/computer-systems), который спускается до процессора.

## Что изменилось \{#what-changed\}

| | Вызовы pyplot (отправная точка) | Объектно-ориентированный API |
| --- | --- | --- |
| На что действует вызов | текущий рисунок и Axes, глобальное состояние | объект, который вы назвали |
| Несколько графиков | каждый вызов действует на последний затронутый | `axs[i, j].method(...)` на каждом |
| Внутри функций и библиотек | зависит от того, что выполнялось раньше | `ax` передаётся явно |
| Изменение графика после рисования | найти его через `plt.gca()` | сохранить возвращённых художников и задать их свойства |
| Память | рисунки хранятся в реестре pyplot до `plt.close` | то же для `plt.subplots`; `Figure()` освобождается, как любой объект |

## Ограничения \{#limitations\}

- **Статичные рисунки.** Matplotlib делает изображения и документы. Интерактивные рисунки в браузере, с масштабированием и подсказками при наведении, — область других библиотек (Plotly, Bokeh), а статистические графики с меньшим количеством кода — область seaborn, построенного на Matplotlib; ни то ни другое здесь не рассматривается.
- **Детали версии.** Размер рисунка по умолчанию, dpi и цикл цветов — те, что в Matplotlib 3.11; их можно изменить в `matplotlib.rcParams` или в файле стиля. Размеры файлов зависят от версии, установленных шрифтов и данных, поэтому измерения выше указывают свои условия.
- **Этот сайт рисует свои рисунки сам.** Рисунки в этих заметках — SVG, которые сайт строит по формулам и измеренным числам, а не вывод Matplotlib; список проверок выше относится к обоим.

## Что нужно запомнить \{#what-you-should-remember\}

- Рисунок — дерево художников: объект `Figure` содержит объекты `Axes`, а каждый Axes — нарисованные в нём линии, точки, столбцы, изображения, оси и текст.
- Создавайте рисунки через `fig, ax = plt.subplots(...)` и вызывайте методы `ax`; функции pyplot действуют на то, что сейчас текущее.
- `plot` — для кривых, `scatter` — для связей, `hist` — для распределений, `imshow` — для матриц, `errorbar` — для оценок с неопределённостью. Каждый возвращает нарисованных художников.
- Подписывайте каждую ось её величиной и единицей; используйте логарифмическую шкалу для данных, охватывающих порядки величины; делайте оси общими у графиков, которые сравнивают.
- На машинах без дисплея используйте бэкенд `Agg`. PNG — для изображений и плотных графиков, SVG или PDF — для штриховой графики. Закрывайте рисунки, созданные в цикле.
- У рисунка одно сообщение, он говорит, что означают его планки погрешностей, и рисуется скриптом.

## Код \{#code\}

Скрипт рисует рисунок $2 \times 2$, в котором есть каждый вид графика из заметки, на синтетических данных с фиксированным начальным значением: две кривые функции потерь в логарифмическом масштабе, диаграмма рассеяния с прямой наименьших квадратов, гистограмма и изображение функции на сетке, а на диаграмме рассеяния — планки погрешностей. Он сохраняет рисунок в PNG, SVG и PDF во временный каталог, который в конце удаляется, печатает размер каждого файла, проверяет размер PNG в пикселях и убеждается, что открытых рисунков не осталось. Запуск: `python -I figure.py`; нужны Matplotlib и NumPy, окно не открывается. Размеры файлов зависят от версии Matplotlib и установленных шрифтов.

```python
"""A figure built with Matplotlib's object-oriented API and saved headless (Python 3.14, Matplotlib 3.x)."""
import pathlib
import tempfile

import matplotlib
matplotlib.use("Agg")                      # дисплей не нужен; вызывать до импорта pyplot
import matplotlib.image as mpimg
import matplotlib.pyplot as plt
import numpy as np

print("matplotlib", matplotlib.__version__, "backend", matplotlib.get_backend())
rng = np.random.default_rng(0)

fig, axs = plt.subplots(2, 2, figsize=(8, 6), layout="constrained")
print(type(axs).__name__, axs.shape)

# 1. Линии в логарифмическом масштабе: две кривые функции потерь, падающие в постоянное число раз за эпоху
epochs = np.arange(1, 51)
train = 2.3 * 0.9 ** epochs + 0.01
val = 2.3 * 0.93 ** epochs + 0.05
ax = axs[0, 0]
ax.plot(epochs, train, label="train")
ax.plot(epochs, val, label="validation", linestyle="--")
ax.set(xlabel="epoch", ylabel="loss", yscale="log", title="Loss per epoch")
ax.legend()

# 2. Диаграмма рассеяния с прямой наименьших квадратов и планками погрешностей у средних по интервалам
x = rng.uniform(0, 10, 200)
y = 1.5 * x + 2 + rng.normal(0, 2, 200)
slope, intercept = np.polyfit(x, y, 1)
bins = np.digitize(x, [2, 4, 6, 8])
centers = np.array([x[bins == b].mean() for b in range(5)])
means = np.array([y[bins == b].mean() for b in range(5)])
sems = np.array([y[bins == b].std(ddof=1) / np.sqrt((bins == b).sum()) for b in range(5)])
ax = axs[0, 1]
ax.scatter(x, y, s=8, alpha=0.5, label="data")
ax.plot([0, 10], [intercept, intercept + 10 * slope], color="black", label=f"fit: {slope:.2f}x + {intercept:.2f}")
ax.errorbar(centers, means, yerr=sems, fmt="o", color="red", capsize=3, label="bin mean ± s.e.")
ax.set(xlabel="x", ylabel="y", title="Relation")
ax.legend(fontsize=8)

# 3. Гистограмма: счётчики возвращаются, поэтому их можно проверить
ax = axs[1, 0]
counts, edges, _ = ax.hist(rng.normal(size=1000), bins=20)
ax.set(xlabel="value", ylabel="count", title="Distribution")
print("histogram:", int(counts.sum()), "samples in", len(counts), "bins; tallest bin", int(counts.max()))

# 4. Изображение функции на сетке с цветовой шкалой
g = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(g, g)
im = axs[1, 1].imshow(np.exp(-(X ** 2 + Y ** 2) / 2), extent=(-3, 3, -3, 3), origin="lower", cmap="viridis")
fig.colorbar(im, ax=axs[1, 1], label="density")
axs[1, 1].set(xlabel="x", ylabel="y", title="Image")

print("fit:", round(slope, 3), round(intercept, 3))
print("artists in the top-left Axes:", len(axs[0, 0].lines), "lines;", "y scale", axs[0, 0].get_yscale())

# 5. Сохранение в трёх форматах во временный каталог, который затем удаляется
with tempfile.TemporaryDirectory() as tmp:
    for fmt in ("png", "svg", "pdf"):
        path = pathlib.Path(tmp) / f"figure.{fmt}"
        fig.savefig(path, dpi=100)
        print(f"{fmt}: {path.stat().st_size:,} bytes, starts with {path.read_bytes()[:4]!r}")
    pixels = mpimg.imread(pathlib.Path(tmp) / "figure.png")
    print("png pixels (height, width, channels):", pixels.shape)

plt.close(fig)
print("open figures:", len(plt.get_fignums()))

# Вывод на CPython 3.14.7, Matplotlib 3.11.2 и NumPy 2.5.4 на macOS (arm64); размеры файлов могут отличаться:
# matplotlib 3.11.2 backend Agg
# ndarray (2, 2)
# histogram: 1000 samples in 20 bins; tallest bin 136
# fit: 1.449 2.094
# artists in the top-left Axes: 2 lines; y scale log
# png: 91,260 bytes, starts with b'\x89PNG'
# svg: 138,450 bytes, starts with b'<?xm'
# pdf: 53,718 bytes, starts with b'%PDF'
# png pixels (height, width, channels): (600, 800, 4)
# open figures: 0
```

PNG имеет $800 \times 600$ пикселей: `figsize=(8, 6)`, умноженный на 100 dpi, и четыре канала (красный, зелёный, синий и непрозрачность). Подобранные наклон и свободный член, 1.449 и 2.094, с точностью до шума восстанавливают 1.5 и 2, использованные при генерации данных. Первые четыре байта определяют каждый формат: сигнатура PNG, XML-объявление, с которого начинается SVG, и заголовок PDF.
